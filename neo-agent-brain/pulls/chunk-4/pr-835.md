Resolves #823

The installed Fleet's open-work producer no longer depends on a token in the process environment. Each GitHub seat's open work is read with that seat's own PAT, resolved from the Fleet's credential store through the registry's `resolveCredential`, as ADR 0038 §2.5.1 row 7 decides. That work is the PRs the seat authored, the ones it holds a review request on, and its authored PRs that closed in its terminal window. One seat's PAT never reads another seat's work, and the rows merge by PR key, so the reducer is unchanged. If a seat has no readable PAT, or its read fails, the pulse is `partial`, names that seat with its next step (never "set GH_TOKEN"), and keeps carrying the seat's rows. A `GH_TOKEN`-class token in the environment remains only as the explicit headless or dev override that every seat then reads with.
