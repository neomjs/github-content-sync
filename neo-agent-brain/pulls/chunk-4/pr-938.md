Resolves #937

🌿 *A fresh seat no longer opens its first session on skill paths that lead nowhere, and a leftover `node_modules` can no longer call itself prepared.*

A Fleet Start now installs every seat checkout's locked dependencies after identity convergence and before workspace preparation, so the first session finds its skills. The new `installAgentRepoDependencies.mjs` has three parts:
- **`installAgentRepoDependencies`** decides per checkout: `installed`, `present`, `unverified`, `not-applicable` or `failed`. A tree the Fleet did not install is never touched. A tree whose owned install never finished installs again, per the seat-folder receipt `.neo-fleet-seat-dependencies.json`.
- **`resolveLoginShellNpm`** takes `npm` and its `PATH` from the operator's login shell, because the Fleet's GUI `PATH` has none. Only six plain variables cross into the shell and `npm`.
- **`runToExit`** runs `npm` as its own process group. A stop signals the whole group and answers only once none of it is left, so a Stop cancels the Start with nothing prepared or spawned, and no lifecycle script still writing.

The rows ride the Start status and the seat's lifecycle status (`setPendingDependencies` → `dependencies` → cockpit `dependencyOutcomes`). They are live while the attempt is pending, and its final rows once it ends, launched or not. No row reads `installing` after the end, and a finished attempt's late report is refused. A Skip, separate from Stop, drains `npm` and the launch goes on (`skipped`). The rows a Stop interrupts read `canceled`. **The Skip signal is groundwork:** nothing an operator can reach fires it until the verb ships (a bridge method plus a lifecycle call, a Brain leaf after this one). The design read's three contracts are in: a Stop cancels, a directory is not a receipt, and the skip control and peer readiness belong to neomjs/neo-agent-institution#610.

Evidence: L3 (the real installer, run under an FM-shaped environment, resolved the real login shell's `npm` and ran a real `npm ci` into a temp clone) → L4 required (an installed Fleet Start of a fresh seat) for AC-9. Residual: AC-9, Residual-Owner: #571.

Prescription checked: `ai/services/fleet/startAgentProvisioned.mjs`, which owns the concern. The Start composes clone → identity → preparation → spawn, and the install sits between identity and preparation, beside `ensureAgentRepo`. No AiConfig touch.
