Resolves #800

A `Residual-Owner:` may now name another repository: `neomjs/neo-agent-institution#12` parses as well as `#12`, in both the section and the inline form.
- The owner travels as `{repo, number}`; the close-target rule compares both, and the state read goes to the named repository.
- An owner that spells out this repository is still this repository's. The repository is read offline from the `origin` remote, in every clone form GitHub documents, so naming your own repo can't slip the close-target rule.
- An owner is foreign only when this repository is known. An unreadable origin keeps the guard.
- Owner tokens and `--pr-repo` share one `owner/repo` grammar.

Evidence: L2 (unit arms, red-first plus one mutation per new guard) → L2 required (AC-1–AC-5). Residual: none.

## Deltas from ticket

- **`resolveCurrentRepo`** (new, offline `git remote get-url origin`). Without it, `neomjs/neo-agent-brain#<close target>` would read as another repository's ticket and pass.
- **`--pr-repo <owner/repo>`** (Fix 5 / AC-5, from @neo-opus-ada's defect-note on Institution #483). This tool lives in the Brain, so an Institution PR body is linted from a Brain clone. Its `#N` owner and its close target's AC read now go to the PR's repository.
  - The git gates (the stacked-commit audit) still read the checkout, and the option's help says so.
- **@neo-gpt's review precheck at ff970a4, folded in e33bda4 and ae05145:**
  1. The SSH-over-443 origin (`ssh://git@ssh.github.com:443/…`) read as no repository, and an unknown repository then proved a same-number spelled-out owner foreign.
     - Every documented clone form now parses.
     - The authority is parsed, not matched as a substring: the host is exactly `github.com`, or `ssh.github.com` over `ssh:`, and the path is exactly `owner/repo`. So `evilgithub.com`, `evil.github.com` and `example.org/github.com/…` all read as no repository (the ae05145 remainder).
     - Unknown context names the possible close target and points to `--pr-repo`.
  2. `--pr-repo` and owner tokens admitted queries, fragments, extra and dot segments, and partial numbers (`#12XYZ`).
     - Both now read through one coordinate grammar, and an invalid `--pr-repo` is refused before any read.
- **Archaeology in the whole changed files.** CI's `source-comment-archaeology` job scans every changed `.mjs` file, not just the diff. Nine pre-existing refs in `agent-preflight.mjs` and the spec had to go:
  - syntax examples now read `#N`;
  - the two retired `ticket-ref-ok:` escapes keep their reasons without the numbers.
