Resolves #923

Claude Desktop launches now carry an explicitly declared reasoning effort through `CLAUDE_CODE_EFFORT_LEVEL`. The shared harness catalog exposes per-field support, accepting Desktop effort while refusing Desktop model declarations. The existing paired resolver still returns `null` for Desktop, so older consumers do not accidentally offer both fields. No declaration means no Fleet effort override.
