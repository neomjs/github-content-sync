Resolves #822

Every roster card read "no lane claimed" on row 4's installed walk ([neomjs/neo-agent-institution#414](https://github.com/neomjs/neo-agent-institution/issues/414#issuecomment-5971533618)). There were two independent losses, and this PR fixes both in the shape Clio's stage-2 read set.

1. **Typed.** A `list_messages` summary now carries the sender's declared `taggedConcepts`. The field is additive, and a retracted row drops it. The classifier already preferred concepts, but the summary never carried them. For claims that declare none, the subject fallback now reads a claim behind a signature mark (`⚖️ [lane-claim] …`) and inside a combined bracket (`🪢 [lane-claim + PR-open · DRAFT] …`). It also splits announcements only outside brackets. A tag in prose stays a mention, and so does `[lane-claim released]`.
2. **Kept.** The activity composer keeps each seat's newest claim or release (`claim-corrected`). It folds them forward from every admitted first page for its viewer and saves them in `lane-claims.json` beside the registry, for the mailbox source and viewer they were read from. A record from another plane or viewer is not shown, and a saved record this process cannot read is never overwritten. The cockpit fold reads that record. A claim now leaves the card only when its seat replaces or releases it, and it survives a Fleet restart. No mailbox read moves into `fleetRoster()`, per Brain #740's decision.

Evidence: L2 (unit arms over the walk's real subjects, plus the real adapter → composer → fold chain) → L3 required for AC-5 (row 4's installed walk step 1 on the next cut). Residual: AC5, Residual-Owner: neomjs/neo-agent-institution#490
