Resolves #916

🌿 The Activity feed can no longer call itself partial on behalf of a seat the operator benched.

The open-work readers now take each seat's participation from the Fleet's presence read, the same `readPresence` the roster and the wake routes use. A seat whose identity node reads `operator_benched` is still read when its PAT works. A read it misses no longer counts toward coverage or appears in the reason, though the pulse record still names it. The reducer keeps the rows a missed seat could have read (the PRs it authored, and the ones where it has a review request) through reads that are otherwise complete. A row first seen after that miss is not counted as `opened`. Unknown participation, an unanswered presence read and a dark seat all still count toward coverage.

Evidence: L2 (unit tests over the reducer, the producer and the readers, with injected presence and GitHub reads) → L3 required for the installed Activity feed reading complete while Preview is benched. Residual: that installed reading, Residual-Owner: neomjs/neo-agent-institution#12.

## Deltas from ticket
- Participation is read through the Fleet's presence read, not `ai/graph/agentIdentityParticipation.mjs`. A plane-mode Fleet must not open the host graph, and that presence read already reaches the identity node in both modes.
- A benched seat is still read when its PAT works, so its rows stay fresh and its merges are still seen. Only its misses stop counting.
- `opened` is now decided per seat. Previously, any missed read suppressed every `opened`. Leaving benched misses out of `complete` without this change would turn a recovered PAT's old PRs into false openings. The snapshot carries `missed` for this.
- Bound: if a missed benched seat has a review request on a row, or might have one because the row's request list continues past its first page (review RA-1), the row is kept even after its author's complete read stops showing it. It keeps its old `observedAt` until that seat reads again or leaves the registry. For the same reason, such a row is never counted as `opened` right after the miss.
