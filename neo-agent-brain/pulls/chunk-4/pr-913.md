Resolves #912

An Engine checkout is `neo.mjs` and carries no `node_modules/neo.mjs`. Seat hydration nonetheless rewrote its Claude hook commands into that path, so every Engine seat's `PreToolUse` rg-replace guard pointed at a file that cannot exist. Node exited 1 without blocking, and `rg --replace` ran unguarded. Now `initClaudeSettings` reads the target's package name from `claudeDir`'s parent, and `retargetClaudeHookCommands` leaves the commands as authored when the target is the Engine. Consumer checkouts keep the retarget. An existing Engine seat is rewired on its next hydration, because `mergeClaudeHooks` lets the template's `PreToolUse` replace the dead one.

Evidence: L2 (unit, against temp repository roots with a declared package name) → L4 required (Post-Merge Validation: an FM-hydrated Engine seat runs the guard). Residual: the installed check, Residual-Owner: #571.
