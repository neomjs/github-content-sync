Resolves #873

The built-in GitHub Workflow MCP client now launches npm from the package that owns its server script, including when the CLI is invoked from the Engine checkout. It shares Neural Link's module-derived root; that root now validates both owned scripts. Explicit connection configurations retain their cwd, argv and environment.

Change class: restoration.

Evidence: L3 (read-only GitHub Workflow CLI call from a foreign checkout, plus isolated transport tests) → L3 required (AC-4 process launch). Residual: none.
