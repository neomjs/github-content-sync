Resolves #968

🌿 The plane's health can no longer call a daily restorable bundle a two-month failure: the laptop says, in its own profile, that no off-host copy is required.

`deploymentMode` is `cloud` on the Docker plane by design, so a null `offHostBackupRequired` resolves to required; with no sync command configured, `runBackupWithOffHostSync` threw its refusal after the success receipt and the lane was marked failed on every run since 2026-08-04 (`lastExitCode 1`, `lastSuccessAt null`) while the bundles passed integrity daily. The local overlay now declares the documented local default (`NEO_ORCHESTRATOR_OFF_HOST_BACKUP_REQUIRED: "false"`), and the scorer's comment names the exit-code fold as the producer of `backup-state-conflict` instead of a receipt writer bypassing the ledger. Three decayed ticket refs in the touched comments became prose.

Evidence: L2 (overlay renders the key for the orchestrator through the real compose stack; scheduler spec 41/41; preflight all gates passed) → L4 required for AC-3 (the next daily run on a cut plane). Residual: AC-3, AC-4, Residual-Owner: #969.
