Resolves #825

The Fleet now serves the memory an added seat could import. `fleetMemoryCandidates` is a read-observe wire method, answered on the host that holds the seats. Each candidate is `{family, source, name, notes, lastChanged}`. The name derives from the folder, never the path, and no file's contents cross the wire.

This is the Brain control op for #571 gap 2 (planner disposition [5972558630](https://github.com/neomjs/neo-agent-brain/issues/571#issuecomment-5972558630)). neomjs/neo-agent-institution#521 consumes it in the Add Agent frame.

Evidence: L1 unit, on real temp folders → L1 required (all four ACs are unit).
