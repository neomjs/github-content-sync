Resolves #896

🌿 Once declared, the operator's one PAT is no longer an alias at `/fleet`.

The relay can now present the operator's one PAT to the plane's fleet surface, as the operator ruled on 2026-10-06 (neomjs/neo-agent-institution#571, option d). The ledger text is in neomjs/neo#19424. A new leaf, `fleet.planeBearerClass` (`NEO_FLEET_PLANE_BEARER_CLASS`), carries the plane bearer's class as the plane's own admission verdict names it. When that class is `github-pat` or `gitlab-pat` and no admission bearer is declared, `resolveFleetPlaneAdmissionBearer` answers the plane bearer, and `assertFleetPlaneAdmissionBearerClass` accepts the equal bytes. Equal bytes alone still declare nothing: an undeclared or non-forge class still refuses, and so does the bootstrap token, whatever the class. The shell exports the class from `/fleet/probe`'s `identity.authSource` (Ada, neomjs/neo-agent-institution#571).

Evidence: L2 (unit, plus the composed `/fleet/events` admission chain with a doubled auth) → L2 required (AC-1 to AC-5 are unit ACs). Plane-first Add on an installed shell is not this PR's: it stays with neomjs/neo-agent-institution#571 and neomjs/neo-agent-institution#12 (Post-Merge Validation below).
