<h2>1.32.0</h2>
<h2>Upgrade notes</h2>
<ul>
<li><strong>Redirects:</strong> the HTTP client transports now follow a redirect only when it stays on the same origin (same scheme, host and port; http to https on the same host is allowed). A deployment whose endpoint redirects to another host or port either configures the final URL or sets <code>redirectPolicy: 'follow'</code> on <code>StreamableHTTPClientTransport</code> or <code>SSEClientTransport</code>. In browsers, a redirected request fails unless that option is set.</li>
<li><strong>New options, both off unless you set them:</strong> <code>maxToolInputElements</code> on <code>McpServer</code> limits the number of array elements and object members in a tool call's arguments. <code>expectedResource</code> on <code>requireBearerAuth</code> accepts only tokens issued for this server (the token's audience).</li>
</ul>
