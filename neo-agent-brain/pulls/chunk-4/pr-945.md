Resolves #944

The Claude seat guard now watches only the ways into an artifact. `add_memory` and `add_message` leave its `PreToolUse` matcher, because Memory Core may store harness ids (operator ruling, quoted on #944). `decideHarnessIdGuard` masks the session's own temp root, `…/claude-<uid>/<project-key>/<session-id>`, in `Bash`'s `command` and in `Write`/`Edit`'s `file_path` before the match, so writing to the scratchpad and reading task output are no longer refused. File content and every GitHub tool input are still matched whole. The refusal now points at the alias remedy: omit `add_memory`'s `sessionId` and stamp the id it echoes.

Evidence: L2 (unit: decision function incl. temp-root masking, entrypoint subprocess, manifest matcher tested unanchored) → L4 required (AC-5: a Fleet-launched seat after re-projection). Residual: AC-5, Residual-Owner: #571.
