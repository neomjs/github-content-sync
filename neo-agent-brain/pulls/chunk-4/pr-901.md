Resolves #900

A seat folder copied to another agents root now starts there. `relocateSeatHome` records the home a move left as `previousSeatHome`, and Start passes that home's root to `prepareManagedAgentWorkspace`. There, each Fleet-owned file still exactly as Fleet rendered it at the old home moves to the new one: the Claude memory pin, the Codex trust block, and the Kimi and OpenCode generated files. The generated files move line by line, and the result must match the current rendering's owned projection. Anything else still refuses, as before. `moveSeatHomes` is the shell's one-shot move. It classifies every row first, copies each materialized home into a staging folder, proves the copy identical, publishes it, and then relocates the binding with its exact `from`.

Evidence: L2 (unit specs on real temp folders, the real registry, and the real workspace preparation) → L2 required (AC-1 to AC-5 name units). Residual: the installed move of the one materialized seat (Sophie's) runs through neomjs/neo-agent-institution#573; Residual-Owner: #571.
