Resolves #792

The Fleet gains one read verb, `fleetRecentTurns`: one page of a seat's newest public turn summaries for the authenticated viewer, over the Memory Core's policy-aware recency read (#741). `fleetRecentTurnsSource.mjs` follows the session-memories sibling: it asks the injected `query_recent_turns` operation for `{agentIdentity, memorySharing: 'team', detail: 'summary', limit, before}` and passes the rows, the next cursor and the plane's `memorySharing` verdict through a fail-honest envelope. The operation returns two of its outcomes as payloads, an error object and a page marked with a fail-closed scope; the source classifies both before it accepts rows, as a failed read with the redacted detail and as a refusal with its own reason. Nothing a client chooses reaches the operation beside the target and the page. The bridge verb, both policy rows (`awaiting-s5`, `read-observe`), the wire vocabulary and the dev fleet server's wiring carry it. It is the producer of the Agent Detail's Thought stream pane (neomjs/neo-agent-institution#476).

Evidence: L2 (the source over an injected operation, and over the Memory Core's real method for its returned outcomes; the wiring and the bridge verb over the real bridge class) → L2 required (AC-1 to AC-4). No residuals: the plane-side witness moved to neomjs/neo-agent-institution#476 before this PR opened, because the plane's containerized fleet server answers this verb `awaiting-s5`.
