## Deltas from ticket
The additive envelope is `a2a: {observation, page, continuation}`. Observation and page fields come from the canonical mailbox response. `continuation` is null at exhaustion or `{slots: ['a2a'], offset}`; when mixed display bounding omits mailbox events it points to the current source page, otherwise to canonical `page.nextOffset`. Consumers follow continuation, not a mixed feed's retained-row count. Omitted observer preserves existing polling and retention.
