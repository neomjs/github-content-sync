Resolves #870

A seat defined while `credentials.enc` cannot be read is now refused before anything is written. Before this change, `defineAgent` took its write snapshot from the lenient read, which answers an empty map for a store it cannot decrypt, and published a one-entry map over every other seat's PAT. Writers now take `readCredentialsForMutation()`, the strict read `FleetTenantService` already has: a missing store is empty, and one that cannot be read or holds no record throws and stays byte-identical. Reads keep their fail-closed empty answer.

Evidence: L2 (unit: real temp stores; the wire answer through `FleetControlBridge` over the real registry) → L2 required (AC-1 to AC-3 are the registry's own write and read paths). Residual: none.

## AC Evidence
| AC-1 | `FleetRegistryService.spec.mjs` "defineAgent over a store that does not decrypt refuses before anything is written, so the other PATs survive" and its "holds no record" twin: the refusal, the store's bytes, the registry rows, and `storeCredential` writing nothing either; `FleetControlBridge.spec.mjs` "defineAgent over a credential store the registry cannot read answers a rejection that names the remedy and no path" |
| AC-2 | `FleetRegistryService.spec.mjs` "a missing store takes the first define, and a readable store keeps every other PAT" |
| AC-3 | `FleetRegistryService.spec.mjs` "a read over a store it cannot read still fails closed, and removing a seat writes nothing to it" |

## Deltas from ticket
- `removeCredential` keeps the lenient read, as The Fix says: over an unreadable store the id is absent, so it writes nothing. The AC-3 arm pins that.
- No shared encrypted-record module: both services keep their own read, now the same shape. A shared primitive would move both services' encrypt/decrypt and key handling, which is a refactor beyond this defect.

## Test Evidence
- Diagonal: with the source change stashed, the three AC-1 tests fail (a define over each unreadable store succeeds, and the wire answers no rejection), while the AC-2 and AC-3 guards pass on both sides.
- All other coverage runs in CI.

## Post-Merge Validation
