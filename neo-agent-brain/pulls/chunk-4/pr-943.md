Resolves #942

🌿 *A slow first install no longer leaves the operator a choice between waiting it out and canceling the Start: Skip ends the install, and the seat launches.*

The Fleet now carries the operator's Skip to a pending Start's dependency install. Each pending Start in `FleetLifecycleService` owns two fences: Stop's, as before, and a Skip fence that `FleetManager.startAgent` hands to the provisioning composer as `dependencySkipSignal`, the seam #938 left unfired. The new wire verb `skipAgentDependencies` (`FLEET_WIRE_METHODS`, both policy ledgers as `stopAgent`, `FleetControlBridge`, `FleetManager`) aborts the Skip fence of every pending Start of the seat and answers `{id, skippedStarts}`. The interrupted checkouts read `skipped`, finished ones keep their outcome, and the Start launches. A Stop still wins.

Evidence: L2 (unit: the verb dispatched through the real wire and bridge into a manager Start that runs the real `installSeatDependencies` behind an injected install) → L4 required (a Skip from the installed Agent Detail) for AC-5. Residual: AC-5, Residual-Owner: neomjs/neo-agent-institution#616.
