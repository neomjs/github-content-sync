Resolves #812

ADR 0041 now says what a receipt is proof of. §2 item 6: a receipt proves the input it recorded — the content it wrote, the set it completed, the composition it started from — and that input only; when the consents render a different input the effect is `pending` again, and its next run is a new application, never a replay. §2 item 7: a change of consent retires nothing wholesale; only the effects whose input it touches read `pending` again. §3 gains the consent arm every implementing leaf inherits, and the Status row names the amendment. This is the authority the implementation of the input-keyed guard waits on (ADR 0005 §6.5).
