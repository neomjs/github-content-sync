Resolves #819

🌿 A computed route can no longer name its producer and stay silent about the pass that made it.

The pass mints one run id before its first read (`randomUUID`, the Brain's `node:crypto` idiom, injectable like `now`) and names it in its opening log line. It hands the id to both `buildComputedRouteFromPass` call sites: the completed pass, and `publishUnavailableComputedRoute` on every early exit. Nothing else moves. The builder already wrote `provenance.runId`, and its consumers already render a present or an absent id: Fleet's route read and the cockpit pane (Institution #513).

Evidence: L2 (unit arms on both branches at this head) → L2 required (AC-1, AC-2). Residual: AC-3, Residual-Owner: neomjs/neo-agent-institution#505
