Resolves #891

🌿 The bench command no longer fails on the first identity it actually writes.

#883's receipt on the plane (Brain `1879b588`) failed with `TypeError: Neo.get is not a function`. Updating an existing node notifies the record's store through `Neo.get`, and the command never loaded Neo's instance manager, which defines it. The fix is the import `services.mjs` and `recreateGraphDb.mjs` already carry. A new spec runs the real entrypoint in fresh processes against a temp graph: seed, bench, show, reseed, show, activate. That reproduces the failure, and it also proves #883's reseed precedence end to end on a seeded identity.

Evidence: L2 (fresh processes over a real temp graph) → L3 required for AC-3 (the receipt on the plane). Residual: AC-3
