Resolves #914

🌿 The operator can no longer be shown a message that the Fleet wire gives him no way to open, mark read or answer.

The Fleet wire gains three verbs for the viewer's own inbox, each under the transport-stamped request identity:
- `fleetOwnMessage` reads one message in full.
- `markOwnMessageRead` writes one receipt.
- `transitionOwnTask` moves a Task the viewer holds.

`composeOperatorMessage` also admits `inReplyTo`, so a reply links to the message it answers. Every verb passes its primitive a whitelisted argument object, so no identity-shaped field and no bulk flag crosses. The plane client and the in-process entry both wire the new primitives, and a primitive that is not wired leaves only its own verb `not-wired`.

Evidence: L2 (unit tests over the bridge verbs, the seam wiring, the wire vocabulary and both policy tables, with injected primitives) → L3 required for the cockpit round trip against a plane, which the Institution consumer owns. Residual: the consumer round trip, Residual-Owner: neomjs/neo-agent-institution#551.

## Deltas from ticket
- The verbs are named `fleetOwnMessage`, `markOwnMessageRead` and `transitionOwnTask` rather than the draft's `*Operator*` names, because they act on the viewer's own inbox whoever the viewer is. The ticket body is updated.
- The seam keeps the name `composeWriter`, and its JSDoc names the extension. Renaming it would have touched the wiring module, its spec and both entry call sites for no behaviour.
- A move the primitive refuses by throwing now comes back inside `result` as `{success: false, rowsAffected: 0, code, reason}`. The reason is a fixed text, never the exception message. A lost race comes back as the primitive's own `{success: false, reason, task}`, and any other throw stays a generic `operation-failed`. This is the review's RA-1.

## Test Evidence
All coverage runs in CI. Locally, the Fleet unit folder passes except 4 base-side failures in `provisioningTemplates.spec.mjs`. That spec reads `.codex/config.template.toml`, which dev does not track, and this PR does not touch it.
