Resolves #898

A seat defined without a memory consent can now take one later, until it first holds its memory. `configureAgent` accepts `memoryImport` (an agent's memory folder, `'none'`, or `null` to withdraw), normalized exactly as at definition. `FleetControlBridge` decides a consent inside the seat's home queue (`FleetManager.withSeatHome`), after any Start already holding it. It refuses the consent while the seat runs, or once it holds its memory: `seatHoldsMemory` reads the import receipt and the family's destination, the same truths `importSeatMemory` reads at Start. Both refusals carry `code: 'FLEET_SEAT_MEMORY_IMPORT_CLOSED'`, so a consumer closes the choice on that code and keeps it open on any other rejection, which a person can correct. The bridge's `configureAgent` now answers a Promise; the wire dispatcher already awaits every handler.

Evidence: L2 (unit specs on real temp folders, and the bridge over a stubbed registry) → L2 required (AC-1 to AC-5 name units). Residual: none in this leaf; each existing seat's installed consent belongs to the move, Residual-Owner: #571.

## Deltas from ticket
- `FleetControlBridge.configureAgent` now answers a Promise, for the convergence read. Its seven direct spec calls await it; the wire path already did.
- A consent is decided inside the seat's home queue, and a running seat refuses it. Sophie's review probe found the race: a consent accepted while a Start held the seat landed after that Start had read the definition, so the seat launched empty under a recorded consent. The new arm holds a Start in the queue; it fails without the queue (decided early) and without the running check (accepted).
- Both refusals carry `code: 'FLEET_SEAT_MEMORY_IMPORT_CLOSED'`, in the bridge's own `code` idiom. Vega and Emmy found on neomjs/neo-agent-institution#574 (RA-1) that the cockpit's Memory row could not tell a closed choice from a correctable rejection without parsing the reason.
- `check-block-alignment` re-aligned the import blocks of `FleetRegistryService.mjs` and `seatMemoryImport.mjs` (whitespace only).
