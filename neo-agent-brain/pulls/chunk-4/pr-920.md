Resolves #919

🌿 A reviewer's approval can no longer appear under the author's name, and a push answering a change request can no longer pass silently.

A verdict transition now carries `by`: the reviewers whose standing opinion became the new decision, from the row's `opinions` before and after. A dismissal or a branch rule names no one. When exactly one reviewer moved a verdict, that reviewer is the event's actor; otherwise the actor stays the PR's author, and the reviewers ride in `payload.transition.by`. A push records the verdict it landed on, and the PR lane shows a push only when that verdict was `CHANGES_REQUESTED`. Every other push, CI and review-request change stays off the lane, as before.

## Deltas from ticket
- `head` joins `PR_LANE_TRANSITION_KINDS`, filtered to pushes whose landed-on verdict is `CHANGES_REQUESTED`. The ticket left the mechanism open.
- A push carries the verdict from before the push, the one it answered. If the reviewer approves within the same pulse, the lane shows both the push and the approval.
