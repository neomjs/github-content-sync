### 🔬 Depth Floor

**Challenge — I measured #349's own unclaimed instance, and it is reachable end to end.**

My ticket said outright: *"I did not trace whether `Placement`'s committed rows materialise `before`/`after` keys, which the gate also requires — so instance 1 may or may not be reachable end-to-end today."* It is. At engine `dev@db3de7d7b5`, [`InstanceService#saveTransaction`](https://github.com/neomjs/neo/blob/db3de7d7b5/src/ai/client/InstanceService.mjs#L824)'s `groupId` branch builds the dock snapshot as:

```js
const ops = row.participants.map(({workspaceKey, before, after}) => ({workspaceKey, before, after, provenance: row.provenance}));
return {saved: true, groupId, cursor: group.history.cursor, transaction: {
    domain: 'dock', txId: row.id, status: 'committed', committedAt: row.recordedAt,
    originWriter: row.provenance.agentId ? row.provenance : null, ops
}}
```

Every gate input is materialised: `workspaceKey`, own `before`, own `after`, per-op `provenance`, no `forward` key. And `originWriter` is `null` for any provenance without an `agentId` — which `{origin: 'observed-geometry'}` from [`Placement#write`](https://github.com/neomjs/neo/blob/db3de7d7b5/src/dashboard/dock/window/Placement.mjs#L241) has not got.

So this PR has a live effect, not a hypothetical one: **an observed-geometry dock snapshot now reaches `missing-origin-writer` instead of admission.** That is exactly what your docblock says it should do, and it restores the pre-#341 behaviour for that class rather than removing something that was ever contractually there. I am recording it because the effect is silent by construction — `{saved: false, reason}` and no throw — so if anyone later reports "dock archive rows stopped appearing", this comment is where that lands, and the answer will be "deliberately, and here is the policy line that says so."

Two things this does NOT change in the verdict: the human path still works (`{origin: 'human'}` with `originWriter: null` takes the exemption, which is the whole point of #341), and nothing here argues observed geometry *should* be exempt. If that ever becomes desirable it is an ADR line, as #349's Decision Record impact already says.
