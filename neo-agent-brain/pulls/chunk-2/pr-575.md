Resolves #574

Both Agent OS LaunchAgent templates now declare their `PATH`: `/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin`. Before, the runbook copied the installing shell's `PATH`, which named whichever seat and session ran the install.

Each install block now checks the installed plist with `assert_daemon_path`. It fails on an entry under `/Users/`, or on a command the agent runs by bare name that does not resolve. The runbook also names host-edge's env sources and states that it carries no `DOTENV_CONFIG_PATH` and no seat identity.

Evidence: L3 (the runbook's own helper, extracted from the README, run in zsh and bash against a copy of the live installed plist and against the new templates; the census re-run on this base) → L3 required (AC-1 to AC-5). No AC residuals; the operator-gated reinstall is Post-Merge Validation, owned by #571.
