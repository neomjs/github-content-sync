Resolves #362

🌿 A fourth package can still join the Brain tier, but it can no longer join it in one place and stay out of the others without a red arm saying so.

The tier's membership — `better-sqlite3`, `chromadb`, `@chroma-core/default-embed` — was written by hand in seven places. It is now written once, as `BRAIN_TIER` / `BRAIN_TIER_PACKAGES` in the cloud-plane denial loader, and the other sites either consume it or are asserted against it: the unit config's install gate builds its requirement rows from the named keys, its error message interpolates the list, the header comment stops enumerating, the spec iterates the constant, and the loader's `NEO_DENIED_PACKAGES` default derives from it while the env override still wins. `dependabot.yml` cannot import, so it is asserted: a new arm reads it with `js-yaml` and requires every member in the npm group's `exclude-patterns`; two more arms require every member to be a declared root dependency and to have exactly one gate row. The two supersets (`CLOUD_ONLY`, the cloud manifest list) are untouched and each now says why it is larger. No new file.

Evidence: L2 (unit — the arms read the live `package.json`, `dependabot.yml` and the gate in this checkout) → L2 required (every AC is code and spec). Residual: none.

## Deltas from ticket
- **The constant lives in the denial loader, not in the unit config.** Site 7 is a production diagnostic whose own JSDoc forbids importing from the test tree, while the config may import production code freely — so the loader is the only one of the seven that all six others can reach. The ticket's Fix item 1 said "the config that already owns the gate"; restated on the ticket (AC-7) with this reason. Still no new file.
- Named keys (`BRAIN_TIER.sqlite` …) beside the ordered list, so the gate's requirement rows address a member without spelling it and without positional coupling.
- `exclude-patterns` had already grown a fourth entry (`neo-agent-skills`, with today's dependabot PRs); the arm asserts containment, so a superset there is allowed by design.
