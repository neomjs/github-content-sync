Resolves #581

🌿 A Fleet attached to a plane now shows the plane's machines, and "snapshot missing" is no longer something the installed app says about a plane that is answering.

The installed Fleet Manager attaches its bundled Fleet to the local plane (127.0.0.1:3102) and reads mailbox, presence and wake truth from it — but wired its deployment-state source to its OWN snapshot file (`devFleetServer.mjs`), a data root with no orchestrator writing one, so the System keeper-view rendered `snapshot-missing` while `get_deployment_state_snapshot` on the same plane answered `available` with five services (Emmy's probe 13:5xZ, mine 13:08Z). That plane tool is the file reader served over MCP, in the very verdict shape `createDeploymentStateReadSource` already consumes, so plane mode now wires `createPlaneDeploymentStateReader(planeClient)` as the source's `readImpl` (a sibling of `planeWhoIsOnlineReader`), the wiring accepts a reader without a path, and `projectDeploymentStateForFleet`'s redaction is untouched. The projection carries the reader's freshness verdict (`stale`) instead of re-aging the snapshot against this process's horizon: the plane decided freshness on its own horizon, `0` disabling staleness. A reader that throws (plane unreachable, an unreadable answer) projects `unavailable / snapshot-read-failed`; the wire verb never fails upstream for a snapshot it could not read. In-process mode is unchanged except a horizon of `0`, which the projection read as stale while its own file reader said available.

Evidence: L2 (unit: the reader's request shape, the verdict through the source to an `ok` projection with the plane's services, the plane's own `unavailable` reason preserved, a throwing reader projected honest, wiring with a reader and no path — red on dev; the mismatched-horizon pair and horizon `0` on both paths — red at e0077c5) → L4 for AC-3 (the installed FM's System view populated after the Brain pin bump + repackage). Residual: AC-3, Residual-Owner: #64 (AC-13; the installed-app verification itself is neomjs/neo-agent-institution#7's, @neo-gpt-emmy / root).

Micro-review eligible: contained — one adapter file beside its siblings, one optional parameter on the wiring, one try/catch in the source, one conditional in the boot entry, the projection's freshness input a verdict instead of a horizon; no wire shape change.
