Resolves #444
🌿 *A drift sweep can no longer spend half an hour asking which twelve identities are subscribed.*

`getExternallyActiveSessionIds` now materializes the subscribed identities once, in a CTE with the same `WAKE_SUBSCRIPTION`, active-status and `harnessTarget` predicates, and matches memory rows against it with an uncorrelated `IN`. Before, a correlated `EXISTS` re-scanned all of `Nodes` for every memory row, in one synchronous statement under the heavy-maintenance lease. On the local plane's graph that was minutes of CPU per drift sweep with no log line. The returned set is unchanged.

Evidence: L3 (the statement planned and timed read-only against the local plane's `memory-core-graph.sqlite`; unit arms locally) → L4 required (AC-3: a deployed summary run). Residual: AC-3, Residual-Owner: #64.
