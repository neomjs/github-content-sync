Resolves #496

The Fleet cockpit can now read the computed Golden Path through one wire method, and the route crosses the plane boundary like every other fleet axis. `fleetGoldenPath` is a read-observe verb on `FleetControlBridge` backed by a `goldenPathSource` slot (the `tasksSource` shape, the same honest not-wired default), wired at the fleet-server boot from two Memory Core operations: the new `get_computed_route`, which serves the synthesizer's `computed-route.json` sidecar from the process that mounts the handoff volume (validated with `validateComputedRouteResult`, passed through under the producer's own `status` / `freshness` / `capturedAt` / `expiresAt` / provenance, items in producer order — never re-ranked) together with the corpus-projection admission for the `computed-golden-path` consumer (current / last-known-good / withheld, the contract `get_context_frontier` already applies, evaluated where the receipt lives), and the existing `get_rem_pipeline_state`. Each axis answers as itself: the operation's typed statuses (missing / unreadable / invalid) become degraded reasons, a failed read is its own unavailable axis with a redacted detail, and the admission keeps the contract's own reason code. The wire vocabulary, the S1 slice ledger (`awaiting-s3`, like `fleetTasks`) and the scope-class ledger (`read-observe`) carry the verb; both parity specs list it; the new specs are on the `unit` job's run list.

`get_computed_route` is the `get_sandman_handoff` sibling: `readComputedRoute` (`ai/services/memory-core/helpers/computedRouteStore.mjs`) is the file-contract half, the tool binds it to the resolved handoff path and reads the projection leaves inline at that use site (ADR 0019); tier `read`, embed-exempt like the other read-only diagnostics.

Evidence: L1 (unit: the store's statuses and admission, the tool dispatch through `callTool` in a stubbed Memory Core process, the source's axes and envelope, the wiring, the bridge default, the ledgers) → L2 required (AC-1, the wire answer from a running fleet server). Residual: AC-1, Residual-Owner: #122.
