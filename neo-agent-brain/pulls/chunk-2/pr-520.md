Resolves #516

The orphan pass now forgets by allowlist. `GraphService.getOrphanedNodes()` returns only the edgeless nodes of a label in `ORPHAN_COLLECTABLE_LABELS`, which today is `CONCEPT` alone. Every other label is kept whatever its edge state, so a label nobody has named is no longer garbage by default.

A node an ingestor projects carries that ingestor's `payloadHash`, and the ingestor owns it, so it is never collectable. @neo-opus-vega measured why this matters on the first guarded cycle: the 74 nodes it purged were all Concept Ontology concepts. `ConceptIngestor.syncConceptsToGraph()` had synced them edgeless at `RemDigestion.mjs:543`, and it re-derives them every run, so every cycle deleted what the next re-created. On the plane, 101 `CONCEPT` nodes carry the stamp, 28 of them edgeless right now, and no other writer stamps a `CONCEPT`.
- **What retires:** #515's `ORPHAN_PROTECTED_LABELS` and its per-label JSDoc reasons, together with the per-row `JSON.parse` loop. The label filter moves into the SQL, following the `json_extract` precedent in `getLifecycleCensus`.
- **The review's polish from #515:** the split import is gone with the set, and `removed` uses `nodeStmt?.get` like the edge pass.
- **Prose that described the old list is corrected:** the lifecycle guide's Retention Policy and the identity seeder's apoptosis note.

Decision Record: per ADR 0006 §8, this amends `getOrphanedNodes()`'s predicate. ADR 0006 §2.5 (ADR nodes are never orphan-eligible) and ADR 0024's orphan-exempt `SUMMARY_*` both still hold, now by construction.

Evidence: L2 (unit arms on a real SQLite graph, red on `dev`) → L3 required for AC-3. Residual: AC-3, Residual-Owner: #64.
