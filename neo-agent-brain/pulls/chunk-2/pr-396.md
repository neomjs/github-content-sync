## Deltas from ticket

The source event handle is the durable occurrence identity. Pagination freezes membership rather than mutable seen flags or lifecycle state. Each page's source manifest fingerprints its immutable occurrence revisions. Current-content reads explicitly carry provider revision and read time; they do not promise historical prose.

The GitHub adapter separates supported metadata kinds from prose-bearing entity types. Inline review comments use numeric REST identifiers; other content uses verified GraphQL nodes. Global roster membership does not substitute for repository-relative trust. Unknown provider errors remain unknown; an HTTP 403 alone does not prove permission denial.

The implementation composes ADR 0036 and the existing Bird View envelope. It adds the missing query/read layer, without replacing or duplicating acquisition or admission. The operator runbook section is reference documentation, with its retirement condition in the document. No turn-loaded instruction slot changes.
