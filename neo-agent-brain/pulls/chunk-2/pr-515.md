Resolves #511

The REM cycle's orphan pass (`GraphMaintenanceService.runGarbageCollection`, after #507's edge pass) now:
- **Keeps the durable records it used to forget.** The protected labels live in one `Set` beside `PROTECTED_EDGE_TYPES`, replacing a 13-clause chain. The set gains:
  - `SESSION_SUMMARY`, whose node id is its vector's id in the collection `query_summaries` searches;
  - the current raw-memory label `AGENT_MEMORY`, next to the legacy `MEMORY` it replaced (both through their constants);
  - `MESSAGE`;
  - the decay clock `SYSTEM_CLOCK`;
  - `KnowledgeBaseTenantManifest` and `nl-transaction-archive`, which are written edgeless by construction.
- **Purges vectors only for the orphans that left storage.** `GraphService#removeNodes` deletes only the nodes the cache holds, so an uncached orphan used to keep its node and lose its vectors.
- **Lets a failed purge reach the pass's existing warn.** The two `.catch(() => {})` would hide any failure.

Decision Record (added after the merge; ADR 0006 §8's re-review trigger applies): this amends `getOrphanedNodes()`'s predicate. ADR 0006 §2.5 holds, because `ADR` stays protected.

Evidence: L2 (unit arms on a real SQLite graph with stubbed vector stores, each red on `dev`) → L3 required for AC-4, since the plane recreates on this head before its dream brake retires. Residual: AC-4, Residual-Owner: #64.
