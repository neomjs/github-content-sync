Resolves #460
🌿 *A mis-shaped LM Studio resident can no longer keep every other role unloaded while its fix goes unread.*

`ensureLmsModelsLoaded` now judges a shape mismatch per role. Unreadable metadata still refuses every mutation, and a mis-shaped resident stays report-only (neo#17079). Genuinely missing roles now get their additive, shaped, pinned load in the same pass. When nothing is missing, the single-probe fast path returns unchanged. The `replacement-required` result now carries `operatorDiagnostic.summary`: the resident's observed and required shape, whether it is JIT-loaded (from `lms ps` `ttlMs`) or pinned, and the `lms unload` / `lms load` pair. The supervisor's degraded readiness line already prints any summary, so the action now reaches it. Both specs join the brain-unit smoke list so these arms run in CI.

Evidence: L1 (unit arms in CI plus one mutation control; no plane) → L4 required for AC-3 (an LM Studio restart on a deployed plane). Residual: AC-3, Residual-Owner: #461.
