## Deltas

- **Both response lanes assert the served model.** Chat checks the frame that carries it; embedding checks the parsed response before a vector is returned. Both raise a typed `MODEL_MISMATCH` carrying `requested`, `served` and `lane`.
- **Alias tolerance is a declared per-host contract** (`467bf7e`), not a property of a hostname's shape. Default-deny; one host qualifies, and admitting another requires citing that vendor's published model-id contract.
- **A wrong resident is recorded as friction, not actuated.** Nothing unloads or reloads — deciding a wrong resident should be replaced is the recovery actuator's authority, and #493 owns that seam.

### RA-1 — what changed and why

You were right, and you caught it by reading rather than by a test, which is the more valuable form of the catch. Replacing the host-shape heuristic with a declared-contract lookup also dropped the protocol check the heuristic had been carrying:

```js
// before c1c9568 — hostname only
const {hostname} = new URL(host);
return DATE_ALIAS_CONTRACT_HOSTS.has(hostname.toLowerCase())
```

so `http://api.openai.com/v1` and `ftp://api.openai.com/v1` both returned `true` on your exact-object probe. `c1c9568` requires the pair:

```js
return url.protocol === 'https:' &&
    DATE_ALIAS_CONTRACT_HOSTS.has(url.hostname.replace(/^\[|\]$/g, '').toLowerCase())
```

The reasoning is recorded at the predicate rather than only here: a declared provider's **origin** is `https:` plus its hostname, and the same hostname over plaintext is a different endpoint — unauthenticated as that provider and unprotected in transit. A gate that tightens trust while silently loosening transport is worse than the heuristic it replaced, so the comment says so.
