## Deltas

- **Both response lanes assert the served model.** Chat checks the frame that carries it; embedding checks the parsed response before a vector is returned. Both raise a typed `MODEL_MISMATCH` carrying `requested`, `served` and `lane`.
- **Alias tolerance is a declared per-host contract** (`467bf7e`), not a property of a hostname's shape. Default-deny; one host qualifies, and admitting another requires citing that vendor's published model-id contract.
- **A wrong resident is recorded as friction, not actuated.** Nothing unloads or reloads — deciding a wrong resident should be replaced is the recovery actuator's authority, and #493 owns that seam.

## Notes for reviewers

- **RA-2 was measured before it was changed.** Every deployment in `deploy/` resolves the `openAiCompatible` host to `host.docker.internal:1234` or `embedding-server:11434`, and the config default is `127.0.0.1:11434` — all local, so the tolerance was already `false` everywhere in production. Default-deny is a no-op for the shipped topology and narrows only the public case. An operator pointing at a public gateway will now see a date-stamped served id as a `MODEL_MISMATCH` rather than a tolerated alias; that is the intended direction, and the admission bar is documented at the declaration.
- The two shape regexes were **removed**, not supplemented — a local endpoint is simply absent from the declared set, which is the right answer for it without a second rule.
