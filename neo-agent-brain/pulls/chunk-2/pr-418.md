Resolves #415

🌿 A starved plane could always say who held the lease; it can now say what that holder did with it the last time, and a diagnosis that took two samples and a code read takes one.

The heavy-maintenance starvation receipt carried `leaseHolder`, `leaseStatus` and the waiters' own causes, and nothing about the holder's behaviour — although `tenant-repo-sync` records `leaseYielded` and `observedYieldCause` on every cycle. `describeHolderYield` (watchdog module, pure, reader injected) reads the current holder's last finished cycle off its durable task state — `taskName` (the owner's first `:`-segment), `leaseYielded`, `observedYieldCause`, `cycleAt` — with every field present and `null` when the holder records nothing. `cycleAt` is a stamp the writer itself sets: `TaskStateService` now writes `lastCompletionAt` in the same terminal mark that persists `lastCompletion` — completed, failed and skipped alike — so the time and the facts can never describe different cycles, and a record persisted before the stamp existed carries its facts with a null `cycleAt`. The watchdog runner stamps the object on the persisted verdict as `holderYield`; `tenant-repo-sync`'s cycle summary now carries `observedYieldCause` beside `leaseYielded` (the strongest cause seen anywhere in the sweep, `lease` outranking `slice`); Memory Core's `healthcheck` detail line names it (`holder's last cycle: yielded true, cause lease, at …`) and `observation.holderYield` carries the object. The OpenAPI contract and the bridge JSDoc document the additive field; a receipt from an older producer folds to `null`, never to a guess. Observation only — ADR 0022's scheduling authority is untouched, and #64's falsifier stands: no arm asserts a free lease as health.

Evidence: L2 (unit — the real `TaskStateService` and lease primitives in `pipeline.spec`'s production-composition arm and in the watchdog spec's writer-composition arm; pure arms for the reader and the fold; no deployed plane in the sandbox) → L2 required (AC-1 to AC-4 are code and spec criteria). Residual: AC-5's live plane read, Residual-Owner: #64.
