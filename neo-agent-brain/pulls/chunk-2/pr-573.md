Resolves #572

Fleet now provisions a seat into the layout a person would make:
- clones at `<agentsRoot>/<id>/<owner>/<repo>`;
- harness homes at `<agentsRoot>/<id>/harness/<type>`.

`fleet.agentsRoot` (`NEO_FLEET_AGENTS_ROOT`) is the one root. It is not a plane member: a seat's working trees and path-keyed memory must outlive any plane. It defaults to `~/.neo-ai/agents` (the `backupPath` shape), and the maintainers' host will set `/Users/Shared/agents` (#571).

The derivations validate instead of hashing. A segment outside lowercase letters, digits, `.`, `_` and `-` is refused, never rewritten, so every segment is the raw value and distinct values cannot collide.

Evidence: L2 (contract arms over the pure derivations and the config tree, and the lifecycle spawn stub) → L2 required (AC-1 to AC-5). No residuals; moving real seats is #571's migration leaf.
