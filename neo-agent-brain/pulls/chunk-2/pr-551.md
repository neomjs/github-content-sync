Resolves #550

A Fleet-managed OpenCode bootstrap now hands the generated wake hook the seat identity it stamps into the envelope. Before this, `bootstrapOpenCodeWakeRoute` passed only the ambient allowlist and the server credential pair, the hook refused to run without `NEO_AGENT_IDENTITY`, and every such route degraded at stage `wake-envelope hook`. The identity is non-secret and already on the child env; no credential class widens.

Evidence: L2 (the new arm executes the real generated hook as a child process; the sandbox has no live OpenCode server) → L3 required (AC-5: a Fleet-managed seat's route reaches `ready`). Residual: AC-5, Residual-Owner: #503.
