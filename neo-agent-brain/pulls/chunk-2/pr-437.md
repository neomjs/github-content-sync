Resolves #434
🌿 *"Disabled" can no longer be something only the snapshot believes.*

`syncTenantRepos` now drops disabled entries from its sweep set before any git or ingest call, so a parked repo is no longer cloned, fetched, materialized or ingested. The access probe and the snapshot row already honoured the flag; now the lane does too. Parked entries are counted rather than logged per sweep (`disabledCount` in the returned details, `N disabled` in the cycle summary), and a selector naming one gets a single WARN. A sweep whose every entry is parked skips as `all-tenant-repos-disabled` and says so in its log line. Parking stays consistent on the bootstrap side too. A parked entry is not seeded: a timestamp seeded while parked would be stale by re-enable and make the entry due on the spot, so the first sweep after re-enabling seeds it and the jitter spread starts there. `resolveConfiguredTenantRepoLabels` no longer counts a parked entry as coverage, because a repo that is never swept never gains a checkpoint and would otherwise keep the tenant lane bootstrap-critical forever. `isTenantRepoDisabled` is exported for that one reader.

Evidence: L2 (unit contract through `runTask` and the default label resolver, with fake git / envelope / ingestion seams; no plane) → L4 required (AC-5: a deployed plane with the toggle on and one parked entry). Residual: AC-5, Residual-Owner: #64.
