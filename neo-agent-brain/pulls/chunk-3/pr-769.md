Resolves #763

🌿 The PR lane no longer tells the fleet about one repository three hours late; it tells it what the producer saw, when it saw it, for every repository it watches.

The PR/lane slot's pull-request contributor now reads the open-work producer's transitions (opened, review verdict, merged, closed) as `pr-activity` events for every repository the producer snapshots, each at the producer's observing pulse. The issue, lane-claim and stall contributors keep their sources: the base reader (the plane's `get_pr_lane_activity` in plane mode, the local corpus tree otherwise) is asked for them without pull-request events (`prEvents: false`, declared on the plane tool) and at the composer's maximum bound, so the final ranking and the caller's bound happen here, after the replacement, and a removed corpus PR displaces nothing. No reader sources GitHub.

**The delivered contract.** The composite's `capability` now carries every contributor's own capability under `capability.slots[<slot>]`; the PR lane's is `capability.slots['pr-lane']`, with `producer: {state: ok|stale|unavailable, observedAt (the high-water time), coverage: complete|partial|…, retained: {since, coveredSince, size, max, full}, coverageGap: {requestedSince, retainedSince, coveredSince}|null}`. The composite's `capturedAt` stays the read clock; the producer's time lives where it was observed. A stale pulse, a partial pulse or a gap degrades the slot and names itself in the composite's reason. The retained window is conservative: the producer keeps the newest `max` transitions by count, so a full window may have cut inside one pulse, and coverage begins at the first pulse after the oldest retained one (`coveredSince`); a reader asking from that pulse or earlier reads a gap, a window with room covers all it holds.

Placement: `devFleetServer` wires the producer outside the plane/in-process branch, so a plane-attached Fleet runs it too; the slot reads it where it lives (a getter, bound at read time) and nothing is published to the plane — one producer, one copy. #762's publication of each seat's open work stays its own leaf and is not a prerequisite here.

Change class: behavior — the PR contributor's source moves from the corpus to the producer; the slot's `{capability, counts, events}` boundary, the composer and the other two contributors are unchanged.
agent-preflight: not hosted here; the archaeology guard and the fleet unit folder ran locally; CI follows.

Evidence: L2 (owning unit specs; the fleet unit folder at the head) → L2 required. AC-5 is the installed row-4 sitting on neomjs/neo-agent-institution#414.

## Deltas from ticket

- The retained window is declared by exporting the producer's `TRANSITION_WINDOW` (the one touch on the producer module); the producer's state shape is unchanged. The window's coverage is stated conservatively (`coveredSince`), because the producer cuts by count, not by pulse.
- The plane tool `get_pr_lane_activity` gains an optional `prEvents` boolean (OpenAPI, handler, memo store); the store keeps one answer per asked shape within a materialization, so a Fleet with its own PR producer and one without do not evict each other's read. A plane older than the flag still answers PR events; the wrapper replaces them before the bound either way.
- The composite capability gains `slots` (each contributor's own capability, keyed by slot). Its `{source, state, confidence, capturedAt, reason}` fields are unchanged.
- Fallbacks, as the ledger says: no producer, or one that has not pulsed, degrades the slot naming the producer and shows no pull-request event — the corpus is no longer a fallback source for PRs. A Fleet without a GitHub token therefore shows issue, lane-claim and stall events only, and says why.
- `since` is accepted by the slot reader for the coverage-gap contract; the composer forwards it when a caller sends it, and today's cockpit sends none.
