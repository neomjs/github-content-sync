Resolves #644

A Fleet seat now starts with the maintainer instructions for its repository in its harness home.
- **Claude:** `<instanceHome>/CLAUDE.md`.
- **Codex:** `AGENTS.md` in the Codex home, inside codex-desktop's nested home too.
- The text is `neo-agent-skills/agents-md`'s composition for the seat's repository, which Skills 0.1.23 (#127) is the first release to export.

Until now a seat on the Brain, the Institution or the Skills repository ran with no instructions at all, because only the Engine tracks the file.

- **The checkout wins when it already supplies instructions to that harness.** For Claude that is `CLAUDE.md` or `.claude/CLAUDE.md`. For Codex it is `AGENTS.override.md` or `AGENTS.md`: Codex reads its home file whole, beside the project budget, so a second copy would load twice. Only a file the harness can read counts, a symlink to one included. A directory, a link to nothing or an unreadable file cannot supply instructions, so Fleet writes the composition and names the entry in `ignored`.
- **An undeclared repository, or a harness without a witnessed user-scope slot, starts normally.**
- **Convergence runs both ways**, through `prepareManagedAgentWorkspace`'s text artifacts and a receipt of Fleet's last write. A new Skills release replaces a file Fleet wrote. When the seat stops taking the file (the checkout now supplies it, or the repository is undeclared), Fleet removes the copy it wrote, with its receipt. A file a person edited refuses the start with `FLEET_WORKSPACE_DIVERGENT`, naming the path, in both directions. A file Fleet never wrote stays and is reported.
- **The decision reaches the caller:** `seatInstructions: {state, reason, ignored?, homeFile?}` on the preparation result and on the status `startAgentProvisioned` returns.

Evidence: L2 (the preparer and the projection run against real temp homes and checkouts, with the published 0.1.23; a real composed start carries the decision) → L3 required for AC-5 (a harness actually loading the file). Residual: AC-5, Residual-Owner: #571 (the seat-launch outcome; the operator's acceptance trail is neomjs/neo-agent-institution#12).

agent-preflight: ran with `--change-class capability`; class and subjects match. Class: capability (`feat`).
