Resolves #682

A Fleet seat can hold more than one repository. Its other repositories live in `metadata.repos` (`[{repoSlug, cloneUrl}]`, beside the working `metadata.repo`). A new `setRepos` wire verb sets them, validating each entry by `setRepo`'s rule, which is now one shared helper. `startAgentProvisioned` clones each one after the working checkout, with the seat's PAT, before the spawn. A clone that fails is reported on the status (`repos: [{repoSlug, state, reason?}]`), and the launch goes on; a failed working checkout still refuses the start. This is the Brain half of the operator's 09-30 request. neomjs/neo-agent-institution#245's form consumes the verb.

Evidence: L2 (stubbed provisioning seams; no seat on this host runs a Fleet build carrying this) → L4 required only for PMV-1. Residual: PMV-1, Residual-Owner: #571.

## Deltas from ticket
- `setRepos` also refuses a seat that has no working repository yet: an extra clone needs a checkout to sit beside. An empty list is allowed, so it can always be cleared.
- `setRepo`'s slug refusal now says "never a reserved owner" instead of naming `harness`. The shared helper serves both verbs, and #675 reserves `memory` too.
- `startAgentProvisioned` now always returns a composed status object (it used to return the lifecycle's own object when there was no `seatInstructions`).
- The aligner fixed a 2-line block that was already misaligned in `fleetServer.spec.mjs`.
