## Deltas from ticket

- **Unconditional, not credential-dependent.** Fix 4 said "on when the seat holds a PAT". Since the 2026-09-27 ruling every Fleet seat holds one, so a credential-aware `resolveMcpMatrix` would serve no case.
- **Existing seats follow.** A seat stored as `null` gets the server at its next Start. That includes a seat whose operator left GitHub off under the old default, because `normalizeMcpOverrides` never stored a value equal to the default. This is the falsifier #659 names; the cost is one toggle per such seat.
