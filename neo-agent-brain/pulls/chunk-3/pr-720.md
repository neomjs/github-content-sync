Resolves #719

🌿 The self-succession arms now run on the clock they claim to test, so a slow runner can no longer pass the predecessor off as already dead.

Both arms ran a 40 ms freshness window against the real clock. A GC pause on a loaded runner made the predecessor's lease stale before the first claim. The dead-predecessor arm's "it must wait" then failed (`sleptMs` 0), and the live-holder control acquired instead of refusing. The differential gate (#650) reports both as introduced reds. The lease core already takes a clock (`acquireAuthorityLease({now})`), but `acquireAuthorityLeaseSurvivingSelfSuccession` didn't pass one through. It now takes `now = Date.now`, uses it for the remaining wait, and passes it to both claims. Both arms drive a fake clock that the sleep stub advances, so no real time is involved.

Evidence: L2 (the two arms, red-first, plus the pulse-removal control) → L2 required. No residual.
