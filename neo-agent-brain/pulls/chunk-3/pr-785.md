Resolves #784

The first run's production `served-plane` observer can now read the plane it is asked about: it composes the Memory Core route below the endpoint (`/mc/mcp` — the ingress answers 404 at `/mcp`), sends the run's consented plane credential as the bearer (read from the referenced file at call time; before that consent no bearer leaves the host and the plane's refusal is the reason), and gets the plane block back as observed through a new `reportServedPlane` option on `runHealthcheck`, asserting nothing — the recipe keeps its own verdict (thrown → `unknown`, wrong plane → `failed`). The recipe hands every observer `(target, {record})`, the record under a bound binding only, so both renderers (CLI and the vessel's broker, which calls `productionObservers({layout, host})` unchanged) inherit it.

Evidence: L3 (the production observer against the canonical local plane, `neo-local-canonical`) → L3 required (AC-4). No close-target residuals.

Micro-review eligible: contained — three existing modules, one additive option, one observer rewired; no new abstraction, no contract an outside consumer reads changes shape (the observer context is additive).
