Resolves #625

🌿 The scene can no longer show a merged PR as work in progress.

`get_graph_scene` now answers a `states` dictionary and a `nodes.state` column. Each issue, PR and discussion codes its stored `properties.state`; a work item without one, and every other kind, codes -1. `projectScene` puts `state` on those three kinds when the answer carries the column, so an older answer projects exactly as before. This is the column Institution #320's heat needs to retire merged and closed work.

Evidence: L2 (unit arms over a real SQLite store and the pure projection; the answer validates against the OpenAPI response schema) → L2 required (AC-1 to AC-3). AC-4 is post-merge, and its deployed check is part of the post-cut measurement in neomjs/neo-agent-institution#320's AC-8.
