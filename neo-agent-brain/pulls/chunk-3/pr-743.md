Resolves #714

The quality-floor instrument exists as a script: `ai/scripts/diagnostics/presetQualityFloor.mjs --preset <id> [--documents <dir>] [--provider-host <url>]` runs one preset's chat model through the SHIPPED Tri-Vector path — one child process per document carrying the preset's env mapped onto the leaf names the local profile reads (`profileInputs`, the parity witness's own mapping), isolated from every plane by the CONSUMED flags under a scratch root the parent creates and removes (`UNIT_TEST_MODE` resolves the graph store to `:memory:`; `NEO_PLANE_DATA_ROOT` and `NEO_REM_RUN_STATE_DIR` — the REM marker is the one writer before the commit hook — point under the root, which is also the child's cwd; the child reports what it resolved and the parent refuses a run that resolved anything else), with a `beforeCommit` sentinel that keeps the payload and refuses the graph write — and measures what came back: schema validity, dangling endpoints (row-backed `memory:` / `session:` targets and `frontier` excepted), grounded names (every word of a claim node's name occurs in the document; `SESSION` / `MEMORY` / `STRATEGY` / `ARTIFACT_*` nodes are the model's own labels and are neither). A preset whose graph provider is outside the Tri-Vector dispatch — the hosted preset's `gemini` — is `unmeasured` with that reason before any request. Three public engine threads ship beside the script as the fixture set.

The floor is the reference model's recorded result on those fixtures, read from the presets table (`referenceFloor()`), never a number in the instrument, and it compares only on the same document set: the table records the set's digest (`documentsDigest`: name + content hash per document, name order) and a run over other documents reads `comparable: false` with the reason, never `met`. `supported` means at or above the reference on every recorded axis (`meetsFloor`). The recorded gemma run through the isolated child over the three fixtures — `schemaValid`, 0 dangling edges, 3–4 grounded claim nodes per document, 0 ungrounded names, 23 s — replaces the 2026-09-23 entry, whose three documents were private session memories nobody can re-run; that earlier reading and the pre-isolation same-day reading (1 dangling edge) stay in the entry's note as variance.

Evidence: L2 (the instrument's helpers and CLI over a fake child, a real-child witness against a fake endpoint from a clean environment, and the recorded run on `google/gemma-4-26b-a4b` through LM Studio on the maintainer host in Test Evidence) → L2 required (AC-1, AC-2). Residual: AC-3 (the hosted run needs an operator-supplied Gemini key AND a graph provider the dispatch accepts — PR #747's lane), Residual-Owner: #744 (its AC-3 is the same receipt; neomjs/neo-agent-institution#351 mirrors it).
