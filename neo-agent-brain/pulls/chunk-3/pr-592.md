Resolves #591

A seat's first Start now clones its repo with the seat's own PAT, so a private repo needs no Git credentials on the Fleet host. `startAgentProvisioned` hands the credential it already resolves (#577) through `ensureAgentRepo` and `provisionAgentRepo` to the clone. The default executor builds its command in `gitCloneCommand`:

- For `https://github.com`, the host a GitHub PAT belongs to, a helper scoped to that host reads the token from the child's environment, so the token never reaches argv. That clone runs outside the host's Git setup. `GIT_CONFIG_GLOBAL=/dev/null` and `GIT_CONFIG_NOSYSTEM` drop the config files, `HOME` is the null device so no `~/.netrc` is read, and `GIT_ASKPASS`, `SSH_ASKPASS` and every environment-injected config variable are removed. So an ambient URL rewrite, header, netrc entry, credential helper or askpass can neither redirect nor authenticate it. Proxy and CA settings reach it through the environment only. Git never prompts.
- Any other remote, ssh, or no credential gets the plain clone, as before.

Evidence: L3 (real `git` against a private neomjs repo, below) + L2 (unit arms over the command builder and the plumbing) → L3 required for AC-3. No residuals.
