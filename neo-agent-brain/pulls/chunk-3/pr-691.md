Resolves #690

The harness catalog now says what a person chooses and how it runs. Each entry carries `product` (`codex`, `claude`, `opencode`, `kimi-code`, `antigravity`, `native-neo`) and `runsAs` (`'app'`, `'cli'`, or `null` for the unlaunchable `native-neo`). `listHarnessProducts()` lists one choice per product, in catalog order, with its types as caller-owned copies. The add-agent form can then show "Codex" once and put the app or the command line behind it, as the operator ruled on 2026-09-28 (neomjs/neo-agent-institution#245). `FleetLifecycleService`'s surviving set now derives from `runsAs === 'app'` instead of listing the three app types a second time.
