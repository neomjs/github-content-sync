Resolves #657

The full Brain unit run stops hanging on CI. `seatProvenance.spec.mjs`'s "an unwritable trace never disturbs the boot" handed `recordTrace` a `/proc` path.
- On Linux, Node's recursive `mkdirSync` never returns under `/proc`.
- It is synchronous, so the 30 s test timeout could not fire: the worker was lost, the pool never drained, and `chroma-teardown` never started.
- The arm now roots the trace below a regular file, which no platform or user can create. `recordTrace` still reports `false`. The production code is untouched.

The spec's import block is also re-aligned, whitespace only (`git diff -w` is empty). The preflight's alignment repair flagged it on the touched file.

Evidence: L2 (the real `recordTrace` run on Linux Node 24 in a container, old root against new) → L3 required for AC-2 (a full CI run exiting on its own). Residual: AC-2, Residual-Owner: #201.

agent-preflight: ran with `--change-class restoration`; class and subject match. Class: restoration (`fix`).
