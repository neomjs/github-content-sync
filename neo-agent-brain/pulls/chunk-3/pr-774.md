Resolves #772

A caught lifecycle failure no longer copies its message onto the roster. `FleetLifecycleService` now has one helper, `failureWords`, which picks what a status may say:
- **a named caller's refusal** without its `<caller>: ` prefix;
- **otherwise its system code;**
- **otherwise nothing:** the status takes bounded words, and `console.error` keeps the cause, including a refusal's own `cause`.

It covers three sites:
- **The Codex Desktop helper cleanup:** its callers' refusals are written for the operator.
- **The seat-lease read:** `deriveAgentInstanceHome`'s refusals embed paths, so this site names no callers.
- **`writeSeatLease`:** its output is unchanged.

Evidence: L2 (unit tests drive the lifecycle service's real paths with injected cleanup, inspection and filesystem seams) → L2 required. Residual: none.
