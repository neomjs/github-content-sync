Resolves #776

The floor's grounding rule kept the dot inside a word, so a canonical Neo path (`Neo.main.DomEvents`) was one token no thread contains — five of the six ungrounded names across today's hosted samples were exactly that, with their identity ("DomEvents", "Workspace", "updateMountedAndVisibleRows") in the thread. Now a word with the `Neo.` root counts by its identity, the last segment: the namespace is the model's knowledge of the codebase, which a thread rarely spells, while the identity is what the thread does or does not name. An identity under the three-letter floor (`Neo.util.Id`) keeps the full path, so a one-letter identity cannot ground on any text that contains the letter. Every other name keeps the every-word rule — `Focus Management` stays invented, a file name is read as before. The reference (gemma) was re-measured under the new rule with the same result; the hosted preset was re-measured once: its remaining miss is a genuine invention, so it stays `candidate`.

Evidence: L2 (the spec's drift arm) for AC-1; L3 (two measured runs, local and hosted) for AC-2 / AC-3. Residual: none.
