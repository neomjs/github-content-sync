Resolves #685

The first-run recipe's placement probe. `probePlacement({target, readers})` reads the machine that will bear a workload and reports two RAM budgets kept apart — the host's (`total − Σ consumers`, each consumer once, a cap never among them) and the guest's (`VM cap − containers' residency`, `null` when the engine was observed running on the host itself) — with `pressure` (`ok` / `swapping` / `unknown`, from swap and compressed memory, never `os.freemem()`), `observed` (one boolean per reader), one `uncertainty` entry per reader that failed or answered an unusable shape, `complete` on each budget (an incomplete budget has no `availableBytes` and never yields an affirmative fit), the VM's host reservation observed or replaced by the named policy `vm-reservation=residency+2GiB`, disk, cores, and `runningPlane` (the canonical compose project, running, with its published ports) for Connect-before-Provision. **One owner per process population:** the production host inventory comes back partitioned (`partitionProcessInventory`: the VM's own processes, each model server with the inventory that could replace it, everything else) and the probe assigns each population one owner — the VM population is replaced by the observed reservation only when a VM topology was observed, a model server's resident set only by an inventory that actually lists its weights (LM Studio by `lms ps`; Ollama and llama-server stay as observed), and container processes on a host-native engine are already in the inventory and are never added a second time. `fitsPreset(probe, workload)` is pure: without preset data it answers `null`; a malformed workload, an incomplete budget, or a swapping host with a local preset is a refusal; the workload is **additional demand** of a new plane, so the host backs the plane's peak and its models with or without a VM while the guest must hold the same peak under its cap — raising the cap alone never moves the host margin. Every reader is injectable and `createDefaultReaders({run})` builds the production shells over an injectable command runner (`os.totalmem`, `ps -axo rss`, `docker info`, `docker stats`, `lms ps --json`, `sysctl vm.swapusage` + `vm_stat`, `docker compose ls/ps`, `df -k /`), each parser pinned against a line measured on a real host. No preset sizing threshold lives here — those are #686's data; the swapping classifier's named share is the module's one constant.

Evidence: L2 (pure module with injected readers; AC-1…AC-7 are unit ACs; the production readers run on fixture command output) → L2 required. Residual: AC-8, Residual-Owner: neomjs/neo-agent-institution#351.

Change class: capability — one new module, one spec, no other file touched.
