Resolves #685

The first-run recipe's placement probe. `probePlacement({target, readers})` reads the machine that will bear a workload and reports two RAM budgets kept apart — the host's (`total − Σ consumers`, each consumer once, a cap never among them) and the guest's (`VM cap − containers' residency`, `null` without a VM) — with `pressure` (`ok` / `swapping` / `unknown`, from swap and compressed memory, never `os.freemem()`), one `uncertainty` entry per reader that failed, the VM's host reservation observed or replaced by the named policy `vm-reservation=residency+2GiB`, disk, cores, and `runningPlane` (the canonical compose project, running, with its published ports) for Connect-before-Provision. `fitsPreset(probe, workload)` is pure: without preset data it answers `null`; with a preset's declared workload it returns `{fits, margins: {host, guest}, reasons}`, and a swapping host gets no local fit whatever the arithmetic says. Every reader is injectable; the production readers are thin shells over the instruments the ticket measured (`os.totalmem`, `ps -axo rss`, `docker info`, `docker stats`, `lms ps --json`, `sysctl vm.swapusage` + `vm_stat`, `docker compose ls/ps`, `df -k /`), each parser pinned against a line measured on a real host. Thresholds never live here — they are #686's data.

Evidence: L2 (pure module with injected readers; AC-1…AC-7 are unit ACs) → L2 required. Residual: AC-8, Residual-Owner: #351.

Change class: capability — one new module, one spec, no other file touched.
