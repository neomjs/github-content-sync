Resolves #639

Fleet now carries Electron's Node execution mode on each generated MCP child, so a packaged app executable runs the server script instead of opening another GUI. Ordinary Node executables retain their existing output, and the Desktop harness environment remains separate. The six native MCP formats, Claude bridge probe, Codex readback and diagnostic capture use the same scoped execution context.

Existing configurations can upgrade only when their managed entries exactly match the prior renderer output. The transport receipt still authorizes MC/KB changes; resident tables, login files and hand-edit refusal remain intact.

Evidence: L3 (installed Codex parser plus real Electron stdio MCP execution, and an isolated copy of the existing seat projection) achieved → L3 required. Live seat restart/tool attachment remains under neomjs/neo-agent-institution#12.
