Resolves #562

A Claude seat is now woken by its own session, without typing into any window.
- **Arming:** at `SessionStart`, `wakeArmingHook` subscribes the seat's pull route (`SENT_TO_ME` on `harnessTarget: 'none'`), then unsubscribes the seat's routes that type into a window.
- **Listening:** the new `wakeListenerHook` runs on `SessionStart` and `Stop` with `asyncRewake`. It polls `poll-digest` from the watermark its own plane wrote (another plane's starts a fresh baseline) and exits 2 with the digest. The harness then re-invokes the session with it, which AC-1 measured live.

The design, the measured premises and the per-poll GraphLog cost are in #562's intake section.

Evidence: L2 (sandbox ceiling: the specs drive both hooks against injected plane and process seams, and an agent cannot install a hook on its own seat) → L4 required for #562's Post-Merge Validation (a re-projected seat whose hook environment resolves the plane, observed waking). Residual: PMV-1, PMV-2, Residual-Owner: #30.

## Deltas from ticket

- **No new adapter.** The pull route needed none: `harnessTarget: 'none'` already means no push. `armSeatWakeRoute` is untouched and still serves the Fleet's push seats.
- **Identity from the leaf.** Both hooks read the seat's identity from its `AiConfig` leaf (`stopHook.projection.agentId`), not from `NEO_AGENT_IDENTITY` directly (ADR 0019, A1).
- **Visible arming outcome.** `wakeArmingHook` reports its outcome before the harness timeout, instead of being cancelled with no output.
- **Listener timeout.** The listener's `timeout` is a day. The harness documents no timeout exemption for `asyncRewake`, and its 600 s default would end an idle seat's listener.
- **Typed refusal.** A credential the plane binds to another identity stops the listener by name, rather than retrying it forever.
- **Spec repairs in `projectSeatHooks.spec.mjs`.** Two receipt expectations had been red on `dev` since the provenance receipt landed; they now include it. Its ticket-ref comments are reworded, because the archaeology guard reads a touched file whole.
- **Out of scope, noted in a defect-note** (`MESSAGE:c19d1788-c7a6-4dcf-9ce1-619b4b02244e`): the Claude hook commands load no seat `.env`, so a seat's hooks resolve no plane until its environment provides one.
