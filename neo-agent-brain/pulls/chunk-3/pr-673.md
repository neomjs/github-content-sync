Resolves #672

`ensureAgentRepo` makes the managed root owner-only before it inspects or clones. Until now `git clone` created `~/.neo-ai/agents` with the umask (`0755`), and outside app data the folders above it need not keep the harness homes private (on the operator's host: `~` `0750`, `~/.neo-ai` `0755`). Institution #379 makes that root the default for the next packaged launch, so seats created after that repackage would have exposed their logins to group `staff`.

`ensureSeatRoot(root)` creates the root `0700` (missing ancestors keep the default mode) or narrows an existing root that grants group or other access, the way `receiverState.mjs` treats its state directories. It runs on the root as `deriveAgentRepoPath` resolves it (`assertRoot`), after that validation, so the directory made private is the one the clone writes into.

Evidence: L2 (arms over real temp directories with the mode read while the clone runs; red against dev's and the reviewed head's `ensureAgentRepo`) → L2 required. Residual: none for #672; the move recipe's `mkdir -m 700` stays with #571.
