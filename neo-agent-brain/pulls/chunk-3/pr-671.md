Resolves #670

Two of #659's fixes that need nothing from #669, split into #670:

- **The registry refuses what Start would refuse.** `defineAgent` and `configureAgent` ask `mcpDeclarationRefusal`, the plan's own MCP checks, before they store a declaration. Turning `github-workflow` on for a Claude Desktop seat is refused when the operator does it, with Start's reason, instead of being stored and failing the next Start. The two registry-local tenant checks are deleted; the plan's check covers them.
- **A seat never borrows the `gh` keyring.** With `NEO_AGENT_IDENTITY` set and neither `GH_TOKEN` nor `GITHUB_TOKEN`, `GraphqlService` refuses instead of running `gh auth token`, whose answer is the host keyring's account. The variable is read from the environment, as `HealthService.checkAgentIdentity` and the tool layer's identity assertion read it; the one AiConfig leaf bound to it (`agentId`, `configBase.mjs:202`) belongs to the hook projection.

The Claude Desktop secret rule now lives in `mcpDeclarationRefusal`. When #669 makes those rows representable, the rule is deleted there and the registry follows.

Evidence: L2 (unit arms for both ACs, red against dev's sources, the `gh` arm with a must-hit control) → L2 required. Residual: none for #670; #659 keeps its own.
