<h2>v13.0.0</h2>
<p>Version <code>13.0.0</code> marks a major milestone, as it's the first version of <code>better-sqlite3</code> to run on <a href="[QUARANTINED_URL: nodejs.org]">the N-API</a>. This means prebuilt binaries should theoretically work across different versions of Node.js and Electron, and perhaps even other runtimes like Bun. As a result, we've removed the deprecated <a href="[QUARANTINED_URL: npmjs.com]"><code>prebuild-install</code></a> dependency, and now prebuilt binaries are published directly with the <code>better-sqlite3</code> code itself. If your platform/architecture doesn't have a prebuilt binary, it should compile during install as before.</p>
<h2>What's Changed</h2>
<ul>
<li>Refactored codebase to use node-addon-api by <a href="[QUARANTINED_URL: github.com]"><code>@​JoshuaWise</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">WiseLibs/better-sqlite3#1498</a></li>
<li>Added a new <a href="[QUARANTINED_URL: github.com]"><code>db.explain()</code></a> method, for running EXPLAIN queries without needing to supply bound parameters.</li>
<li>Added a new <a href="[QUARANTINED_URL: github.com]"><code>preparedStatement.toString()</code></a> method, for getting the expanded SQL of a prepared statement.</li>
