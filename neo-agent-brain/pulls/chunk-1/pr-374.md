Resolves #373

The orchestrator container can pass its healthcheck in a Brain image again, and its `git` children no longer pile up as zombies. The probe imports the Engine as the `neo.mjs` package (`neo.mjs/src/Neo.mjs`, `neo.mjs/src/core/_export.mjs`) instead of Engine-checkout paths a Brain image never has. The service declares `init: true`, so Docker's init reaps children that node, as PID 1, never would. A new arm in `daemon.spec.mjs` resolves every module the probe imports and asserts `init`. The existing arm pins the probe's text only, which is how this stayed green in CI since the split.

Evidence: L3 (isolated #253 rehearsal at Brain `d5ae3e8767`: disposable project, no published ports, no live binds, sync off) → L3 required (orchestrator healthy in a Brain image; zombies reaped). Residual: none.
