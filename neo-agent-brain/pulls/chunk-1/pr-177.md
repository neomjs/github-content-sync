## The three things that were wrong before this commit

**1. The population was a seed set.** 168 rows derived from custody rows alone. Two independent audits and the tree agreed it could not run: those seeds imported modules nobody was bringing.

The fix needed two sources, because each is blind in a different direction:

| source | misses |
|---|---|
| custody rows (`authoritySource` present) | 19 tracked files dispositioned *without* one — `ai/daemons/orchestrator/daemon.mjs`, `Orchestrator.mjs`, five orchestrator services, all of `ai/services/fleet/**` |
| transitive import closure | anything nothing imports — the five per-server `config.template.mjs`, which a generator copies rather than imports |

The `authoritySource` discriminator is mine. I added it to kill 13 false plane conflicts and narrowed the mover set in the same stroke.

**2. The plane rule measured the wrong property.** My first rule asked *"can this module run on edge"* (does its closure reach a cloud-only driver). It cut through subsystems:

```
rule                              edge/cloud   cross-plane edges   edge reaching cloud-only
capability (cloud-reachability)      457/158          562                   16
membership (subsystem locality)      139/476          179                   17
membership, cloud-safety vetoes      138/477          176                   16
```

*"Could this run on edge"* and *"whose subsystem is this"* are different questions and only the second predicts coupling. Cloud-safety is now a **veto**, never the assignment. The 16 is constant across all three rules, which is how I know it is a real finding and not an artifact of the rule I picked.

**3. Specifiers were preserved instead of recomputed.** A file moving from `ai/x/` to `cloud/x/` changes depth against a target that stayed at the root — preserving them yields 556 confidently-wrong paths. Every relative specifier is now recomputed from the plane map; `src/**` becomes `neo.mjs/src/**` per ADR 0040 §2.3.
