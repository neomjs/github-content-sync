Resolves #262

Integrates the extraction-profile kernel into the tenant repository lane without creating a second ingestion or digest authority. Graph, YAML, and AiConfig tiers now pass through one canonical projection; absent profiles synthesize an executable RawRepoSource or ParserSource route; custom extractors and parsers resolve per tenant rather than mutating process-global registries.

The existing materialization digest now binds extraction identity and yielded paths. Full runs publish one proof-bound extraction snapshot before the checkpoint can commit the same identity; same-SHA profile changes force null-base replay. Reconciliation keeps physical deletion (`pathsAfterPush`) separate from profile yield authority and reuses the replacement-gated generation classifier. Public push ingestion cannot supply internal profile/proof fields.

Related: #260, #263, #184, #253.
