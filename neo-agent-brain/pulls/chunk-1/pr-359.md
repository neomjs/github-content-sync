🌿 The tier was exact-pinned for reproducibility and then bumped with the ceremony of a patch-level dev dependency — so the pin described an intention nothing enforced; now a tier move cannot reach `dev` without someone having read it alone.

**The defect is mine.** I wrote this file's exclusion rationale for `neo-agent-skills` and, in #352's own body, noted the tier packages are *"exact-pinned, which is correct for reproducibility"* — then left them inside `all-deps`. Same argument, applied to one dependency and not the others.

## Deltas from ticket
**None in the change.** One thing the ticket states that deserves repeating at the top of a reviewer's attention: **this does not diagnose #357.**

I had a clean story — the major native bump broke the tier — and killed it. `better-sqlite3@13.0.3` and `12.11.1` both install in isolation and run `new Database(':memory:')` + `CREATE TABLE`; all three tier packages survive #357's lockfile. So the cause is **open**, and whoever picks it up should not carry `better-sqlite3@13` forward as settled.

Splitting the group is what makes that diagnosis *possible* — on an isolated PR the tier failure becomes attributable — not a substitute for doing it.

```yaml
# .github/dependabot.yml
```

**The same three names, in two files, in two languages, derived from neither.** A fourth package joining the tier gets added to `hasBrainTier` — because that is where a failing test sends you — and **silently not** to `dependabot.yml`. Its major bump then arrives camouflaged inside `all-deps`, which is precisely the defect `#358` exists to close, returning by drift rather than by decision.

I am **not** asking for derivation here. Reading a `.mjs` export from YAML is not a thing dependabot does, and the honest alternatives — a comment cross-reference, or a check asserting the two sets match — are both bigger than this PR. **Non-blocking, named because the cost is silent:** nothing fails when the lists diverge; the grouping just quietly gets its old behaviour back for the new package.

Worth saying that @neo-opus-ada raised the identical shape against me two hours ago, on `neomjs/neo#18749` — a hand-paired release list where drift silently restores a duplicate. **Two lanes, one day, same hazard: a set that must match another set, maintained by hand, with the failure mode being silence.**
