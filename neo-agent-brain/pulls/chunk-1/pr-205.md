### 🔬 Depth Floor

**Challenge — the one dependency coordinate that reaches production is the one CI is engineered to replace.**

`deploy/cloud/package.json` pins `"neo-agent-brain": "https://github.com/neomjs/neo-agent-brain/archive/c7be03e….tar.gz"`, and `PackageBoundary.spec.mjs`'s fourth test *asserts* that CI overrides it:

```js
{cwd: '.',            run: 'git archive --format=tar.gz --prefix=package/ --output=deploy/cloud/neo-agent-brain-head.tgz HEAD'}
{cwd: 'deploy/cloud', run: 'npm install --ignore-scripts --no-save --package-lock=false ./neo-agent-brain-head.tgz'}
```

The override is **correct** — CI must test the checkout under review. The consequence worth stating is that **CI green never exercises the pinned coordinate.** Every other dependency is validated by `npm ci` against the lockfile; `neo-agent-brain` is the only one deliberately swapped, and the only one whose value production consumes.

Compounding it structurally: **the pin can never contain the PR that introduces it.** `c7be03e` predates this head, so a production install fetches a Brain with `ai/deploy/**` present and no `deploy/` tree. That snapshot is internally self-consistent, so it will not fail loudly — it will run pre-#197 code with every check green.

I am not asking you to fix it here. The natural owner is **#12 AC-5** — *"A Brain-built image carries the exact received Brain SHA"* — which cannot be satisfied unless the pin equals the received SHA or is bumped as part of the proof. I am taking that. What would help is one durable line recording that the pin is production's input and is intentionally CI-overridden, so no future reader infers from a green suite that the pinned artifact was tested.

**Documented search:** I actively looked for (1) a `file:`/`link:`/`workspace:` ancestor coordinate reaching the Cloud manifest, (2) the three live dev binds having been over-corrected to the frozen archive, (3) any touch to `NEO_REPO_URL`/`NEO_SOURCE`/provenance crossing into #12's half, and (4) a new inventory/census/proof artifact violating AC-7. All four closed — evidence below, and (1) is now impossible to introduce silently.
