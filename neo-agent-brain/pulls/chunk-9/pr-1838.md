<h2>v13.2.0</h2>
<h2>What's Changed</h2>
<ul>
<li>musl detection on Linux now reads <code>/proc/self/maps</code> instead of calling <code>process.report.getReport()</code>. The old method could hang on reverse DNS lookups (<a href="[QUARANTINED_URL: redirect.github.com]">#1527</a>) and gave the wrong answer under some runtimes (<a href="[QUARANTINED_URL: redirect.github.com]">#1517</a>). It's kept only as a fallback, with network lookups disabled.</li>
<li>fix: throw if unsafeMode() is called on a closed database by <a href="[QUARANTINED_URL: github.com]"><code>@​kevin9327</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">WiseLibs/better-sqlite3#1533</a></li>
<li>load locally compiled binaries before prebuilt binaries by <a href="[QUARANTINED_URL: github.com]"><code>@​everett1992</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">WiseLibs/better-sqlite3#1521</a></li>
<li>Rewrote the <a href="[QUARANTINED_URL: github.com]">custom configuration docs</a>. To use a custom SQLite amalgamation, keep <code>better-sqlite3</code> as a normal dependency and compile it from a <code>postinstall</code> script. The local build is then used instead of the prebuilt binary.</li>
</ul>
