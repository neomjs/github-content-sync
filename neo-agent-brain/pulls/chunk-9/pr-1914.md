Resolves #1903

Coalesces pending `urgent: true` `wake/digest` records for a returning primary-session seat (`codex-desktop` and `antigravity`) at its next idle boundary instead of draining each older urgent record on a separate turn. When all staged urgent records fit (`<= 48` source events, `<= 16 KiB` UTF-8), one `[WAKE][priority:high]` digest resolves each bucket's `latest` summary by true wire-contract event recency (`latestTs` / `sentAt` / `grantedAt` / `lastModifiedAt`) while preserving every member's source event IDs and delivery receipt. Under overflow, `selectUrgentPrimaryWakeTurn` surfaces fresh tail work on Turn 1 alongside an oldest-first prefix whenever `[oldest, newest]` fits; across consecutive incompatible full/oversize records, it alternates 1:1 between retiring the oldest prefix/singleton and promoting the newest compatible suffix so fresh urgent work surfaces within at most 2 idle turns while retiring at least one oldest record per 2-turn cycle even under continuing arrivals.

Evidence: L2 (receiver + Fleet primary-session mock-transport integration across Codex and Antigravity) → L3 required (AC-3 installed-seat catch-up timing after host runtime restart). Residual: AC-3, Residual-Owner: #1735.
