Resolves #1772

`who_is_online` now names an identity by its stored name when it has no `displayName`. The Fleet's "Authored by <name>" lookup therefore finds auto-provisioned seats such as Maryam, instead of routing their PRs as unowned. `_projectAgentLiveness()` read a top-level `name`, which parsed SQLite rows never carry: the store keeps `properties.name`. It now reads `props.displayName || props.name || node.id`, so every row with a `displayName` reads as before.

Evidence: L2 (a unit arm runs `who_is_online` over the spec's graph store; red on the merge base) → L3 required for AC-3 (the deployed plane and the installed Fleet). Residual: AC-3, Residual-Owner: #759.
