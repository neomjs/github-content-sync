Resolves #1772

`who_is_online` now names an identity by its stored name when it has no `displayName`. The Fleet's "Authored by <name>" lookup therefore finds auto-provisioned seats such as Maryam, instead of routing their PRs as unowned. `_projectAgentLiveness()` read a top-level `name`, which parsed SQLite rows never carry: the store keeps `properties.name`. It now reads `props.displayName || props.name || node.id`, so every row with a `displayName` reads as before. Since distinct identities can then carry one name, the author lookup resolves a shared name only to the identity whose account opened the PR, and to no seat otherwise.

Evidence: L2 (unit arms run `who_is_online` over the spec's graph store and resolve PR owners through `normalizePullRequest`; red on the merge base) → L3 required for AC-4 (the deployed plane and the installed Fleet). Residual: AC-4, Residual-Owner: #759.
