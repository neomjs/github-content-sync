Resolves #1870

The Brain's six repo-local lints now run as named steps of one `Brain Lint` job (`.github/workflows/brain-lint.yml`), so a push takes one runner where it took one per matching lint (an `ai/**/*.mjs` PR started three or four). The job triggers on the union of the lints' scan surfaces, the same list under `pull_request` and `push`, so it runs exactly when one of them would have. Each lint keeps the environment it ran in: Retired Primitives, Identity Vocabulary and MCP Test Location on the bare checkout, OpenAPI Service Parity after `npm ci --ignore-scripts`, and Config Template SSOT and Script Plane after `npm run prepare`. Every lint step runs after an earlier one fails, so a red job names each failing lint. The six single-lint workflows are gone, and the scan-root parity registry keys one entry per lint, naming the workflow that runs it.

Evidence: L2 (unit specs and a mutation control in a worktree; a workflow cannot run locally) → L4 required (AC-1 and AC-2 need a real push). Both L4 receipts are this PR's own run. Residual: none.
