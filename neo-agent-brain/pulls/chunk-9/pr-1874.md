Resolves #1872

🌿 *A finished rotation can no longer call the session it just opened "unknown".*

The server stamps `originSessionId` from the request's Memory Core session on a self-addressed `sunset-successor` marker, as it already did on the sunset handover that the marker answers (#1739). The receipt read passes the marker's stamp through `successor`, and the `complete` branch records it as `newSessionId`, which `fleetWakeRoutesSource` already maps into the Fleet's rotation row. A marker sent before this change keeps `null`, which the Fleet shows as `unknown`. The completion log line names the new session too.

Evidence: L2 (unit arms on the stamp and on the completed record, each red alone on `dev`) → L2 required (AC-1). Residual: none.
