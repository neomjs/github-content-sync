Resolves #1802

Fleet now asks for a rebase when an approved pull request has a confirmed merge conflict and its completed CI is red. The conflict check can turn the rollup red by itself. The author receives the integration action on a seat-owned PR, and the existing rotation receives it on an eligible outside PR. The row continues to report its actual CI result, including independent failures for the integrated head to recheck.

Evidence: L2 (shared selector, cockpit projection and wake planner) → L2 required (ACs 1–3).
