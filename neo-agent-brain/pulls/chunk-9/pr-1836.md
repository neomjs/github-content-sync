Resolves #1835

`github.com/microsoft/onnxruntime` answers 404, and `onnxruntime-node@1.21.0` fetches CUDA binaries from that repository's releases in its Linux x64 install script. So every Brain CI job running `npm ci` with scripts failed. A repo-root `.npmrc` sets `onnxruntime-node-install-cuda=skip` for every install in a Brain checkout. Brain runs on CPU only, and the CPU binaries ship in the npm package.

Evidence: L2 (npm 11.21.1 hands the key to install scripts as `npm_config_onnxruntime_node_install_cuda`; `npm config get` reads `skip` in this checkout) → L2 required (AC-1's receipt is this PR's own CI jobs). No residuals.

Micro-review eligible: config — one dotfile line and its comment, no source change.
