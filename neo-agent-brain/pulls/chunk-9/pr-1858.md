Resolves #1857

A refused Antigravity project binding now leaves one line in the Fleet log, naming the seat, the refusal code and the harness generation the Start ran. On 2026-11-19 Antigravity 2.33.0 refused every Gemini seat's binding (#1856) and nothing recorded which step refused, because the Start answers the cockpit with a fixed refusal. `finishAntigravityStart` now logs, for example, `seat 'neo-gemini-julia' Antigravity binding refused (route-mismatch) on generation 2.33.0 (052eb434356d); the seat was stopped.` A Stop during binding logs nothing.

Evidence: L2 (unit spec in CI) → L2 required (AC-1..AC-3). Residual: none.

## Deltas from ticket

- **The code is a token or the reason:** the cause's `code` is logged when it is a short word token (refusal codes, system codes like `ENOENT`), else the launch-admission reason (`start-failed`, `process-exited`, `plan-changed`).
