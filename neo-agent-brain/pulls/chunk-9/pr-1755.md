Resolves #1753

🌿 A route the rebuild restores can no longer tell anyone that months-old mail is new.

The message-edge rebuild now stamps a message's read receipt (`readAt` = its `sentAt`, `readAtSource: 'rebuildMessageEdges'`) in the same queued write that restores its `SENT_TO`. It stamps only where the node has no `readAt`, has a `sentAt` and keeps no `DELIVERED_TO` receipts, and that predicate lives in the `UPDATE`, so a read that lands first wins. `--stamp-restored-routes <first>-<last>` replays the stamp for the `SENT_TO` rowids of a run made before this change: the plane's 06:09Z run, whose 1,245 resurfaced messages reached seven inboxes as unread. The replay retires under #1754 after that one plane run.

Evidence: L3 (dry run of this branch's code against the live graph, opened read-only) → L4 required for the plane apply (#1754's ACs). Residual: the apply and its receipt, Residual-Owner: #1754.
