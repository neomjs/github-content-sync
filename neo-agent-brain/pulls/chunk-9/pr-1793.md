Resolves #1777

A repeat sunset now rotates when its writer's Memory Core session changed. A Claude seat's PreToolUse hook stamps every `add_memory` and `add_message` with `writerKey` (a hash of the seat and its harness session id) and `writerTurn` (the turn the presence hook minted). Memory Core stores both, and a stamped save closes its own turn instead of the seat's newest. `readSunsetReceipt` releases a receipt whose handover and same-turn save carry the stamp. The rotation lane logs each wait reason once per receipt.

Evidence: L3 (a headless run of the seat's own Claude Code 2.1.325 with the real presence and stamp hooks, against a fixture stdio `neo-mjs-memory-core` whose schema declares no stamp) → L4 required (AC-9: a live repeat sunset after the plane cut and the seats' hook projection).
