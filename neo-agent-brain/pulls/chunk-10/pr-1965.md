Resolves #1964

Memory Core's graph-cache bound defaults to off (`null`). With the 60,000-node bound from #1960, each eviction stripped the identity hubs' vicinities. Every message projection then reloaded them and held mc-server's event loop for 70–85 s on the plane cut to `00762332`. The live process has run unbounded since the operator's inspector mitigation at 20:58:47Z. This PR makes a restart keep it that way. The env binding `NEO_MC_GRAPH_CACHE_MAX_NODES` stays, so a plane can still set a bound for a measured experiment. The leaf's docblock names what a default bound needs first.

Evidence: L3 (the incident's live block attribution from `mc_event_loop_block`, plus the unit spec red on base and green at head) → L3 required (AC-1, AC-2). Residual: AC-3, Residual-Owner: #1843.

## Deltas from ticket
- The boot spec keeps #1959's pin assertions. It drops `maxGraphNodes === graphCacheMaxNodes`: at a `null` default both sides are null whether or not the wiring reads the leaf, so the assertion witnessed nothing. The redesign that turns a default bound back on owes that witness (#1964's corrected AC-2).

- **The incident this prevents from recurring** (receipts on #1959 and #1964): four blocks of 70–85 s within seven minutes of the cut. The 85.3 s one carried only `job:message-graph-projection:2`. After the live mitigation, blocks fell to 1–13 s and the CPU to 8 %.

### 🔬 Depth Floor

- **Challenge**: Non-blocking env-decode guard for `#1843` when bounded collection returns: `graphCacheMaxNodes: leaf(null, 'NEO_MC_GRAPH_CACHE_MAX_NODES', 'number')` decodes via `Env.parseNumber` (`ai/Env.mjs:71-80`), which accepts `0` and negative numbers. Because `Database#runGarbageCollector` (`ai/graph/Database.mjs:234, 237`) and `Database#requestGarbageCollection` (`:314`) check only `me.maxGraphNodes === null || me.lastAccessMap.size <= me.maxGraphNodes`, setting `NEO_MC_GRAPH_CACHE_MAX_NODES=0` in an experiment (assuming `0` means unbounded) resolves `maxGraphNodes = 0` and evicts 100% of non-pinned nodes after every `addNode` macrotask (`evictCount = size - 0`). Binding `metadata.parse` to `Env.parseIntAtLeast(name, {env, min: 1})` (`ai/Env.mjs:166-175`, per ADR 0019 §5.2) when `#1843` revisits the collector will make non-positive env overrides fall back cleanly to `null`.
