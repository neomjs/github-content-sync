Resolves #1919
Related: #759

Adds the `closeout` open-work wake kind so closing a watched `OPEN` parent issue's last sub-issue (`subIssuesSummary.total > 0 && completed === total`) wakes each agent steward seat once (`assignees` via `seatIdentities.byLogin`, falling back to `author` only when unassigned), holds unreachable routes in `pendingMerges` without escalating, clears held closeouts when a read re-observes an open sub, seeds the first `closeout` window at the pulse that first runs it (`at - overlapMs`, never an older PR watermark), and suppresses backlog bursts on baseline/`quiet` rounds.

Evidence: L2 (Playwright unit, OpenAPI schema, and host-to-plane wire/intake suite in CI) → L2 required (AC-1, AC-2, AC-3).
