Related: #1927, #1555, #87, #1254

Decision Record impact: amends `adr:0002-phase3-wake-substrate-standards-alignment` (`§5.2.2` / `§5.2.3`: `next_turn` unread persistence continues to hold for direct messages while unseen broadcasts may be drained at session end via `mark_read({all: true, includeUnseenBroadcasts: true})`).

Wires recipient auto-read stamping at the Memory Core MCP `get_message` adapter boundary (`getMessageTool` → `MailboxService.getMessage(args, {recordRead: true})`, returning `readReceipt` alongside `body` so durable, in-memory-only, and unapplied stamps remain distinguishable; skipped when `keepUnread: true`, when `observer` is set, or when the caller is not a direct/`DELIVERED_TO` recipient) and adds `includeUnseenBroadcasts` to `mark_read({all: true})` (mutually exclusive with `includeUnseen: true`) so session-end drains clear all unread delivered broadcasts without sweeping unseen direct messages.

Evidence: L2 (Playwright unit suite + OpenAPI/service parity against SQLite/Chroma sandbox) → L4 required (AC-6 post-merge live seat session receipt after Memory Core plane reload). Residual: AC6, Residual-Owner: #1927.

## Deltas from ticket
- Named the session-end broadcast drain flag `includeUnseenBroadcasts` (boolean, default `false`), validated with strict boolean checks before the `all` branch and made mutually exclusive with `includeUnseen: true` (`TypeError`) so no session-end broadcast drain can widen to unseen direct messages.
- Preserved automatic stamp durability outcomes in `get_message` via `readReceipt` (`{status: 'read'|'not_applied', durable, readAt?, retryable?, warning?}`) while keeping `body` intact across durable, in-memory-only, and missing-row states.
- Reconciled damaged per-recipient `DELIVERED_TO` cache projections in `MailboxService.getMessage` via single-message `repairMessageGraphIntegrity({ids: [messageId], limit: 1})` when `sentTo === 'AGENT:*' && !deliveryEdge`, matching `markRead` while leaving genuine legacy broadcasts without delivery edges unstamped.

## Slot Rationale
- `learn/agentos/decisions/0002-phase3-wake-substrate-standards-alignment.md` (not turn-loaded): `rewrite` of `Status`, `§5.2.2`, and `§5.2.3` `next_turn` notes (+2 lines net) to record that session-end broadcast drains may mark unseen broadcasts read while direct messages retain turn-start unread delivery.
- `ai/mcp/server/memory-core/openapi.yaml` (`get_message`, `mark_read` tool summaries kept `<= 120` chars): `rewrite` to expose `keepUnread`, `readReceipt`, and `includeUnseenBroadcasts` (with explicit `includeUnseen` mutual-exclusion contract) at the MCP tool boundary.
