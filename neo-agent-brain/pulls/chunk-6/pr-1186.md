Resolves #1185

🌿 An FM update can no longer spend its handoff re-hashing runtimes that its successor re-hashes anyway.

Survivor validation called `readRuntimeGeneration` once per distinct runtime pin. Each call re-hashed the whole payload (965 MB, ≈6 s at load average 5.6) inside the handoff's one 10 s deadline. At 12:11Z three pins meant ≈19 s and a refusal, so every update ended unclean and running seats crossed stale. Yet the successor's `verifyPin` already re-hashes every retained payload before any generation is active again.

`readRuntimeGeneration` now splits at the payload inventory. `readRuntimeGenerationRecord` keeps the sealed-directory, record, compatibility and binding checks, with the same refusal codes, but skips the re-hash; it is now the handoff's default `verifyRuntime`. Each survivor's outcome (`verified`, `<keys> revoked` or `unresolved (<reason>)`) reaches the stage witness. The refusal set in ADR 0034 §2.5 item 4 is unchanged.

Evidence: L2 (unit: a real sealed generation pinned by two admitted seats, the handoff, then the successor's recovery) → L3 required (AC-5, an installed FM update with ≥ 5 seats pinned to ≥ 3 runtimes). Residual: AC-5, Residual-Owner: neomjs/neo-agent-institution#732.

## Deltas from ticket

- The witness lines carry only the outcome: `devFleetServer` already stamps each line with elapsed ms, so per-seat durations are the differences between consecutive lines.
- `performHandoff` hands its witness to `verifySeats(witness)`, keeping one witness implementation. The ledger row is added on #1185.
- The sealed-generation fixture moves to `test/playwright/unit/ai/services/fleet/fixtures/sealedRuntimeGeneration.mjs`. With it, each sealed seat pins its own real generation, Started by a boot of that runtime the way a surviving seat is. These are the controls Sophie's [design read](https://github.com/neomjs/neo-agent-brain/issues/1185#issuecomment-6267668308) asked for.
- `readRuntimeGeneration` keeps its refusal order (inventory before bindings). A mode-change test pins it: the full read refuses with `runtime-integrity-failed`, where the record read refuses with `runtime-binding-invalid`.
- `agent-preflight` realigned the top import blocks of `FleetLifecycleService.mjs` and its spec, which were already misaligned. It is whitespace only, and `?w=1` hides it.

## Test Evidence

  - escaping link: `survivor seat: unresolved (runtime-payload-invalid: Contents/Resources/organism/escape has a non-relocatable link)`.

  The link test runs alone because the describe block is serial.
