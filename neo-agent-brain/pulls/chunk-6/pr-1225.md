Resolves #1223
Related: #571

Converges a `claude-desktop` seat's `<instanceHome>/ccd-session-presets.json` to its provisioned checkout `cwd` via `convergeSeatSessionPreset` before `FleetLifecycleService.start` spawns the app: rewrites any stale local preset (`target.kind` absent or `'local'`) to `cwd`, leaves non-local presets untouched, leaves the file byte-identical when its local presets already name `cwd`, seeds one preset when a signed-in profile has no preset file (and returns `'no-account'` without writing when the profile has no signed-in account yet), logs non-`'unchanged'` convergence outcomes in `FleetLifecycleService.start`, and refuses a missing or relative `cwd` in `FleetLifecycleService.resolveLaunch` before spawn just as `codex-desktop` does.

Evidence: L1 (Playwright unit tests over temp Claude Desktop profiles and `FleetLifecycleService.start`) → L3 required (AC-4 live Fleet Manager start of Mnemosyne's seat). Residual: AC-4, Residual-Owner: #571.
