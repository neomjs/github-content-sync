Resolves #1301

Short-circuits `waitForSeatWindowRect` on deterministic macOS Accessibility / AppleEvents denials (`-25211`, `-1743`, `-10004`, `not allowed assistive access`, `not authorized to send Apple events`) while preserving retry polling for not-yet-opened windows (`-1719`), classifies each matched denial into its own code-preserving reason (`ASSISTIVE_ACCESS_REFUSAL_REASON` for `-25211`, `AUTOMATION_ACCESS_REFUSAL_REASON` for `-1743`, `PRIVILEGE_VIOLATION_REFUSAL_REASON` for `-10004`) on `FleetLifecycleService#restoreSeatWindow` (`windowPlacement`, where `requested` carries `{...saved.rect}`) and `captureSeatWindow` (`windowCapture`) with a single `warnWindowRefusal` helper that attaches a System Settings remedy only when the class names its grant, and forwards `windowPlacement` through `FleetManager#fleetRuntimeStatus()`.

Evidence: L2 (Playwright unit specs for `seatWindowRect`, `FleetLifecycleService`, and `FleetManager` with injected `execFileFn` and window seams) → L2 required (AC-1, AC-2, AC-3). Residual: none.

(-1719)` when a newly spawned process or its `window 1` has not materialized yet; `assistiveAccessRefusal` / `isAssistiveAccessError` therefore classify TCC/AppleEvents permission denials by code (`-25211` Accessibility, `-1743` Automation of System Events, `-10004` AppleEvents privilege violation) and exclude `-1719` so startup window polling remains intact.
