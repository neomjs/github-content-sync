Wires the live cross-process ADR admission projection channel between Memory Core (`GraphService` / `AdrIngestor` persisting admitted `ADR` rows to the shared SQLite `Nodes` table) and the Knowledge Base (`AdrSource` / `adrAdmissionCatalog` / `TenantRepoIngestEnvelopeBuilder` reading `aiConfig.memoryCoreDbPath`) so a KB process running without `AdrIngestor` in-memory reads the authoritative admitted ADR catalog across process boundaries, reconciles 5-state availability (`old-only`, `new-only`, `both-present`, `neither-present`, `interrupted/retried`), resolves slugs/aliases/repository locators with private `neomjs/neo-stage` reader authorization, and preserves existing admitted KB documents with `admissionAvailable: false` when the shared SQLite database is absent or unreadable.

Evidence: L3 (Playwright unit suite spawning an isolated KB child process without `AdrIngestor` reading the shared Memory Core SQLite `Nodes` store via `aiConfig.memoryCoreDbPath`) → L3 required (AC1, AC2, AC3, AC4).

Per §9 Strategic-Fit Step-Back:

- **Rationale**: The premise is right and already half-delivered.
