Resolves #1194

`bootstrapWorktree` now writes each missing config from the source's bytes, where it used to call `fs.copyFile`. A packaged FM's read-only runtime generation no longer passes its mode on to a fresh seat's checkout. The per-server materialization that failed with EACCES on the next line now writes a file the seat owns, and copy-then-reread-then-rewrite becomes a single write.

Evidence: L1 (the `bootstrapWorktree` unit spec over a read-only source tree) → L1 required (#1194's ACs are properties of the function). The packaged observation is neomjs/neo-agent-institution#736's own AC-2.
