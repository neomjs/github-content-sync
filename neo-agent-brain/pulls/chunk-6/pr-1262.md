Resolves #1260

While a packaged Fleet verifies its runtime and recovery settles, it refuses every Start (#1198 AC-4, unchanged). Its roster now says so before the click. `FleetLifecycleService#startGateRefusal` names the gate, checking `start`'s own fleet-wide gates in `start`'s order. `fleetRoster` stamps that sentence into `launchRefusal` whenever the seat has no refusal of its own, and the Institution card already keeps Start closed on `launchRefusal`. The seat journey now waits for that offer the cockpit's way before each Start, so the pre-install rehearsal stops pressing a closed Start 0.4 s after the wire answers.

Evidence: L3 (a packaged candidate's windowless rehearsal on this machine) → L3 required (AC-3). Residual: AC-4, Residual-Owner: neomjs/neo-agent-institution#732.
