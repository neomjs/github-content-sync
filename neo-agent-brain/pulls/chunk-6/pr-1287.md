Resolves #1286

Related: neomjs/neo#20114

The Neural Link's MCP Registry entry now publishes from GitHub Actions. `.github/workflows/publish-mcp-registry.yml` is dispatched by hand from `dev`. It installs `mcp-publisher` 1.8.4 with its sha256 pinned, logs in with GitHub OIDC, and publishes `ai/mcp/server/neural-link/server.json` and nothing else. The registry needs a credential that can read the org role for the `io.github.neomjs` namespace, and the interactive login can't provide one: that was the operator's 403 on 2026-10-26. OIDC from a `neomjs` repository is that credential, and it needs no secret.

Evidence: L1 (static: the workflow parses, and its pin equals the release asset's digest) → L3 required for AC-3 (a dispatched run against the live registry, possible only after merge and after npm releases `neo-neural-link@1.0.0`). Residual: AC-3, Residual-Owner: neomjs/neo#20114.
