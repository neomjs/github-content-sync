Resolves #1200

🌿 *A Codex seat can no longer be revoked by a server it was never granted.*

`McpLaunchAdmissionService.recoverServers` now compares only the targets the Start was granted (`start.profile.grants`, the set it already checks against the generation's servers). Before, every Codex Desktop survivor failed `server set changed` by construction: its Start plans all four servers, while the issuer admits Neural Link alone. So every FM update revoked every Codex seat; it happened to all three at today's 15:17Z update. The handoff fixture gains a `remote` option that reproduces that shape.

Evidence: L1 (unit handoff arms through the real issuer and journal; red-first on `dev` reproduces the installed failure line) → L3 required (AC-4, an installed FM update with the three Codex seats running). Residual: AC-4, Residual-Owner: #1198

- **One semantic edge.** A planned target the issuer never granted is now set aside instead of refused. It holds no grant, so no authority can return through it (ADR 0034 §2.5 item 4).
