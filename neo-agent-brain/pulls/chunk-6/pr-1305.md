Resolves #1302
Related: neomjs/neo#20114, #1282

Terminates the full detached process group (`-bridgeProcess.pid`) when `ConnectionService.manageConnection({action: 'stop'})` stops a Bridge spawned by this server, waits until its TCP listener port closes before returning `{message: 'Neural Link Bridge stopped.'}` (throwing if the port remains open, while leaving externally started Bridges untouched when `bridgeProcess === null`), and installs stdio `end`/`close`, `SIGINT`/`SIGTERM`/`SIGHUP`, and parent-orphan exit supervision across `Server.mjs` and `standalone.mjs` so closing `stdin` or killing a parent launcher shell cleanly ends the MCP server process.

Evidence: L2 (Playwright child-process & loopback TCP/WebSocket harness in `ConnectionService.spec.mjs` and `standalone.spec.mjs`) → L2 required (AC-1..3 process-group termination, port release, stdio EOF, and parent-termination exit).

| AC-3 | `test/playwright/unit/ai/services/neural-link/ConnectionService.spec.mjs` (`manageConnection stop never stops an already-running external Bridge that this server did not spawn (#1302)`) |

## Deltas from ticket
- **Parent-death supervision:** Added `isParentProcessAlive` (`ppid` change or `kill(ppid, 0)` poll in `standalone.mjs#superviseChild` and `Server.mjs#installStdioLifecycle`) alongside direct `SIGINT`/`SIGTERM`/`SIGHUP` forwarding so parent shells/launchers that exit without forwarding `SIGTERM` or closing `stdin` still terminate the MCP server.
- **Bridge-lifetime disposition:** A spawned Bridge (`detached: true`, `unref()`) intentionally outlives the stdio MCP server when the session ends on `stdin` EOF or parent exit (`#1302` Out of Scope, preserving shared-Bridge survival across reconnects/seats); only an explicit `manage_connection({action: 'stop'})` terminates a Bridge spawned by that server.
- **`win32` limitation:** Process-group signaling via `process.kill(-pid, signal)` is POSIX-only (`process.platform !== 'win32'`). On Windows, `signalBridgeProcess` signals only the `npm` wrapper process and `stopBridgeProcess` rejects honestly when the child listener port remains bound.
- **Executable launcher mode:** Set `0o755` (`100755`) on `ai/mcp/server/neural-link/standalone.mjs` in git so `npx` / `.bin` symlink invocation executes the launcher directly without `EACCES`.
