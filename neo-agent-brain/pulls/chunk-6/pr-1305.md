Resolves #1302
Related: neomjs/neo#20114, #1282

Terminates the full detached process group (`-bridgeProcess.pid`) when `ConnectionService.manageConnection({action: 'stop'})` stops a Bridge spawned by this server, waits until its TCP listener port closes before returning `{message: 'Neural Link Bridge stopped.'}` (throwing if the port remains open, while leaving externally started Bridges untouched when `bridgeProcess === null`), and installs stdio `end`/`close`, `SIGINT`/`SIGTERM`/`SIGHUP`, and parent-orphan exit supervision across `Server.mjs` and `standalone.mjs` so closing `stdin` or sending `SIGTERM` to `npx` cleanly ends the MCP server process.

Evidence: L2 (Playwright child-process & loopback TCP/WebSocket harness in `ConnectionService.spec.mjs` and `standalone.spec.mjs`) → L2 required (AC-1..3 process-group termination, port release, stdio EOF, and `npx` `SIGTERM` exit).

## AC Evidence
| AC-1 | `test/playwright/unit/ai/services/neural-link/ConnectionService.spec.mjs` (`manageConnection stop terminates a detached npm-spawned Bridge process group, waits until the Bridge port closes, and rejects if the port remains open (#1302)` + `run-bridge.mjs shuts down cleanly and releases its port on SIGTERM (#1302)`) |
| AC-2 | `test/playwright/unit/ai/mcp/server/neural-link/standalone.spec.mjs` (`closing the MCP server stdin ends the server process even while connected to a live Bridge (#1302)`, `SIGTERM to the npx process ends both the standalone launcher and the MCP server process (#1302)`, and `superviseChild forwards termination signals and kills the child when its parent process disappears (#1302)`) |
| AC-3 | `test/playwright/unit/ai/services/neural-link/ConnectionService.spec.mjs` (`manageConnection stop never stops an already-running external Bridge that this server did not spawn (#1302)`) |
