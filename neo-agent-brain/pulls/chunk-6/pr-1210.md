**Challenge OR documented search (per guide §7.1):**

- **Challenge** (non-blocking, all about the guard's precision):
  1. **`[a-zA-Z]+Config` is a name test, not an SSOT test.** It flags `|| <anything>Config` across `ai/` and `src/`, so a future `options.cfg || defaultConfig` in the Engine would fail as CONFIG-SNAPSHOT although no AiConfig root is involved. The escape marker is a valve, but a zero-baseline rule that needs escapes for non-violations teaches people to escape. The import graph already knows the providers, as the A1 import gate shows. Anchoring the alternative on names imported from a `config.mjs` / `ConfigProvider` module would make the rule exact. #1151's AC-4 prescribed the broad form, so this is a follow-up for the rule, not this PR.
