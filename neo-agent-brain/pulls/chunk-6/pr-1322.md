## Deltas from ticket

`observeStewardWake` returns `{attentionCounts, evaluation}` through one shared service projection, rather than reading counts again in the CLI. Direct Node invocation preserves the existing root/Cloud package boundary. Complete, stable zero-demand coverage is retained as an observed empty window; unavailable coverage cannot become a measured zero.

The runbook now uses a verified stable provider repository ID, with the mutable slug only in `displayLocator` (ADR 0036 §2.2). It also states the existing production ceiling: PR/Discussion collectors always retain unsupported-history gaps, so the all-family zero-gap projection currently degrades real GitHub sources and suppresses vacancy/payload calculation. This PR preserves that qualification guard and every provider gap. The parent's measurement disposition must precede an expensive scan intended to establish those metrics.
