Resolves #1282

Related: neomjs/neo#20114

The Neural Link now runs from its own npm package, with no Brain checkout. `npm run pack:neural-link -- --out <dir>` builds it from four things: the server's import closure (an acorn walk from its three entrypoints), its runtime assets, the config overlays `prepare` writes on a clean clone, and a manifest whose identity comes from one declaration, `ai/mcp/server/neural-link/server.json`. That file's `name` is the `mcpName`, and its new npm `packages` entry gives the package name and version. The result has nine dependencies, none native and none store-backed.

The package's `bin`, `standalone.mjs`, does two things before the server starts:
- it declares the standalone placement by env: `~/.neo-ai/neural-link`, with `logPath` beneath it;
- it passes the package root as `--cwd`.

So `ConnectionService#spawnBridge` starts the packaged Bridge through its existing path. ConnectionService, BaseServer and planeConfig are unchanged. ADR-0019 §10.7 gains the standalone row.

Evidence: L3 (a cold `npx` run of the packed tarball on this machine, with a fresh HOME and npm cache) → L3 required for AC-2. Residual: AC-6/AC-7 (the operator's first npm publish and the registry publish), Residual-Owner: neomjs/neo#20114.

Decision Record impact: amends `neomjs/neo-agent-brain#adr:0019-aiconfig-reactive-provider-ssot` (§10.7, the standalone Neural Link package row; checked against §5: the launcher sets leaf env vars and reads none, so there is no second resolver, and no profile is inferred from install location).
