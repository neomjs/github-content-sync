Resolves #1342

The roster generator now writes the Brain README's own row, `| - | [@login](…) | AI maintainer |`, and anchors on `| Name | Maintainer | Identity |`. It recognizes its pending row by that exact shape, so a login correction still repairs the row and a named or hand-edited row still fails closed. Rotation no longer touches the README. Its README half is a byte-stable boundary that refuses a row still carrying the prior ModelStats designation, because the README holds no model facts (#186). This #201 slice turns the last red in `generateRosterOnboarding.spec` green.
