Resolves #1254

Adds `projection: 'full' | 'compact' | 'counts'` (default `'full'`) to `list_messages` (`MailboxService.listMessages` + `openapi.yaml`). `'compact'` projects each surfaced row to the 9 triage fields (`messageId, from, to, sentAt, readAt, wakeSuppressed, priority, taskState, subject` truncated to 160 characters with `'…'`) while preserving `seenAt` stamping on `recordSeen: true`. `'counts'` ignores `limit`/`offset` (`paginationIgnored: true`), stamps no `seenAt`, and returns `{totalCount, unreadCount, byToClass, bySender, bySubjectTag, unreadDirectMessageIds}` in under 1,500 bytes for a 130-row unread inbox.

Evidence: L2 (Playwright unit suite + subprocess MCP tool dispatch + OpenAPI service-parity lint) → L4 required (AC-5 live post-merge seat recovery + `context-recovery` and `session-sunset` follow-ups in `neo-agent-skills`). Residual: AC-5, Residual-Owner: #1250.
