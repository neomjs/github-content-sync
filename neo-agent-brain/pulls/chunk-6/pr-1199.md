Resolves #1196
Refs #1151

Adds stat-signature caching (`ino:size:mtimeMs:ctimeMs`) for reconciled (`0` pending) WAL segments in `readPendingWalRecords` (`memoryWalStore.mjs`) and `readPendingMessageWalRecords` (`messageWalStore.mjs`) so steady-state 250 ms drain polls skip re-reading and `JSON.parse`-ing historical JSONL segment files when file metadata is unchanged, and adds `pruneReconciledMessageWalSegments` wired into `appendWalMessage` (`MailboxService.addMessage`) via detached `.catch(() => {})` scheduling off the awaited append return path so reconciled non-active message-WAL segments are bounded by `retentionLimit` (`aiConfig.memoryWal.retentionLimit`, shared across both WAL families per ADR 0019 C4) without blocking `add_message` on historical segment reads.

Evidence: L2 (Playwright unit specs for `memoryWalStore` and `messageWalStore` with `fs.readFile` call-count instrumentation, read-gate falsifier proving `appendWalMessage` resolves before prune segment reads complete, and polled segment pruning verification) → L2 required (`AC-1`, `AC-2`, `AC-3`).
