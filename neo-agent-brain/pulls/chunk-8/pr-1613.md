Resolves #1607

Open-work wakes are now sent by the plane as `@system`. Until now they went through the operator's own `add_message` and arrived as the operator's messages: a human principal, high priority, first in every drain. The Fleet round now submits a bounded observation (repo, number, head, kind, episode, recipient, check names) to a new host-internal tool, `admit_open_work_wake`. The plane admits it only from the operator's verified session and checks every token. It composes the message in `openWorkWakeMessage.mjs`, which is now the one place the kinds and the wording live, and sends it at normal priority with its wake on. It records the operator as `task.observedBy`. This follows option (B) and the boundaries from Julia's design read (`IC_kwDOUBzDFM8AAAABlaFicQ`), accepted on the ticket.

Evidence: L2 (unit specs over the real graph and mailbox: intake, contract, round, strict reply gate) → L3 required (AC-4 on the installed FM). Residual: AC-4, Residual-Owner: #759.

## Deltas from ticket
- **Episode check:** grammar instead of "at most 128 characters". An open action's episode must be an ISO instant. A `post-merge` episode must be the producer's merge transition id for this PR and head, `<repo>#<n>@<head>:merged:open->merged#<instant>`, which runs past 128 characters for long repository names. So the episode carries no text of its own, and `openWorkWakeMessage.spec.mjs` checks that the reducer's real id passes.
- **One kind list:** the tool schema has no `kind` enum; `OPEN_WORK_WAKE_REASONS` is the list, and the planner imports it.
- **Strict reply gate:** a `system` sender is exempt (`MailboxService.mjs`, Julia's boundary 3). This also covers the Orchestrator's overdue-register DMs to a seat with no history. `MailboxService.spec.mjs` keeps an agent refused as the control.
- **Shared operator check:** `isHumanOperatorIdentity` is extracted from the `requestPublish` recipient check, which now calls it, and the intake's caller gate uses it too. `resolvePrincipalClass` is exported for the recipient check.
- **Tier `extended`:** the tool is the Fleet host's intake, not an agent tool, so it stays off seats' default surface (the Neural Link precedent in `openapi.yaml`).
- **Health gate:** the tool is exempt from the embedder health gate, as `add_message` is (`Server.mjs` `getHealthExemptTools`). It never embeds, and a refused call would drop a wake the round already admitted.
