Resolves #1620

Each knowledge-base spec that calls `SearchService.ask()` now resets `SearchService.askCallTimestamps` before every test. The synthesis rate cap (20 per minute by default) keeps its window on the singleton, and a Playwright worker runs many spec files in one process. A test that came after the twentieth model-reaching ask in its worker's minute got degraded references and no prompt. That was the `capturedPrompt: null` red on PR #1613, which depended on CI's worker layout, not on that PR's diff.

Evidence: L2 (a deterministic red and green, made by binding the cap's own env leaf `NEO_KB_ASK_MAX_RPM` at process start, ADR-0019 rung (ii)) → L2 required (AC-1, AC-2).
