Resolves #1625

The operator's present/away mode is now plane state. `set_operator_presence` writes one shared graph record and refuses any caller that is not the Fleet's human operator. Both `who_is_online` answers carry the record as `operatorPresence`, and an `away` past its `until` reads `present` with `expired: true`. The write answers `changed`, so the FM toggle (`neomjs/neo-agent-institution#929`) sends its one broadcast per change without reading first.

Evidence: L2 (unit specs, including set → read across the `callTool` dispatch) → L2 required (AC-3 names specs as the evidence). Residual: none.

## AC Evidence
| AC-1 | CI-covered: `OperatorPresenceService.spec.mjs` "the operator goes away until morning, and every seat reads it", "an agent is refused, and the record stays as it was", "a call with no bound identity is refused" |
| AC-2 | CI-covered: `WakeSubscriptionService.spec.mjs` "the operator's mode crosses the dispatch: set_operator_presence writes it, both answers carry it (#1625)"; `OperatorPresenceService.spec.mjs` "an away past its until reads present, flagged expired, and returning after it is no change" |
| AC-3 | CI-covered: `OperatorPresenceService.spec.mjs` (8 tests: set, read, expiry, refusal, invalid input), and the existing who_is_online schema pin now holds `operatorPresence` |

## Deltas from ticket
- **Owner:** a new graph-backed `OperatorPresenceService` beside `TurnPresenceService`. `WakeSubscriptionService` (~1.9k lines) only joins the read.
- **The write answers `changed`.** Only the record's owner knows whether a write changes what readers see, so #929's once-per-change broadcast needs no read first.
- **`admin` tier, health-exempt.** It is operator-only, so `harness-embedded` seats never list it. It is a one-node graph write, so the operator can still go away during an embedder outage.
- **Readers see the durable row,** read from SQLite like the roster, never a process cache. `sharedEntity: true` lets RLS-scoped reads (`get_node`) see it too.
- **The `TurnPresence` tag becomes `Presence`** and carries both tools, so the full-surface `initialize` catalog stays within its 15-line budget (`ServerInstructions.spec.mjs`).

Intake: drift probe zero (no `dev` commit since the ticket). Prescription checked: `ai/services/memory-core/WakeSubscriptionService.mjs` — better owner: `ai/services/memory-core/OperatorPresenceService.mjs` for the record and its gated write. Config is ruled out (ADR-0019 bans runtime mutation), and so is the mailbox, because a broadcast is an event, not state. The gate is `isHumanOperatorIdentity`, the operator predicate the open-work intake uses (#1613), and it is as strong as the plane's identity binding.
