🌿 The clear can no longer say "already clear" about a repo the daemon is still suppressing.

`clearTenantRepoBackoff` reads and writes the manifest under `createTenantRepoAccessKey(repo)`, the key the sweep writes, and the sweep's six key sites call the same function. Each outcome row carries `tenantId` beside `repoSlug`. The summary line says `unchanged` where it said `already clear`, because that count also holds `no-persisted-state` rows.
