Resolves #1722

A Claude sunset now rotates at once or not at all, and never into a copy.
- **Plane:** the receipt's turn ends at its writer's close: a terminal interval that the writer's own `add_memory` lands with. The turn's own tail no longer refuses its rotation, older intervals that never closed no longer hold it, and another session's close authorizes nothing.
- **Receiver:** a rotation types at the first 3 s pause, asked again every second, and fails 60 s after the receiver accepted it. It never types minutes late into a seat someone restarted by hand.
- **The keystroke itself is fenced.** An attempt the receiver stopped waiting for, a deadline crossed mid-attempt, or a seat another session claimed since the first attempt opens no session. The script re-checks the deadline right before Cmd+N.

Evidence: L2 (unit arms red on `dev` and green at the head; one receiver probe run on both trees) → L4 required (AC-6: a live Claude sunset rotating end to end, which needs a cut and a real sunset). Residual: AC-6, Residual-Owner: #1373.

## Deltas from ticket
- **The wake hold.** A false prompt also ended the plane's wake hold early. The receipt turn's tail now keeps the hold on: › "the wake hold stays on through the receipt turn's own tail and ends with activity after its close".
- **Dialog-gate defers.** A rotation deferred by the dialog gate is age-bounded and asked again every second too. Wakes keep the dialog gate's count bound.
- **Removed:** `HUMAN_INPUT_DEFER_BOUND`. The age bound replaces it, and the receiver was its only reader.
- **Round 1 (Emmy, 5907715379).** Two additions:
  - *Writer attribution.* A close counts only when a memory of the writer's own Memory Core session lands within `WRITER_CLOSE_SKEW_MS` of it; live, 1–2 ms apart. A memory after the receipt from a session already writing before it refuses the request. A session first seen after the receipt attributes nothing (Round 2), so a sunset turn whose session reconnected waits on presence alone.
  - *Effect fence.* It reads the seat holder the Claude wake listener records (`listeners/<seat>.json` beside the manifest) and the attempt's abort signal. A holder that appears after an unreadable first read trips it (Round 2). The script re-reads the holder right before Cmd+N, and an unreadable record refuses the keystroke.
- **Residual.** The receipt carries no sender session, so when another session saved more recently than the writer just before the receipt, the plane cannot tell it from the writer's reconnect. The host fence still refuses a session opened since the first attempt. Noted as a defect-note, not ticketed.
