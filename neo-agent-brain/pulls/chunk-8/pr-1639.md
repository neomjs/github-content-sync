Resolves #1618

The question box mirror now reads an ask the way the operator's case 3 does: once the turn's text or the ask recommends an option ("I'd", "I would", "I recommend", "my pick is"), the box hands that pick back whatever verb opens it. A bare "I'll" keeps today's agent-step gate. A box that asks what he saw, or a step only he takes ("Will you …", "Could you …"), stays his, beside the existing carves. In a turn the operator did not prompt, any ask blocks once, with a directive naming both exits. Both box reminders end on the ticket's test sentence.

Evidence: L2 (the matcher and the shared decision in unit; the adapter seam for "once") plus a replay of the real asks below.

### 🔬 Depth Floor

- **Challenge**: Two non-blocking regex boundary watchpoints verified via a standalone Node probe against `origin/pr-1639:ai/scripts/lifecycle/deferencePhraseMatch.mjs` (zero misfires in the 494-ask corpus, worth folding if `#1640` revisits this file):
  1. **Uncontracted negation on `i\s+would` in `RECOMMENDED_PICK` (`deferencePhraseMatch.mjs:354`):** `\b(?:i\s+would|i['’]d|...)` rejects contracted `"I wouldn't"` (no word boundary after `would`) and `"I do not recommend"` (`recommend` doesn't follow `i\s+`), but matches uncontracted `"I would not touch the schema yet."` (`matchWrapUpAskDeference({ask: 'Keep Option A?'}, 'I would not touch the schema yet.')` returns `'Keep Option A?'`). Adding `(?!\s+(?:not|never)\b)` after `i\s+would` and `i['’]d` closes that asymmetry.
  2. **Progressive observation verbs and duplicate `heard` in `HUMAN_ANSWER_ASK` (`deferencePhraseMatch.mjs:377`):** `\byou\s+(?:see|saw|seen|notice[ds]?|hear[ds]?|heard)\b` omits progressive `seeing` / `noticing` (`matchWrapUpAskDeference({ask: 'Are you seeing the spinner on reload?'}, 'I recommend waiting for reload.')` returns the ask, whereas `'Did you see the spinner?'` returns `null`), and `hear[ds]?|heard` lists `heard` twice.
