Resolves #1725

🌿 No backfill run can call itself done any more while the index still holds a message its sender took back.

A rerun now checks every message against the index, retracted ones included. A retracted message the index still holds, from a write that landed after its answer was lost or a retraction whose own delete failed, is deleted and counted as `compensated`; a dry run counts it without deleting. A failed delete, in this pass or in the mid-write compensation, is counted with `failed` instead of rejecting the run, and the next run retries it.

Evidence: L2 (unit arms on injected graph and collection doubles; the plane's index is out of a PR's reach) → L2 required (AC-1 to AC-5). Residual: AC-6, Residual-Owner: #35.
