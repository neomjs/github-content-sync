Resolves #1560

Omits the duplicate `description` field from `Neo.ai.mcp.ToolService#buildToolHandbookEntry` (`ai/mcp/ToolService.mjs:447-469`) and from `get_mcp_tool_handbook`'s `'200'` response schema across all 6 MCP server `openapi.yaml` specs (`file-system`, `github-workflow`, `gitlab-workflow`, `knowledge-base`, `memory-core`, `neural-link`), keeping `handbook` (`entry.handbook`) as the single prose field on every found tool. Across the 4 fleet MCP servers (`153` listed tools, measured by calling `getToolHandbook(tool.name)` on each listed tool of `memory-core`, `github-workflow`, `knowledge-base`, and `neural-link`), `151` operations do not define `x-neo-tool-handbook`, so `entry.description` and `entry.handbook` previously emitted the identical `operation.description` string twice (`75,831 B` of duplicate prose across the 4 fleet servers; `40,420 B` in `memory-core` alone; `2,798 B × 2` on `add_memory`). Graduated from `neomjs/neo` Discussion `#20680` (Track 2 — Option I).
