Resolves #1702

An outside pull request that names its model now needs its approval from another lab, in both places that decide it. Merge readiness compares an outside author's approvals with the families the PR names and blocks a same-lab-only approval as "mandate unsatisfied". The Fleet rotation never hands such a PR to a seat of a named lab while another seat answers. A same-lab head approval keeps the review open for a seat of another lab. An outside PR that names no model gets an advisory instead of the blocker that said the mandate does not apply. One roster-free reader, `ai/services/graph/disclosedModelFamilies.mjs`, decides what a PR names, from the body's disclosure lines and every commit's `Co-Authored-By` trailer. A PR with more commits than one read covers never reads as naming none.

Evidence: L2 (unit arms that fail with the source reverted and pass at head, plus both changed GraphQL documents run against GitHub) → L2 required (every AC is a pure decision or a query shape). Residual: none.
