Resolves #1682

A seat that writes its sunset handover can now continue in a fresh session through the host wake receiver.
- **Arming.** At every Start, the Fleet arms one `SESSION_ROTATE` route per Claude Desktop seat, addressed to the `userDataDir` it launched. That route admits only `session/rotate` envelopes; every other route admits only `wake/digest`.
- **Delivery.** On a rotation, the receiver raises the seat's own process, opens a fresh session with Cmd+3 then Cmd+N, and pastes and submits the event's prompt.
- **Guards.** It never types into a window picked by app name. It types only after a quiet minute of keyboard and pointer, because typed delivery races a person at the machine (#30).

The detector and emitter that send the event are #1383, whose installed receipt is blocked by #1682.

Evidence: L2 (mock dispatch: route admission, the step's argv and refusals, the human-input gate and its bound, Fleet arming against a scripted plane, subscribe idempotency through the tool path) → L4 required for AC-7 (an installed rotation of a live Claude seat). Residual: AC-7, Residual-Owner: #1383.

## Deltas from ticket
- **The context gate skips rotations.** A rotation exists because the session is full, so a size read could only hold it back. Wakes keep the gate.
- **Human input has its own defer bound.** It is 120 re-drains, about 2 h, beside the dialog's 20, because a person works longer than a dialog stays open. Exhaustion reads `human-input-defer-bound-exhausted:<reason>`.
- **`armFleetSeatWake` takes a `routeClass` (`wake` | `rotation`) instead of a second module.**
  - `FleetManager.armSeatWake` arms the rotation route after the wake route, through its own `rotationArmFn` seam.
  - It returns `rotationRoute` beside `wakeRoute` but does not yet record it on the lifecycle record. The card and journal are neomjs/neo-agent-institution#842's half.
- **One shortcut table.** Claude's `freshSessionShortcut: 'n'` moves from `harnessRouting.mjs` into `hostHarnessMetadata.mjs`, which the receiver and `resumeHarness` both read. That duplicate is the only deletion. The old loop (`checkSunsetted`'s sunset branch, `SwarmHeartbeatService` step 3, `resumeHarness`) retires with #1383's detector, which replaces it.
