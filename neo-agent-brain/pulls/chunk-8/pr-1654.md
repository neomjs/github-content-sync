Resolves #1646

🌿 "Nobody can see who still has quota" stops being true the moment a seat starts a turn.

Each seat's turn now carries its plan-capacity reading to the plane. The Claude hook reads the Desktop app's newest usage sample on `start` and hashes the account key before it leaves the seat. `record_turn_presence` stores the reading per seat (`SEAT_CAPACITY`), apart from the turn interval: newest observation per window, and a reset that still lies ahead carries over to a sample without one. Verbose `who_is_online` returns each seat's capacity as observed, stale or unobserved, plus a `pools` map across seats that share a pool key. The Fleet's throttle seam, empty since neomjs/neo#15272, gets its first reader: `rate-limited`, `none` or `unknown` from that reading, at one presence read per snapshot. The rotation skip moved to #1653.

Evidence: L2 (unit arms on every layer, plus this seat's real Desktop usage sample through the hook's reader) → L3 required (AC-4: real seats on a plane that runs this code). Residual: AC-4, Residual-Owner: #1653.
