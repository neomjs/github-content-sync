Resolves #1629

An outside pull request no longer waits unseen for either of the two reasons Julia found:
- **A bot's review is no touch.** The snapshot reads each latest review's author type, the reducer marks a bot's review, and `holderOf` leaves the row untouched, so it still goes to the rotation.
- **A rotation action first seen at baseline wakes one seat once.** Only an `admitted` rotation slot is kept as it is. A quiet round records the slot unsent, and any other round wakes one seat, the producer's first pulse included. Seat-held kinds keep their baseline.

Evidence: L2 (unit specs over the holder, the reducer, the planner and the gate) → L3 required (AC-5, a live outside pull request after the FM update). Residual: AC-5, Residual-Owner: #759.

## Deltas from ticket
Sharpened in the intake comment on #1629:
- **A stored `baseline` slot retries.** The live ledger already holds rotation slots stored as `baseline`. Keeping them as they are would leave every row observed before the deploy silent. `openWorkWakes.spec.mjs` covers a stored slot waking once, with its original episode.
- **A quiet round sends nothing.** `quiet` is `!activation` in `wireFleetOpenWorkWakes.mjs`, and a quiet round admits no send. A rotation row seen in one is recorded unsent, and the next round retries it. The ticket's "first pulse" is therefore the first activated pulse.
- **The previous snapshot stays priced.**
  - Reading the review author's type changes `OPEN_WORK_SNAPSHOT`, and with it the `queryHash`.
  - `wakeGateOf` refuses a retained failed call it cannot price, which would hold a not-yet-activated producer for the 24-hour window. An activated producer is unaffected, because activation is durable.
  - `OPEN_WORK_QUERY_COSTS` keeps the previous document's hash for one generation, and the next change to the document replaces that entry. #1630 is next.
  - The formula cost stays 3: the change adds a field, not a connection.
- **Left as it is:** a pending Copilot review request is `login:Copilot` and wakes nobody until Copilot posts. After that, the bot rule applies.
