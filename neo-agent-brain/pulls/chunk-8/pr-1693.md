Resolves #1383

🌿 A seat that writes its handover no longer waits for a person to open its next session, and no wake reaches the session that ended.

A container-plane `session-rotation` lane reads each rotatable seat's newest self-message. An open sunset handover becomes one signed `session/rotate` envelope on the seat's `SESSION_ROTATE` route (armed by the Fleet since #1682), keyed by the receipt's message id; the host receiver opens the fresh session and types its first prompt. A prompt or a newer session after the receipt refuses it, a re-send of a request the receiver never accepted included, and so does a second request inside the minimum interval; each step is a record on the handover node (`sessionRotation`) and an orchestrator log line. While a receipt waits, the plane holds the seat's wakes on both delivery paths: `poll-digest` keeps the watermark, and a push digest stays queued in the coalescing engine, so the fresh session receives them. `checkSunsetted` now reads the sunset from the receipt, and the graphless restart loop it fed retires.

Evidence: L2 (unit: the lane over in-memory graphs, the hold through `poll-digest` and the push digest, and one envelope through the real `WebhookDeliveryService` into a live receiver on a rotation route) → L4 required for AC-13 and AC-14 (a rotation on an installed plane, by day and by night). Residual: AC-13, AC-14, Residual-Owner: #1373.

## Deltas from ticket
- **The detector is a new lane, not `checkSunsetted`.** The rotation needs the graph, so it runs in the container plane (`scheduling/sessionRotation.mjs`, sibling of the expiry sweep). `checkSunsetted` reads the same receipt only to keep the idle nudge off an ended session.
- **The receipt reads live in their own import-free module** (`ai/daemons/wake/sunsetReceipt.mjs`), not in `queries.mjs`: Memory Core's hold imports them, and `queries.mjs` would make `better-sqlite3` statically reachable from `ai/services.mjs` (`hostBarrelImportReach.spec.mjs`).
- **"Terminal presence" is read as "no prompt since the receipt" plus "the turn that wrote it has ended".** A woken Claude turn runs `UserPromptSubmit`, so presence alone cannot tell a wake from a person; the hold removes woken turns, and a typed wake carries its nonce.
- **The id is written before the send** (`sessionRotation.eventId` on the handover); a send the receiver never accepted goes again under that id, which the receiver collapses.
- **`runTaskExpirySweepTask` became `runCountingLaneTask`**, shared by both graph lanes instead of a second copy.
- **Deleted:** `resumeHarness.mjs`, `harnessLifecycle.mjs`, `windowsBatchSpawn.mjs` and their specs, the heartbeat's sunset branch and `harnessStateDir`. Windows keeps no fresh-session path (`WindowsSupport.md` says so).
- Two criteria struck and two restated on the ticket (sixth amendment): no plane-side context reading exists for a Claude seat, and repair routing is #1373's.
