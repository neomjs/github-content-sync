Resolves #1590

Antigravity seats now start from the Fleet's admitted builds by default: `fleet.harnessGenerations.antigravity` is `true`. An opted-in Start admits the installed `/Applications` bundle only to bootstrap a family that holds no generation. The installed 2.30.0 therefore no longer displaces the store's feed-admitted 2.31.0, which was the downgrade #1590 measured. Unit workers now resolve the store root beneath their own Fleet root, never the host's `~/.neo-ai/harnesses`.

Evidence: L2 (unit: a held newer build wins over an unseen older installed bundle, red on `dev`; the unit run's store root, red on `dev`) → L4 required (AC-5, AC-6: on the operator's Mac, a restarted seat runs the generation copy, and the next vendor release reaches it). Residual: AC-5, AC-6, Residual-Owner: #1531.
