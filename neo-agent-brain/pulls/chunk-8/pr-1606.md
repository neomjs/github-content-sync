Resolves #1594

Fleet now reads `AGENTS.md` as a Claude project file, after `CLAUDE.md` and `.claude/CLAUDE.md`, which is Claude Code's own fallback. A checkout file whose first line is the Engine's pointer marker (`<!-- neo-agents-md: pointer -->`, neomjs/neo#20749) counts as not supplied, for every harness. A checkout whose generation failed therefore gets the home copy. Before this change, a Claude seat on the Engine whose generation failed would have launched with the 328-byte pointer as its only instructions, because `.claude/CLAUDE.md` links to `AGENTS.md`.

Evidence: L2 (fake-filesystem projection arms, and a red-first runner over base and head) → L2 required (AC-1, AC-2, AC-3).

|---|---|

Its control: a generated `AGENTS.md` with no `CLAUDE.md` is `repository-supplied`, reason `the checkout carries AGENTS.md`. Also the per-harness table arm, where `claude-code` now lists `AGENTS.md` |
| AC-2 | CI: the same arm. A `claude-code` checkout whose `.claude/CLAUDE.md` and `AGENTS.md` hold the pointer, and a `codex` checkout whose `AGENTS.md` holds it, are `projected`; `ignored` names each file with `the pointer: no rules were generated` |
| AC-3 | CI: the other arms pass. The per-harness table arm gains `AGENTS.md` for `claude-code`, the ticket's first rule (see Deltas) |

## Deltas from ticket
- AC-3 said the existing arms pass unchanged. One arm tabulates which files each harness reads, so its `claude-code` row gains `AGENTS.md`. The projection now reads a file's first line, so the fake filesystem gives a readable file default rules content.
- The marker is copied from the Engine (`AGENTS_MD_POINTER` in `buildScripts/util/agentsMdPointer.mjs`), because this repository pins the Engine at `cc24c59e`, before the pointer existed. A spec arm compares the copy with the pinned Engine's pointer: it skips while the pin predates the pointer and asserts once a pin bump carries it. The copy becomes an import then.
- A file that vanishes between `stat` and the read now reads as absent (`ENOENT`), like one that was never there.

  - Head: all three green.
