Resolves #1722

A sunset's rotation now waits only on the turn that wrote its receipt. `readSunsetReceipt` used to take the latest expiry over every active turn-presence interval begun by the receipt's time. A turn that ends without `add_memory` stays active for its whole TTL, so it held the rotation after the sunset turn had closed. The read now takes the newest interval started at or before the receipt, which is live while it is active and unexpired. An older open interval holds nothing.

Evidence: L2 (the lane over an in-memory graph, plus the real `TurnPresenceService` writer and `add_memory`) → L4 required for AC-3 (a live Claude sunset; it can only run after the cut). Residual: AC-3, Residual-Owner: #1373
