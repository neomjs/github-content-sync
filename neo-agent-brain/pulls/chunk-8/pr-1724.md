Resolves #1723

Antigravity App 2.32.1 supplies its sidecar a bare loopback host and port. The installed trial refused it before it could observe a main session. This change accepts that address and the HTTP(S) loopback origin form. It passes the original environment unchanged to the vendor sender. The App ancestry check now walks past an Antigravity Helper to the actual main executable, and startup reports a bounded failure category.

Evidence: L3 actual vendor child metadata on the failing build and repaired dispatch fixtures. L4 installed signed delivery remains on #571.
