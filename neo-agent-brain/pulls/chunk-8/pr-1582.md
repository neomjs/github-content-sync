### 🔬 Depth Floor

**Challenge OR documented search (per guide §7.1):**

- **Challenge**: `formatTurnDocumentForRead` matches every line that starts with `Agent Thought: `, so a prompt or response that quotes such a line is relabelled too. The turn text has no escaping, so a regex cannot tell the structural header from content. Where the split metadata is complete, the read can compose the text with the read label and skip the regex, which is then needed only for a stored document without metadata. Non-blocking: rare, and it changes a label inside quoted text, never a decision.

Also to watch, none blocking:
- `weight: e.properties?.weight || 1.0` is now the sort key, and a broadcast's `SENT_TO` edge is written with weight 0, so those edges sort as 1.0. `??` keeps a real zero.
