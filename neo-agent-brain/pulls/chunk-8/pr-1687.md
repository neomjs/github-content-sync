Resolves #1679

🌿 A deadline on a Task becomes a promise the plane keeps, and "swept nothing" can no longer mean "never looked".

The Task expiry sweep moves from the swarm heartbeat, a host-edge lane that is graphless by contract, to a `task-expiry-sweep` lane the container-plane role owns. It runs on its own cadence leaf `orchestrator.intervals.taskExpirySweepMs` (ten minutes, `<= 0` disables), without the heavy-maintenance lease like its light siblings, and records each run's `sweptCount`; a run that expires Tasks logs one INFO line. `Orchestrator#sweepExpiredTasks` awaits the graph and throws without one, so a plane whose graph failed to mount records failed runs instead of successful sweeps of nothing.

**Merge waits** for #1679's go-live precondition: Home counts what expired (the design seat's Institution leaf), or the operator declines that count in words. The first run on our plane expires 11 open asks to him that carry a deadline ([measured](https://github.com/neomjs/neo-agent-brain/issues/1679#issuecomment-6854510486)). Review can run now.

Evidence: L2 (unit: one scheduling-pipeline run against the in-memory test graph) → L4 required (AC-5: a probe Task on the live plane reads `Expired` within one cadence after the cut). Residual: AC-5, Residual-Owner: neomjs/neo-agent-institution#951.
