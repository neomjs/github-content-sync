Resolves #1674

🌿 "The plane needs about that much" now has to name a window, its coverage and its command, or it is not a figure.

The plane gets a sampler for its containers. `ai/scripts/benchmark/plane-sampler.mjs` reads each container of a compose project through `docker exec` into its own cgroup, once per tick, and writes every tick to `samples.jsonl` and a summary to `report.json`. The rules live in the pure `helpers/planeSamplerCore.mjs`:

- A series is one container's. A service with replicas has one entry per replica; nothing is summed or differenced across them.
- Resident heap is `memory.stat`'s `anon` alone.
- A failed read is a gap. An I/O or network part that failed or is malformed is `null`; an empty one is a measured 0.
- An interval in which any counter went backwards is dropped whole and counted as a reset.
- A figure without a usable interval is `null`, and `intervals` says on how many each figure rests.
- Volumes belong to the project by its compose label, not by a name prefix.

`learn/agentos/measurements/plane-sampler.md` records the method, what the figures leave out, and one reference run.

The instrument existed outside this repository since 2026-10-27; this is its port into the Brain's shape (a pure core, `commander`, `isEntryModule`, the one percentile of `helpers/stats.mjs`). It reads no AiConfig.

Change class: capability (`feat`).

Evidence: L2 (unit: 16 core arms and 3 CLI arms against a stand-in `docker`, CI-covered) plus one live run against a plane (outside CI) → L2 required for AC-1 to AC-4 and AC-7, a live run for AC-5. Residual: none.

## Deltas from ticket

- `--project` is required. The ledger listed it without a default, and a default would name one deployment.
- Rules the port adds to the original: a read without cgroup v2 memory and CPU throws and so counts as a gap; an `--out` that already holds `samples.jsonl` is refused instead of appended to; the report is built by a pure function from injected timestamps.
- A window of ten minutes at 30 s holds 19 intervals, so its p95 equals its maximum. The page says so.
- The first CI run was red in `unit`: `lint-retry-bounds` classifies every exponent expression under `ai/`, and the port wrote two byte sizes as `2 ** n`. They are products now.
- Round 1 (Emmy), at the fourth commit. The ticket's ledger and "The Fix" follow these on #1674:
  - the report is keyed by container (`containers`, each with its `service`), and every row of `samples.jsonl` names its container;
  - `restarts` became `resets` and covers every cumulative counter;
  - byte totals are `null` without a usable interval, and `intervals` is new;
  - expected ticks round up, the last wait ends with the window, and a stop interrupts it;
  - volumes are read by the project's label.
