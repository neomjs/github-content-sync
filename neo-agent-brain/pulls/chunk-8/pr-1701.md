Resolves #1685

Strategic anchors in the Native Edge Graph now expire on the session's own clock unless actively re-asserted and clear immediately when a backing work item closes or merges: `GraphService#upsertNode` is the single write-seam owner of stored anchor lifetime—clearing `gravity_well` (while preserving `strategic_weight` history) whenever an `ISSUE`, `PULL_REQUEST`, or `DISCUSSION` lands with `CLOSED` or `MERGED` state and keeping the later `gravity_well_asserted_at` across interleaved sessions—`SemanticGraphExtractor` stamps `gravity_well_asserted_at` from `resolveSessionTimestamp(session?.meta)` only when a session asserts `gravity_well: true` (omitting anchor fields otherwise), and `GraphService#readSceneGraph` emits `gravityWell: 1` only for open/non-terminal anchors asserted within `strategicAnchorWindowMs` (`NEO_GRAPH_STRATEGIC_ANCHOR_WINDOW_MS`, 30d default via `parsePositiveWindowMs`).

Evidence: L3 (live plane `get_graph_scene` census over 213,930 nodes + real SQLite scene-read verification) → L4 required (AC-6 installed Observatory Roadmap walk after Brain deploy). Residual: AC-6, Residual-Owner: neomjs/neo-agent-institution#485.

Decision Record impact: aligned-with `adr:0019-aiconfig-reactive-provider-ssot`, `adr:0024-native-edge-graph-model`.
