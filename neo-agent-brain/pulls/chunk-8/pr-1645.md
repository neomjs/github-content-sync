Resolves #1640

The Claude Stop hook's night arm now keys on the operator's recorded presence instead of guessing it from the prompt. The Fleet mirrors the plane's presence into `operator-presence.json` beneath `fleet.dataDir`, on a `changed` write and on any roster read that disagrees and overlapped no presence write (`ai/services/fleet/operatorPresenceRecord.mjs`). Every Start hands the seat that path under a new reserved slot, `NEO_OPERATOR_PRESENCE_PATH`, read as `seat.operatorPresencePath`. The hook reads it with one file read:
- an `away` record blocks a box ask in any turn, the operator's own handoff included, and the reminder names when Nightshift went on;
- an operator message past the grace ends the away whatever it says; a `[WAKE]` or synthetic turn never does;
- a `present` record silences the unattended arm;
- no record, including the plane's never-set `{mode: 'present', since: null}`, keeps #1639's prompting classifier.

Evidence: L2 (unit specs, plus the real hook script run end to end, below) → L3 required (AC-7: an installed FM writes the record and a live seat's turn blocks). Residual: AC-7
