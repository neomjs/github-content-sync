Resolves #1710

A sunset handover now reaches the summary lane, which stamps its receipt count. The session-rotation lane can then request the fresh session instead of waiting until a prompt refuses it. The handover reader selected `$.type = 'MESSAGE'`, but the store writes messages as `{id, label, properties}`, so it matched none of the plane's 580 handovers. It now selects the label and reads only handovers sent inside the session-rotation window (`orchestrator.sessionRotation.windowMs`, 3 h). The summary lane reads that window from its scheduling `intervals`.
