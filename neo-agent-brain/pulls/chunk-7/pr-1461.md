Resolves #1460

A micro review's bulleted metadata did not end its Findings section, so the attribution self-check became a synthetic author action. Round 2 then rejected the correct one-row disposition. The extractor now recognizes bulleted bold metadata as a section boundary while retaining actual checkbox findings, including bold action labels.

Evidence: L1 (production relation validator and existing service unit coverage) → L1 required (review-document parsing contract).
