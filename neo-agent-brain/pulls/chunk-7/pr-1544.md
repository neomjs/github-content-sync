Resolves #1539

Implements the Antigravity update-suppression and feed-acquisition leaf (AC-5) of Epic #1531:
- **In-seat update suppression (`ai/services/fleet/prepareManagedAgentWorkspace.mjs`):** Adds `convergeAntigravityAppStorage` and calls it from `prepareAntigravityArtifacts` (`lines 1683-1730`), converging `"autoCheckForUpdates": "false"` into `<instanceHome>/app_storage.json` while preserving unrelated runtime keys (`hubSurfaceColor`, `wcv-*`) and failing closed (`FLEET_WORKSPACE_DIVERGENT`) on symlinks, malformed JSON, or non-boolean-string `autoCheckForUpdates` values.
- **Feed acquisition + streaming SHA-512 verification (`ai/services/fleet/antigravityUpdate.mjs`):**
  - `readAntigravityUpdateConfig` reads `Contents/Resources/app-update.yml` and `Contents/Info.plist` (`com.google.antigravity`) and derives the `https://` `latest-${arch}-mac.yml` manifest URL.
  - `parseAntigravityUpdateManifest` parses `electron-updater` YAML (`version`, `files[0].url`, `files[0].sha512`, `files[0].size`), refusing stub or non-HTTPS manifests and validating 64-byte base64 SHA-512 digests.
  - `verifyAntigravityArchive` and `streamAndVerifyAntigravityArchive` stream archive responses to disk through a `Transform` byte-length limiter and incremental `createHash("sha512")`, checking exact byte length and SHA-512 digest via `crypto.timingSafeEqual` before extraction.
  - `checkAntigravityUpdate` and `acquireAntigravityUpdate` fetch `latest-${arch}-mac.yml`, read the family ledger via `readHarnessGenerationLedger` (`ai/services/fleet/harnessGeneration.mjs`), short-circuit `up-to-date` and same-admitter `already-rejected` builds (expiring automatically when the admitting code changes), extract `Antigravity.app` via `/usr/bin/ditto -x -k`, and hand the bundle to `materializeHarnessGeneration`.
