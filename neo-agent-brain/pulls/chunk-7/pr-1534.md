Resolves #1532

This adds `ai/services/fleet/harnessGeneration.mjs`, the engine of epic #1531. A vendor GUI harness build becomes an immutable, admitted copy under `<root>/<family>/<id>/` only if every check passes on the copy:
- the bundle id;
- the signing Team ID;
- `codesign --verify --deep --strict`;
- the Gatekeeper assessment;
- the family's capability probe.

A rejection records its reason and never changes the selection. That is the shape that turns this week's Codex outage (#1530) into a recorded verdict. No seat behaviour changes here; the seat-Start leaf wires it in.

Evidence: L2 (CI: unit specs with injected host seams) → L3 required (AC-5: real installed bundles), achieved by the host witness below. Residual: none.
