Resolves #1392

Keeps `pending` as the single settlement owner in `ai/mcp/client/stdioToStreamableHttp.mjs` until a received response is committed to `localTransport.send(message)` in the deferred microtask or `retire()` / `answerFailure()` settles an unreceived request. Marking `request.received = true` on valid response receipt in `wire().onmessage` prevents `retire()` and `answerFailure()` from racing a received response while preserving duplicate-response rejection, retired-generation callback fences, non-response stale-generation fences, and terminal local-close gating.

Evidence: L1 (unit suite verified on inert transport callbacks and loopback HTTP server in `StdioToStreamableHttp.spec.mjs`) → L1 required (AC-1..AC-4).
