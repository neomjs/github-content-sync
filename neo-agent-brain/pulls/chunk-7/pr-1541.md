Resolves #1535

The open-work producer now reads only with each seat's own PAT: the Fleet entrypoint no longer hands the process's `GH_TOKEN` to every seat.

The PRs no seat authored are read in one search across every repository instead of one per repository. The reading seat's PAT goes from 14 searches (42 points) to 1 search (3 points) a pulse.

A PAT that GitHub answers with `INSUFFICIENT_SCOPES` is now named as refused, with the new-token next step, instead of "the next pulse reads again".

Evidence: L3 (unit specs, plus two read-only live probes: `wakeGateOf` over the installed Fleet's state, and the producer's query against GitHub) → L4 required (AC1–AC4: certification on the installed Fleet over 24 h, the flag on, live wakes). Residual: AC1, AC2, AC3, AC4, Residual-Owner: #759.
