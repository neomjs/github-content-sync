Resolves #936

With multiple Codex instances open, System Events could resolve the intended process and then rebind a saved process object to a same-named sibling. The wake guard consequently reported a false focus loss and never reached prompt delivery. Addressed Codex routes now retain only the numeric System Events process ID, use it directly for activation and input, and compare an atomic foreground-PID read against the intended Unix PID. Non-Codex routing and draft restoration remain unchanged.

Evidence: L3 (native compilation, exact-target negative controls, and automatic wake arrival through the installed candidate) → L3 required (live intended-chat delivery). Residual: AC5 final merged-source adoption, Residual-Owner: #30.

| AC-2 | The generated native guard passed the intended process and refused a same-bundle sibling, a missing process, and a rebound automation ID. [Independent receipt](https://github.com/neomjs/neo-agent-brain/issues/936#issuecomment-6513270229). |
| AC-3 | Existing adapter and dialog-gate tests retain draft capture, submit/restore boundaries and non-Codex behavior. |

## Deltas from ticket
The live falsifier identified stored process-reference aliasing, so this uses direct System Events numeric IDs and atomic foreground observation instead of the ticket's proposed AppKit activation rewrite. No new adapter, route, configuration or retry loop.

The unchanged dialog-probe expression `role of focused element of window 1` fails native compilation in both installed baseline and candidate; out of scope, noted in defect-note `MESSAGE:2a9d7a7d-9ef9-4585-9b2a-2e2804059733`.

## Test Evidence
Native compile and guard controls were independently repeated by Sophie. The host receiver was reloaded while idle using the exact tested adapter digest; its unknown-record count did not increase. Its delivery receipt and actual automatic message arrival agree for Emmy; a subsequent normal-priority wake arrived in the same chat as well. These observations establish the repaired local delivery path, not indefinite reliability or other hosts.
