## Summary

Adds the guarded `update_issue_body` MCP tool (`IssueService#updateIssueBody` + `/issues/body/update` OpenAPI route) to `neo-mjs-github-workflow` so seats whose harness shell policy refuses `gh issue edit` can replace issue and pull-request bodies directly over MCP when the 15-comment thread cap redirects live state into the body.
