Resolves #1370

A unit run now sheds the placement and git identity it inherits from the shell that starts it.

`test/playwright/isolateUnitEnvironment.mjs` runs before `configTemplateResolver.mjs` binds the harness values, and removes three things:
- the plane identity;
- every path-valued `NEO_*` name (`*_PATH`, `*_DIR`, `*_ROOT`, `*_BASE`);
- `GIT_AUTHOR_*` and `GIT_COMMITTER_*`.

So a seat's Fleet Manager placement no longer moves the config's prod leaves or counts plane members as placed, and the seat's identity no longer overrides a fixture's. `NEO_TEST_*`, endpoints, credentials and the agent identity stay. Workers inherit the harness boundary and skip the scrub.

Evidence: L2 (pure unit arms, plus full suite runs in an FM-launched seat with the seat environment present) → L2 required (AC-1 needs an FM seat; AC-2 and AC-3 are CI properties). Residual: none.

## Deltas from ticket
The scrub is narrower than the ticket first proposed, and the ticket body is corrected to match:
- **The broad scrub turned five local passes red.** Removing every inherited `NEO_*` name broke `McpServersHealth`'s remote boots, which need `NEO_MCP_REMOTE_TOKEN`, and three `SessionService` arms, which reach the model host. CI skips those specs through `NEO_TEST_SKIP_CI`.
- **So only placement goes.** Endpoints and credentials stay.

## Test Evidence
- **Same instrument on base:** on `b6f24069`, the same eight files fail the ten arms in this seat.
- **Full unit suite at head in the seat:** 14,752 passed and 2 failed, plus 1 flaky that passed on retry.
  - Skips fall from 29 before this change to 13, because specs that skipped under the seat environment now run, and pass.
  - The two failures were the pre-existing neural-link boot, and `LiveServiceGuards` flagging my own spec fixture, which named a model port beside `NEO_TEST_SKIP_CI`. The fixture now names a port-less `.test` host.
  - The flaky `HealthService.starvationFold` arm passes 80 of 80 in isolation.

  - Both seat runs show a `HealthService.starvationFold` arm passing on retry under full parallel load, a different arm each time.
  - Brain Unit's comparison on this PR shows whether that is base behaviour.
