Resolves #1480

Start now brings each seat checkout current before the harness launches. It runs three steps, each recorded on the checkout's dependency row, and none of them ever blocks the launch:
- it fast-forwards a clean checkout on its default branch (`update`);
- it installs keyed by the lockfile digest, adopting a current tree the Fleet never installed (`adoptedFrom: 'unverified'` in the receipt);
- it runs the repository's own `seat:start` script (`seatStart`).

Evidence: L2 (unit arms, with the fast-forward run against real git and a local remote, plus the full Brain unit suite) → L2 required (AC-1 to AC-6). Residual: neo's `seat:start`, Residual-Owner: neomjs/neo#20429; the installed receipt after a Fleet restart and the sunset Step 1 retirement, Residual-Owner: neomjs/neo-agent-skills#289.

Class: capability (`feat`).

**Merge order:** after neo pins `neo-agent-skills` ≥ 0.1.88. Met: neo `dev` pins 0.1.90 since neomjs/neo#20442. On an older pin, the first Start after merge would reinstall each seat with the 250k sunset gate that neomjs/neo-agent-skills#275 removes.

## Deltas from ticket
- The fast-forward lives in `ensureAgentRepo.mjs`, beside the trust proof it calls. Its fetch shares the clone's credential path through `gitRemoteCommand`, extracted from `gitCloneCommand`.
- Every git call runs with the checkout's hooks and fsmonitor off, no host config and none of the Fleet's environment, because the checkout is the seat's to write. The merge also refuses to overwrite an ignored file. Real-git arms show that a hook and an ignored file which a plain merge runs or replaces stay untouched here.
- The Brain declares no `seat:start` of its own here. ADR-0019 §5.6 makes `--migrate-config` a config-lifecycle decision, which neomjs/neo-agent-skills#289 now carries.
