Resolves #78

The deference mirror now reads live operator dialogue the way the operator ruled on 2026-08-25, and it reads the Claude desktop wrap-up `ask`.

- **Text in dialogue.** `detectDeferencePhrase` no longer carves every operator-prompted turn. A registry phrase fires there only after a pick the agent stated itself in the same paragraph (case 3: "I'd …", "I recommend …", "that's next"). A paragraph that names a peer deadlock (case 1) or operator-owned work (case 2) stays carved. Autonomous turns are unchanged.
- **The wrap-up ask.** The Claude adapter reads the turn's newest `mcp__ccd_turn__wrap_up` call. Its `ask` is a handback when two things hold: the turn's text states the pick, and the ask is a go-ahead on the agent's own step ("Should I …", "Fix/Run/File/Review …"). It stays carved when it names operator-owned work.
- **The phrase registry is not widened.**
