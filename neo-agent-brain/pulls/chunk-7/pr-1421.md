Updates `sass` from 1.106.1 to 1.107.0
<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="[QUARANTINED_URL: github.com]">sass's releases</a>.</em></p>
<blockquote>
<h2>Dart Sass 1.107.0</h2>
<p>To install Sass 1.107.0, download one of the packages below and <a href="[QUARANTINED_URL: katiek2.github.io]">add it to your PATH</a>, or see <a href="[QUARANTINED_URL: sass-lang.com]">the Sass website</a> for full installation instructions.</p>
<h1>Changes</h1>
<h3>Command-Line Interface</h3>
<ul>
<li>
<p>The <code>--fatal-deprecation</code> flag can now exclude deprecations that would otherwise be included by passing a version number. To exclude a deprecation, add <code>-</code> before its name. For example, <code>--fatal-deprecation=1.107.0,-import</code> includes all deprecations that were present in Dart Sass 1.107.0 <em>except</em> for the <code>@import</code> deprecation.</p>
</li>
<li>
<p>The <code>--fatal-deprecation</code> flag now takes the special value <code>dart-sass-2</code>, which treats as fatal all deprecations that will become fatal in Dart Sass 2.0.0.</p>
</li>
</ul>
<h3>JavaScript API</h3>
<ul>
<li>
<p><code>Options.fatalDeprecations</code> can now take a <code>DeprecationSelectorDifference</code> object of the form <code>{include: ..., except: ...}</code>, where the <code>include</code> field lists deprecations to mark fatal (which can be version numbers) and the <code>except</code> field lists deprecations <em>not</em> to mark fatal. The <code>except</code> field takes precedence over <code>include</code>.</p>
</li>
<li>
<p>Add a (non-enumerable) <code>sass.deprecations.dartSass2</code> property which can be passed to <code>Options.fatalDeprecations</code> to mark as fatal exactly the deprecations that will become fatal in Dart Sass 2.0.0. This can be combined with other deprecations or used in a <code>DeprecationSelectorDifference</code> to modify exactly which deprecations it covers.</p>
</li>
<li>
<p>Passing a version number beyond the current Dart Sass version to <code>Options.fatalDeprecations</code> is now deprecated. See <a href="[QUARANTINED_URL: sass-lang.com]">the Sass website</a> for details.</p>
</li>
</ul>
<h3>Dart API</h3>
<ul>
<li>
<p>Add a <code>Deprecation.dartSass2</code> property which returns exactly the set of deprecations that will become fatal in Dart Sass 2.0.0.</p>
</li>
<li>
<p>Passing a version number beyond the current Dart Sass version to <code>Deprecation.forVersion</code> is now deprecated.</p>
</li>
</ul>
<h3>Embedded Protocol</h3>
<ul>
<li>Add a <code>CompileRequest.fatal_deprecation_except</code> field which excludes deprecations from being considered fatal if they would have been enabled by <code>CompileRequest.fatal_deprecation</code>.</li>
</ul>
<p>See the <a href="[QUARANTINED_URL: github.com]">full changelog</a> for changes in earlier releases.</p>
</blockquote>
</details>
