Resolves #1407

Route the remaining JSONL readers through `bundlePayload`, preserving U+2028/U+2029 within records instead of treating them as line boundaries. Add `openJsonlStream` for stdin, with the same error/close handling as file readers. File ingestion uses the existing extension decoder. Keep the module name to avoid changing its writer API and existing callers; widen its documentation and state the accepted `.jsonl`, `.jsonl.br`, and `.jsonl.gz` extensions explicitly.

Evidence: internal parser behavior and a CI census, covered with real temporary files/streams and synthetic records; no operator-only acceptance criteria or residuals. Vector persistence uses an in-memory collection seam, not a live production database.

## Deltas from ticket

No substantive scope change. The stream reader owns its input: closing or leaving early destroys the input stream. Added split-UTF-8 and early-close coverage. The census rejects direct readline imports, including aliased imports, rather than relying only on the spelling of a `createInterface` call.
