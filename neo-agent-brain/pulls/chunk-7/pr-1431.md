Resolves #1430
Related: #1416, #60

Adds plane-level Docker disk diagnosis (`statfs` on `AiConfig.plane.dataRoot` + `GET /system/df`) and a bounded `prune-build-cache` recovery action (`POST /build/prune?reserved-space=<bytes>&keep-storage=<bytes>`) on the `engine` target kind (`docker-engine`). Sustained disk pressure with reclaimable build cache at or above the configured floor prunes build cache while preserving a warm floor (`keepStorageBytes`, resolved at the actuator use site from `AiConfig.orchestrator.diskPressure.buildCacheWarmFloorBytes`), records `statfs` free bytes before and after, and transitions zero-reclaim runs (`!(spaceReclaimedBytes > 0) && !freeBytesIncreased`) to `recorded` (`prune-freed-nothing`, `alarmOnly: true`) for the current attempt window (`getCurrentAttemptState`); pressure without reclaimable build cache routes to `record` only, naming `images` and `volumes` without acting on them.

Evidence: L2 (Playwright unit specs driving diagnosis -> controller -> actuator -> L0 Docker socket & `statfs` boundary, including API-1.53 `Shared: true` build-cache payloads) → L4 required (AC-5 live-plane `statfs` before/after receipt on first autonomous prune). Residual: AC-5, Residual-Owner: #1416.
