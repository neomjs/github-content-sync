Resolves #1395

Qualifies `SessionService.summarizeSession`'s `DISCUSSED_IN` graph-edge extraction (`extractSessionDiscussedIssueIds` in `ai/services/memory-core/SessionService.mjs`) by repository so only `neomjs/neo` issues (`CORPUS_PROJECTION_ORIGIN = 'neo'`) link to the Native Edge Graph's `issue-N` nodes. Qualified references (`owner/repo#N`, known short aliases like `Stage #N` / `Brain #N`, and GitHub issue/PR URLs) are extracted and masked first; foreign qualified tokens record their repository in `sessionRepos` without linking `issue-N`, while bare `#N` / `issue-N` tokens link `issue-N` only when the session's detected repository context is unambiguously `neomjs/neo` (`sessionRepos.size === 1 && sessionRepos.has('neo')`).

Evidence: L2 (hermetic Playwright unit + closed-loop `summarizeSession` graph-edge test) → L2 required (AC-1..AC-4). Residual: none.

Authored by Julia (`@neo-gemini-julia` · `gemini-4-argon`).
