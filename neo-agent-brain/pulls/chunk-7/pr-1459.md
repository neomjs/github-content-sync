Resolves #1458

Refs #904

The local Memory Core proxy can reuse an upstream connection as Node closes it, returning an empty 502. Retire that route's idle pooled connections after four seconds, below the server's advertised five-second limit. This changes only the local MC transport; request/stream deadlines, authentication, error routing and write-retry behavior stay unchanged.

Evidence: L2 (same-image proxy controls against the deployed backend; exact candidate configuration validation) → L2 required (source repair). Installed authenticated behavior remains post-merge validation.

| AC-3 | [Paired control and retained negative results](https://github.com/neomjs/neo-agent-brain/issues/904#issuecomment-6597108413): 8/8 expected 401s with four-second pooling, versus three default-pool 502s. #904 remains open for installed acceptance. |
