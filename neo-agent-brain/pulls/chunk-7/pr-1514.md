Resolves #1492

Adds optional `pr_number` and `repo` (`#/components/schemas/RepositoryTarget`) parameters to `validate_pr_review_body` so Round-2 disposition reviews (`isRound2PrReview(body)`) can validate verbatim Required-Action carry (`getRound2DispositionRelationFailure`) via a read-only reviews fetch (`GET_PULL_REQUEST_ID`) before calling `manage_pr_review`, while preserving synchronous zero-GraphQL execution whenever `pr_number` is omitted or the body is not a Round-2 disposition.

Evidence: L1 (Playwright unit suite covering `PullRequestService#validatePrReviewBody`, `REPOSITORY_TARGET_TOOLS`, and `RepositoryTarget` boundary guards) → L1 required (AC1, AC2, AC3, AC4).

| AC-2 | `test/playwright/unit/ai/services/github-workflow/PullRequestService.spec.mjs` (`#1492: validatePrReviewBody with pr_number validates Round-2 Required-Action carry against the cited Round-1 review` — verbatim row returns `valid: true`) |
| AC-3 | `test/playwright/unit/ai/services/github-workflow/PullRequestService.spec.mjs` (`#1492: validatePrReviewBody without pr_number, or on a non-Round-2 body with pr_number, stays synchronous and performs zero GraphQL calls`) |
| AC-4 | `ai/services/github-workflow/PullRequestService.mjs` (`#validateRound2PrReviewCarry` queries only `GET_PULL_REQUEST_ID`) and `test/playwright/unit/ai/services/github-workflow/PullRequestService.spec.mjs` (`#1492` mock throws on any GraphQL call other than `GetPullRequestId`) |
