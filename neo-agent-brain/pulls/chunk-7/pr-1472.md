Resolves #1471

The roster now says once why the whole Fleet refuses Start, and whether that will pass by itself. `fleetRoster` folded the lifecycle's start gate into each row's `launchRefusal`, where a seat's own refusal outranks it, so a reader could not tell a booting Fleet from seats that each refuse.

- `FleetLifecycleService#startGate` replaces `startGateRefusal` and returns `{state, reason}`. `state` is `'booting'` while runtime verification or recovery runs, so Start opens by itself, and `'refused'` for a gate that holds until something changes.
- `createFleetCockpitStatus` carries that gate at the DTO's top level, `null` when Start may run.
- Rows keep the gate's reason as their `launchRefusal`.

This is the Brain half of neomjs/neo-agent-institution#841 AC-3. Its cockpit line names the boot phase from `startGate`, and it re-reads quickly only while the Fleet boots.

Evidence: L2 (unit: the lifecycle's gate and the roster DTO on the Brain's unit setup) → L2 required (AC-1 to AC-3). Residual: none.
