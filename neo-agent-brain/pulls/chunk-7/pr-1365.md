Resolves #1364

An `AGENT:*` broadcast's send-time cohort now comes from the graph store, through the canonical `readAgentIdentityNodes` that wake delivery and the heartbeat already use. Before, it came from the in-memory node cache, so an identity that was persisted but not loaded (after a restart, a `syncCache` eviction or a test reset) got no `DELIVERED_TO` edge and never saw the broadcast. The predicate is unchanged: an `@` id, not the sender, `accountType` agent. The legacy `AGENT`-label branch goes, since nothing writes that label. This also removes the cache dependence behind the intermittent `MailboxService.ListMessagesCost` 500-of-1000 red (defect-note `139c4cc4`).

Evidence: L2 (unit arms against the real graph store and mailbox projection) → L2 required (every AC is a unit-suite property). Residual: none.
