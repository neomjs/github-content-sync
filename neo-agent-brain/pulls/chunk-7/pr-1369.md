Resolves #1368

`ai/services/shared/isEntryModule.mjs` realpaths both `process.argv[1]` and the module before comparing them. Every entry check under `ai/` (140 files), plus `test/playwright/compareUnitFailures.mjs`, now calls it. A script run through a symlinked path therefore no longer skips its CLI block and exits 0.

`isThreadEntrypoint`, the entrypoint predicate behind ADR 0019's C1 rule, learns the helper's spelling. Without that, the migration would have demoted `runAgent.mjs` and every daemon.

Evidence: L2 (unit arms on real, symlinked and `--preserve-symlinks-main` paths, both lint readers' arms, and the full unit suite at head) → L2 required (every AC is a unit-suite property). Residual: none.
