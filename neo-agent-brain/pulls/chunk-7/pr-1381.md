Resolves #1380

The idle-out nudge is now the heartbeat, and it fires once per idle stretch, thirty minutes after a seat's last known activity. Both detectors read one shared "last known activity" — the newest of the seat's memory, turn-presence beacon and outbound message (`ai/scripts/lifecycle/lastKnownActivity.mjs`), legacy and current memory rows ordered by one parsed time — instead of the memory alone, so a seat deep in a tool loop or a fresh session no longer reads as idle. The `idle_out_nudge` lock is released only by newer activity, never by age, so an unanswered nudge is not repeated inside the stretch and can no longer trip the fleet-wide wake safety gate (three abandonments did, under the 15-minute boot ramp). Both dispatchers honor that lock: the per-seat nudge writes it immediately before its emit, after the content reads, so a failing read leaves nothing behind; the all-idle dispatcher (`swarmWakeCooldown.mjs`) refuses to wake a coordinator whose nudge is still unanswered, and `pulse()` passes the swarm wake through the same readiness gate as a per-seat nudge. The cadence emitter in `pulse()` step 6 — a plain pulse on every 20-minute tick to every A2A-quiet seat — is gone; its readiness and backoff gate moved onto the nudge routing through `WakeDecisionService.decideReady`. The pulse carries the seat's own last `lane-state:` line, its idle minutes and the sunset rule derived from the receiver's gate constants (`idleOutPulseSummary.mjs`), and both digest renderers print them. The receiver's context gate skips a wake whose every pulse is an idle-out pulse when its probe shows the session active inside `activeWithinMs` (live where a probe exists — OpenCode and Kimi; the detector's presence read is the guard for Claude, Codex and Antigravity, whose probes return `null`); the coalescer tallies each heartbeat pulse by its pulse-id source, so a GitHub mention or review request riding the same transport is content and delivers, and a digest from a producer without the tally delivers too. `idleThresholdMs` defaults to 30 min. A read-only diagnostics script (`idleGapTurns.mjs`) counts the turns that began after more than an hour idle, per seat per week; the week-before-enablement reading is on #95. `NightShiftLeasedDriver.md` §6 states the delivery floor and names the lane's switch — the host-edge posture's `NEO_ORCHESTRATOR_SWARM_HEARTBEAT_ENABLED`, which this PR leaves `'false'`.

Evidence: L2 (unit specs: scenario graphs for both detectors, the lock, both dispatchers across cooldown windows, the receiver's drain with an injected probe, the pure policies, the coalescer's digest, both renderers, the metric's fixture graph) → L2 required (every AC is unit-pinned or a doc edit; turning the lane on is a deployment input outside this PR). No residuals.
