Resolves #1409

`projectDeploymentServiceForFleet` now carries a service-level `startedAt`, lifted from `inspect.currentRun.startedAt` (the container run's start). It is `null` when any link in that path is absent or the value is not a string. `inspect` itself stays off the wire, per #314's field rule. neomjs/neo-agent-institution#844 needs this field to see a restart that falls between two cockpit reads; PR neomjs/neo-agent-institution#854 consumes it.
