Resolves #1366

`lint-guides` gains `--root <dir>`. That root's guide directories and relative paths are linted, its `package.json` scripts join the Brain's for the `ai:*` check, and tool tables still resolve against the Brain's OpenAPI. Without the flag nothing changes. This is the Brain half of restoring the guide-quality gate that has run nowhere since neomjs/neo#17806 (defect-note `a03b68c6`); a neo workflow that calls it follows as a neo ticket.

Evidence: L2 (unit arms on a fixture repository, plus a real run against neo's tree) → L2 required (every AC is a unit-suite property). Residual: none.
