Resolves #1181

A pointer left at a moved ADR's old path (`type: redirect`, ADR 0006 §2.9) is no longer read as a record. One shared reader, `ai/services/shared/adrRedirect.mjs`, classifies a document before the numbered-filename heuristic:
- both KB extraction paths skip it; the repository path reports it as skipped with reason `redirect`;
- the graph ingestor creates no node, edge or vector for it.

ADR 0006 §2.11 now names one discovery territory, `learn/agentos/decisions`.

ADR 0040 §2.7.1 records the FM cut's order, which the operator made a blocker for Engine v13.3. The order is: these readers, then Institution publishes (neomjs/neo-agent-institution#686), then the Engine paths become pointers (neomjs/neo#19730). Custody admission and authoring guidance follow. The move admits nothing new and neither prunes nor rekeys graph state, and the legacy state some of the five already carry (`adr-0037` is an `ADR` node with its own vector) stays for the migration (#1014). The ADR's text is the decision record, so the reviewer reads one place.

Evidence: L2 (unit arms on both KB extraction paths, the graph ingestor and the shared reader) → L2 required (AC1–AC4). Residual: the live KB readback in Post-Merge Validation, Residual-Owner: #1010.
