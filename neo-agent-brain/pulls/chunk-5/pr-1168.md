Resolves #1167

🌿 A Codex seat's own tool approvals can no longer pass for a hijacked launcher.

Recovery of a Codex Desktop seat's Neural Link grant (#1156) refused whenever the workspace's `.codex/config.toml` named the bound table at all. The resident's per-tool approvals, `[mcp_servers."neo-mjs-neural-link".tools.<tool>]`, seeded from the template, name it implicitly, so every Codex Desktop seat's first Start on the new FM refused with `workspace-mismatch` (Euclid, 2026-10-19 02:16Z). Codex merges config layers key by key (`codex-rs/config/src/merge.rs`; Mnemosyne's `codex mcp get` from Euclid's workspace showed the home launcher intact beside the project approvals). So `codexProfileProjection` now leaves a table's `tools` out, as it already left `enabled` out: both are the seat's own settings. A table holding only those names no launcher, and drops from the projection, from the home binding hash, and from the project check. A project table naming any launcher key still refuses.

Evidence: L2 (unit, real TOML projection and recovery) → L3 required (AC-3, Euclid's Start). Residual: AC-3, the installed Start on the next FM candidate. Residual-Owner: neomjs/neo-agent-institution#736. Tonight's seats run on Mnemosyne's workaround: the approvals are stripped from three project files, with backups.

## AC Evidence

|---|---|
| AC-1 | `launchProfileCustody.spec.mjs`, "the seat's tool approvals for the bound table keep custody in either layer": approvals in the project file, then in the home config, both recover the grant |
| AC-2 | the same spec, "a project table that would win over the bound home table refuses": a full table with another `command`, and a table naming only `env` with a forged grant, both refuse `workspace-mismatch` |
| AC-3 | Post-Merge |

## Deltas from ticket
- The ticket named the project check. The change sits one layer lower, in the projection, so home-layer approvals stop counting as an unrecorded edit to Fleet's table (`prepareManagedAgentWorkspace` hashes the same projection for its receipt). Fleet writes its launcher tables without `tools`, so existing bindings and receipts hash unchanged.

The 18 fleet specs that touch Codex launch custody: 612 passed, 2 skipped. Controls: with the original source the project arm fails with Euclid's exact `workspace-mismatch`; with this branch's first revision, the check-only version, the home arm fails with `projection-mismatch`.
