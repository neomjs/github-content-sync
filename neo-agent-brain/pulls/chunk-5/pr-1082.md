Resolves #1074

Gives an unresolved Codex Desktop helper-cleanup state an exit inside `FleetLifecycleService#start` and forwards `cleanupUnresolved` alongside `failureReason` through `FleetManager#fleetRuntimeStatus` and `createFleetCockpitStatus`. When a seat's main process has exited (`!priorRecord.child`) and `priorRecord.cleanupUnresolved` is set, `start(id, opts)` now re-probes a missing `crashpadExecutable` and re-runs `finalizeCodexDesktopHelpers(priorRecord)` once before deciding whether to refuse or proceed with spawning; if cleanup still fails, `start()` refuses with a message naming the live helper PID(s) or unreadable process table while preserving `cleanupUnresolved: true` and `failureReason` on `status(id)` and the roster row.

Evidence: L2 (Playwright unit specs for FleetLifecycleService, manageCodexDesktopRuntime, FleetManager, and fleetCockpitStatus) → L4 required (AC-3 Institution card/plan consumer and AC-4 installed Stop fleet → Start fleet walk). Residual: AC-3, AC-4, Residual-Owner: neomjs/neo-agent-institution#725, neomjs/neo-agent-institution#12.
