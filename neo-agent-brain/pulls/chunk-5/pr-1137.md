Resolves #1136

A Codex seat's next Start now moves the MCP rows Fleet itself wrote onto the installed runtime instead of refusing them. The converger recognises an exact earlier render at the packaged runtime the rows name (an app bundle or an earlier generation, in the current runtime's bundle shape) and in Neural Link's vocabulary from before `NEO_NL_PORT`. Anything else still refuses `FLEET_WORKSPACE_DIVERGENT` with the file untouched: a hand-pointed executable, another managed byte, a root outside the packaged shape, rows naming two runtimes. A workspace-preparation refusal now writes its message, artifact and cause to the Fleet log its reason already pointed at.

Evidence: L3 (the patched converger driven read-only on the three real GPT seat files, every write blocked) → L3 required (AC-5). Residual: the installed Start (L4, operator-gated), Residual-Owner: neomjs/neo-agent-institution#12 (the installed witness `neo-agent-institution#674` assigned its restart-on-the-new-generation check to).
