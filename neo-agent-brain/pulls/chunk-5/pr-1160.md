Resolves #1157

ADR-0019 and its two guards stop prescribing a config snapshot.

- **The ADR** states the test-isolation ladder from `neomjs/neo#19856`: delete what `UNIT_TEST_MODE` resolves, bind worker-wide values in the harness env, pass a pure operation its input, and only then use `snapshotAiConfig`, the one named B4 exception, which carries a sunset.
- **The B4 guard's ceiling hint** names that ladder instead of `configSnapshot.mjs`.
- **The DB-path rule** also gates Chroma's endpoint leaves.
- **The antipattern guard** scans `src/` beside `ai/`.

This is Ticket 1 of three: `#1150` and `#1151` remove what the old prescription built.

Evidence: L2 (unit: guard specs red-first against the `origin/dev` guards, both guards over the real tree, the ADR ownership check) → L2 required.

## Deltas from ticket
- **§4's lint sentence now points at the B4 row.** It promised a fail-build check of every `aiConfig.<path> = …` write. The row already says that rule is PARTIAL, so the sentence was the same false assurance `#508` corrected in the row.
- **Three generic uses of "by construction" are reworded** (the ADR's B4 row and §4, and the guard's parser note), because `neomjs/neo#19856` reserves the phrase for test isolation.
- **Rung (i) is scoped to "the test DB and its collections".** `logPath` is worker-scope env, so it belongs to rung (ii).
- **The ceiling-breach CLI arm** pinned `configSnapshot` in the hint (my `#1097`). It now pins `ADR-0019 §5.4` and refuses the old remedy.
- **Source comments say "the isolation ladder"**, not `ADR-0019 §5.4`, because the archaeology check treats an ADR number in a comment as decay-prone. The stderr hint is a string, so it keeps the precise pointer. The same check fails on a legacy `ticket-ref-ok` escape at `check-aiconfig-antipatterns.mjs:79` for any PR touching that file, so that line is rephrased.
