Resolves #1055

Identity recency (`queryRecentTurns`) returns only `AGENT_MEMORY` nodes that carry `agentIdentity` and `timestamp`. The write path stamps both; the session ingestor and its lazy back-fill stamped neither. Both projections now take the keys from the Chroma row through `rawMemoryRecencyKeys`, beside the other raw-memory identity helpers, and a node that lacks a key its row carries re-projects on its next sync. `repairRawMemoryRecencyKeys.mjs` heals the history: it re-projects existing nodes per session through `syncSessionToGraph`, and projects identity-carrying rows that have no node through `ingestSingleRow`. It is a dry run by default; `--apply --offline` writes.

Evidence: L3 (unit specs through the real ingestor, GraphService and `queryRecentTurns`, plus a read-only dry run on the plane) → L4 for AC-5, the offline apply on the canonical plane after merge.

## Deltas from ticket
- **AC-3's mechanism**, now adopted into the ticket body. The first version put the recency keys into `computeMemoryPayloadHash`. On the plane, 22,893 legacy `memory:<uuid>` nodes have a canonical twin, every twin pair that carries a hash agrees, and `reconcileRawMemoryGraphIdentities` refuses any pair whose `payloadHash` differs. So the hash keeps its fields, and the sync's skip also requires `carriesRawMemoryRecencyKeys`.
- **Legacy-only rows are left out.** A row whose only node is a legacy projection is counted, not projected: a canonical node beside it would be a twin, which the reconciler owns. A later repair run re-projects it once converged. That includes 497 of #1018's rows, whose convergence waits on [#1018's own graph pass](https://github.com/neomjs/neo-agent-brain/issues/1018#issuecomment-6201916835).
