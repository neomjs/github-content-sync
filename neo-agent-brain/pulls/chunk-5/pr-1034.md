Resolves #1033

The stdio-to-HTTP bridge now returns the standard MethodNotFound response for an unsupported `server/discover` request before initialization. The client can then initialize normally, without the probe reaching a session-required HTTP endpoint and closing both transports. After initialization the bridge continues forwarding traffic unchanged; bearer handling and sanitized failure reporting remain intact.

Evidence: L2 (real executable with an inert loopback HTTP fixture, plus transport controls) → L4 required (installed native client MC/KB use). Residual: recipient acceptance, Residual-Owner: #571.
