Resolves #1138

🌿 *A restart can no longer turn a stopped seat into one that cannot start.*

Since #1051, boot recovery stamped every saved seat whose process is gone `exited`, whatever state it was saved in. The FM roster rejects that word, so Ada's Start stayed excluded through every restart. Recovery now writes `stopped`, the word lease adoption already uses for the same fact, with the unsupervised-exit reason only when the seat was saved running. The codec still reads `exited` from journals the earlier builds wrote, and recovery re-persists those entries as `stopped`.

Evidence: L2 (unit tests: a real journal on disk, the real recovery path, a stubbed process table) → L2 required (AC-1–4 are unit-observable; the installed check was dropped from #1138 because no open ticket owns FM release acceptance). No residuals.

## Deltas from ticket

- Two fixtures that set `exited` by hand now say `stopped`.
