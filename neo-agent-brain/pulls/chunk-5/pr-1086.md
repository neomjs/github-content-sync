## Deltas from ticket
- Implemented `configSnapshot` via a private `#configSnapshot` field and getter/setter (`beforeSetConfigSnapshot`) rather than a reactive `configSnapshot_` slot because `Neo.core.Config` defaults to `clone: 'deep'` on assignment (which would sever the caller's `configSnapshot` reference from the stored snapshot) and assigns `me[_key] = value` before running `beforeSet*` hooks.
- Used `util.types.isProxy` (`node:util`) and `!(candidate instanceof Base)` in `isPlainSnapshotObject` so `beforeSetConfigSnapshot` deterministically rejects `aiConfig` (`ConfigProvider`), `{...aiConfig}`, and any snapshot containing a live `createHierarchicalDataProxy` subtree (`aiConfig.openAiCompatible`, `aiConfig.localModels`, `aiConfig.orchestrator`, `aiConfig.ollama`), even though `createHierarchicalDataProxy` allocates a fresh nested `Proxy` per property access.
