Related: #508, #1090

Adds a single whole-config snapshot injection seam (`TextEmbeddingService.configSnapshot` + `createConfigSnapshot()` + `beforeSetConfigSnapshot()`) to `TextEmbeddingService` per ADR 0019 §5.4 and converts `TextEmbeddingService.retry.spec.mjs` to mutate an isolated per-test snapshot (`configSnapshot`) instead of the shared `aiConfig` singleton, eliminating all 80 shared-config writes across 12 leaves in the spec (`657 → 577` total B4 shared-config writes across `test/**`). Remaining B4 test concentrations (`577` writes across `55` files) and `TextEmbeddingService` snapshot seam follow-ups are tracked in successor #1090.

## Deltas from ticket
- Implemented `configSnapshot` via a private `#configSnapshot` field and getter/setter (`beforeSetConfigSnapshot`) rather than a reactive `configSnapshot_` slot because `Neo.mjs`'s reactive setter writes via `setRaw` before invoking `beforeSet*` and does not restore the prior value when `beforeSet*` throws (so a reactive slot cannot host a throwing validator without leaving the rejected value installed).
- Used `util.types.isProxy` (`node:util`) and `!(candidate instanceof Base)` in `isPlainSnapshotObject` so `beforeSetConfigSnapshot` deterministically rejects `aiConfig` (`ConfigProvider`), `{...aiConfig}`, and any snapshot containing a live `createHierarchicalDataProxy` subtree (`aiConfig.openAiCompatible`, `aiConfig.localModels`, `aiConfig.orchestrator`, `aiConfig.ollama`).
- Re-pinned `TextEmbeddingService` source-line anchors in `test/playwright/unit/ai/deploy/OllamaProviderEnvCoordinates.spec.mjs` and `test/playwright/unit/ai/deploy/ProviderReadinessEnvCoordinates.spec.mjs` to match the direct `this.#getConfig()` / `cfg` reads, and filed #1090 to own the remaining `577` B4 shared-config writes (`55` files) plus `TextEmbeddingService` snapshot follow-ups (`VectorService.batchFailureIsolation.spec.mjs` -> deleting `openAiCompatibleHostFn_`, resetting `ollamaProvider` on `configSnapshot` change, and cloning whole consumed subtrees in `createConfigSnapshot()`).
