Resolves #1105

`npm run ai:delta-digest` states what a review range changed. It reads git and measures from the merge-base:
- the range's commits, and its merges, each marked when its remerge-diff is non-empty;
- every path, with status and counts, and named `--generated` globs counted apart;
- the symbols and test titles acorn finds added, removed or changed at both ends;
- the tickets the commit messages close;
- each code file's added comment and code lines;
- with `--since`, what changed after a review anchor, and whether through own commits or only through merges.

Authors and reviewers can cite the digest instead of recall. pinDrift's git runner and batch reader move to `gitObjects.mjs`, which both diagnostics import.

Evidence: L2 (a unit spec over a temp git fixture, plus the CLI on real Brain ranges) → L2 required (every AC is a CLI or unit property). Residual: none.

## Deltas from ticket
- Imports count as symbols (`import <local>`), so an import a change adds or drops shows beside the declarations it serves.
- A class's own entry is its header, so a change to one member marks only that member.
- `classifyAddedLines` reads a line opening with `*` as a JSDoc continuation, so a generator method written `*name() {` (one such line in the Brain today) counts as comment. Out of scope, noted in a defect-note.

### 🔬 Depth Floor

- **Challenge**: In `classifyAddedLines(lines, file)` (`ai/scripts/diagnostics/deltaDigest.mjs:290`), any non-block-comment line whose trimmed text starts with `*` (`line.startsWith('*')`) is counted as a `comment` line so multi-line JSDoc blocks whose opening `/**` sits outside the diff hunk are still recognized. A newly added JS generator method in a class/object (e.g. `*walk(node) {`) or a leading-`*` multiplication continuation line also starts with `*` when trimmed and would be tallied as `comment` rather than `code`. Non-blocking for merge since generator methods are rare in this codebase and narrowing the check to `/^\*(?:[\s/]|$)/` is a one-token refinement if generator-heavy files ever trigger false positives.
