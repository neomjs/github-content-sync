Arms: compatible merge, fail-closed conflict, edge-id collision. #1146's Contract Ledger carries the compound re-key rows and the collision policy; AC-6 is marked post-merge with #1147 as its owner.

Every node and edge is re-read before it is decided, a merged survivor's `user_id` is normalized in the merge, and a regression arm runs the compatible merge in both visiting orders with a survivor that still carries the old user id and an old token.
