Resolves #1061

Normalize stripped macOS `launchd` GUI `PATH` values in `FleetLifecycleService.snapshotAmbientProcessEnvironment()` by appending `/opt/homebrew/bin` and `/usr/local/bin` after existing segments (such as organism `shims` and `node_modules/.bin`) without duplication while returning non-`launchd` `PATH`s unchanged. Because `snapshotAmbientProcessEnvironment()` supplies both `start()`'s default `resolvedProcessEnvironment` (`FleetLifecycleService.mjs:743–745`, every managed seat's spawn env) and `resolveAntigravityStartContext` (`:3083` → `startAgentProvisioned` → `generateAntigravityMcpFiles`), both managed seat spawns and `.neo-fleet-mcp/github-workflow.sh` preserve Homebrew and local binary directories when `Neo Harness.app` launches from Finder or Dock.

Evidence: L2 (Playwright unit specs in `test/playwright/unit/ai/FleetLifecycleService.spec.mjs` and `test/playwright/unit/ai/services/fleet/generateAntigravityMcpFiles.spec.mjs`) → L2 required (AC-1, AC-2, AC-3).
