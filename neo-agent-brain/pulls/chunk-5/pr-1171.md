Resolves #1170

🌿 A Codex Desktop seat's own launcher can no longer fail the check meant to protect it.

`inspectPreparedRemoteMcpAdapter` runs the installed Codex against a plane-attached seat's prepared `CODEX_HOME` and required every local stdio row's env to equal the plain Node runtime env. Since #1156, a Codex Desktop seat's `neo-mjs-neural-link` row is Fleet's launcher table, so every plane-attached Codex Desktop Start refused at this gate (Euclid, 2026-10-19 02:54Z). The real `codex mcp list --json` row from Euclid's prepared home has the generation executable as `command`, `[…/fleetMcpLauncher.mjs, --server, neural-link]` as `args`, 19 env keys, and `env_vars: []`. Start now passes the servers it launches through the issuer (the codex binding's grants). For those rows the inspection checks the launcher contract the renderer writes: the bound runtime and launcher for that server, nothing forwarded from the host, and env limited to the plan's runtime env, the seat's login, the plane placement, the issuer and the grant (the grant by presence). `LAUNCHER_ENTRYPOINT` moves to `managedAgentWorkspacePlan.mjs` so the renderer and the inspection read one value.

Evidence: L2 (unit, the inspection on a fixture of the real row shape) → L3 required (AC-4, Euclid's Start). Residual: AC-4, the installed Start on the next FM candidate. Residual-Owner: neomjs/neo-agent-institution#736.
