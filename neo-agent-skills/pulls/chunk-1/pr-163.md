Resolves #155

Architecture review now reads a touched stateful owner's Neo shape and routes the inherited debt it verifies, whatever the verdict.

- **`audits/core-idiom-audit.md`, new check 5:** trace each effect from the host's call site to the code that runs.
  - A subclass or override must be able to replace that code, and one owner ends its lifetime.
  - A handler bag over closure state, an effect body that calls statics by class name, or a host that names the class at its call site defeats replacement, even inside a registered class. Registration is not dispatch.
  - The exemption no longer covers a closure that owns state.
- **`references/pr-review-guide.md`:**
  - The §7.5.1 trigger now reaches modules that own instances, resources or effects, through an explicit relative link.
  - §0 field 2 reads such an owner with its creator and its destructor.
  - §2 item 5 routes three ways, whatever the verdict:
    - a wrong shape the patch adds is this PR's Required Action;
    - verified inherited debt gets a real issue and never blocks a safe fix;
    - a suspicion stays tagged as a hypothesis.
  - The reviewer-seeded section folds into that item. The intro list is cut, and §4, §5.1 and the self-review bullet are compressed.
