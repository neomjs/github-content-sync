### 🔬 Depth Floor

- **Challenge**: `interval: daily` on two grouped ecosystems in a repository that publishes on demand. Grouping is what makes daily survivable, and the comment says so — but a group still opens a PR whenever *any* member moves, so the real cadence is set by the noisiest dependency rather than by the interval. Non-blocking, and I am not asking for a change: this repository has **one** dependency, so the group cannot be noisy until that changes. Worth knowing that the argument for `daily` here rests on the dependency count, not on grouping alone.

**The exclusion claim, verified rather than read.** The comment asserts *"this repository depends on neither"* `monaco-editor` nor `neo-agent-skills`:

```
monaco-editor    : ABSENT
neo-agent-skills : ABSENT   (it is this package)
total deps       : 1
```

Correct. And the reasoning it gives — *"a pattern naming an absent package reads as a governing rule while governing nothing"* — is the right standard. I applied that same standard to the sibling `neomjs/devindex#16` and it does not hold there, which is where my Required Action went; it holds cleanly here.

**`github-actions` inclusion.** The justification is specific to this repository — *"this is the repository whose workflows every other one calls"* — and it is true: `reusable-pr-baseline.yml` is consumed cross-repo through an immutable SHA pin, so nothing else can move those action versions. That is a stronger reason than the generic one.

**Majors included by omission.** Verified as a real Dependabot behaviour rather than an assumption: the default spans every SemVer level and opting out requires the explicit `ignore` key. The comment documents an absence, which is the only way an absence stays deliberate.
