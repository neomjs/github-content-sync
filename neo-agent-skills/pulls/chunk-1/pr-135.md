Resolves #134

🌿 Once a bearer has accepted a name, nothing in the ritual can call it pending.

The ritual now has four gates: peer-sketched, criterion-audited, bearer-assented, peer-unvetoed.
- **Phase 6 (Operator Confirm) is gone.** Its one durable idea now sits on the bearer's assent in Phase 4: assent means genuine liking, not tolerance.
- **Landing is now Phase 6.** It fires on assent with no standing veto, and it lands `name` together with `displayName` and the README name.
- **The operator weighs in as an equal peer**, by sketching, auditing or vetoing, and never by approving. The callability bar now also asks whether a name can be typed on an ordinary keyboard (operator hint, 15:4xZ).
- **The SKILL.md description and its manifest mirror** drop "operator-confirmed".
