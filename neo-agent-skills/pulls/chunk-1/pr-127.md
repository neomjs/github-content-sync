Resolves #100

`--repo neo,neo-agent-brain` and `generate({audience, repos})` compose one `AGENTS.md` for a set of repositories: every section once, in source order, when any repository in the set declares it. Two sections claiming one list number are refused, because a repository-specific replacement for a numbered gate is valid alone and renders twice in a union. The package now exports the generator as `neo-agent-skills/agents-md`, so Fleet can build a seat's home instructions in-process (neomjs/neo-agent-brain#644). Single-repository output is byte-identical for all ten variants.
