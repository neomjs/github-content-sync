## Summary

Enforces a `220`-byte `descriptionBudget` on every skill's YAML frontmatter `description:` field (`create-skill/references/skill-authoring-guide.md:83`) and compacts all 39 skill descriptions from `18,431` bytes (`19,032` bytes including `description: "..."` syntax) to **`7,385` bytes** (`7,970` bytes including syntax — a **`-11,046` byte / `-59.9%` reduction**, saving ~2.7k tokens on every session boot while keeping every trigger clause intact and moving enforcement summaries, `CRITICAL` warnings, and empirical anchors into the `SKILL.md` router bodies where they load on invocation only).

### `/turn-memory-pre-flight` Load-Effect Audit

- **Always-loaded surface (session boot index):** Every harness loads the 39 `SKILL.md` frontmatter `name` + `description` fields at session start. Compacting all 39 descriptions to one sentence (`117–217` bytes each, `0` overrides needed) reduces the always-loaded description payload by **`11,046` bytes (`18,431` → `7,385` bytes)** and its manifest mirror (`skills.manifest.json`) by the same `11,046` bytes.
- **Conditionally-loaded surface (`SKILL.md` router body on invocation):** Enforcement summaries, `CRITICAL` notes, and empirical anchors (`Evidence Ladder` link in `pull-request/SKILL.md`, Playwright config warnings in `ticket-create/SKILL.md` and `whitebox-e2e/SKILL.md`, Stage 0/1 placement anchors in `structural-pre-flight/SKILL.md`) moved into the router bodies while keeping every `SKILL.md` within its `routerByteBudget` line cap (`6–16` lines) and preserving all 29 canonical rows in `.agents/skills/document-references.v1.json`.
