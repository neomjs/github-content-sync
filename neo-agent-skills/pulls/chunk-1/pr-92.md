Resolves #91

Every repository that calls the reusable baseline now gets a credential scan on each pull request. The engine's guard, which only neomjs/neo ran, ships here as `neo-agent-skills-secrets`. A stable `Secrets` job in `reusable-pr-baseline.yml` runs it with `--all` over the caller's tracked files. The port keeps the allow-marker reason rule from neomjs/neo#18913. It also fixes one thing the engine's copy gets wrong: the entry check realpaths both sides, so the installed `bin` symlink runs the guard. The PR includes the 0.1.11 release bump, as #89 did for 0.1.10.

Evidence: **L2** — the guard's contract suite (process-level and through a symlink), the baseline contract with six new negative mutations, and the packed tarball. The job's live run needs 0.1.11 on npm, so it is listed under Post-Merge Validation.

agent-preflight: not hosted here; baseline jobs ran. Change class: `capability` (`feat`).
