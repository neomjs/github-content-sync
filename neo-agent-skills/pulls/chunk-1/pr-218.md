Resolves #217

The `AGENTS.md` that `npx neo-app` writes now tells an outside agent how to run, reach and recover the app. Before, it said `server-start` "serves the workspace and opens it" and that the app connects "once the Neural Link MCP server is configured", and the cloud cold walk of neomjs/neo#20114 spent minutes reading `node_modules` for the rest.

`§orientation` now states the port and URL (`http://localhost:8080`, or `$PORT`, else the next free port), `-- --no-open` and Node 24. `§skills` states that the Neural Link is already configured (`.mcp.json`, `.codex/config.toml`) and needs one approval, the reload rule for "No active App Worker sessions found", and `npx playwright install chromium` for a headless page. The generator test asserts each line. 0.1.63.

Evidence: L2 (generator contract test on the real app variant) → L3 required for AC-2 (the next cold walk on a published release). Residual: AC-2, Residual-Owner: neomjs/neo#20114.
