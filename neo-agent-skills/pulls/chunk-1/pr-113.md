Resolves #112

The materializer now computes its links from a physical root. Before, Node realpathed the package it runs from, but `--root` was kept as given, so a root behind a symlink got relative links computed between two path spaces, and every link dangled. On macOS, `os.tmpdir()` is such a root (`/var` → `/private/var`). That is why `test-lint-skill-corpus`'s "clean non-Neo consumer" case failed on every seat's local run while Linux CI stayed green. One line changes: `root = realpathSync(resolve(…))`.

**No version edit.** #111 merged first and set `dev` to 0.1.17, which is not published yet. The operator publishes once, after this PR, so this fix ships in that same 0.1.17.

Evidence: L2 (the real materializer driven against a fixture consumer, under both a macOS-logical and a physical temp root) → L2 required (AC-1–AC-3). Residual: none.
