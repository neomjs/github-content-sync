Resolves #136

Adds the self-hosted `pr-body` job (`name: PR body`) to `.github/workflows/skill-corpus.yml` and expands `on.pull_request.types` to `[opened, edited, synchronize, reopened, ready_for_review]`. On every pull request, `pr-body` first resolves the latest released version served by the npm registry (`npm view neo-agent-skills version`), installs the immutable released `neo-agent-skills@${SKILLS_VERSION}` guard into `${{ runner.temp }}/neo-agent-skills-pr-body`, fetches the live PR body via `github.rest.pulls.get` into `${{ runner.temp }}/pr-body.md`, and judges the body with the released guard before sparse-checking out `scripts/check-pr-body.mjs` at `github.event.pull_request.head.sha` to judge the body with the head guard as well.

`agent-preflight: not hosted here; baseline skill-corpus and check-pr-body contract suites ran` (`--change-class capability`).
