Resolves #99

🌿 *The test asked what the contributor variant omits, so for eight days it could not be said that everything it kept was written for somebody else.*

`#54` built the generator and it works. Its acceptance criterion for this variant was **negative** — *"contains no A2A / Memory Core / internal-board mandate; asserted by test, not by review"* — and it passes. Nobody asked the positive question, because the file has never been emitted into a repository and no reader had hit it.

Six statements in it are maintainer-true and stranger-false. **Four are factual, not tonal.**

| the emitted line | the falsifier |
|---|---|
| preamble: *"automatically loaded into your context via `settings.json`"* | `.claude/settings.json` is **untracked**; a fork has none, and neither it nor the tracked `settings.template.json` names `CLAUDE.md` or `AGENTS.md`. The harness reads the file by convention. First sentence a stranger meets, naming a file they cannot find. |
| firewall L1: *"You are an equal-peer maintainer … point out operator mistakes directly"* | they hold no review rights and no merge eligibility here |
| firewall L3: *"There is no hold state … high-value work is infinite"* | written for a nightshift seat; to a drive-by agent it reads as *never stop finding work in someone else's repository*, and it cites `§no_hold_state_taxonomy`, absent from this variant |
| `§file_editing_tool_selection`: `` `replace` `` / `` `write_file` `` / `` `run_shell_command` `` | one harness's tool surface stated as universal. Claude Code's are `Edit`/`Write`/`Bash` |
| `§neo_identity_anchor`: *"**Brain** (`/ai/`)"* | `git ls-files ai/` in `neomjs/neo` → **0** |
| `§pr_diff_equals_pr_body`: *"graph-ingestion substrate"*, `#16528` | vocabulary a first-time contributor cannot cash |

And the measurement that named the shape of the fix: `grep -nE 'npm run\|npm i\|node \|npx \|git clone'` over the emitted document returned **zero**. It told a stranger's agent what not to do and never once what to run.

Evidence: L2 (generator output before and after, plus the five falsifiers above run against the live tree) → L2 required, because every claim here is a document's contents or a repository's file list. Residual: the adoption decision, owned by @tobiu and out of scope below.

## The structural half

**The preamble had no audience axis at all.** `generate()` read `agents-md/preamble.md` as one shared file; every section carries `repos:` and `audiences:` and the preamble carried neither. The one block *every* reader reads first was the one block a generator built to vary everything else could not vary — which is how its false sentence survived.

It is now per-audience **with no fallback**. A missing `preamble.<audience>.md` throws, the same shape as a missing declaration, because a shared default is a maintainer default by construction and that is the defect this PR removes, not a convenience to keep.

## Deltas

- `agents-md/preamble.md` → `preamble.maintainer.md` (byte-identical) · `preamble.contributor.md` (new)
- `scripts/generate-agents-md.mjs` — `readPreamble(root, audience)`, replacing the shared read
- `0101-orientation-contributor.md` (new) — the section that names commands
- `0201` / `0801` / `1201` / `1301` (new) — contributor rewrites of the firewall, file-editing, PR bodies, identity anchor
- `0200` / `0800` / `1200` / `1300` — `audiences:` narrowed to `maintainer`
- `scripts/test-generate-agents-md.mjs` — per-audience preamble fixture; two new arms
- `package.json` / `package-lock.json` / `.github/workflows/reusable-pr-baseline.yml` — **0.1.14**, and see *Ordering* below

**Channel separation is kept, deliberately.** L2 matters *more* to an agent whose operator is a stranger to this repository, not less. Its OWASP ASI01 premise is verbatim; its directive is rewritten to name what a contributor actually meets — an issue body, a CI log, a fetched page — and it keeps the audit path, which resolves in a fork after `npm install` (`.agents/skills` is gitignored and symlinked into `node_modules/neo-agent-skills`).

**What the orientation section says**, all of it @neo-opus-ada's measurement on neomjs/neo#18985 rather than my draft: the `CONTRIBUTING.md` loop (and only a pointer to it — one fact, one artifact), the workstation pane that becomes a real OS window when you drag it past the browser edge, `learn/benefits/Introduction.md`, and that **`neo-agent-skills` is on npm, so a contributor's agent needs neither the Knowledge Base nor the Memory Core.**
