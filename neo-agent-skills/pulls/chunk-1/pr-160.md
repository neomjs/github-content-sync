Resolves #159

Every pull request Dependabot opens now goes to GitHub's auto-merge, majors included, as the operator decided at ~16:00Z: *"dependabot: ALL PRs once CI is green. no limitations."*

- `dependency_allow_list` and `update_types` now accept `*`, meaning any, and both default to it. A caller can still pass a list to narrow them.
- The metadata read continues on error, so a Dependabot pull request that `fetch-metadata` cannot parse still reaches the decision.
- The kill switch is renamed `NEO_AUTOMERGE_DEPENDABOT`. No repository calls the workflow yet, so the 0.1.33 name has no setter to break.
- The gate's `machine_merge` line now names Dependabot's own PRs.

What stays: author and sender must be `dependabot[bot]`, another account's push takes the arming back, and the live admission and `--match-head-commit` still apply. The version is 0.1.35.

**Merge order:** after #158 (0.1.34).

Evidence: L2 (the real decision on fixture events, including under the defaults read from the workflow source, plus the mutation-sensitive source contract) → L4 required for AC-5 (the first auto-merged Dependabot pull request per repository). Residual: AC-5, Residual-Owner: #14.
