Resolves #194

The automerge contract now checks that `continue-on-error: true` directly precedes the `dependabot/fetch-metadata@<ref>` step for any ref, where it used to match the literal `@v2`. Dependabot's v3 bump (#173) no longer reads as a lost guard, and removing `continue-on-error` still fails. The version moves to 0.1.53 because 0.1.52 is already claimed by the open #190 and #193.

Evidence: L1 (the corpus job's contract suite, run on this head and against #173's workflow file) → L1 required (#194's ACs are properties of the validator). Residual: AC-4 needs #173's CI after this merges.
