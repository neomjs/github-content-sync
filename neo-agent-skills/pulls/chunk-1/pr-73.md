Resolves #7

🌿 The premise pre-flight could ask whether a PR leaned on something not yet ratified, but never whether it was quietly undoing something already ratified — so the cheaper failure was catchable and the expensive one was not; now both are one row apart.

The catalog asked *"Upstream not graduated?"* — does this PR **depend** on an ungraduated artifact. The inverse was missing: does this PR **reverse** a graduated decision. That direction is worse precisely because everything looks right — the upstream is legitimate, CI is green, and the diff reads as implementation while amending the authority that governs it.

Evidence: **L1** (source-level substrate change, verified against the repository's own three guards) → L1 required; this is reviewer guidance in a conditionally-loaded audit file, with no runtime surface to exercise. Residual: whether the row is load-bearing enough to deserve mechanical validation — Residual-Owner: #7's own Out of Scope, which names that as a follow-up decision.
