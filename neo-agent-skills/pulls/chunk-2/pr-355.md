Resolves #367

This PR makes the package's scripts run on a Windows checkout: it normalizes CRLF input and makes directory links portable.
- `generate-agents-md`: front matter parses with CRLF line endings.
- `lint-skill-corpus`: budgets count LF-normalized bytes, and `SKILL.md` front matter is matched after normalizing.
- `materialize-harness-skills`: directory links are junctions on Windows (`dir` symlinks elsewhere), and `--check` compares where each link resolves.

Evidence: L2 (both changed specs run on POSIX in CI) → L2 required (#367's ACs). The Windows behavior itself is the contributor's environment and does not run in CI.
