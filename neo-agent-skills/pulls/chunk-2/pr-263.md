## Summary

Scopes `§verify_before_assert` ([`agents-md/sections/0600-verify-before-assert.md`](agents-md/sections/0600-verify-before-assert.md)) by claim class across all maintainer `AGENTS.md` variants emitted by `neo-agent-skills`, and aligns the `blog-post` skill ([`.agents/skills/blog-post/SKILL.md`](.agents/skills/blog-post/SKILL.md), [`.agents/skills/skills.manifest.json`](.agents/skills/skills.manifest.json), and [`.agents/skills/blog-post/references/blog-authoring-guide.md`](.agents/skills/blog-post/references/blog-authoring-guide.md)) so public narratives, outbound posts, and funding/pitch copy share the reader/acceptance pre-flight and a single final-version fact-check gate run by a seat that did not draft the claims.

1. **`agents-md/sections/0600-verify-before-assert.md` (`AC-1`, `RA-1`, `RA-2`):**
   - Preserves the core rule trigger and artifact scope (*"Before asserting a factual claim, premise, or framing in any public artifact (review, ticket, Discussion, comment, commit, memory), run the tool that would falsify it, scoped below."*), the Pre-Flight statement, `the tool RESULT is the V-B-A` in the Prior-art sweep, and `Step 2.5`'s `cross-substrate sweep for high-blast proposals`.
   - Adds **Scope by claim class (`neo-agent-skills#262`)**:
     - **(1) Code, runtime, architecture** — re-run every time; a check is spent the turn it ran (`neo #15780`).
     - **(2) Record claims with a receipt** (number+query, decision+anchor, date+commit) — cite the anchor; re-measure only if changed or missing (`neo-agent-skills#262`).
     - **(3) Business and pitch text** — sets the cadence for every claim inside it (including `(1)`/`(2)`): mine the record first, write from anchors, and run **one consolidated fact check at the final version**, never per-revision sweeps (`neo-agent-skills#262`).
   - **Compactions funding exact `0 B` neutrality (`1,411` → `1,411` B):** retired the `Tools are always available, always read-only, always cheap` and `#11089 self-Drop+Supersede` prose (already covered in `AGENTS_ATLAS.md §anti_hallucination_policy` and `0100-core-values.md`) and kept the anti-pattern rationale sentence in `blog-authoring-guide.md` §2 rather than duplicating it in the turn-loaded section.
2. **`.agents/skills/blog-post/SKILL.md`, `.agents/skills/skills.manifest.json`, and `.agents/skills/blog-post/references/blog-authoring-guide.md` (`AC-2`, `RA-3`):**
   - Routes funding/pitch copy (`funding/**`) alongside blog and outbound posts (`11` lines in `SKILL.md`, `205` B <= `220` B `descriptionBudget` in `skills.manifest.json`).
   - Codifies the **Reader / Acceptance Pre-Flight** (*"why would the audience NOT click?"* for posts; *"why would they NOT accept us, and why would they?"* for funding/pitch copy, mining the record first) in §1 and the **Single Final-Version Fact-Check Gate** in §2 — explicitly requiring **a seat that did not draft the claims** to run the final-version check (`RA-3`).
3. **Commit-message retrieval anchor (`AC-3`):**
