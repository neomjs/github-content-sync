Resolves #346

`neo-agent-skills-agents-md --pointer` is now a consumer's whole `AGENTS.md` stage. It registers the `neo-agents-md` git filter (clean, a `cat` smudge, required), writes the generated rules into `--out`, and lets the index re-read the file. `git status` stays clean, and git keeps the pointer.

The pointer, its marker and the filter's clean CLI live in `scripts/agents-md-pointer.mjs`, exported as `neo-agent-skills/agents-md/pointer`. This moves the mechanism that neomjs/neo#20749 put in the Engine, with neomjs/neo#20777's smudge, next to the generator. The Engine and `devindex` can then each declare one line, and the Brain can import the marker. Version 1.4.0.

Evidence: L3 (real git in temporary consumer checkouts, with the package under `node_modules` as a consumer installs it) → L3 required (AC-2, AC-3).

## Deltas from ticket
- The stage is a flag of the existing bin (`--pointer`), not a sibling bin. A consumer's `generate-agents-md` script stays one line, and the Engine's `agentsMdArgs` guard accepts it unchanged.
- The pointer names the first repository of `--repo`, by convention the consumer itself (`neo,neo-agent-brain` → `neo`).
- The README documents `--pointer` and the `./agents-md/pointer` export, and the ticket's Contract Ledger names that README as their docs.

  - Run with a `HOME` whose `.gitconfig` signs commits and carries a failing `neo-agents-md` filter, the earlier test failed. Now it passes.
