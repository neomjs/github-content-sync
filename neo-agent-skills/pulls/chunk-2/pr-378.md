Resolves #377

🖖 A sunsetted seat can no longer be rotated into a second session while its own resumed transcript keeps working.

neomjs/neo-agent-brain#1383 will open a fresh session for a seat whose newest self-DM is a sunset handover. Two writers could still break that:
- A transcript that resumes after its own sunset (two seats did on 2026-11-13, neomjs/neo-agent-brain#95 comment 6849148334) would race the rotated session.
- An untagged addendum to a handover would silently cancel the rotation.

`context-recovery` step 1a now has the resuming transcript rescind first: a `sunset-rescinded` self-DM, and only if it resumes work rather than staying quiet (`session-sunset` Step 9's stale-wake invariant stands). Its ledger slot records `successor | rescinded`. `session-sunset` Step 8 makes an addendum carry the handover tag (Vega's input).

Evidence: L1 (the payloads' text, the corpus lint, this repository's tests) → L1 required (every AC is a statement about the payload's text). Residual: none.

## Deltas from ticket

- The rescind is conditional on resuming work, which tightens the ticket's wording. `session-sunset` Step 9 says post-sunset wakes in the old transcript are noise. A transcript that obeys that writes nothing, and only one that resumes anyway rescinds.
- `session-sunset` gets one sentence for the addendum. The rescind lives only in `context-recovery`, so the rule has one home.

- **`context-recovery` step 1a: `keep` in this payload.** It fires once per resumed sunset, during recovery, which is where the handover is already being read. A miss puts two sessions on one seat. Discipline-only, and the detector reads its output.
- **`session-sunset` Step 8: `keep`, one sentence**, beside the receipt it qualifies.
- **Load effect:** no `SKILL.md` changes, so the always-loaded delta is 0 bytes. The two conditional payloads grow by 437 bytes against the corpus lint's 250, justified in the commit (`[skill-growth-justified: …]`).
- **Retirement:** both lines go when the rotation reads a structured handover state instead of the newest self-DM's tag.
