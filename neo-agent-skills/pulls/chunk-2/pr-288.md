Resolves #287

`whitebox-e2e-protocol.md` §3 now tells an e2e author to wait for what the test acts on, not for first paint. A lazily imported plugin installs after the component's first render, so a gesture or one-shot read can beat it. Two engine flakes on 2026-11-05/06 had exactly that cause: IssuesShowcase's menu triggers (neomjs/neo#20407) and CalendarMonthEventDrag's drag plugin (neomjs/neo PR #20404). The package moves to 0.1.91.

Evidence: L1 (a guidance sentence in a skill payload; the corpus lint and the repository suite) → L1 required (#287's ACs are text and a version). Residual: none.
