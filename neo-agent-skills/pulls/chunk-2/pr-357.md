Resolves #353

## Summary

When a repository worktree or review checkout does not have `neo-agent-skills` installed in `node_modules`, the required `neo-agents-md` clean filter crashed git upon cleaning `AGENTS.md`.

The clean command now checks if `node_modules/neo-agent-skills/scripts/agents-md-pointer.mjs` exists before delegating to node. When the module is absent, it drains stdin (`cat >/dev/null`) and answers the pointer already held in the index (`git cat-file blob :AGENTS.md`).

## AC Evidence

- `scripts/test-agents-md-pointer.mjs` gains a real-git worktree case without `node_modules` where `AGENTS.md` is rewritten: `git status` and `git add AGENTS.md` exit 0, and the stored blob remains the pointer. The case fails against the previous clean command (exit 128).
- With the module present, existing contract checks continue to pass.
- Version bumped to 1.4.3 in `package.json` and `package-lock.json`.

## Test Evidence

- Ran `node scripts/test-agents-md-pointer.mjs`: pass (`✅ agents-md-pointer contract checks pass.`).
- Ran `node scripts/check-version-bump.mjs --base dev`: verified 1.4.2 → 1.4.3 bump.
- Ran `node scripts/check-commit-authorship.mjs --base dev`: pass.
