Resolves #271

`scripts/check-pr-body.mjs` now exports `findImageEmbedViolations(body)` and appends its findings to `visible` in `findBodyViolations({body})`. It scans `markdownContentLines(body)` with CommonMark inline code spans stripped for Markdown (`![alt](url)`) and HTML (`<img … src="url">`) image embeds hosted on `raw.githubusercontent.com`, reporting each offending URL and its session-authenticated `https://github.com/<owner>/<repo>/blob/<ref>/<path>?raw=true` replacement.

Evidence: L2 (`node scripts/test-check-pr-body.mjs`, `npm test`, `npm run lint`) → L2 required (all 3 ACs are pure offline contract properties covered by the unit suite and corpus lint). No residuals.
