## Slot rationale (§1.1) and load effect

- **§1 visuals sentence: `rewrite`.** The optional-diagram sentence becomes the requirement. It is edge-case-triggered, because it loads only behind this skill's trigger, and the cost of a miss is a review cycle (the operator's RC on neomjs/neo#20226). DISCIPLINE-ONLY today, but a MACHINE-ENFORCEABLE-CANDIDATE: a neomjs/neo lint could fail a changed `learn/blog/*.md` with no visual. #265 keeps that out of scope until the rule slips.
- **§5 Images + Ship: `keep`, new.** These are mechanics, so they sit beside File / Register / SEO. The receipt clause is the slot that makes an author emit the rule in the PR body.
- **`SKILL.md` closing line: `compress-to-trigger`.** The router gains the trigger words only; the rule body lives in the atlas.
- **Retired:** §1's byline sentence (§5 **Identity** already says it) and the closing "Empirical Anchor" section (line 5 already anchors #13486).
- **Load effect:** the always-loaded Map (`SKILL.md`, loaded when the skill fires) grows 34 B; the conditional atlas (`blog-authoring-guide.md`) shrinks 40 B. No turn-loaded substrate changes.
