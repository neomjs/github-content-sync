🌿 After this, "waits on a peer's line" can no longer be the last thing a seat says.

The sunset trigger now reads the wake plane's gate in tokens: sunset at or before 200k context tokens and never run above 250k, because `ai/daemons/wake/contextGatePolicy.mjs` (neo-agent-brain) defers every wake into a session above it and the seat never sees the receiver's warning; the instrument is named (`get_usage` on Claude Desktop, the harness's own gauge elsewhere), and the 75 % line survives only as the fallback for a harness without a gauge. The post-recovery "~300k" rule of thumb from #145 is replaced by the gate, which sits below it. The continuity self-DM is named as the sunset receipt that neomjs/neo-agent-brain#1383 reads at the gate before asking neomjs/neo-agent-institution#842 for the fresh session: at night the seat writes it and ends, by day the sunset stays the seat's call. `post-review-pickup` §7 gains the wait rule: a turn never ends into an unbounded wait; owned lanes first, then a self-scheduled wake inside the cache TTL or a subscription, because `AGENT:*` broadcasts do not wake. The skill description and its manifest row carry the same trigger within the 220-byte budget.
