Resolves #244

The operator's merge rule for neo-stage (2026-10-30): *"i will not merge a single new PR without a before and after screenshot in the PR body. at least one."* The review template now checks every neo-stage PR for that pair, with one line under Conditional Audit Triggers keyed on the repository:

```diff
+- **📸 Before/After Audit:** PR targets `neomjs/neo-stage`. The body embeds at least one before (base) and one after (head) screenshot of what it changes; a missing pair is Request Changes, since the operator merges no Stage PR without one.
```

Evidence: L1 (a static template line; the corpus lint, version check and every test runner ran locally) → L1 required (AC-1, AC-2, AC-3). The line takes effect on the next neo-stage review.
