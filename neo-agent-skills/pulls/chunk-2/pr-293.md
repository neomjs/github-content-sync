Resolves #292

A PR that adds one-shot logic now files its retirement ticket before the review request. One-shot logic means a data fix, migration or repair whose job is done after one run.
- **Ownership:** the ticket is assigned to the author and natively `blocked_by` the close target, so it turns ready at merge.
- **ACs:** deploy if needed, run with a receipt, then delete the code, its tests and any code only it uses.
- **Reviewer side:** a missing retirement ticket is one Required Action.

This is @tobiu's rule from neomjs/neo-agent-brain#1502, verbatim: "there MUST be a task to USE the logic, and then retire it." It is placed where it fires only for the rare PR it concerns, with no template line.

Evidence: L1 (two skill-payload sentences; their trigger is author and reviewer reading) → L1 required (no runtime or CI claim). Residual: none.
