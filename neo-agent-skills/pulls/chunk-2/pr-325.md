Resolves #324

Enforces `--audience app` skill closure in `scripts/lint-skill-corpus.mjs` (§3 reference integrity) and adds regression coverage in `scripts/test-lint-skill-corpus.mjs`:
1. Rejects relative Markdown links (`[...](./...)` / `[...](../...)`) from an `app`-audience skill (`SKILL.md` and `references/**/*.md`) that resolve into a non-`app` skill directory.
2. Rejects prose units (paragraphs and individual list items outside fenced code blocks) in an `app`-audience skill that reference a non-`app` skill name (backticked `` `<skill>` ``, slash-invoked `/<skill>`, or `.agents/skills/<skill>`) without an explicit `Agent OS` / `maintainer` scope qualifier.

Evidence: L2 (automated skill-corpus lint and `test-lint-skill-corpus.mjs` fixture suite, `43/43 passed`) → L2 required (AC-1, AC-2, AC-3). Residual: none.
