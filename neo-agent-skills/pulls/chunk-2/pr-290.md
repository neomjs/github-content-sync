Resolves #284

🌿 A faithful reviewer can no longer welcome a first-time contributor with a single link.

The micro form's `Opening` now asks for thanks for one specific judgement, then pointers into Neo, each linked at its canonical owner: what Neo is, the part the PR touched, how to run it, and what to pick up next. Setup stays a link to the Engine's `CONTRIBUTING.md`, never a pasted command pair, and the npm fact stays. The full form's `Peer-Review Opening` carries the same rule for external and first-time contributors. Version 0.1.91.

Class: capability (`feat`): the templates now ask reviewers for an orientation they did not ask for before. agent-preflight: not hosted here (no `ai/` tree); the `skill-corpus` workflow carries lint, budgets and the version bump.

Evidence: L1 (template text, corpus lint and budgets) → L1 required (AC-1–4). Residual: none.

## Deltas from ticket

- The ticket's Design authority line was added during intake: #97's operator source quote, "giving some hints and input on the neo ecosystem". The shipped slot had reduced that to one link.
- The ticket expected net bytes about flat. The example shrank (453 → 441 bytes), but the rule now names four pointer kinds where it named one, so the two assets grow by 93 bytes net (micro +61, full +32). The sunset below covers it.
- The example's "next" points at help wanted, not good first issues. The Engine's `CONTRIBUTING.md` reserves good first issues for first-time contributors, and this opening is written at their first merge (Sophie's finding).

## Slot rationale and load effect

- **Micro `Opening` slot:** `rewrite`. The rule goes from "ONE entry point" to four pointer kinds.
- **Full `Peer-Review Opening`:** `rewrite`. Generic encouragement becomes the same pointer rule for external and first-time contributors.
- Trigger frequency: one external-contributor review at a time. Failure severity: moderate; a newcomer lands one PR and leaves unoriented. Enforceability: `DISCIPLINE-ONLY`, since no lint reads an opening.
- **Load effect:** neither file is always-loaded. Both are assets the `pr-review` router names, read only when a reviewer picks that form. The always-loaded delta is zero; the conditional delta is +93 bytes.
- **Sunset (from #97):** retire the slot when an external-contributor review path exists as its own skill, or when a body lint enforces the opening.

Decision Record impact: none. ADR 0008's skill anatomy is unchanged, and no router or manifest is touched.
