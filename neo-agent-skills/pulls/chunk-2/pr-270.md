Resolves #269

Adds the **Long-Horizon Surrounding-Topology Check (Surface Evolved Since `createdAt`)** discipline to `ticket-intake` and `ticket-triage` so maintainers picking up or triaging older tickets whose core intent remains valid and whose named surface or class family changed since `createdAt` (`git log --since=<createdAt> -- <path>`, `get_class_hierarchy`) map the ticket onto evolved subclasses, layout adapters, and multi-sibling/addon consumers rather than validating only the originally named file in isolation or halting valid backlog items with `needs-re-triage`.
