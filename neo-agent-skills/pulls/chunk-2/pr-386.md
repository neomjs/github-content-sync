🌿 A reconnect can no longer pass for a new session.

`context-recovery` step 1a now covers both sides of a sunset. The transcript that wrote the handover rescinds if it resumes work (#377). Any other session is its successor. It sends a self-DM with the subject `[sunset successor] <handover id>`, tagged `sunset-successor`, `inReplyTo` the handover and `wakeSuppressed: true`, once per handover: only when an outbox read by that tag, with `includeArchived: true`, shows no subject naming the handover's id, so a second recovery in the same successor sends none. The subject carries the id because no mailbox read returns `inReplyTo`. The rotation's reader skips the marker when it looks for the receipt, and `complete` keys on it (neomjs/neo-agent-brain#1712, Ada). Until #1712 lands, the marker, as the newest self-DM, ends the rotation outright (#377, Fix item 3). The line names its retirement: D#19401, when Memory Core sessions bind to the transcript.

Evidence: L1 (skill text; lint) → L3 required (a rotated seat's successor marker completes its rotation on the plane, which needs the lane readers). Residual: the plane receipt, Residual-Owner: neomjs/neo-agent-brain#1712.
