Resolves #255

The pr-review template's 📸 Before/After Audit now counts a Stage screenshot only if it renders for a signed-in viewer. It names the route that works on the private repository, `https://github.com/neomjs/neo-stage/blob/<full-sha>/<path>?raw=true`. It also treats a `raw.githubusercontent.com` embed as a missing pair; that form is what left neomjs/neo-stage#519 and neomjs/neo-stage#630 with pairs nobody could see.

Evidence: L1 (the template line, corpus lint, version check) → L1 required (both ACs are properties of the text and the lint). No residuals.

## Slot rationale
This PR modifies one line: the 📸 Before/After Audit, a conditional trigger in `pr-review-template.md`.
- **Disposition:** `keep`, amended in place. It is loaded once per Stage review and never always-loaded.
- **Frequency:** it fires on every neo-stage PR review.
- **Severity:** a miss leaves the operator without visible evidence for a merge he gates on screenshots (neomjs/neo-stage#519, neomjs/neo-stage#630).
- **Enforceability:** a reviewer reads the URL's host.
- **Retirement:** retire the line when neo-stage turns public or a PR-body lint enforces the route.
