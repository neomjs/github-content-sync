Resolves #256

Skills now ships the CodeQL lane as a reusable workflow, `.github/workflows/reusable-codeql.yml`, and runs it on itself (`codeql.yml`). Each language leg analyses with `build-mode: none` and uploads under Default Setup's own `/language:<language>` category, so alert history carries over. Each job gets least-privilege permissions. The engine's extraction guard is ported to `scripts/check-codeql-extraction.mjs`; the lane fetches it at the workflow's own commit and runs it from `runner.temp`, never from the caller's checkout. With a committed workflow, a fork pull request gets a CodeQL run, which Default Setup never gave it. That is the deadlock behind #338.

**Merge-order gate (AC-4):** the operator switches CodeQL Default Setup off in the Skills settings before this merges. While Default Setup is on, GitHub refuses this lane's Advanced-Setup uploads.

Evidence: L2 (the guard's verdicts and exit codes under a fake Actions API, plus the workflow contract with negative mutations, all in `npm test`) → L3 required (AC-2: the lane's own run on this PR). Residual: none once this PR's CodeQL run is green.

## Deltas from ticket
- **Caller prefix.** The guard matches Analyze legs as `Analyze (<language>)` directly or as `<caller job> / Analyze (<language>)` when called, so its own job never matches.
- **Testable exit codes.** `runGuard()` returns the exit code (`0` clean, `1` dropped, `2` unread), so the tests assert exit codes without spawning a process.
- **Guard delivery.** The guard is fetched over the API at `job.workflow_sha` and run from `runner.temp`. This follows `reusable-pr-baseline.yml`'s rule that a guard never runs from the caller's checkout. It is a single dependency-free file, so the job needs no install.
- **Intake.** I authored this ticket on 2026-11-01. The drift probe since then found zero intersection on the edit surface; only the cited precedent `reusable-pr-baseline.yml` moved. Prescription checked: `.github/workflows/reusable-pr-baseline.yml` owns this concern, as the shared-CI precedent that consumers call at a release tag.
