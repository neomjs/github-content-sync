Resolves #256

Skills now ships the CodeQL lane as a reusable workflow, `.github/workflows/reusable-codeql.yml`, and runs it on itself (`codeql.yml`).
- **Analysis.** Each language leg analyses with `build-mode: none` and uploads under Default Setup's own `/language:<language>` category, so alert history carries over. Each job gets least-privilege permissions.
- **The guard.** The engine's extraction guard is ported to `scripts/check-codeql-extraction.mjs`. The lane fetches it at the workflow's own commit and runs it from `runner.temp`, never from the caller's checkout.
- **Fork PRs.** With a committed workflow, a fork pull request gets a CodeQL run, which Default Setup never gave it. That is the deadlock behind #338.
