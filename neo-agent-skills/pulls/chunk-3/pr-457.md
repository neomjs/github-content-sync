Resolves #455

Plugin bundles no longer carry fetchable links to other neomjs repositories' guides. Directory Policy §2F applies there just as it did to the skill-file links fixed in #453.

What changes:
- An absolute `github.com/neomjs/<repo>/(blob|raw)/…` or `raw.githubusercontent.com/neomjs/…` link now projects as the name `neomjs/<repo>:<path>`.
- An absolute link to a skill in this repository is reduced to its repo-relative path and takes the existing skill-aware rewrite: own skill, bundled sibling, or `neo-agent-skills:` name.
- `--check` now refuses any neomjs blob or raw URL in a bundle.

`plugins/neo` has no such links, so only its version moves. The 33 links across the 10 skills that #446's magnets will bundle are covered from the first projection.

Evidence: L1 (contract tests, `--check`, local) → L1 required (AC-1 to AC-3).

agent-preflight: not hosted here (no `ai/`). Baseline `npm run lint -- --base origin/dev` and `npm test` ran, exit 0.
