Open and closed-unmerged PRs still run every check, as the workflow's one-context rule requires; the header now says why a merged head is the one exception.

Evidence: L2 (contract arms over the committed workflow, with negative mutations) → L2 required (AC-1, AC-2). Residual: the jobs-API count on a merged Engine PR is post-merge.
