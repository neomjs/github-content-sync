Resolves #453

Plugin bundles no longer hand Claude a fetchable URL to a skill they don't contain. The Anthropic Software Directory Policy (§2F) says a plugin "must not direct Claude to dynamically pull behavioral instructions from external sources", and the generator's HTTPS rewrite did exactly that.

What changes:
- A reference to a skill outside the bundle now projects as the name `neo-agent-skills:<skill>/<rest>`, which no session can fetch.
- `--check` fails on any `neo-agent-skills` blob or raw URL inside a bundle.
- `plugins/neo` is regenerated. Its single link (`context-recovery-workflow.md:112`, pointing at pr-review's identity-claim audit) is now a name. That link also ships in the 2.6.1 submission currently in review.

Evidence: L1 (contract tests, `--check`, `claude plugin validate`, local) → L1 required (AC-1 to AC-3).

agent-preflight: not hosted here (no `ai/`). Baseline `npm run lint -- --base origin/dev` and `npm test` ran, exit 0.
