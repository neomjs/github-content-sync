Resolves #434

The default-deny publish lint now ships once, as bin `neo-agent-skills-public-docs`, instead of one copy per spoke. It holds the union of the devindex, Institution and Brain copies, and each spoke-specific value is an input: `--spoke`, the manifest fields `excludedDirs` and `sourceLinkRoots`, and client-name terms from `NEO_PUBLIC_DOCS_FORBIDDEN_TERMS`. Both mount shapes in use pass, `treeMount` (devindex, Institution) and Brain's `treeMounts`. Minor bump to `2.4.0`, because consumers opt into the new bin.

Evidence: L3 (the real bin, run on each spoke's live head) → L3 required (AC-1 names the live manifests). Residual: none.

agent-preflight: not hosted here; `skill-corpus` (this repository's CI) runs on this head, and `check-pr-body` ran locally on this body.

Review focus: the `treeMounts` and `sourceLinkRoots` semantics, since the hub materializer (neomjs/pages#158) reads the same manifest, and the git-tracked rule for source links.

## Deltas from ticket
- **The third copy joins the union.** Brain's copy (neomjs/neo-agent-brain#1892 at `9e4696b0`) arrived with the ticket and is not a twin: it has `treeMounts`, tree-parent checks, forbidden terms and links into `ai/**`. A bin without these would leave Brain on its own copy. The ticket's Contract Ledger now has a row for each added surface.
- **A source link must reach a path git tracks**, not just a file on disk. This replaces the Brain copy's hard-coded list of ignored `config.mjs` overlays.
- **A forbidden-term finding names the term by its position, never its text**, so a public CI log never repeats a client name. The summary line counts the terms checked, so an unset variable reads `0 forbidden term(s) checked` rather than passing silently.
- **Each scan reads a line once.** The copies' link pattern could rescan the whole file from every bracket. The new spec has timing arms in the style of `check-guides`' crafted-guide arms.
- A duplicate tree id is refused; before, two leaves silently collapsed into one file.

## Test Evidence
- Live acceptance with the real bin, one detached worktree per head: devindex `fd98ff5` 26 OK, Institution `16d78135` 7 OK, and Brain `9e4696b0` 62 OK once its manifest adds `excludedDirs` and `sourceLinkRoots: ["ai/"]`. As-is, Brain gets 42 findings, each one an `ai/` source link. The spoke copies pass on the same heads.
- Red control on a live guide: one added line in devindex `learn/OptIn.md` produced the copy's three findings (host path, private repository, broken link) plus the forbidden term, and the term's text appeared nowhere in the output.
