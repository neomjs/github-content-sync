Resolves #424

An agent PR body that embeds a frame now carries a `Frame critique:` line. The line names what a reviewer could fault in each frame and what became of it. The shared body check refuses an agent body that embeds an image without the line, the PR template asks for it under Test Evidence, and the rendered-surface audit tells the reviewer to read it against the frames. A human PR is judged on its close target alone, as before.
