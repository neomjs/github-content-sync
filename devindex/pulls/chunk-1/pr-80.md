Resolves #1

The fix for #1 arrived with the dependency: this repository now installs `neo.mjs@13.2.0` (`package.json` declares `^13.2.0`, and the lockfile resolves 13.2.0). That release carries both engine halves, `refreshColumns` and `isMeasuredWidth`. This PR adds the regression arm the ticket's reproduction implied, `test/playwright/e2e/grid/ColumnResize.spec.mjs`. The test drags the `rank` column's resize handle 150px. The body cells must take the header's width mid-drag and on drop, and the following columns must shift by exactly the width gained. A second arm scrolls the grid and requires every component-backed `User` cell to show its own row's record. No app or view code changes.

Evidence: L3 (local headless Chrome against this app's own dev server: green on the installed 13.2.0, red on 13.1.0) → L3 required (AC-2…AC-5 are rendered-grid behavior). Residual: none. devindex CI runs only the unit project, so these arms run outside CI, like the existing `grid/` specs.
