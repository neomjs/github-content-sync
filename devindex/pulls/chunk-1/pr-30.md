Resolves #10

`-f` told the engine's build scripts they were running inside the neo.mjs checkout. In this workspace they weren't, and that shipped the wrong app: the production bundle carried the engine package's pre-split `apps/devindex`, along with Portal, AgentOS and the examples, behind this repository's own entry files. Dropping `-f` from `build-all`, `build-all-questions`, `build-themes` and `build-threads` builds this repository's code and SCSS instead.

Evidence: L2 (both builds run against `neo.mjs@13.1.0`, their outputs compared by file and by bundled class) → L2 required: a build-script change whose output is the observable. No residuals.

## AC Evidence
| AC-1 | `-f` removed from `build-themes` and `build-all` (and `build-all-questions`) |
| AC-2 | `-f` removed from `build-threads`, on a reproduction instead of a comment: with it, `webpack.config.appworker.mjs` never redirects the App worker's `import(\`../../${appPath}\`)` context to the workspace, so `dist/production/chunks` carries `Portal.view.Viewport` (5 chunks), `AgentOS.view` (10) and `Neo.examples` (533). Without it, those counts are 0, 0 and 1, and the learn provider's `contentPath` is this repository's `"/learn/"`, not the engine's `learn/guides/devindex/` |
| AC-3 | With the engine's three `apps/devindex` SCSS folders moved out of `node_modules/neo.mjs/resources/scss`: no `-f` → 14 `apps/devindex` CSS files in each of `development`, `esm` and `production`; control with `-f` → 0 in each |
| AC-4 | Met as amended in #10 ([Grace's confirmation](https://github.com/neomjs/devindex/issues/10#issuecomment-5814770872)): the clean build holds this workspace's app and service-worker entrypoints and its 14 stylesheets per environment. The count change is accounted for: 16,646 → 14,408 files, all 2,238 of them engine-app `chunks/` that AC-2 removes |
| AC-5 | Every run above asserted `test ! -e dist` after `rm -rf dist`, before building |

## Deltas from ticket
- **AC-4 was amended in #10.** The original criterion expected `-f` to matter only for themes and asked for an unchanged file count. The measured baseline was the bug itself: 2,238 chunk files of engine apps that this repository never runs. Emmy proposed the accounted-for replacement and Grace applied it ([5814770872](https://github.com/neomjs/devindex/issues/10#issuecomment-5814770872)). ## Test Evidence

- `npm run check-data-tracking`, `neo-agent-skills-materialize --check` and the unit project are green. One unit spec (`OptInPhaseIsolation`) flaked once in a parallel local run (`ENOENT` renaming `threshold.json.tmp` in the shared data dir), then passed 3/3 alone. It's untouched by this diff, and CI on `dev` is green.
- **Found, not fixed here:** without `-n`, `build-themes` and `build-threads` crash in inquirer 14 (`Prompt type "list" is not registered`), with or without `-f`. Recorded as a defect-note.
