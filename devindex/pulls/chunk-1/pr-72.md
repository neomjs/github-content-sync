<h2>🧰 WebMCP</h2>
<p>New <a href="[QUARANTINED_URL: playwright.dev]">page.webmcp</a> and <a href="[QUARANTINED_URL: playwright.dev]">frame.webmcp</a> give access to the tools that a page registers through the experimental <a href="[QUARANTINED_URL: playwright.dev]">WebMCP</a> browser API, so you can test them like any other part of your app:</p>
<pre lang="js"><code>const browser = await chromium.launch({ args: ['--enable-features=WebMCP'] });
const page = await browser.newPage();
await page.goto('[QUARANTINED_URL: example.com]');
<p>for (const tool of await page.webmcp.tools())
console.log(tool.name, tool.description);</p>
<p>const result = await page.webmcp.callTool('add', { a: 2, b: 40 });
console.log(result.content[0].text); // &quot;42&quot;
</code></pre></p>
<p><a href="[QUARANTINED_URL: playwright.dev]">Playwright MCP</a> also supports WebMCP by default, with page-defined tools offered to the agent as <code>webmcp_&lt;tool&gt;</code>. Pass <code>--no-webmcp</code> to opt out.</p>
<p><a href="[QUARANTINED_URL: playwright.dev]"><code>playwright-cli</code></a> exposes them as well:</p>
<pre lang="bash"><code>playwright-cli webmcp-list
playwright-cli webmcp-call search_catalog --params '{&quot;query&quot;:&quot;cats&quot;}'
</code></pre>
