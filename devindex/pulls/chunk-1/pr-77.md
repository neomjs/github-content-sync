<h2>Neo.mjs v13.2.0 Release Notes</h2>
<p><strong>Release Type:</strong> The Dock Layouts Release, a massive features release: 2,195 merged pull requests, as close to a major as a minor gets, with the package's entry points unchanged
<strong>Stability:</strong> Stable
<strong>Upgrade Path:</strong> See <em>Upgrading from 13.1</em> below for stable package entry points, removed files and scripts, and behavior changes that require action.</p>
<blockquote>
<p><strong>TL;DR:</strong> 13.0 and 13.1 were Agent OS releases. 13.2 belongs to the Engine, and its centerpiece is Dock Layouts: declare an application's panes and where they go, and the engine builds the splitters, tabs, edge rails and drop targets. Then the arrangement leaves the browser window. Tear a pane out into its own OS window, carry it to another window, bring it home, and undo or reset the whole journey. The panes stay the same live components, not copies, because the app's windows share one App Worker. Around it, the repositories split: the Agent OS and the Fleet Manager moved to their own repositories, so <code>neo.mjs</code> installs, builds and tests as the Engine alone. Grid cell editing was rebuilt for pooled rows, so an edit follows its record through scrolling. Next comes Agent Institution, the cockpit where an operator runs a standing team of AI agents, itself an application on this release's Dock Layouts.</p>
</blockquote>

<h2>📋 13.2 in 2 Minutes</h2>
<p><strong>The one line:</strong> a workspace can leave its window. Panes go out as real OS windows and come home as the same live components, under one undo history.</p>
<p><strong>Three heroes:</strong></p>
<ol>
<li><strong>Dock Layouts.</strong> Each workspace keeps its arrangement in one document in the App Worker, and one shared history spans the windows. A pane can leave as a real OS window and come home with its state, and Undo, Redo and Reset cover the whole journey.</li>
<li><strong>The repositories split.</strong> The Agent OS and the Fleet Manager left the Engine's repository and release on their own lines; the Engine builds, packs and tests without them.</li>
<li><strong>Grid cell editing.</strong> Editing returned to the Grid, built for its pooled rows and cells: double-click, Enter or F2 starts an edit, and scrolling its cell out of view suspends the edit instead of losing it.</li>
</ol>
<p><strong>The scale:</strong> 2,195 pull requests merged in <code>neomjs/neo</code> since 13.1.0 was published on 2026-07-03, about 920 of them Agent OS, Fleet Manager and DevIndex work done here before it moved. Across the organization the count is 3,041, with 379 in the Brain's repository and 333 in Agent Institution's (GitHub search <code>is:pr is:merged merged:&gt;=2026-07-03T21:40:28Z</code>, the 13.1.0 release's publish time, run 2026-10-11 15:29Z). The <em>Full Changelog</em> at the end groups them.</p>
<p><strong>The short route:</strong> build a workspace from panes and zones with the <a href="[QUARANTINED_URL: github.com]">first Dock Layout tutorial</a>, then edit in place in the <a href="[QUARANTINED_URL: github.com]">Grid cell-editing example</a>: double-click a cell, or press Enter or F2, then type or pick a number, a date or a country. The <a href="[QUARANTINED_URL: github.com]">5,000-record Buffered List</a> shows a bounded row pool.</p>
<p><strong>Read for your work:</strong> Dock if an app needs an IDE-shaped layout or spans windows; the repositories split if you install or contribute; Grid cell editing if users change data in place; <em>Also in 13.2</em> and the upgrade path if you extend or ship the Engine.</p>
<p><strong>Three longer reads:</strong> <a href="[QUARANTINED_URL: github.com]">Drag it to the other screen</a> shows what Dock Layouts give a multi-window dashboard and its users, <a href="[QUARANTINED_URL: github.com]">A workspace that can leave its window</a> tells how the windows share one application, and <a href="[QUARANTINED_URL: github.com]">One repository per reader</a> tells the split and the cockpit we build next.</p>

<h2>🧩 Dock Layouts: a workspace that can leave its window</h2>
<p>Arrange the Workstation: drop panes into tabs from an <a href="[QUARANTINED_URL: redirect.github.com]">indicator menu</a>, split a zone, <a href="[QUARANTINED_URL: redirect.github.com]">fold a pane into an edge rail</a>. Then pull a tab past the browser window's edge, and it <a href="[QUARANTINED_URL: redirect.github.com]">becomes a real OS window mid-gesture</a>. Carry it over another window, and that window <a href="[QUARANTINED_URL: redirect.github.com]">takes over the drag as a tab header</a> whose drop zones <a href="[QUARANTINED_URL: redirect.github.com]">answer the held pointer</a>; release, and the pane joins the target. Close a popup, and <a href="[QUARANTINED_URL: redirect.github.com]">all its panes return to main in one undoable step</a> with their component, provider and store identities intact. <a href="[QUARANTINED_URL: redirect.github.com]">Undo and Redo</a> walk the arrangement across windows, and <a href="[QUARANTINED_URL: redirect.github.com]">Reset to default</a> brings back the shipped one.</p>
<!-- raw HTML omitted -->
<p><em>The Metrics tab carried over the 100k Matrix, before release: the indicator offers five placements, and the region the tab would take is painted. A frame from the Workstation's film tour.</em></p>
<h3>One document for the whole workspace</h3>
<p>That continuity needed a different foundation. Before it, you could select the second tab and resize its split, and the first tab came back. An initial edge-zone band offered no resize handle, while a split made by rearranging panes did. The July <a href="[QUARANTINED_URL: redirect.github.com]">choreography</a> and <a href="[QUARANTINED_URL: redirect.github.com]">perspectives</a> demos could move a pane into a popup opened from the workspace and bring it home, but those gestures exposed a deeper problem. Selection lived in a view while geometry lived in the stored layout; the next projection could disagree with what the user just did (D#17818, <a href="[QUARANTINED_URL: redirect.github.com]">#17836</a>).</p>
