<h2>[0.57.0]</h2>
<h3>New Features and APIs</h3>
<ul>
<li>Adds <code>editor.wordWrapIndicator</code> to display an indicator at the wrapping column of soft-wrapped lines.</li>
<li>Adds <code>editor.fullwidthCharacterWidth</code>, with <code>font</code> and <code>twoCells</code> modes for rendering full-width characters.</li>
<li>Adds <code>languages.score</code> to score a language selector against a URI and language.</li>
<li>Exports the <code>editor.DiffEditorViewMode</code> type.</li>
<li>Adds <code>isForAnotherDocument</code> to the inline completion <code>languages.LifetimeSummary</code> type.</li>
</ul>
<h3>Updates</h3>
<ul>
<li>Updates the editor core to VS Code commit <code>6a598d4a13031703d483d103c1d934a36ad27971</code>, validated in <code>0.57.0-rc.2</code>.</li>
<li>Updates bundled DOMPurify from 3.4.8 to 3.4.15.</li>
</ul>
