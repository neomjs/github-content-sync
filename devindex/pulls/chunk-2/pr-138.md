<h2>Neo.mjs v13.4.0 Release Notes</h2>
<p><strong>Release Type:</strong> A minor release, and the householding one. The open Engine issues went from 243 when 13.3.1 shipped to 5 at the cut on 2026-11-09, the fewest since 1.0.0. Most of the drop came in a sweep that began on 2026-11-05 at 189, through premise reads, delivered fixes and moves to the repositories where the work belongs. Beside it ship five other changes:</p>
<ul>
<li>CI that runs only the test tiers a change can reach, with the Brain-gated tier retired;</li>
<li>Neural Link specs that run in hosted CI without a Bridge;</li>
<li>one Pointer Events sensor for every drag, in place of the mouse and touch sensors;</li>
<li>grid header groups and CSV export;</li>
<li>93 completed requests filed before 2025, the oldest from November 2019.</li>
</ul>
<p><strong>Stability:</strong> Stable. Set at the cut candidate after the release gate.
<strong>Upgrade Path:</strong> Not a drop-in for every app. Eleven behaviour changes are listed under <em>Upgrading from 13.3.1</em>. The package's entry points are unchanged.</p>
<blockquote>
<p><strong>TL;DR:</strong> An open issue is a claim that something is still broken or still wanted. On 2026-11-05 the Engine held 189 of those claims, 111 of them filed more than 180 days earlier, and nobody could say which still held. Writing code had stopped being the scarce part; deciding whether a months-old report is still true had not. So each of the 189 got a premise read against current source by the maintainer who knows that code, and one of four verdicts: close with a citation, rewrite, move to a Discussion, or holds. Bugs were fixed rather than triaged, and small requests were built rather than parked. The gate, fewer than 25 open, held at 03:45Z on 2026-11-08, and 5 remained at the cut, the fewest since 1.0.0 shipped in November 2019. In the same window Engine CI learned to start only the test tiers a change can reach and retired its Brain-gated tier, single-app Neural Link specs began running in hosted CI without a Bridge, one Pointer Events sensor took over every drag, grids gained header groups and CSV export, and 93 requests filed before 2025 were completed, the oldest from November 2019. Eleven behaviour changes need a look before you upgrade; the package's entry points are unchanged.</p>
</blockquote>

<h2>📋 13.4 in 2 Minutes</h2>
<p><strong>New to Neo.mjs?</strong> It is an agent institution, persistent AI maintainers with identities, memory and peer review, together with the multi-threaded application engine they build, in sibling open-source repositories (<a href="[QUARANTINED_URL: github.com]">README</a>). This note covers the engine. Your app's components, state and data stores run in a worker, the App Worker; the main thread applies DOM changes and answers layout questions.</p>
