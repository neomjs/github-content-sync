# Add committed codeql-analysis.yml workflow for external fork PRs

## Context

While investigating why external fork PR `neomjs/neo-agent-brain#1412` did not trigger CodeQL whereas first-time contributor fork PRs on `neomjs/neo` (such as `neomjs/neo#20191`) run CodeQL automatically upon maintainer workflow approval, we audited `neomjs/neo-agent-institution` and confirmed it has the exact same configuration gap (`path: "dynamic/github-code-scanning/codeql"`, `id: 355628319` + ruleset `#21641205` requiring `CodeQL`).

## The Problem

`neomjs/neo-agent-institution` currently relies on GitHub's UI-managed **CodeQL Default Setup** (`dynamic/github-code-scanning/codeql`, `id: 355628319`) while branch ruleset `#21641205` (`dev`) enforces `code_scanning` (`CodeQL`). Because GitHub's Default Setup hard-excludes pull requests originating from forks (`isCrossRepository: true`), any external contributor fork PR opened against `neomjs/neo-agent-institution` will never trigger CodeQL and will be permanently blocked from merging.

On `refs/heads/dev` (`ec62d81d`), `neomjs/neo-agent-institution` currently has two active CodeQL analysis categories generated by Default Setup:
- `category: "/language:javascript-typescript"` (`id: 2069748067`, `build-mode: none`)
- `category: "/language:actions"` (`id: 2069746708`, `build-mode: none`)

## The Architectural Reality

- All workflows in `neomjs/neo-agent-institution/.github/workflows/` (`ci.yml`, `claim-responder.yml`, `dependabot-automerge.yml`, `shared-pr-baseline.yml`) declare explicit `permissions:` so CodeQL's `actions` scanner reports zero alerts.
- Matching `refs/heads/dev`'s two existing categories (`/language:javascript-typescript` and `/language:actions`) with `build-mode: none` in `.github/workflows/codeql-analysis.yml` ensures seamless category continuity when Default Setup is disabled in repository settings.

## The Fix

Add `.github/workflows/codeql-analysis.yml` to `neomjs/neo-agent-institution`:
1. Trigger on `push: branches: [dev]`, `pull_request: branches: [dev]`, and weekly `schedule: - cron: '24 9 * * 3'`.
2. Declare explicit top-level `permissions: contents: read` and job-level `permissions: actions: read, contents: read, security-events: write`.
3. Configure `strategy.matrix.language: ['javascript-typescript', 'actions']` with `build-mode: none` on `github/codeql-action/init@v4` and `category: "/language:${{ matrix.language }}"` on `github/codeql-action/analyze@v4`.
