# Add canonical PR template and align CONTRIBUTING LLM disclosure

## Context

Phase-2 sibling alignment following cross-family approval and merge of Engine [`neomjs/neo#21056`](https://github.com/neomjs/neo/pull/21056) (`Resolves neomjs/neo#21055`) per operator `2026-11-15` rollout direction (`Engine` first, then `Brain`, `Skills`, and `Fleet Manager`).

External AI-assisted/AI-generated pull requests arriving in `neomjs/neo-agent-institution` currently receive no repository-local `.github/PULL_REQUEST_TEMPLATE.md` in the GitHub web UI, while `CONTRIBUTING.md` (§3 item 4, §4 `For Human Operators of AI Agents`, §4 `For Autonomous Agents`) does not yet ask contributors to specify the **model, exact version, reasoning effort (`reasoning: default` when hidden), and agent/harness** on `Authored by ` or explain the **cross-rival-lab review** rationale.

## The Problem

- **No `.github/PULL_REQUEST_TEMPLATE.md` pre-fill:** Contributors opening a PR on GitHub do not get the unified `§9.1` skeleton (`Resolves #`, concise outcome/behavior-change prompt, linked `Evidence Ladder` L1–L4 hint + `Evidence:`, `## AC Evidence`, `## Deltas from ticket`, `## Test Evidence`, `## Post-Merge Validation`, `Authored by `), causing outside PRs to omit required anchors validated by `.github/workflows/shared-pr-baseline.yml`.
- **Under-specified AI disclosure in `CONTRIBUTING.md`:** `CONTRIBUTING.md:157` says only *"please briefly mention which model or agent framework was used (e.g., \"Generated by Gemini 3.1 Pro,\" \"Automated via Claude\")"*, missing exact version, reasoning effort (`default` fallback), the `Authored by ` structure, and the cross-rival-lab review routing rationale; §3 item 4 (`CONTRIBUTING.md:145`) and §4 Autonomous Agents (`:168`) do not yet point to `.github/PULL_REQUEST_TEMPLATE.md`, `npx neo-agent-skills-pr-body`, or the `Authored by ` requirement.
- **Parser safety in raw templates:** `disclosedModelFamilies.mjs` (`neomjs/neo-agent-brain`) scans raw PR bodies (including comments) for vendor/model family names; the added `.github/PULL_REQUEST_TEMPLATE.md` must keep all HTML comments and placeholders free of vendor/model names so `disclosedFamiliesOf()` returns `[]` on unfilled templates.

## The Architectural Reality

Design authority: `"Both audiences use the canonical body and factual attribution; private identity, routing and lifecycle requirements apply to maintainers only."` (`.agents/skills/pull-request/SKILL.md`), together with operator `2026-11-15` cross-rival-lab disclosure direction and the merged Engine Phase-1 implementation in [`neomjs/neo#21056`](https://github.com/neomjs/neo/pull/21056).

Prescription checked: `.github/PULL_REQUEST_TEMPLATE.md` and `CONTRIBUTING.md` — own GitHub PR pre-fill template and public contributor/AI transparency guide in `neomjs/neo-agent-institution`.

- `neomjs/neo-agent-institution` currently has no `.github/PULL_REQUEST_TEMPLATE.md` (verified against `CONTRIBUTING.md` and `.github/`).
- Open unassigned `neomjs/neo-agent-institution#990` (*Explain scoped help in Institution contributor guidance*) owns optional help-invitation wording under `D#21005` / `neomjs/neo-agent-skills#398` and explicitly preserves existing disclosure requirements — left untouched.
