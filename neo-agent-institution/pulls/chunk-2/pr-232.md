Resolves #229

The shell now admits `about:blank`, the realm `Neo.Main.windowOpen` opens every same-origin popup in before it replaces the location with the document. The cockpit's tab tear-out and its header pop-out share one host seam (`VesselContainer#openTearOutVessel` → `windowOpen`), and in the packaged shell both were refused silently. `isHarnessPopupUrl` is `about:blank` plus the harness documents, used only for window opens; `will-navigate` keeps the document predicate, so the staged realm's one exit is a harness document. The smoke's popup slice now opens through the engine's `windowOpen`, the product path it had been skipping.

Evidence: L3 (the real FM in a real Electron 43.1.0 shell, booted from this branch with a scratch profile; red under dev's handler, green at the head) → L3 required (AC-2, AC-3, AC-4). No residuals; the installed-app check is the ticket's Post-Merge Validation.
