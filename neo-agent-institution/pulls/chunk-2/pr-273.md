Resolves #258

Slice 2 of #258, which closes the ticket together with #272 (#271, slice 1). Stacked on #272 → #270: the three commits below are this PR's own; the rest drop out as those land.

- **A path that needs no canvas.** The Observatory gains a side panel beside the surface: every node of the read as a list row (route rank or hops from the route, label, kind), and below it the selected node's relations seen from it (the type as the feed carried it, `to`/`from`, the other end). The arrow keys move the node selection. A relation row moves the selection to its other end, so the graph can be walked from the keyboard. Without a canvas worker the lists take the whole body. The rows are `data.Store`s of `data.Model` records (`GraphSceneNodes`/`GraphSceneRelations`), pane-local like the Golden Path pane's.
- **One selection, shared.** A `graphSelectionId` leaf joins the Viewport provider. The Observatory and the Golden Path pane bind it both ways, so a canvas click, a list row, a relation row and a Golden Path item all reach the same origin-qualified id. Each Golden Path item gets a compact graph button: it is live where the graph read's route lists the item (`GraphSceneEnvelope.resolveRouteId` maps the route's bare `issue-9853` onto the scene's `neomjs/neo#issue-9853` without an origin of its own), and it marks the selected item.
- **Withheld, named beside the read.** The graph source reads no route admission, so a withheld route's neighbourhood arrives `current`. The Observatory also binds the Golden Path leaf and appends `route withheld · <reason>` to the graph read's own line. Two sources, two facts, neither folded into the other.

Evidence: L2/L3 (unit contracts; the real shell over the Neural Link; both-skin goldens; a perf probe on hardware) → L3 required for AC-3, AC-4 and AC-5. Residual: AC-6's live-wire receipt (post-merge)

## Deltas from ticket
- **Aggregation.** The ticket allows an aggregate tier only where an exercised larger budget shows it helps, and the 10× receipt shows it does not yet. None was built.
- **Golden Path parity is a select action.** The item's button selects; it does not switch to the Observatory. The shared leaf makes the Observatory open on that node whenever it is shown.
