Resolves #345

Packaged FM now stores Fleet registrations, encrypted credentials and their keys under `<userData>/brain/fleet`, outside the replaceable app bundle. Checkout smoke uses its isolated Fleet store too. The runtime path report and isolation guard now include `fleetDataDir`, so this missing binding cannot hide behind an empty roster.

Evidence: L2 (both profiles resolved through the real Brain configuration plus positive/negative isolation checks) achieved; L2 required for this repair. The installed data-preservation and first-start witness remains under #12.
