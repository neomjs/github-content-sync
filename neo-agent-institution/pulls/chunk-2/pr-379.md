Resolves #378

The installed Fleet Manager no longer puts agent seats in its own app data. `buildPackagedBrainEnv` places the seat root only when its caller must contain it, which the packaged smoke does inside its throwaway root. The installed app leaves the Brain's `fleet.agentsRoot` default, `~/.neo-ai/agents`, in force. That follows the operator's ruling of 2026-10-01: one default for everyone (neomjs/neo-agent-brain#571). An operator's own `NEO_FLEET_AGENTS_ROOT` still wins, because the fragment no longer shadows it.

Evidence: L2 (the Brain's own `fleet.agentsRoot` resolution, run on the env this change builds) → L4 required for AC-3 (the installed app, rebuilt, with Sophie's and Ada's seats moved). Residual: AC-3, Residual-Owner: #7.
