# PR Micro-Review

**Class:** contained. The card's stylesheet re-values existing FM tokens at one scope and adds one visual arm; there is no new abstraction.

**Verdict:** Request Changes

**Glance:** The token work is right, and I checked it against the idioms it cites:
- Every selector sits under `.agent-plane-setup.neo-panel`.
- `Connect` carries `.fm-add-submit`'s exact signal mix (14% / 55%, weight 600).
- The scale matches the toolbar's `32 / 32 / 6`, with text padding where the toolbar's icon buttons have none.
- The arm mirrors `mountPlaneSetup`'s insert rather than calling it. That's fine for a render witness, since the mount has its own unit arms.

The one thing I looked for and found is **clipped controls**. Measured at `712673e42b`:
- The row spans 128–156 (27 px), with `overflow: hidden` and `flex: 1 1 0%`.
- `Connect` spans 120–152, so its top 8 px are clipped. The input spans 123–155, so its top 5 px are clipped. Their bottoms also sit 3 px apart. Both goldens show this: `Connect`'s top border and the input's top edge are cut.

The mechanism: the row's `overflow: hidden` removes a flex item's content-based minimum height. So `flex: 1 1 0%` in the Panel body's column gives the row the leftover 27 px, and `align: 'end'` pins the 32–34 px controls to the bottom, past the top edge. AC-1's "32 px tall" passes because it measures the element's box, not what shows. The missing `flex: 'none'` is from my #212 row config. #218 is where it became visible, and where the goldens would lock it in.

**Findings:**
- [ ] **The row sizes to its content.** Add `flex: 'none'` to the row in `PlaneSetupPanel.mjs`, and change its layout to `{ntype: 'hbox', align: 'center'}`.
  - Verified at this head in a scratch worktree: the row spans 126–174 (48 px), and `Connect` and the input both span 138–170, nothing clipped.
  - With a status text present, the status line keeps its 31 px (`overflow: visible` keeps its minimum), and the card grows instead of clipping.
  - Re-capture both goldens.
- [ ] **The arm fails on a clipped control.** Assert that each control lies inside the row (`top >= row.top`, `bottom <= row.bottom`) and that `Connect` and the input share a top, so a squeezed row can't pass on element heights again.
