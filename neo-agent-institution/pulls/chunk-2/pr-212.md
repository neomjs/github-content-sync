Resolves #211

A packaged shell now attaches to a plane from its own record, and the cockpit offers to create that record. Until now a Finder double-click booted in own-mode ("NO INSTANCE", the sample roster), because the shell learned its plane only from the environment variables that the launcher script exports.

- **Boot seam** (`harness/planeConfig.mjs`, `main.mjs`):
  - `plane.json` under `userData` names the plane base.
  - The viewer's PAT sits beside it, encrypted by `safeStorage`, or is not stored at all.
  - At boot the record joins the packaged env fragment as `NEO_FLEET_PLANE_BASE` + `NEO_FLEET_PLANE_BEARER`, the launcher's variables. A variable already set wins.
  - The stored bearer never follows a plane base that came from somewhere else, and a plain-http base is refused unless it is loopback.
- **Broker pair** (ADR 0034 §2.3.8): `planeStatus()` reads whether a plane is configured. `attachPlane({planeBase})` has main:
  - prompt for the PAT in its own window (the existing `promptFleetCredential`);
  - check it on the plane's MCP route in two steps: an `initialize` with no credential must meet a bearer challenge before the PAT leaves main, then the authenticated `initialize` is accepted only when the Memory Core names itself (a stranger's host refuses as `not-a-plane`);
  - store it and relaunch.

  Neither reply carries the PAT.
- **Card** (`view/PlaneSetupPanel.mjs`): inline under the top chrome, dismissible, and never a gate. `ViewportController#mountPlaneSetup` creates it only for a packaged shell with no plane configured, so a browser or a configured shell never instantiates it. It reaches main through a workspace main-thread addon (`WS/ShellPlane`), so there is no engine remote and no pin bump.

Evidence: L2. Unit arms cover the record, the broker, the preload surface, the addon, the card and its mount; the visual and NL capture suites were compared against `origin/dev`. That meets L2 for AC-2, AC-3 and AC-4. AC-1 needs L3, because the packaged double-click needs the operator's machine. Residual: AC-1's live receipt, Residual-Owner: #12.
