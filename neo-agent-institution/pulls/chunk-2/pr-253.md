Resolves #243

The Observatory now has its own keeper view: the left rail shows Observatory, and `/observatory` gives the 3D Golden Path scene the whole view instead of a strip tab under the roster. The cockpit's `observatory` pane is gone from the dock catalog and from `stream-tabs`, and the Route graph tab stays in the strip.

A keeper view sits outside the cockpit's provider, so the `goldenPathEnvelope` leaf moves up to the Viewport provider. The cockpit's Golden Path read still writes it, through setData's closest-owner walk, which is how `deploymentState` already reaches the System view. There is still one read owner and no second fetch.

The move surfaced an engine gap: the Route graph serializes its bound envelope for the canvas worker, and from the cockpit's child scope that serialization came out `{}` (bisected against `adad639f8e`). neomjs/neo#19269 fixed it upstream, and this PR bumps the engine pin to `dev@a87a89e2`, which carries it.

Evidence: L2 (unit in CI) + outside-CI capture suites on Darwin → L3 required (AC-1, AC-2 and AC-3 are NL arms; AC-4 is a visual arm). Residual: none.
