Resolves #246

The fleet legend reads **working · idle · stuck · rate-limited · offline**. Benched, unobserved and stopped fold into Offline, and the reason rides the row. `SourceHealth.resolveFleetDisplayState` now returns `{state, reason}`:
- the bench is the roster's fact and holds in every topology;
- a wired runtime keeps its session state, and is offline · stopped when it stops;
- a seat Fleet runs no process for is offline · unobserved.

The health bar, the card, the detail pane and the roster's "Hide offline" filter all read that one resolver. "External harness" and bare "wedged" are gone from operator text; "stuck" says what it means on its title. A failed roster read never turns agents offline: the last-known rows stay, and a grid that was live reads stale with the reason.

Evidence: L3 (unit arms + the visual suite rendered on Darwin, five goldens re-captured and stamped) → L3 required (AC-5's goldens). No residuals.

## Deltas from ticket
- **The card's word is just `offline`; the reason rides its title.** The detail pane's new session row spells `offline · <reason>` out. At the 314 px vessel width, `offline · unobserved` ran under the card's verbs (the geometry arm "the state word never runs under the verbs" read 963 px of overlap).
- **"Hide offline" hides what the legend counts as offline** (the resolver), not only raw `state: 'off'`. Otherwise the filter would leave `offline` cards on screen. The collection re-filters only on mutations and filter edits, so the roster's record-change handler re-runs an enabled filter whenever a field it reads changes (`state`, `sources`, `participationStatus`). Emmy found the gap: a bench-only or runtime-only change left the view stale while the tally was right.
- **A malformed roster answer is a failed read.** It returned early and left a live grid's badge live with no reason. It now degrades like a thrown read: stale with "Roster answer was malformed", while a grid that never answered stays cold. Euclid and Emmy found it, along with an arm that seeded rows already offline before the failure and so could not show a working row staying working.
- **The Review preset's legend now fits beside the title.** Five swatches need less room than seven, so its golden and geometry arm flip from "wraps under the title" to "on the title's line".
- **Removed:** `--fm-state-external` (defined in both themes, applied by no rule) and the dot's `.fm-state-unobserved` rule (no display state reaches it). `--fm-state-unobserved` stays for the System view's chips.
- A wired runtime reporting a state outside the five still shows its literal word on the card; the tally counts it offline, so the bar never undercounts.
