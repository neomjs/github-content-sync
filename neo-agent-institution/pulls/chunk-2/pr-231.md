Resolves #227

The packaged shell's credential window is now a native password field. It serves plane attach and every credential-bearing Fleet verb, and it replaces a window that had no field and no button. It has Paste, Cancel and a method-specific submit button (Connect / Admit / Add agent), and the label reads "GitHub or GitLab PAT".

Because the field is native, macOS holds Secure Event Input while it has focus, and ⌘V pastes through the Edit menu. A window-only preload hands the value to main once, on submit. Every settle path destroys the window, and the cockpit's renderer and the App Worker never hold the credential. `promptFleetCredential` moves from `main.mjs` into `harness/credentialPrompt.mjs`: −88 lines in main.

Decision Record impact: depends on neomjs/neo#19238 (PR neomjs/neo#19239), which amends ADR 0034 §2.3 with item 9. §2.3's falsifier requires that amendment first, so neo#19239 merges before this one.

Evidence: L3 → L3 required, for AC-1/AC-2. The run was an Electron 43.1.0 probe on darwin driving this module in a real window; the receipt is below. A shipped `.app` sits one rung up, and that is Post-Merge Validation.

### 🔬 Depth Floor

**The structural property worth naming, because it is stronger than the PR claims: the ban holds by absence, not by restraint.** A renderer that *has* a credential channel and declines to use it is one refactor away from leaking; a renderer with no such channel cannot leak one. `harness/preload.cjs` at this head contains no `clipboard`, no `readText`, no `before-input-event`, no credential symbol and no `<input` — so the cockpit's capability surface is not "the credential path is unused" but "there is no credential path". That is the property ADR 0034 §2.3's heading asserts, and it is now enforced by the shape of the file rather than by a comment. It is also why moving `promptFleetCredential` out of `main.mjs` (−88 lines there) matters beyond tidiness: the implementation and the capability it implies are no longer in the same file.

**Challenge (non-blocking, and it belongs to the record rather than the code): the CSP is half-quoted, and the code is right where the ADR is terse.** The document's policy is `default-src 'none'; style-src 'unsafe-inline'`.
