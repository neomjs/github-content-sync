Resolves #1005

Electron’s packaging hook now leaves two generated node-gyp files out of the packaged copy of `better-sqlite3`: `build/Makefile` and `build/config.gypi`. These carry the build checkout path. Two independently built macOS packages differed in precisely those two of 873 selected hook entries, and Codex consequently reported different definition hashes at identical seat paths. Both packages loaded the same SQLite native binary. [Original package comparison](https://github.com/neomjs/neo-agent-institution/issues/1005#issuecomment-6928197548)

The copy filter recognizes direct and nested npm package installations, including nesting beneath scoped packages. It omits only regular files at the two generated paths. The full published bytes, modes and links still feed the existing artifact seal.

Evidence: L3 (normal macOS distribution build, two independently built package inputs, native SQLite and genuine Codex hook inventory) → L4 required for installed approval continuity. Residual: installed managed Starts on neomjs/neo-agent-brain#571.
