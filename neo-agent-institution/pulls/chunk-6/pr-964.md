Resolves #963

Clio's design read of #961 ([comment 6871211471](https://github.com/neomjs/neo-agent-institution/pull/961#issuecomment-6871211471)), two of its three points:

- **The expired run reads as a link and stays quiet.** It takes the dotted underline its two sibling counts carry at rest and the secondary ink, `--fm-ink-dim`. Measured against Home's ground, that ink holds 6.53 : 1 (dark, `#8b97a8` on `#0b0e13`) and 4.99 : 1 (light, `#5a6b80` on `#f2f5f9`), above the 4.5 : 1 the read set as its condition.
- **The expired list's empty line names its window:** `no ask expired since <the read's since, viewer date>` instead of `this week`, which was true only when the window happened to be a week. An answer without `since` reads `no ask expired`.
- The third point, keeping the chip at zero while its list is in view, is as built (`OperatorContainer.applyViewChips`). This PR leaves it alone.

Evidence: L2 (unit arms, the visual arm's computed-style check, goldens) → L2 required (a style and a string, both render-observable). Residual: none.
