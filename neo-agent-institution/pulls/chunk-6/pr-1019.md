- The ticket expected no golden change. Nine full-view goldens frame the product bar, though. Eight change only inside the band (y 9–40). `cockpit-review-1280` also carries the activity row's live GitHub avatar, re-fetched at capture: 125 px in one 14 px square at y 602–615.
- The test lives in `Cockpit.spec.mjs`, not `NightshiftToggleNL.spec.mjs`. The isolated CI job skips every spec that takes the `neuralLink` fixture, so a test there never runs in CI. The gap test needs no Brain.
