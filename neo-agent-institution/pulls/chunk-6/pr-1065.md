Resolves #1064

Dependabot stops proposing `plist` for the root. The root pin mirrors the parser version that `app-builder-lib` resolves in `harness/package-lock.json` (#1055), and plist 5 has no default export. With plist out of the all-deps group, the next run carries the engine bump on its own. Today that bump is #1057, red on plist since 2026-11-26.

The header's coverage note now matches what Dependabot does: `neo.mjs` tracks `#dev` and moves inside the group, and only `neo-agent-brain`'s commit pin stays manual.

Evidence: L1 (a static config; Dependabot reads it only once it is on `dev`) → L1 required (AC-1, AC-2). AC-3 is post-merge by its own wording.

Micro-review eligible: config-leaf — one `ignore` entry and a corrected comment, no code.
