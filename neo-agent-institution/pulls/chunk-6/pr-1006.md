A fresh managed Start can keep the approved Codex wake command across an unrelated Fleet update. The unsigned macOS packer declares the hook's imported modules and installed dependency trees. Under the existing runtime lease, the host copies the declared execution payload into a sealed, content-addressed directory. The executable, frameworks, native packages, wake protocol and imported code all contribute to its address. Both the Start and its later receivers derive that address from the verified parent generation.

The companion reader is [Brain PR #1805](https://github.com/neomjs/neo-agent-brain/pull/1805). Merge the Brain reader before this producer. A package assembled against an earlier Brain keeps its current wake behavior. Signing-enabled releases retain their generation-bound hook until Ada's [independently signed hook carrier](https://github.com/neomjs/neo-agent-institution/issues/1007) ships.
