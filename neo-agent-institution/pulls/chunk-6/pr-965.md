Resolves #957
Related: #312

Selecting a node while `Nodes` is open keeps `Nodes` expanded (`flex: 1`) above `Selected node` (`flex: '0 1 auto'`, `.is-split { max-height: 50% }`), reveals the selected row with one row of context below it (`ObservatoryNodeList#revealRecord`), and wires keyboard entry and action focus across the two sections (`ArrowDown` on `observatory-nodes-title` → selected row else row `0`, `ArrowUp` on row `0` → `observatory-nodes-title`, `Enter` / `Space` on a row → first visible action in `Selected`, `Escape` from `Selected` → back to the row at the same `scrollTop`, and `Clear` / second `Escape` → closes the split at the same `scrollTop`).

Evidence: L3 (local Darwin Chromium NL/e2e keyboard + split-layout verification and 1392x850 BEFORE/AFTER captures across dark and light skins; unit + component specs in CI) → L4 required (AC-6 installed candidate walkthrough). Residual: AC-6, Residual-Owner: #485.
