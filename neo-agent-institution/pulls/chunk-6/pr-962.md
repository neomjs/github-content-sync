Resolves #842

The roster card gains one line for the seat's session rotation, and the journal words the `session-rotation` events that neomjs/neo-agent-brain#1694 emits. Both use one formatter, `AgentOS.util.SessionRotation`:

| Rotation state | Card and journal words |
|---|---|
| `completed` | `rotated 5 Jul 21:17 · from 1a2b3c4d to 5e6f7a8b`: the fresh session is named, nothing is raised |
| `requested` | `rotating since …`: the old session is not retired yet |
| `refused` | `rotation refused · minimum-interval · next 5 Jul 22:47`, in the limited ink |
| `incomplete` | `rotation incomplete · no-fresh-session`: reported, with no action |
| `none`, `unobserved`, `unknown` | no line |

Times are viewer time, as on Home. On the card and on the journal row, the title keeps both full session ids and the receipt.

**Where the card's rotation comes from.** The roster row carries none: its `wake` comes from a separate producer.
- **The read.** `SessionRotation.load` reads `fleetWakeRoutes` for the cards alone. `SessionRotation.admit` writes each seat's `seats[].rotation` onto its `FleetAgent` record, as the Fleet answered it. An older Fleet's seats without the field, an unreadable answer, and an unwired verb write nothing.
- **When it runs.** On the first activity page and on a `session-rotation` event the store has not seen, so it costs no read per tick. It never fills the Wake pane, where reading the routes stays the operator's explicit first act. An operator's own read there refreshes the cards as well.
- **Where the answer lives.** It belongs to the profile that answered. It is held on the cockpit owner (`rotationRead`) and admitted only while that profile is still the bridge's, so a read of one instance never lands on another's roster. `TargetBinding#retireRoster` retires it on a switch.
- **Re-applying it.** Every roster admission re-applies the held answer with no wire call: the first snapshot and any seat joining a wired roster. The roster read's recovery fences pin its exact wire order. An unchanged rotation writes nothing.
- **The alternative.** The intake on #842 (6870439485) records a `rotation` axis on the roster row, which belongs to a Brain leaf if this read ever shows in the cost.

Evidence: L2 (unit arms, visual goldens) → L4 required (AC-3, the installed receipt). Residual: AC-3, Residual-Owner: neomjs/neo-agent-brain#1373.
