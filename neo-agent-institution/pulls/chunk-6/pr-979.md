Resolves #978

The packaged shell now passes the receiver's declared state directory to Fleet with the manifest and base from the same source. Missing or ambiguous native state clears only that coordinate, while a selected LaunchAgent still supplies its own state when an incomplete environment loses. Unpackaged launches continue to inherit.

Evidence: L2 (isolated LaunchAgent and child-environment fixtures) → L2 required (the selected declaration and child-env contract). Related: neomjs/neo-agent-brain#1731.

Change class: capability (`feat`). `agent-preflight` is not hosted here; the shared baseline runs in CI.
