<h2>electron v43.7.0</h2>
<h1>Release Notes for v43.7.0</h1>
<h2>Features</h2>
<ul>
<li>Added <code>initiatorOrigin</code> to webRequest and protocol handler requests, <code>DownloadItem.getInitiatorOrigin()</code>, and a trailing <code>frame</code> argument to the <code>will-download</code> and <code>preconnect</code> session events. <a href="[QUARANTINED_URL: redirect.github.com]">#53704</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Added the <code>ELECTRON_DEBUG_DRAGGABLE_REGIONS</code> environment variable, which visualizes and logs draggable regions in unpackaged apps to help debug custom title bars. <a href="[QUARANTINED_URL: redirect.github.com]">#53633</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
</ul>
<h2>Fixes</h2>
<ul>
<li>File System Access permission requests and the <code>file-system-access-restricted</code> event are scoped to the requesting document, grants are reset when the origin's last page closes, and write access works in in-memory sessions. <a href="[QUARANTINED_URL: redirect.github.com]">#53694</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed <code>session.setPermissionCheckHandler</code> receiving the top-level origin and a null <code>webContents</code> for <code>hid</code> and <code>usb</code> checks made from a subframe. <a href="[QUARANTINED_URL: redirect.github.com]">#53689</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed <code>webContents.on()</code>, <code>removeListener()</code> and <code>removeAllListeners()</code> throwing &quot;Object has been destroyed&quot; for <code>console-message</code> listeners after the WebContents was destroyed. <a href="[QUARANTINED_URL: redirect.github.com]">#53496</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed a crash on Linux when <code>process.env</code> was written while another thread was reading the environment, and a memory leak when a worker thread exits. <a href="[QUARANTINED_URL: redirect.github.com]">#53510</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed a possible crash on Windows when a file dialog was shown for a window that was being closed at the same time. <a href="[QUARANTINED_URL: redirect.github.com]">#53584</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed a renderer crash when the main process sent IPC to, or a page navigated, a same-process <code>window.open()</code> child whose <code>contextIsolation</code> differed from its opener's. <a href="[QUARANTINED_URL: redirect.github.com]">#53540</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed an issue where the browser-side check that blocks drag and drop between cross-site frames of the same page was disabled. <a href="[QUARANTINED_URL: redirect.github.com]">#53750</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed crashes in <code>setDisplayMediaRequestHandler</code> when the granted frame had been destroyed or another tab was granted by id. <a href="[QUARANTINED_URL: redirect.github.com]">#53671</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Fixed several non-functional DevTools integrations: the Security panel's &quot;View certificate&quot; button, Ctrl+wheel zooming inside DevTools, and DevTools keyboard shortcuts (e.g. F8) while the inspected page has focus. <a href="[QUARANTINED_URL: redirect.github.com]">#53631</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li>Internal <code>&lt;webview&gt;</code>, <code>window.close()</code> and <code>executeJavaScript</code> reply IPCs are validated against the sending frame. <a href="[QUARANTINED_URL: redirect.github.com]">#53726</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li><code>&lt;webview&gt;</code> without <code>allowpopups</code> also blocks links opened into a new window by modifier-click, and such windows navigate as the clicking document rather than as a browser-initiated load. <a href="[QUARANTINED_URL: redirect.github.com]">#53718</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li><code>getUserMedia</code> with <code>chromeMediaSource: 'desktop'</code> no longer accepts WebContents source ids; use <code>chromeMediaSource: 'tab'</code> with <code>webContents.getMediaSourceId()</code> or <code>setDisplayMediaRequestHandler</code> to capture a WebContents. <a href="[QUARANTINED_URL: redirect.github.com]">#53707</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li><code>nodeIntegrationInWorker</code> now applies only to workers created by frames that themselves have Node integration; enable <code>nodeIntegrationInSubFrames</code> to keep Node in workers created by subframes. <a href="[QUARANTINED_URL: redirect.github.com]">#53712</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li><code>openExternal</code> permission requests started by a frame that has since gone away are attributed to that frame's origin rather than to the navigating page. <a href="[QUARANTINED_URL: redirect.github.com]">#53698</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
<li><code>pointerLock</code> and <code>keyboardLock</code> permission requests now report the requesting frame, and <code>execCommand('paste')</code> requires user activation in the frame that calls it. <a href="[QUARANTINED_URL: redirect.github.com]">#53701</a> <!-- raw HTML omitted -->(Also in <a href="[QUARANTINED_URL: redirect.github.com]">42</a>, <a href="[QUARANTINED_URL: redirect.github.com]">44</a>, <a href="[QUARANTINED_URL: redirect.github.com]">45</a>)<!-- raw HTML omitted --></li>
</ul>
