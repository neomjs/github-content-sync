### Summary

Sorts the Accounts agent list alphabetically (A–Z, case-insensitive) by displayed name (`displayName || githubUsername || id`), with deterministic identity (`id`) as the tie-breaker, while preserving active selection.

### Key Changes

- **Store sorting (`AgentDefinitions.mjs`)**: Configured primary sorter on `displayName` using case-insensitive fallback `displayName || githubUsername || id` with `id.localeCompare()` tie-breaker, plus secondary sorter on `id`.
- **Reactive re-sort on record edit**: Overrode `onRecordChange` in `AgentDefinitions` to invoke `this.doSort()` when records mutate so edited definitions immediately reflect the proper order.
- **Seeding & roster updates (`Panel.mjs`)**: Ensured stores seated on `afterSetAgentDefinitionsStore` inherit sorters via `AgentDefinitions.sortersOf()`, and `onAgentRosterChange` triggers store sorting.
- **Selection preservation (`Controller.mjs`)**: In `loadAgentDefinitions()`, cached and restored `selectedAgentId` across store rehydration so the user's active selection and configuration card stay focused on the same agent.

### Verification & Testing

- **Unit tests**: Added 4 tests to `test/playwright/unit/apps/agentos/Accounts.spec.mjs` verifying:
  1. Initial load case-insensitive A–Z ordering with fallback and tie-breaker.
  2. Adding definitions maintains sort order while keeping active selection.
  3. Editing/renaming definitions updates order while keeping active selection.
  4. Controller refresh preserves alphabetical order and active selection.
  - All 72 tests passed: `npm run test-unit -- test/playwright/unit/apps/agentos/Accounts.spec.mjs`.
- **E2E assertions**: Added rendered `.fm-accounts-name` list order checks in `test/playwright/e2e/agentos/AccountsConfigSurface.spec.mjs`.
- **File size guard**: Verified `npm run check-app-file-sizes` passes (0 files over the 1000-line bar).
