## Fix

One line in `parseStamp`: split on `/\r?\n/` instead of `'\n'`, so a CRLF checkout parses exactly like an LF one. `parseStamp` is the only consumer of the stamp file's text (both main-flow reads go through it; `listingEntries` parses `git ls-files -s` output, which git writes LF on every platform), so this is the whole class. No `.gitattributes` — an existing clone keeps its CRLF until the file is checked out again — and no whole-line trimming: only the line ending is removed, values were already trimmed.
