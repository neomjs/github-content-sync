Updates `webpack-dev-server` from 6.0.0 to 6.1.0
<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="[QUARANTINED_URL: github.com]">webpack-dev-server's releases</a>.</em></p>
<blockquote>
<h2>v6.1.0</h2>
<h3>Minor Changes</h3>
<ul>
<li>
<p>Run as a plugin from the top-level <code>plugins</code> of a multi-configuration, serving every configuration from one server. (by <a href="[QUARANTINED_URL: github.com]"><code>@​alexander-akait</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5765</a>)</p>
</li>
<li>
<p>Fix client progress modes, socket URL credentials, overlay and progress lifecycles, server startup error handling and local IP lookup; export <code>BaseServer</code>. (by <a href="[QUARANTINED_URL: github.com]"><code>@​alexander-akait</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5739</a>)</p>
</li>
<li>
<p>The browser client, the error overlay and both transports now come from webpack-dev-middleware, so this package has no client code of its own. Every option keeps its name and meaning, <code>allowedHosts</code> and the origin checks still apply here, and this server's <code>{ type }</code> messages are still sent next to the middleware's, so React Refresh keeps working. <code>client/index.js</code>, <code>client/socket.js</code> and <code>client/clients/WebSocketClient.js</code> still resolve while the client's internal files are gone, and the console wording, the overlay and the progress indicator are now the middleware's. <code>client.webSocketTransport: &quot;sse&quot;</code> adds Server-Sent Events, a universal build now runs in Node without the client throwing, and <code>sendMessage()</code>, <code>getClientEntry()</code> and <code>getClientHotEntry()</code> still work, a subclass's overrides included, but are deprecated. (by <a href="[QUARANTINED_URL: github.com]"><code>@​alexander-akait</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5750</a>)</p>
</li>
</ul>
<h3>Patch Changes</h3>
<ul>
<li>
<p>Keep hot and live reload working after a cancelled &quot;Leave site?&quot; dialog. (by <a href="[QUARANTINED_URL: github.com]"><code>@​alexander-akait</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5744</a>)</p>
</li>
<li>
<p>Keep the overlay for a runtime error thrown while the page is still loading. (by <a href="[QUARANTINED_URL: github.com]"><code>@​alexander-akait</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5745</a>)</p>
</li>
<li>
<p>Validate the <code>Host</code> and <code>Origin</code> headers and enforce same-origin checks on WebSocket upgrade requests handled by proxies with <code>ws: true</code>. This prevents cross-origin pages from connecting to proxied WebSocket services through the development server. (by <a href="[QUARANTINED_URL: github.com]"><code>@​UlisesGascon</code></a> in <a href="[QUARANTINED_URL: github.com]"><code>cb1534a</code></a>)</p>
</li>
<li>
<p>Validate options with a precompiled schema to cut ~115ms from startup. (by <a href="[QUARANTINED_URL: github.com]"><code>@​alexander-akait</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5746</a>)</p>
</li>
<li>
<p>Validate Host and HTTP/2 authority headers independently of Origin protocol exceptions, including when <code>allowedHosts</code> is <code>&quot;all&quot;</code>. Handle malformed open-editor URLs with a controlled response and parse their query without relying on the Host header. (by <a href="[QUARANTINED_URL: github.com]"><code>@​bjohansebas</code></a> in <a href="[QUARANTINED_URL: redirect.github.com]">#5771</a>)</p>
</li>
</ul>
</blockquote>
