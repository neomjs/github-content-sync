Resolves #923

Engine neomjs/neo#20792 sends every renderer call through `SharedCanvas#getCanvasId()`. That method reads the reactive `canvasId` config. `observatoryCanvas.spec.mjs` builds its host with `Object.create(ObservatoryCanvas.prototype)` and shadows the configs it reads, but `canvasId` was not among them. The read therefore reached `core.Base`'s `#configs` on an unconstructed object and threw, failing 3 unit tests. With `Isolated Institution` required, every PR went red. The host now shadows `canvasId`, which is what #20792 did for the engine's own bare hosts.

The same PR moves both Skills workflow pins `@v0.1.84` → `@v1.3.7`. That is Dependabot's #893, byte for byte. The ruleset's new `Shared PR Baseline / PR baseline` context comes only from v1.x. Without the pin bump this PR could not pass, and #893 cannot take the spec fix.

Evidence: L2 (CI runs every pre-merge AC on this PR against engine `dev`) → L2 required (AC-1, AC-2). AC-3 waits for the merge.
