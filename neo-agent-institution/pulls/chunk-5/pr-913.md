Resolves #912

The installed Fleet now switches on open-work wakes. `bootProductBrain`'s packaged environment carries `NEO_FLEET_OPEN_WORK_WAKES: 'true'`, so the Fleet server sets the Brain leaf `fleet.openWorkWakes`. A seat will then hear when its own PR goes green or red. The unpackaged run of the same boot, the smoke boot and the UI-transport boot set nothing, so they keep the leaf's default `false`. A peer's dev Fleet therefore never wakes seats a second time.

Evidence: L2 (a source arm pins the declaration in the one boot and its absence in the other two; red on `origin/dev`, green at the head) → L4 required (AC-3: wakes from the installed Fleet). Residual: AC-3, Residual-Owner: neomjs/neo-agent-brain#759 (the epic where the live receipts are owed).
