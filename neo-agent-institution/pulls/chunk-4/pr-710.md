Updates `cssnano` from 9.7.0 to 9.8.0
<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="[QUARANTINED_URL: github.com]">cssnano's releases</a>.</em></p>
<blockquote>
<h2>v9.8.0</h2>
<h3>Feature Changes</h3>
<ul>
<li>
<p>feat(postcss-normalize-url): stop rewriting URLs</p>
<p>The plugin only changes the <code>url()</code> token (unquoting, whitespace, escaping) and keeps the URL byte-identical. It no longer removes dot segments or duplicate slashes, decodes percent-escapes, removes default ports or strips the trailing dot of host names, because these are not equivalent for every server or bundler. It keeps whitespace inside a quoted <code>@namespace</code> URL as well, because the namespace name is an identifier compared character by character rather than a URL that gets fetched.</p>
</li>
<li>
<p>feat(cssnano-preset-default): remove postcss-svgo from the preset</p>
<p>The presets no longer run <code>postcss-svgo</code>; run it before cssnano or optimize SVG assets with the SVGO cli instead. A <code>svgo</code> option is now ignored. The output changes for CSS with inline SVG data URIs, and for CSS with URLs that <code>postcss-normalize-url</code> used to rewrite (see the <code>postcss-normalize-url</code> changeset).</p>
</li>
</ul>
<h3>Patch Changes</h3>
<ul>
<li>Always convert between <code>cm</code> and <code>mm</code>, and convert <code>q</code> to <code>cm</code> or <code>mm</code>, since metric units relate by exact decimal factors. <code>q</code> is never the output unit.</li>
</ul>
</blockquote>
