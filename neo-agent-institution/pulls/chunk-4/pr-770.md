Resolves #769
Part of #732

Extends `LivenessController#reconcileRoster` (`apps/agentos/view/fleet/cockpit/LivenessController.mjs`) from checking only `kind === 'cleanup'` (`#742`) to checking the full set of row-mapped `controlReason` kinds (`cleanup`, `pending`, `failed`, `unavailable`, `exited`) introduced by `#749` (`PR #768`). When a subsequent snapshot row transitions to `running` or `stopped` (`next.controlReason === undefined`), `reconcileRoster` clears any row-mapped `record.controlReason` to `null`; while an in-flight `pendingAction` or a C2 round-trip `controlReason` (`rejected`, `timeout`, `unauthorized`, `superseded`) is active on the record, `reconcileRoster` preserves it over any incoming row-mapped `controlReason`.
