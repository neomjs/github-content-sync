Resolves #735

Refs #739, #732, #734, #424, #477, #516

Implements the shared `starting` transport state and cockpit banner for both a slow Fleet child past its 15 s readiness window (`reason: 'fleet-starting'`, `#739`) and a stored Agent OS plane still coming up at login (`reason: 'plane-starting'`, `#735`):
- **Harness boot & plane-starting recovery (`harness/brain.mjs:379-577`, `harness/main.mjs:1179-1224, 1489, 1558`):** Exports `PLANE_STARTING_BOUND_MS = 180_000` (derived from the operator-machine cold-login Docker + 4 Agent OS container boot measurement of `127–137 s` from `kern.boottime` recorded on `#735#issuecomment-6270967146` [QUARANTINED_URL: github.com]), `PLANE_STARTING_RETRY_MS = 5_000`, `startTransportFact`, `markTransportStarting`, `readTransportFact`, and `bootFleetWithPlaneRecovery`. Attaches `appLifecycle.watchBrainChild` only after the Fleet child reaches readiness so an initial pre-ready `plane-attach` exit does not record `owned-child-termination` (`severity: 2`) or block the recovery spawn from settling `running`.
- **Spine banner & 1 s starting poll (`apps/agentos/util/SpineBanner.mjs:129-154, 296-308`, `apps/agentos/util/BrainHealthRead.mjs:19-84`, `apps/agentos/view/fleet/cockpit/LivenessController.mjs:885`):** Gives `transport?.phase === 'starting'` precedence over a cold `grid.connection` timeout/connecting verdict while `brainBootPromise` is in flight, renders `Fleet starting · <N> s` (`#739`) and `Agent OS starting · <N> s` (`#735`) with Clio's `>= 60 s` `"Longer than usual."` sentence (`#734#issuecomment-6256233636`), re-polls `brainHealth` every `1000` ms while starting, and invokes `owner.reconnectFleet()` immediately when the starting transport settles `up: true` / `running`.

Evidence: L2 (Playwright unit + pipeline specs across harness and cockpit) → L4 required (AC-5 live login with Agent OS auto-starting on the installed Fleet Manager). Residual: AC5, Residual-Owner: #516.
