Resolves #752

Since Brain #1193, a Fleet that finds no Bridge on its NL port starts one, detached. This PR makes every smoke own that Bridge's coordinates and its end:
- **Port:** `bootSmokeBrain` allocates `NEO_NL_PORT` beside the Chroma and Fleet ports, so no smoke's Fleet settles on the operator's `8081`.
- **Teardown:** `teardownBrain` stops the `run-bridge.mjs` listening on that port and proves it released (`stopRunBridge`, `awaitPortReleased`). The run-state records the port, so a crashed run's next sweep does the same.
- **Rehearsal:** it starts a Bridge of its own only when the Fleet's has not appeared within the settle window. The receipt names whose Bridge served (`isolation.bridge`), and `teardown.bridgePortReleased` fails the verdict when the port is still held.

Evidence: L3 (packaged rehearsals on macOS in own roots, red and green on the same Brain) → L3 required (AC-1, AC-3). Residual: AC-1 (the plain packaged smoke's half), Residual-Owner: #732.

## Deltas from ticket
- **Prescription:** sharpened at intake (in the ticket body). The run lets the Fleet start its Bridge and reaps it, rather than pre-starting one so the Fleet adopts, because a fresh install takes the start branch.
- **Race:** the first green run found one. The Fleet answers its wire before its Bridge settle ends, so a probe right after boot saw nothing, and the rehearsal's own Bridge lost the bind (`EADDRINUSE`) to the Fleet's. The rehearsal now waits out the settle window (`FLEET_BRIDGE_SETTLE_MS`).
- **Deletion:** the sweep's inline command reader became the shared `readProcessCommand`.
