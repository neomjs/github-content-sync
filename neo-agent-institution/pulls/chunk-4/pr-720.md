Resolves #712
Related: #505

Pairs the Fleet cockpit's `detail.autoHidden` dock write with `Controller#applySelection` via `CockpitPerspectives.syncDetailAutoHidden` so the right-edge `AgentDetail` inspector reveals when a resident is selected and returns to the rail (`autoHidden: true`) when selection clears (`Escape`, `deselect`, or a roster refresh dropping the inspected resident), unless the operator pinned the pane (`detail.pinned === true`). Perspective restore, capture, and reload reconcile `detail` via `CockpitPerspectives.reconcileDetailPin` so a pinned inspector stays open and an unpinned edge reveal returns to the rail.

`agent-preflight`: not hosted here; baseline `check-app-file-sizes`, unit, and NL/e2e ran (`change-class: restoration`).

Evidence: L4 (Playwright unit + whitebox Neural Link E2E against live App Worker and Chromium layout at 1400 px; installed packaged-cut verification is post-merge) → L5 required (AC-4). Residual: AC-4, Residual-Owner: #505.
