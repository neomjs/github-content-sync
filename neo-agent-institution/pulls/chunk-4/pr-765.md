<blockquote>
<h2>v9.9.0</h2>
<h2>What's Changed</h2>
<ul>
<li>
<p>cssnano now ships its presets and plugins in a single package, so installing it adds one cssnano package to your dependency tree instead of about thirty, and you have fewer packages to review in audits and lockfile updates.</p>
<p><code>preset: 'lite'</code> and <code>preset: 'advanced'</code> now work without installing another package. An installed preset package still takes precedence over the built-in one and prints a one-time <code>CSSNANO_INSTALLED_PRESET</code> warning; pass the imported preset function to keep it without the warning. Full names such as <code>cssnano-preset-default</code> fall back to the built-in preset when no package is installed. Projects that require <code>cssnano-preset-default</code> directly must declare it as a dependency, or switch to <code>preset: ['default', {...}]</code>. <code>overrides</code> and <code>resolutions</code> that pin an individual plugin no longer apply.</p>
</li>
</ul>
</blockquote>
