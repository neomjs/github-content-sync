Resolves #663

Fleet pop-out windows now take the source pane's outer footprint instead of the dragged tab header's size. `VesselContainer` uses the engine's `Placement.resolveVesselSize` for fallback, floors and the initiating screen's bounds; proxy geometry supplies position only. The click path forwards its pane measurement into the same contract and preserves Detail's existing 480×640 composition. A pointer tear-out of Detail stays measured. This removes FM's duplicate size-floor calculation and adds no configuration or lifecycle path.

Evidence: L2 (real cockpit host/unit coverage) → L4 required (installed AC-4). Residual: AC-4, Residual-Owner: #12.

Change class: restoration (`fix`) — restore the documented pane-sized behavior. `agent-preflight`: not hosted here; shared baseline jobs validate the PR in CI.

Design read: [Clio's accepted prescription and journey](https://github.com/neomjs/neo-agent-institution/issues/663#issuecomment-6100483324). The footprint is the pane's size as rendered; a cramped source pane can remain cramped, so Mailbox content readability is evaluated separately on the installed candidate.
