Resolves #551

🌿 The operator's Mailbox can no longer show a message that cannot be opened, answered or resolved.

The operator's 10-07 ask, on the installed Mailbox: open a message's full content, mark the operator's own messages read, reply to the one selected, and resolve a question explicitly. Selecting a row (click, Enter, Up/Down, through the grid's own row model) opens one detail view beside the list, the way Memories reads a record beside its own (a narrow pane stacks it under). The view reads the message under the operator's identity (`fleetOwnMessage`, neomjs/neo-agent-brain#915) and never marks it read. On the operator's own inbox it adds `Mark read` · `Reply` · and apart `Resolve: mark Completed`, as Mnemosyne's design read on this ticket accepted. Reply opens the compose reveal for the sender with `Re:` and `inReplyTo`, and a reply never moves the Task. A refused action shows its reason beside the Brain's `code`. A row reads as read or resolved only after the inbox re-read that follows. Every other host stays read-only: the pane defaults to the observer entry, the one #596 will reuse.

Evidence: local, a Neural Link e2e against a fixture plane → an installed run required for AC-6 (one real question on the next #12 candidate). Residual: AC-6, Residual-Owner: #490.
