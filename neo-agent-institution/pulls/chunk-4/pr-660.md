The seat card now words the refusal Brain #964 / #966 added. A run of `proof-unavailable` audit entries reads `New <server> connection waiting` while the run's first entry is younger than one launcher's fixed 60 s retry budget — the title names the credential, prints the issuer's diagnostic only when the contract admits it, and states the launcher's protocol, never its live state — and `New <server> connection still unanswered` once the run has outlasted that budget, with restart advice only when the lifecycle controls allow one.
