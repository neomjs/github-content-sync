Resolves #521

Each time the form is shown, Add Agent asks the Fleet (`fleetMemoryCandidates`, Brain #825) which existing agents' memory the new seat could continue. It sends the operator's choice as `memoryImport`; Brain #797 copies it and guards Start. Only a wired read that finds nothing records `'none'` by itself. A fleet that answers without a list is unavailable: the frame says why in the operator's words, offers Retry, and adds the seat only after *Start with empty memory* is chosen. Only the latest read owns the answer, and a submission waits for the read in flight.

Evidence: L3 (rendered on the dev-server build through the real mounted cockpit and Accounts views over the authenticated bridge; the repaired frames are committed goldens) → L4 required for the walk on an installed shell, where Mnemosyne's seat imports her memory through this step. Residual: that walk, Residual-Owner: neomjs/neo-agent-brain#571.
