### 🔬 Depth Floor

**Challenge OR documented search (per guide §7.1):**

- **Challenge** (non-blocking, latent): `readRevision(root)` runs `git rev-parse HEAD` with `{cwd: root}`. When `root` is `undefined`, Node runs git in `process.cwd()`. Measured: `execFileSync('git', ['rev-parse','HEAD'], {cwd: undefined})` returned the current checkout's HEAD. So a caller that omits `productRoot` would record the packer's working-directory HEAD as product identity, which is exactly the "current host guess" this PR exists to exclude. Today's one production caller cannot reach it, because `stageOrganism` passes `resolvePackRoots()`, which always resolves `productRoot`. Hence no Required Action. A one-line guard would make the boundary structural instead of a caller convention: `if (!root) return null` at the top of `readRevision`. It covers the Brain revision's identical path too. Optional, your call.
