Resolves #559

🌿 A seat's model and reasoning effort stop being settings only its harness can see.

Agent Detail › Configuration gains the **Seat** group: one row each for `model` and `reasoning effort`. Each row says what is declared beside what the harness's config reads and when a declaration applies, offers only what the harness itself lists (Brain #864's catalog), and writes through the existing configure round-trip. A Claude app seat says its app sets both per session. A Start the Fleet refused for the declared model reads its reason on the roster card and on the row the card sends the operator to.

## Deltas from ticket

- **A refused Start re-polls the roster** (`FleetLifecycleIntentAdapter.rosterMayRead`, used by the per-card intent and Start fleet). This is the design read's answer to the cockpit fork. A refusal the Fleet answered re-polls; a timeout, an unauthorized bridge, or a rejection that never left the cockpit does not. A re-poll keeps the card's own reason, because roster rows carry none.
- **A refusal speaks only for the declaration it names** (`SeatModel.refusedReason`). After the operator changes the declaration, the row stops repeating a refusal that was about the old one. The card keeps reporting the last start, which stays true.
- **Brain pinned at `f24815d`**, the #869 merge, in `package.json`, the lockfile and `ci.yml`, as Institution PRs do today. The standing order to track `dev` for org-internal dependencies applies to this pin and is raised separately.
- **Out of scope, noted in defect-note 1cd6f3e1:** a Neo VDOM update keeps a hidden Button in the DOM when a sibling gets new text in the same pass. `SeatModelContainer` leaves a hidden link's text alone to avoid it.
- **`seat-model-differs-running.png` is gone.** A running seat now reads the stopped seat's sentence, and its unit and e2e arms assert it.
