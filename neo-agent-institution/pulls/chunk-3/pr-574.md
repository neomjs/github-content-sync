Resolves #572

🌿 A seat defined before Add Agent asked about memory can no longer reach its first Start without anyone having asked.

Agent Detail › Configuration › Seat gains a Memory row. Its line says what the definition records — "no import choice recorded", "recorded: import no memory" or "recorded: import the memory at …" — and never what the seat's home holds or that an import ran. **Choose** or **Change** opens Add's own choice: the Fleet's candidates in Add's list, then *Start with empty memory*, with the chosen candidate's folder under **Details** before Save. It has the same discovery outcomes and preselection rule, built from `AddAgentFlow`'s helpers rather than a copy. Save sends `{id, memoryImport}` through `configureAgent` (neomjs/neo-agent-brain#898, PR neomjs/neo-agent-brain#899); the accepted readback re-seats the row. Every refusal shows in the Fleet's words; only its code `FLEET_SEAT_MEMORY_IMPORT_CLOSED` (the seat runs or already holds its memory) withdraws the offer, and any other refusal leaves the choice open to correct. This lets the twelve rows in the installed FM keep their PATs and still get their memory: Gap 12 of neomjs/neo-agent-brain#571.

Evidence: L2 (unit with the real Detail inspector, controller and shared Store; Darwin visual goldens) → L2 required for AC-1 to AC-5. The Institution's declared Brain pin still precedes neomjs/neo-agent-brain#899, so the closed state is proven against the Fleet's contract here and exercised end to end only by the paired candidate (Post-Merge Validation).

`check-ticket-archaeology` on the changed modules: 0 violations.
