Resolves #522

A Claude Desktop seat whose session opened outside its folder now says so. The roster row's `sessionFolder` (neomjs/neo-agent-brain#826, `{state, expected, observed?, reason?}`) is read through one worder, `util/SeatSessionFolder`, at three densities.
- **The card's status row** ends a Start with the session's folder: "session opened in the wrong folder · reopen", "session not opened yet · open the folder", or "session folder unknown: <reason>". The card names no path, not even in its title: paths are Detail's (#499).
  - Precedence, as Clio decided: a confirmed wrong folder outranks even a live round-trip, because a live seat in the wrong folder is the failure itself. "Not yet" and "unknown" sit below one. `ok` shows nothing.
- **Detail's Seat row** shows the state word only ("wrong folder · see Repository"), on one line that fits the Detail width. The first-launch step gives way to it.
- **Detail's Repository pane** says the rest under its clone path, wrapped whole: where the session opened, and the next step.
  - The launch's `expected` folder is the verdict's authority. The pane's path stands for it ("this folder") only while the two are the same.
  - Once the repository changed or was cleared since the launch, the pane names the launch's folder. It offers a Restart only into a repository the pane shows: a Restart provisions from the current repository (`FleetManager.restartAgent` → `startAgent`).
- `FleetAgent` and `RosterRow` carry `sessionFolder` through; it is `null` on every other row and from a Brain that reports none.

Evidence: L2 (unit arms; a real-browser capture over the NL harness with the Brain's folder fact set per state, at the Detail's own width) → L2 required (AC-1 to AC-3 unit, AC-4 capture). Residual: the installed walk on a real desktop seat, Residual-Owner: #12.
