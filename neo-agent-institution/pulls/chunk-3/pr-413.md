Resolves #411

🌿 A seat on this fleet no longer needs a terminal to sign in to its own plane.

Brain PR neomjs/neo-agent-brain#728 puts a seat's Memory Core and Knowledge Base on the plane the Fleet serves. The seat signs in with its own plane credential, set through the new credential-bearing verb `setPlaneCredential({id, credential})`. Once a Brain pin carries #728, a seat on the local plane refuses to start until that credential is set. This PR is the cockpit's way to set it, and it ships first: on pin 8 the verb is absent, and the action says so.

- **Shell.** `projectPublicCredentialIntent('setPlaneCredential', …)` returns `{id}` only. The main-process prompt asks for the seat's own identity-only PAT, never its checkout PAT; its submit reads "Set".
- **Card.** "Memory & knowledge" offers "Plane credential · Set" to a seat on this fleet whose harness reaches a remote Memory Core. "Local services" now reads "This fleet", like the launcher chip above it.
- **Round-trip.** `{id, planeCredential: true}` routes to `runPlaneCredentialIntent`, which writes no record and shows the Brain's own outcome. A bridge without the verb, or worker ingress, sends nothing and says why. Accounts and Agent Detail both get this without change.

Evidence: L2 (unit: the projection, the prompt copy, the card's offer and refusal, the round-trip's outcomes) + L3 local (Darwin visual: the three Accounts goldens, re-captured) → L4 required for AC-5 (the installed FM, on a pin carrying Brain #728). Residual: AC-5, Residual-Owner: #7.
