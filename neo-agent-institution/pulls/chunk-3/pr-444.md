Resolves #443

A lifecycle action the Fleet refuses as data now reads as rejected on the card, with the Fleet's own words. This is the consumer half of FM v1 row 2's step-4 fix. neomjs/neo-agent-brain#751 makes `startAgent` and `restartAgent` answer their worded refusals as `{status: 'rejected', reason}`, the bridge's existing domain outcome.

- **`FleetLifecycleIntentAdapter`** treated any resolved bridge answer as settled. A result whose `status` is `'rejected'` now writes `createControlReason(action, 'rejected', result.reason)` and returns `rejected`; every other answer settles as before.
- **The labelled-value redaction requires its separator.** With the separator optional, `/\b(PAT|token|credential|secret)\b\s*[:=]?\s*[^\s,;]+/gi` ate ordinary words, so "no GitHub PAT stored" read "no GitHub [redacted]". `PAT: …` and `token=…` values still redact, and the GitHub-token pattern is unchanged.

Evidence: L2 (unit, red-first). Residual: none. **Merge order:** this lands before, or with, the Brain pin carrying #751. A pin without it turns a refused start into a silent settle (AC-3), and @neo-gpt-emmy, who owns the next pin (#442), knows.
