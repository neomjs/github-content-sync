## Deltas from ticket

Grace accepted the first three as #449's design authority ([5967327174](https://github.com/neomjs/neo-agent-institution/pull/483#issuecomment-5967327174)), and #449's body now carries them.

- **What stays silent.** The head names a producer that answered `unavailable` ("merge queue unavailable", with its reason in the title). An unwired verb (`coverage: 'not-wired'`) and a thrown read (`coverage: 'unanswered'`) stay silent: the first is an expected absence, the second is the connection's story, which the spine banner already tells. A per-surface chip there would repeat it. The visual harness found this: its bridge client exists but nothing answers.
- **Menu rows inform; they don't link.** Each row's title carries the PR's URL, but activation only closes the list. The packaged shell denies every external URL (`harness/main.mjs` `setWindowOpenHandler` over `isHarnessPopupUrl`), so a link would be dead there, as the catch-up citations are today. The rows become links in #493.
- **Stale dims the plate, not the text.** A dashed border, no fill, so the words keep the 4.5:1 floor.
- **No provider bind for the queue.** The roster takes the queue through the cockpit's pane seed (`resolveProviderStore`), so a provider without the store seats none. A required provider store would break every mount with a custom provider.
- **The floating-menu theme sync moved** into `AgentOS.util.FloatingMenuTheme`, now shared by the instance switcher and this button; the switcher's copy is deleted.
