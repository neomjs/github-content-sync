Resolves #396

The installed Fleet Manager now records where its agents' seats live, once, and every launch passes that recorded root to the Brain. An ordinary restart can no longer give an existing seat a fresh, empty home, as it did for Sophie at 16:05Z after #379.

- `harness/seatRootRecord.mjs` (a sibling of `planeConfig.mjs`): `seat-root.json` in `userData`, `{root, origin, recordedAt}`, written atomically and owner-only.
  - **The first launch without a record chooses once:** the launch's `NEO_FLEET_AGENTS_ROOT` (`environment`), else the legacy `<userData>/brain/fleet/agents` while it holds a seat (`adopted`). Failing both, `main.mjs` records the root the Brain resolves (`default`).
  - **A present record answers without touching the filesystem.** An environment root that disagrees with it is reported (`HARNESS_SEAT_ROOT_ENV_IGNORED`) and ignored.
- `harness/main.mjs`: the packaged boot settles the root before building the env, passes it as `agentsRoot`, and logs `HARNESS_SEAT_ROOT {origin, root}` on every launch.
- The builder ships the module, and `pack.spec` lists it.

Evidence: L3 (the packaged env as `main.mjs` builds it, through the real Brain config resolver, for an installation holding a legacy seat) → L4 required for AC-7 (the repackaged app). Residual: AC-7, Residual-Owner: #7.
