Resolves #593

🌿 An Activity PR row can no longer show only its number when the event behind it says what happened.

`getPullRequestStatus` (`apps/agentos/view/fleet/activity/RowContainer.mjs`) now reads the open-work producer's `payload.transition` before the corpus path:
- a verdict names its new decision (`changes requested`, `approved`, `review required`);
- a push that answers a change request names `changes pushed`;
- an opening names `opened`;
- a merge or a close names the PR's state.

Reviewers are named only when several moved a verdict, because neomjs/neo-agent-brain#920 makes a single reviewer the row's actor, and this text never repeats the actor cell. An unknown kind or decision names nothing. Events without `transition` resolve exactly as before.

Evidence: L2 (unit tests over the resolver with producer-shaped and corpus-shaped payloads) → L3 required for the installed Activity tab on the next candidate. Residual: that installed reading, Residual-Owner: #490
