Resolves #524

A seat's commit identity now has one row in the cockpit, placed as Clio decided on #524.
- **Add** reads the identity after the define stands. It mounts the row inline only when the derivation fails (`missing`, `mismatch`) or the read itself fails (`unknown`, with "Read again"). A declaration goes through `configureAgent`. The Fleet's read-back answer closes the row, and the status line keeps the identity the seat commits as.
- **Detail › Configuration** keeps the row for every state, with one action per state: "Declare identity", "Read again" or "Change identity". It reads once per seat shown. The declaration goes through the shared config runner, with the row as its own owner token.
- **The roster card** names the row when a Start is refused while the last start's identity needs repair. The title keeps the Fleet's own words.

One reading, `util/SeatGitIdentity`, words every state, so Add, Detail and the card say the same thing. The Brain pin moves to `dbd35bc2`, which is `786d9c4a` plus neomjs/neo-agent-brain#839 and nothing else. That adds the `fleetSeatGitIdentity` verb the row reads.

Evidence: L2 (unit arms, plus a real-browser NL walk that declares in Add and then Starts) → L2 required (AC-1 to AC-4 unit, AC-5 captures). Residual: the installed walk, Residual-Owner: #12.
