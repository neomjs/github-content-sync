Resolves #571

The installed shell now carries the operator's attach PAT to the fleet surface, under the operator's ruling (d).
- **The attach** asks the plane's `/fleet/probe` with the bearer and records its class verdict (`authSource`) in the plane record. No second secret is stored, and the class is never guessed.
