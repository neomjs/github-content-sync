Resolves #440

The setup card's `run` and `re-check` actions reach the vessel's effect channel. `shell-setup-effect` runs the one consented effect through the Brain's shared orchestration (neomjs/neo-agent-brain#765's `setupOrchestration.mjs`, on dev's pin 447d96e): the settle pass first, then `performEffects` with `effectIds: [effectId]` in the recipe's order rules (an earlier effect that is not `ok` halts it), a refusal reported in the orchestration's words with nothing written, and the reply is the re-evaluated run — one serialized operation, the config source (`ai/configBase.mjs` under the runtime root) injected by main, no second implementation of the effects. `shell-setup-evaluate` runs the settle pass before reading whenever the run holds a `reconcile-required` row, so `re-check` settles an interrupted effect through the CLI's rule. The card distinguishes a shell that cannot run effects at all (`no-brain-root`, `not-packaged`, `no-shell`: the row becomes the operator's instruction, counted as a manual action) from an orchestration refusal (the shell's own word on that effect: the status line speaks, the last observation stands). `EFFECT_UNWIRED_REASON` and its arm are gone. The e2e fixture shell now runs the three effects to a completed run: the quiet confirmation fires, the card retires from the primary slot, the chrome reads `11 of 11 observed ok · complete`.

Evidence: L2 (unit with the fake orchestration; the card's fixture-shell e2e) → L3 required (AC-4's completed run on the fixture plane); AC-1/2/3/5 unit + e2e. Residual: the installed host's real run (AC-4's receipt on #351 is this PR's e2e count plus the first real completed run). Residual-Owner: #351.
