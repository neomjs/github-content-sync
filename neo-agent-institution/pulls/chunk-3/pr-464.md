Resolves #440

The setup card's `run` and `re-check` actions reach the vessel's effect channel. `shell-setup-effect` runs the one consented effect through the Brain's shared orchestration (neomjs/neo-agent-brain#765's `setupOrchestration.mjs`, carried by dev's Brain pin — 804356b at this head): the settle pass first, then `performEffects` with `effectIds: [effectId]` in the recipe's order rules (an earlier effect that is not `ok` halts it), a refusal reported in the orchestration's words with nothing written, and the reply is the re-evaluated run — one serialized operation, the config source (`ai/configBase.mjs` under the runtime root) injected by main, no second implementation of the effects. The broker keeps the run's record path only: every serialized operation reads the bound record from disk, so an effect whose acknowledgement write was rejected is found `pending` by the next request and settled by observation, never run again, and a bound record that is gone or unreadable refuses the operation. `shell-setup-evaluate` runs the settle pass before reading whenever the run holds a `reconcile-required` row, so `re-check` settles an interrupted effect through the CLI's rule. The card distinguishes a shell that cannot run effects at all (`no-brain-root`, `not-packaged`, `no-shell`: the row becomes the operator's instruction, counted as a manual action) from an orchestration refusal (the shell's own word on that effect: the status line speaks, the last observation stands). `EFFECT_UNWIRED_REASON` and its arm are gone. The e2e fixture shell now runs the three effects to a completed run: the quiet confirmation fires, the card retires from the primary slot, the chrome reads `11 of 11 observed ok · complete`.

Evidence: L2 (unit over module doubles and over the pinned Brain's own modules on a temp layout; the mounted card against the fixture shell, which assigns the step statuses — a consumer projection, never a host run) → L3 required (a completed run on an installed host, and that run's density). Residual: the installed run and its count, L3-deferred; #351 also holds the fixture path's count as a projection and the ADR item-10 sentence until its docs leaf exists. Residual-Owner: #351.
