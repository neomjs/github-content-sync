Resolves #547

The setup card's unit and e2e tiers now ask the real setup broker over the pinned Brain instead of a hand-written recipe. One fixture, `test/playwright/fixture/pinnedSetupHost.mjs`, scripts the world outside the host's files (the machine, a command runner that records and never runs, a plane that answers only once the compose project is up) and leaves every row's status and reason to the recipe. A page installer puts that broker behind `window.neoShell`, so the served cockpit runs its real mount path against it. No production file changes.

The hand-written sample had drifted: eleven rows where the recipe has twelve, a hosted preset shown as a candidate where the recipe recommends it, another chat model in the table. Wiring the card to the real broker also surfaced a defect no tier could see: a run the card starts has no target and stops at `write-env` (gap line on #351, comment 5981291794, with the planners). The arm from a cold host to `done ok` is that fix's witness and is not in this PR.

No visual surface changed: test files only.

Evidence: L2 (unit tier and the served cockpit in a headless browser, both over the pinned Brain's own recipe, record, host-effect and orchestration modules) → L2 required (every AC is a property of the test tiers). No residual.

agent-preflight: not hosted here; baseline jobs ran (the unit tier, the card's e2e spec).

## Deltas from ticket

- **The planner added one criterion** (AC-4, #351 comment 5981959620): the card's actual cold request as an arm of its own. Every arm that binds a target by hand is how the defect stayed invisible.
- **Re-scoped on the day it was filed.** The ticket first asked for the e2e to reach `done ok`. It cannot: the card sends no target, and the pinned recipe then fails `write-env`. The ticket's second and fifth criteria were re-worded before this PR opened; the remaining arm belongs to the fix.
- **The scripted plane answers as the profile does.** Nothing serves until the compose project is up; then the plane is the Brain's canonical local plane, whatever a run was bound to. An arm holds the fixture to that, so a hand-bound target is never flattered.
- **The view spec no longer states the recipe's row order.** It compares the store with the evaluation row for row; the order is the recipe's to change (neomjs/neo-agent-brain#844 swaps two rows).
