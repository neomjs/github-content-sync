Resolves #481

The setup broker now answers the re-evaluated run for any effect that actually ran, so the card's row shows what happened: `verify` reads `pending` with the Brain's reason while its recall has not landed, and `failed` with the plane's reason when the write was refused. Before, both cases answered a refusal without the run; the card kept the stale row and said the effect "could not run". A report that moved nothing stays a refusal, word for word. One hunk in `harness/setupBroker.mjs`; the rest is its witness and the consent tests' repair.

No visual surface changed: one reply rule in the broker and its unit arms; no card file is touched. #481 was narrowed to this witness on 2026-10-04 by both planners and restated by its author; AC-2 lives in #540. The reply rule's authority is ADR-0034 §2.3 item 10 as amended by neomjs/neo#19396 (merged 2026-10-04).

Evidence: L2 (unit tier: the broker over the pinned Brain's own recipe, record, host-effect, orchestration and verify modules, with the command runner, the plane and the observers' three outside reads replaced) → L3 required for AC-1's installed reading (a real plane that recalls). Residual: the installed witness to `done`, Residual-Owner: #534.

agent-preflight: not hosted here; baseline jobs ran (the unit tier, `check-app-file-sizes`).

## Deltas from ticket

- **A production hunk the ticket did not expect.** #481 assumed the row would render the reason unchanged. It could not: the broker dropped the run whenever the orchestration reported a line. The rule is now "an effect whose own receipt moved answers the run"; it covers a refused write as well as a waiting recall.
- **An arm for a host that already runs a plane.** With an env file, secret files and a running project in place, the three host effects read `observed; not performed by this run`, and a forced call changes neither file and reaches no command. The compose project name is a constant, so this rule is what keeps the card off a live plane; it had no test.
- **The consent tests await an arrival instead of a fixed delay** (the flake recorded on #351). One 20 ms grace remains, for an absence that must not come; its expiry cannot fail a correct broker.
- Found and not fixed here, each with its owner: the card's top effect row is a silent no-op (neomjs/neo-agent-brain#840); the card offers four `run` buttons (#535).
