Refs #23 (parent design-authority arc). Implementation Cut A of the merged IA sketch (`institution-header-detail-ia.html`, PR #57): the cockpit bar. **The structural law, landed:** state never sits between action buttons. The bar's declared item order is now views (+ their exception line) → spacer → **the state block** (fleet + wake pills, one right-aligned group) → actions (contextual Reconnect · start summary · recall chrome · Start fleet).

**Label-content rewrite (the derivation modules carry it):**
- `SpineBanner.deriveSpineBanner` returns `{hidden, kind, text, title, ariaLabel}` — `text` is a STATUS WORD (`fleet offline` / `fleet starting` / `fleet blocked` / `fleet failed` / `fleet connecting` / `fleet degraded` / `feed pending` / `agent os stopped|degraded`), `title` the full honesty sentence with the retained cause, `ariaLabel` its screen-reader mirror. Every reason-retention, surface-partition and ranking doctrine is untouched — the sentences moved channels, they did not change.
- `ViewerWakeTelltale`: the chip wears `wake live · 12s` / `wake off`; the consumer's verbatim reason rides title (line 1, as before) AND now the aria label. The live capture's `"wake: wake stream disconnected (connec…"` (duplicated axis word, mid-word clip) is unrepresentable.
- `SpineBannerComponent` drops the text→title mirror for first-class `bannerTitle_`/`bannerAriaLabel_` attribute channels (the telltale's exact pattern — no channel rides another as a change proxy).

**Declared collapse order** (container queries on the existing `fm-cockpit` context): wide = pills stacked vertically (the operator's vertical-space observation) · ≤1180 = one pill row · ≤730 = words retract to the chip family's marks (font-size 0; title/aria keep the full truth) and action labels drop to glyphs — **view labels never drop**. No form ever clips mid-word.

**Witness moves:** the spineBanner derivation suite re-pinned to the word/sentence channel split (every sentence doctrine now reads `title`); chromeBinding asserts word on text + sentence on title AND aria; the 720 visual witness flips from the ellipsis-pressure regime to the designed mark regime — its own receipt demanded it go red on exactly this design fix, and it did.
