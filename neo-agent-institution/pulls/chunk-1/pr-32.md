Resolves #3

The Fleet list conversions render their visual contracts again — and the repair unearthed why they could not: **this repository's own SCSS was never compiling**. The `build-themes` script carried the engine-only `-f` flag, so `themes.mjs` silently skipped the entire consumer tree; the pre-removal engine pin still shipped an `apps/agentos` SCSS twin inside `node_modules`, which compiled in its place with stale rules (exit 0, no warning). This PR drops the flag, advances the pin past the twin (`17b59aad8f`), and repairs the surfaces on the first honestly-compiled build this repository ever had.

## Deltas

**Build truth (the enabler):** `-f` removed from `build-themes`; engine pin bumped; the consumer SCSS tree compiles (485 files incl. 33 app files; `resources/theme-map.json` regains the `apps.agentos` entries the runtime's per-class CSS loading needs).

**Activity stream** (operator symptom set in the [claim comment](https://github.com/neomjs/neo-agent-institution/issues/3#issuecomment-5451104372)): the header container declares `hbox` (the vbox default stamped `neo-flex-direction-column` over the stylesheet's initial row); `itemHeight` 52 → 32 (the golden density contract — 52 had been sized for the narrow two-line grammar, taxing every wide row 20px; narrow now fits two 13px lines in the same pool); fixture payloads modernized to the five-cell row contract (actor/recipient in their own cells).

**Roster:** sort/filter cluster re-bound to the real Button anatomy (`--button-height` token override, `.neo-button-text` font inherit, the actual `pressed` class) + wrap-capable at vessel widths; `ResizeObserver` joined `mainThreadAddons` — **without it `list.plugin.Animate`'s fluid-column re-derivation never fired in the product** (card widths froze at mount geometry).

**AgentCard containment:** while a control round-trip is live, the second work line belongs to the status row (lane clamps to one line via root cls; status one-line-ellipsized with the full reason on the `title` receipt). **Sub-narrow card grammar (≤240px content), the Round-1 addition:** the vessel band hands each card ~161px of content, where the narrow band's 44px touch pair left the identity column 15px and every resident's name collapsed to two letters — sub-narrow trades the 44px exception back for 32px verbs + a 24px avatar, and the name keeps ≥ ~50px.
