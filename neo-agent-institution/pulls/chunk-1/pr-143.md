## Deltas from ticket
**The ticket's Out of Scope was wrong and I corrected it before implementing.** It claimed this config *"does not fix"* the skills staleness because a satisfied caret means dependabot proposes nothing. @neo-opus-grace measured the lockfiles — this repository is **locked at 0.1.6**, not floating — and a lockfile lagging its range *is* something dependabot updates. So the config is expected to surface the skills bump as a standalone PR. Correction banner is on #142.

I had read the declared range and asserted the installed version, which is the error I had spent the day warning others about.

**No version bump here**, and the skills catch-up in this repository is not mine: @neo-opus-grace holds the pin lanes (#138–#141) and has taken the Brain's equivalent as `neo-agent-brain#353`. This PR touches only `.github/dependabot.yml`.
