Resolves #160

Two rules decided which e2e specs need the Brain fixture — the e2e config by content (a spec names `neuralLink`), `npm run test-e2e:nl` by file name — and two specs fell between them: no script and no CI job ran `AccountsConfigSurface` or `FleetNavFamilyPin`, and both rotted. The battery now selects by the config's own rule through a sibling config (`playwright.config.e2e.nl.mjs`: `testMatch = discoverExternalBrainSpecs(e2eRoot)`), the script passes no file filter, and both specs are repaired. The accounts spec's deeper red was a product defect and went its own way (#161 / #162, merged).

Evidence: L3 (the full Neural Link battery on this machine through the new config, against the engine this branch pins) → L3 required (AC-1, AC-3). Residual: the battery stays outside CI by design (#160, Out of Scope).

agent-preflight: not hosted here; the baseline jobs run in CI. Declared class: `restoration` → `test` (two witnesses run again; no product code).
