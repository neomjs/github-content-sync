Resolves #63

Related: #69 (the empty-fleet CTA, same design pass), #24 (parent), #70 (the witness battery this lane's spec joins)

One config line on the activity row removes the whole stretch family: `RowContainer` is a CSS grid (its SCSS owns the five columns and centers the cells) but inherited the container default `{ntype: 'vbox', align: 'stretch'}` layout, which stamped `neo-flex-align-stretch` on every pooled row — outranking the grid's `align-items: center` at (0,2,0) vs (0,1,0) — and wrote `flex: 1 1 0%` onto each of the five cells. The row now declares the Engine's base layout: no flex classes, no inline flex, the grid owns alignment. The buffered-history witness reads the row geometry at three paints (first paint · deep in recycled history · back at the top) with mixed kinds, and was red on the unfixed baseline at the first row.

Evidence: L3 (the geometry witness against the mounted 500-record pool, the live cockpit read through the DOM, the four re-captured goldens read) → L3 required (a first-paint rendering contract). Residual: the over-wide chip at first paint that #63 observed on the live feed was not reproduced as a separate event — the baseline witness stopped at the row's `align-items: stretch` before its width read; the mechanism that stretches a chip to the row width (column-flex fallback + inline `flex: 1 1 0%`) is removed and the width invariant is now asserted at all three paints. Residual-Owner: none open; a future sighting re-opens with the witness already in place.
