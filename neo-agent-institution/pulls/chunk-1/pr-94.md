- The ticket left `--fm-panel` vs `transparent` to the design read: `--fm-panel`. A transparent strip vanished into the pane ground and left the hairline to do all the work; the panel plate keeps the strip legible as chrome and matches the card plate, which is what "flat panel surface" in the block's own comment meant.
- **The design gate cannot see this class of change.** The first `--update-snapshots` run wrote nothing: pixelmatch at Playwright's default threshold (0.2, YIQ) scores `rgb(41,45,40)` → `rgb(20,26,35)` at ≈180 of the ≈1400 it allows, so the old goldens compared as equal and stayed. The goldens were deleted and re-captured so the stored pixels carry the truth, and the default-shell arm gained a computed-style witness (every inline header on `--fm-panel`, edged by `--fm-line`, no image) — the golden is the record, the witness is the gate. Filed nowhere else: the comparator's blindness in the dark range is a property worth knowing for #13's remaining leaves, stated here.
