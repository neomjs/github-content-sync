Resolves #140

`neomjs/neo` consumed `neo-agent-skills@0.1.6` in [#18742](https://github.com/neomjs/neo/pull/18742) (merged `e1f1d00307`) and retired its own bare `ticket-ref-ok` marker with it. This repository stayed on 0.1.5, which made it the last consumer of the shared baseline still judging source by the older guard.

## Deltas

A durable comment here carrying `#1234 [not-ticket-ref: authority]` failed this repository's baseline while the identical line passed in `neomjs/neo`. Two consumers of one governance substrate disagreeing about the same rule is what `neomjs/neo#16553` was opened to end — one release later, in the same shape.

**All three coordinates move, because two different jobs read two different ones:**

| job | resolution | pin |
|---|---|---|
| `skills-materialized` | `npx --no-install …-materialize --check` — the **caller's** `node_modules` | the **lockfile** |
| `source-comment-archaeology`, `substrate-size`, `pr-body` | `npm install --prefix "$RUNNER_TEMP" neo-agent-skills@${SKILLS_VERSION}` | the **`uses:` SHA** |

- `shared-pr-baseline.yml` — `uses:` → `@6b009521fac6f571be2200cadbeab734cfcffe6d`, the merge commit of [neo-agent-skills#72](https://github.com/neomjs/neo-agent-skills/pull/72). The adoption comment names the new coordinate and the rule it adds; a stale rationale beside a moved pin is how the next reader mis-dates the contract.
- `package.json` — floor to `^0.1.6`. The file's own 4-space formatting is untouched.
- `package-lock.json` — resolves 0.1.6. The range already *permitted* it; a range permits, a lockfile pins.

0.1.6 only **widens** what the guard accepts — a typed `[not-ticket-ref: <reason>]` marker now binds to a deliberate reference as well as to a colour — so it cannot newly fail a line 0.1.5 passed.
