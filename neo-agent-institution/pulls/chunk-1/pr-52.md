## What this is

The clean rebuild of the cockpit core against the operator's 20/100 architecture verdict (recorded verbatim in #50) and the three answered decisions: **partial provider** (multi-consumer truths only), **container = declaration + dock loop**, **fresh PR** (PR #51 closed).

## The provider architecture (twice corrected in review — the final shape)

The derivations are **real pull-based formulas** (`daemonFault`, `instanceState`, `spineBanner`, `viewerWakeTelltale`): formula effects run at construction and re-run on their tracked child + parent data dependencies — the operator-confirmed reference shape, with a shared module helper (`deriveBannerVerdict`) so the dot mirror can never disagree with the banner sentence. `instanceState` deliberately declares NO local twin: the formula's `setData` reaches the Viewport-owned key through the closest-owner walk (a child redeclaration would shadow the parent authority — reviewer falsifier, now a witness test).

One engine behavior shapes the data block: `setData` drills object values into **leaf paths**, so each derived object also declares a leaf-complete data default — the declaration that makes every leaf a trackable config for the slot binds (`data.spineBanner.text` etc.).

Review provenance, honestly: round 1 shipped a hook-based derive after I misattributed dead bindings to three "engine gaps"; the reviewer's positive controls plus re-measurement falsified two of them (static chrome binds; custom reactive configs bind), and his formula probe (2→3→7 re-runs) plus the operator's refinement retired the third ("child formulas never re-run"). What was actually broken originally: formulas writing to undeclared keys. The leaf-complete declarations fixed that substrate, and everything above is the workaround-free architecture on top of it.

The banner's bound-instance label prefix is retired with this cut: the instance switcher beside it is the one name authority in the chrome (`chromeBinding.spec.mjs` pins the live reveal path, the parent-owned dot writes, and the independent title/aria channels end to end).
