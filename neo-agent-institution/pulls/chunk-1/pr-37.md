## What

`apps/agentos/design/institution-memories-pane.html` — the scan pattern for the memories pane, scored against the §04 bar and built strictly over the **existing** `SessionSummary` / `SessionTurn` records, with #36's four review laws applied from birth (contrast contract in the CSS, `Neo.grid.Container` destination, Institution identity, semantic falsifiers):

- **Two scan axes:** recency bands (viewer-calendar today/earlier, chrome tier, section rows) as the outer skeleton; `category` as a closed-set kind chip on the T2 kind axis (EventChip's `--fm-kind-*` mechanism; null → named `uncategorized` neutral chip).
- **Hierarchy:** `title` is the only weighted line (body 600, 2-line clamp); `summary` a 2-line clamped detail body at 68ch; quality/impact/memoryCount stay honest mono facts — no meters, nulls render nothing.
- **Provenance grammar:** summary cards wear `derived` (pill); drill rows wear `authored` once in the drill head — the DERIVED↔AUTHORED distinction the two models already carry becomes visual grammar. Response stays the authored row's primary line (existing ruling kept), prompt demotes to one detail line.
- **The retrieval-hint affordance (#20's named element):** an affordance-class chip per card copying the card's `query_raw_memories("…")` form, derived view-locally from title/session — clipboard is a view capability, no adapter change; the exact query rides the button `title`; no derivable hint → no chip.
- **Co-authors** compress to monogram marks (selected target excluded — existing rule), full identities on `title`.
- **Cold + full + all-null** all rendered: `No sessions in this corpus.`, the populated bands, and the all-null card resolving to the pane's existing named words (`Title unavailable for this session.` / `Summary unavailable…`) — never a blank slot.
- **Destination + interaction (#24 law 0 · law 1):** custom-styled `Neo.grid.Container`, law-1 name `AgentOS.view.fleet.memories.Grid`; grid-owned selection/focus/keyboard; the existing INTENT-shaped drill (open/back/more) keeps its mechanics as row→detail — read-only throughout.
