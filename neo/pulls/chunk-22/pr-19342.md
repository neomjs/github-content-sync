**Other information:**

Adds `test/playwright/unit/util/Performance.spec.mjs`, which pins the behavior
listed on #19133. Test-only change: `src/util/Performance.mjs` is untouched.

The singleton has no reset, so each test uses its own key. Exact durations come
from replacing `performance.now` for the body of a test and restoring it in
`finally`, following the timer-stub pattern already used in
`test/playwright/unit/util/Function.spec.mjs`.

Covered rows:

- `markStart` then `markEnd` records one sample of the elapsed time
- `markEnd` without a `markStart` records nothing
- a second `markEnd` after one `markStart` records a single sample
- the eleventh sample drops the oldest and leaves ten
- `getAverage` returns the mean, and `0` for an unused key
- `getSma` matches `getAverage`
- `getMetrics` returns copies, so mutating the returned `samples` array does not
  change the singleton's data

Local verification:

```bash
npm run bundle-browser-deps
npm run test-unit -- test/playwright/unit/util/Performance.spec.mjs   # 8 passed
npm run test-unit                                                    # 4732 passed, 7 failed
```

The seven full-suite failures are in
`test/playwright/unit/buildScripts/distAppAssets.spec.mjs` and
`test/playwright/unit/util/HighlightJs.spec.mjs`. They also fail on the
unmodified `dev` checkout (`e4f6632`) in this environment, so they are unrelated
to this spec.
