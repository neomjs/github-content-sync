Resolves #19248

Over a target window, a converted tab drag showed its live pane in a window-sized proxy. That was a third proxy shape, between the in-window tab header and the popup, and it covered the dock layout the hand aims at (the operator, 2026-09-26). Now the target shows the same tab-header proxy the drag showed in its own window, and the pane stays in the parked vessel until the drop.

- `TabSortZone`: the engaged transition record carries `proxyRect`, which is the dragged tab header's measured extent plus the grab offset inside it (`dragElementRect`, `offsetX/offsetY`). The sensor's own `sourceRect` input (the park's anchor) is unchanged.
- `DragCoordinator`: sizes and places the target proxy from `proxyRect`, and fails closed on a non-finite extent or offset. It also flags `embodyHeader`. The window drag's popup-origin offsets no longer place the target proxy.
- `DragZone#getDragProxyVdom`: the drag proxy's content, taken out of `createDragProxy` so a cross-window target renders the same content.
- `VesselEmbodiment`: when `embodyHeader` is set, the proxy is a `DragProxyComponent` over that content, and nothing is staged. `restore` / `promote` retire it; `snapshot()` reports `header`.

Evidence: L2 (unit arms, red on dev; Neural Link journeys on the real Workstation) → L2 required for AC-1, AC-2 and AC-4; AC-3 needs a hand (see Deltas).

## Deltas from ticket
- **The placeholder logic is not retired.** A popup dragged by its native title bar still moves its live content into the target: it is a real window, a group popup has no single header, and the operator called that path good as it is. The native path is the placeholder's remaining reader.
- **`proxyRect` rather than a re-used `sourceRect`.** The record's extent is the header's, as the ticket asks. The field name now says what it sizes, and it carries the grab offset too.
- **AC-3 needs #19186 first.** The header proxy renders in the target window. Under a real hand the park leaves the vessel on top of the target (#19186, the operator's recording), so the vessel covers the proxy just as it covers the drop zones.
