Resolves #19273

Closing a Workstation popup now returns all its panes to main in one undoable Group transaction, following the [operator's product decision](https://github.com/neomjs/neo/issues/19273#issuecomment-5848943534). Surviving original tab homes retain their positions; other panes append to a main stack. Undo reopens the popup, and redo returns its panes and closes it again. Component, provider, store and descendant identities survive.

Reload is distinct from close. The read-only `Main.windowNativeIsClosed` observes the exact retained physical handle after document control authority expires; missing, superseded or unreachable handles remain unknown. If opener reload loses that observation, a formerly bound popup recovers on the existing reconnect-lease expiry. Never-bound admissions retain their previous policy. Queued edits trigger fresh preparation, and a successor binding refuses the stale return.

Evidence: L3 (local macOS Chrome, Neural Link, headless and headed) → L3 required by AC-2. Residual: none for the selected return-to-main behavior.

Change class: capability — adds native-close return and a read-only physical observation; app policy stays in Workstation.
