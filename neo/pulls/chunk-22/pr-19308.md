Resolves #19307

`PerspectiveLibrary#savePerspective(record, {activate: false})` into an empty library left `activeLayoutId: null` beside the record it had just saved. The whole-candidate validator refuses that state, so the documented option could never succeed on a first save: the caller got `saved: false` and an invariant it could not have met. The saved record is the only one the pointer may name, so it now takes it, as a replaced active holder already hands its activeness on. `activate: false` keeps meaning "never move an existing pointer".

Evidence: L2 (unit) → L2 required for AC-1/AC-2. Residual: AC-3 (the Institution NL spec on an engine pin carrying this)
