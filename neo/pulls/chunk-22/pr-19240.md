Resolves #19237

ADR 0034 §2.3.2 now names the one non-document the shell's window policy admits: `about:blank`, the realm `Neo.Main.windowOpen` stages every same-origin popup in before it replaces the location with the document. The amendment bounds it three ways: no content, refused as a capability sender (§2.3.4), and an exit only through `will-navigate` onto a harness document. It also records that the shell's admission follows the engine's staging contract. A handler that admitted documents alone refused every product popup silently, which is the FM's dead tear-out and pop-out. The §2.2 C3 row and §6's smoke line point at the amendment. The implementation is neomjs/neo-agent-institution#229.

Evidence: L1 (the ADR text against the source it describes: `src/Main.mjs#windowOpen` and the Institution harness's `configureWebContents` / `isTrustedIpcSender`) → L1 required (a decision record; the runtime receipts live on the implementation PR). No residuals.
