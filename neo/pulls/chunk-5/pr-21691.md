Resolves #21690

`Neo.grid.header.Toolbar#passSizeToBody` now returns while any item is still its config. Reassigning a Gantt's `taskColumns` at runtime made the center toolbar measure its new `TimeAxisHeader` mid-construction, and `item.vdom.id` threw an unhandled TypeError. The toolbar's post-update pass (`Toolbar.mjs:313`) measures the built header right after, so the columns still take their new width.

Evidence: L3 (headless Chromium e2e, one spec against `dev`'s and head's `Toolbar.mjs`) → L3 required (an error and a width in the browser). Residual: none.
