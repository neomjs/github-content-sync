Resolves #21143

Transforms `examples/ConfigurationViewport.mjs` into a workbench layout:
- **Stage (`.neo-example-container`, `.neo-workbench-stage`)**: Centers the rendered component at a readable size on a theme surface with a stable rect suitable for cover screenshots (`flex: 2`, centered flexbox layout with `padding: 30px`).
- **Inspector (`.neo-configuration-panel`, `.neo-workbench-inspector`)**: Contains and groups component controls with title "Inspector" on a dedicated header toolbar (`flex: 1`, min-width 280px).
- **Reset button (`.neo-button-reset`)**: Restores all modified configs and control states to their initial values recorded when the example component was instantiated.
- **Theme switch (`.neo-button-theme-switch`)**: Defaults to Portal's theme (`neo-theme-neo-light`) and cycles through available themes (`neo-theme-neo-light` -> `neo-theme-neo-dark` -> `neo-theme-chalk`).
- **Mobile responsiveness**: Under 600px / 390x844 viewport, stacks the layout vertically (`flex-direction: column`) with stage on top and inspector below, keeping the component visible.
- **Backwards compatibility**: Retains all existing configuration change handlers and preserves initial states seamlessly across `onConfigChange`, `onRadioChange`, and `onConfigRecordChange`.

Evidence: L3 (Playwright unit spec + headless live runtime probe on 1440x900 and 390x844 viewports) -> L3 required (ticket ACs).

          label = page.locator('.neo-example-container label');

    await input.press('Tab');
    await expect(label).toHaveText('A different label');
    await page.getByRole('button', {name: 'Reset', exact: true}).click();
