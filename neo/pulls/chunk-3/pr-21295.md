## Deltas from ticket

- The server sits in `buildScripts/util/`, not `helpers/`. `classify-test-scope.yml` declares `buildScripts/helpers/` outside the e2e launch chain, and `util/` already holds this script's `preserver-start`.
- With neither `--port` nor `PORT`, the server takes 8080 and moves up past a taken port, as webpack-dev-server did. An explicit port that is taken fails.
- `create/component.mjs` starts the server by its path inside the engine, so it also works from a workspace.
- `run({open})` is the exported command-line entry. A generated workspace's `buildScripts/server.mjs` passes its app's route as data no shell parses (neomjs/create-app#72 keeps #74's rule), and a later `--open` or `--no-open` still wins. The entry traps no signals: the default ends the process.
