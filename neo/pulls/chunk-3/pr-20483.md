Resolves #5218

`component.DateSelector`'s month and year label is now a button. It opens a new `Neo.component.MonthYearSelector`, which slides in from the top over the whole date selector. Twelve months sit on the left, a page of ten years on the right with page buttons, and OK and Cancel below. A click or an arrow key moves the pending month or year. OK, or Enter on an option, moves the value to the same day in the picked month and year, clamped to the month's length and to `minValue` / `maxValue`, just as the previous / next month buttons move it. Cancel or Escape closes it unchanged. Either way, focus returns to the label.

- **Keys stay inside.** The selector is a child component, the pattern `table.header.Button` uses for its `filterField`. The keys it handles set `cancelBubble`. As plain vdom inside DateSelector they would also reach DateSelector's handlers, because `KeyNavigation` fires every matching handler of a component: an arrow would move the day grid, and Escape would close `form.field.Date`'s picker.
- **Focus.** Tab wraps inside the open selector through `Neo.main.DomAccess.trapFocus`, the primitive `dialog.Base` uses. On close, focus moves to the label before the selector leaves the DOM, so a date field's picker never sees focus leave.
- **Placement.** The selector's vdom reference sits in the header. `changeMonth()` and `changeYear()` address the root's children by index (header, day view), so a third root child would break the slide animations. The root gets `position: relative` as the anchor.
- **Styles.** `MonthYearSelector.scss` reads the `--dateselector-*` variables, so all four themes apply without theme files of its own. DateSelector loads these styles with its own (`afterSetWindowId`), so the first slide-in is already styled.
- `DateSelectorModel#onKeyDownEnter` now skips the whole header. Before, only the month buttons were skipped, so with `selectOnNavigate: false`, Enter on the label would commit the keyboard destination.
- `useMonthYearSelector: false` keeps the plain label. While the selector is open, the wheel no longer moves the day view underneath. The class is exported from `component/_export.mjs` next to DateSelector.

Evidence: L3 (the browser specs run in real Chromium in CI's components suite) → L3 required (a widget must render and behave in a browser). Residual: none.

## Deltas from ticket

- OK / Cancel and year paging (ten years per page) are additions. Paging keeps the years list short without a scroll range, and OK gives the keyboard a point to commit.
- Existing consumers get one new tab stop: the label sits between Previous Month and Next Month. The two Date field tests that walk the picker's Tab order now include it (the ledger's "Tab order" row).
