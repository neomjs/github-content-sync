Resolves #21211

🌿 What the engine's build runs no longer depends on a third party's default branch on the day it runs.

`buildScripts/build/highlightJs.mjs` now bundles the installed, lockfile-pinned `highlight.js` (11.12.0) with esbuild, as `parse5.mjs` does. It writes the same two files to the same paths with the same ten languages, and needs no git, no network and no second install. Related: #21213.

Evidence: L3 (a forced build on this machine; the dev-mode Portal read in headless Chromium) → L3 required (AC-5, AC-6). Residual: AC-7, Residual-Owner: neomjs/create-app#61.

## Deltas from ticket
- The spec imports each bundle in a child Node process. Imported inside the Playwright worker, the bundle's default export had no `listLanguages`; plain Node gets `hljs`, which is what a browser gets.
- The "no process" arm is a top-level test, so it can run alone: the bundle arms share a `beforeAll` that fails on the old script.
