Resolves #21252

A subtree added to a `TreeStore` in one `add()` under an expanded, visible parent now shows all its levels. `splice()` used to collect an attached node's visible descendants while the batch was still being ingested. Children that followed the node in the same call were not in `#childrenMap` yet, and the projected-parent check then skipped them, because their parent was only queued, not projected. Step 2a still computes the insert index where it did. It now defers the subtree collection to step 2b, which runs once the whole batch is ingested, so insert positions do not change. No API change, no migration.

Evidence: L2 (red-first unit spec, 1194 data/collection/grid unit specs) -> L2 required (#21252 reproduces with a standalone store probe).

## Deltas from ticket
- **Narrower than the prescribed fix.** The ticket proposed recording the candidate subtrees and projecting them all in step 2b, with their insert index. The insert index stays where it was. `getInsertIndexForNode()` reads the previous sibling's last visible descendant and skips any sibling whose last descendant is not projected. After the whole batch is ingested, that descendant can be a node of the same batch, so the method would fall back to an earlier sibling. Only `collectVisibleDescendants()` moves.
- **The exclusion the ticket asks for already holds.** A node is only queued when its parent is already in the projection (`me.map.has(parentId)`), so a child of a node added in the same batch is never queued itself. A re-added node can appear twice in `visibleToAdd`, as it could before; `Collection#splice` skips a key it already maps.
- **Out of scope:** a child listed before its parent in one batch is still re-parented to `root`. The ticket names this order case; it is the existing behavior for disconnected nodes and needs its own decision.
- **Overlap:** outside PRs #21009 and #21035 (both for #21008, changes requested since 11-15) also edit `splice()`. #21009's second hunk sits just above step 2a, so whichever lands second rebases.
