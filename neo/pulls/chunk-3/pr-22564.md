## Deltas from ticket

The design seat has not answered yet, so the four open bindings use my recommendations. Each answer changes one binding in `theme-base`; a new role for Q1 would also add that role to theme Neo's palette.
- **Q1, the bar's hover border:** a new role, `border-accent-hover`, one grade toward the text in each scheme (light `accent-700`, dark `accent-500`), as `border-strong-hover` is to `border-strong` (rule 22). It is pending the design seat's ruling on #22533 (rule 13), and `73fe5756a4` reverts in one commit if she rules otherwise. Two bindings came before it. `focus-ring` alone shares `border-accent`'s grade in light, so hover and rest painted one colour (Sophie's RA-1). The by-hand `light-dark(background-accent-hover, focus-ring)` left Material Dark's hover equal to its rest (Sophie's witness). A two-role mix is excluded by ADR 0044 decision 4.
- **Q2, the non-working shade:** `background-neutral-hover`.
- **Q3, the now marker:** `text-danger`, bound by hand. In light it paints darker than the released crimson.
- **Q4, the editor's Cancel fill:** `transparent`, following the button package. Cancel is outlined by the editor's border.

`scheduler/HeaderSurface.spec.mjs` measures contrast with the palette check's `parseColor` and `contrastRatio` (`24fb40a7b2`). Its own helper read the first three numbers of a computed colour as `rgb()` channels. Bound to theme Neo's roles, the header computes as `oklch()`, so Neo Dark's header measured 1.0003:1 where it reads 13.01:1. The spec passes on `dev` and at head. Three other specs carry the same helper; a defect-note routes them.

One side effect is declared in `expected.json`: the editor goes from 35px to 34px tall, because `font-family-sans` has other line metrics than the system stack.
