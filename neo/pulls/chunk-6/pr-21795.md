Resolves #21793

🌿 A select can no longer break the label column it stands in.

`Neo.form.field.Select` gains TextField's `labelPosition` (`'top'` by default, or `'left'`) and `labelWidth` (150), and the timeline editor's Resource field uses `'left'`. In the scheduler's editor it now starts in the label column of Title, Start, End and Progress, and the dialog is 20 px shorter. A left label adds `label-left`, and `Select.css` lays the field out as two columns with the error under the select. An existing select renders as before.

Evidence: L3 (headless Chromium e2e and a component spec, red on base and green at the head) → L3 required (the layout comes from `Select.css`, measured in the rendered editor). Residual: none.

## Deltas from ticket
- Only `'left'` adds a class (`label-left`). Top is the field's own layout, so an existing select keeps its class list.
- AC-1 runs at 1440 px, the spec's desktop size, rather than 1280.

## Test Evidence
