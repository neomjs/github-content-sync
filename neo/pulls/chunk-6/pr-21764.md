Resolves #21761

One resolver now owns the start-theme rule that ten example `onStart` functions each carried as a twelve-line copy.

Evidence: `src/util/Theme.mjs` gains `resolveStartTheme({prefersDarkTheme, themes, url})` next to `getThemeNamespace()`; the ten `app.mjs` files (`examples/board/{basic,cardDesigns,cardEditor,columns,multiSelect,swimlanes,wipLimits}/`, `examples/form/validation/`, `examples/gantt/dependencies/`, `examples/grid/tree/`) import it and pass its result as `mainView.theme`; the copies are gone. The extraction keeps the same expressions in the same order, so each example starts in the same theme as on `dev`.
