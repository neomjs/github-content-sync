# PR Micro-Review

**Class:** contained. It touches one source file (`src/timeline/draggable/EventDragZone.mjs`) and adds only private state, with no consumed contract. It applies the startup buffering #22153 already established in `SortZone`.

**Verdict:** Approved

**Glance:**
- **The claim:** a `drag:move` that arrives while `dragStart` awaits `DragDrop.setConfigs` is dropped, and a proxy style delta sent before `insertNode` is lost. Either leaves the scheduler and gantt preview stranded at the bar's start.
- **What I verified at `293f297a7c`:**
  - A per-invocation `#activeStart` token buffers only the latest frame.
  - `grabOffset` stays anchored to the press coordinate, as the ticket's trap requires.
  - An overlapping start or a `resetDragState` drops stale frames.
  - The post-mount flush registers once per proxy, applies `#latestProxyStyle` as of callback time, and stands down when `dragProxy` has changed or the style was reset.
- **Evidence:** `red-on-base` passes, so the `steps: 3` sweeps in `BasicNL.spec.mjs` are red on base. The two new unit cases cover buffering, the flush and mid-start cancellation, and unit and e2e are green at the head.
- **Bounded repair:** no site outside the prescription is touched.
- **What I looked for:** a moment where the flush could apply an older style than a direct delta already painted. It cannot, because every `dragMove` rewrites `#latestProxyStyle` before the callback reads it.
- **Non-blocking note:** `.catch(() => null)` also swallows an error that isn't a destruction. `error !== Neo.isDestroyed && console.error(…)`, as `sheet.Handle#settle` uses, would keep such an error visible.
