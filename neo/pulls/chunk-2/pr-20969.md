Resolves #20957

### Summary
- Added `ViewportController.getWidgetPopupUrl()` in `apps/colors/view/ViewportController.mjs` to build the environment-aware relative URL for `apps/colors/childapps/widget/index.html` (no prefix in `development`, `${Neo.config.environment}/` in built environments).
- Updated `Viewport.mjs` `popupUrl` config and `ViewportController.createBrowserWindow()` to use `ViewportController.getWidgetPopupUrl()` so the child widget URL is constructed in a single place.
- Added unit tests in `test/playwright/unit/apps/colors/ViewportController.spec.mjs` covering both `development` and `dist/production` environments.

### Verification
- `npm run test-unit -- test/playwright/unit/apps/colors/ViewportController.spec.mjs` (3 passed)
- Verified on a local production build (`npm run build-all` + `npm run server-start`): detaching the Grid widget opens `/dist/production/apps/colors/childapps/widget/index.html?name=grid-panel&dashboardId=neo-dashboard-1` with live updating cells while removing the grid from the main window.
