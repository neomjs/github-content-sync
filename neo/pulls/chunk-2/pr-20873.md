Resolves #20872

Synchronous `update` listeners can grow or empty a delta array, but default dispatch used its earlier length. Read the length once after the event so every final entry is dispatched in order and an emptied batch stays empty. This also removes the two diagnostic-specific length refreshes.

Change class: restoration (`fix`). `agent-preflight` is not hosted in this Engine checkout; shared baseline checks run in hosted CI.

Evidence: L2 (real Main dispatch with stubbed DOM actions) → L2 required (unit-contract ACs). Residual: none.
