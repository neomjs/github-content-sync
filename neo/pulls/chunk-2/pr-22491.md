Resolves #22448

`npm run theme-release-compare` loads every theme-Neo surface twice:
- **Released:** neomjs.com, with a desktop Chrome user agent.
- **`dev`:** a built `dev` tree served on loopback.

It does so in every scheme the surface lists. For each element whose computed style differs, it reports the released value, the `dev` value, and the custom properties on the element that resolve to the `dev` value, roles first. It saves both frames per surface and scheme, plus `report.json` and `report.md`. It sits beside its sibling `theme-equality.mjs` in `buildScripts/util/`.

Evidence: L3 (a live run against neomjs.com and a built `dev` export, with the positive control reproduced) → L3 required (AC-1, AC-2).
