Resolves #22394

Stock themes now supply their normal motion roles in `Global.css` and generated themes inherit the base declarations. The Engine's structural stylesheet still collapses durations for reduced motion. The existing reference guard checks that every theme class supplies unconditional definitions for roles read without fallbacks in structural stylesheets.

Related: #22295, #22359

Decision Record impact: aligned-with `adr:0044-design-system`, decision 3.

Evidence: L3 (computed CSS and consumer transition duration in Chromium, original and final trees) → L3 required (AC-2 and AC-3). The remaining acceptance criteria are covered by local checks and the release-note handoff.

CI jobs: +0. The targeted assertions run in existing unit and component families.
