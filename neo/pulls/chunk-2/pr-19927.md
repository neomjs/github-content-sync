Resolves #19926

`Neo.main.DeltaUpdates#changeNodeName` now returns the replacement `HTMLElement` (`clone`) after swapping it into `node.parentNode`, and `Neo.main.DeltaUpdates#updateNode` rebinds `node = me.changeNodeName(node, value)` so properties ordered after `nodeName` in the same delta (`scrollLeft`, `scrollTop`, `style`, `innerHTML`, `textContent`) apply to the live replacement node instead of the detached old element.
