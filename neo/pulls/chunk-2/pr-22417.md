Resolves #22415

`Neo.button.FloatingAction` is a Button that floats at the bottom edge of its window, inside the safe area. While its `scrollTarget` scrolls down it collapses to its icon (`scrollBehavior: 'collapse'`) or hides (`'hide'`). An upward scroll, or reaching the top, brings it back. Five theme value files carry its 17 component variables, and the two neo themes bind them to ADR 0044 roles. `examples/button/floatingAction/` shows both behaviors on a phone screen over a Store-backed task list. This is the first leaf of #22414.

Evidence: L3 (the live example in Chromium at 390 × 844: wheel scrolls toggled the classes, measured in the DOM) → L3 required (AC-3 and AC-5 are browser behaviors; touch scrolling on a physical phone is a release check of #22414). Residual: none.

  - Hiding the filter while scrolling is the `'hide'` behavior on display; an app that must keep a control reachable picks `'collapse'`.
  - A button passes over mid-list rows, as floating buttons do. The list's end padding keeps the last row clear.
  - Inserting a row above the visible ones lets scroll anchoring read as a downward scroll and collapse "New task".

## Deltas from ticket

- **Listener identity:** two buttons on one target need `scope` in the listener. `Neo.isEqual` compares functions by name and source, so two bound copies of `onTargetScroll` counted as one listener. The live example showed it: the second button never received a scroll event. The listener is now `{scroll: me.onTargetScroll, scope: me}`, which compares by instance id, and the "two buttons" spec pins it.
- **Per-element positions:** scroll events arrive coalesced. One wheel gesture delivered a single event at `scrollTop` 500, so the first design never got a direction. Positions are now kept per element and start at 0, and the "one coalesced scroll event" spec pins it.
- **Legacy themes:** light, dark and cyberpunk carry literals, as their sibling button files do, until Step 6 migrates them to roles.
- **Example:** the example grew through the cold reads. It now has all five themes with a ThemeSwitcher, padded rows with a subtle-border divider, done tasks marked through a calculated label, and a title and filter button that show the active filter.
