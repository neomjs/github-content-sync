Resolves #22360

`theme-equality` now mounts only the sheets `theme-map.json` names when the map carries its `Neo` class tree, which is the set `Neo.main.addon.Stylesheet` requests. Built sheets whose sources are gone stop counting as differences on a long-lived checkout. A sheet the map names but the build did not write fails closed, and a map without the tree keeps the directory walk.

Evidence: L2 (unit red on base → green; map vs walk compared on a real built tree for all five themes; the component spec run locally) → L2 required (AC-1, AC-2, AC-3).
