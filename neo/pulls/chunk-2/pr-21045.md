Adds `learn/guides/datahandling/Gantt.md` (182 lines) providing a comprehensive guide for building Gantt charts with linked tasks in Neo.mjs.

### Guide Structure
1. **What a Gantt chart is in Neo.mjs**: Explains `Neo.gantt.Container`, dual reactive stores (`TaskStore` and `DependencyStore`), locked tree columns, and time axis projection.
2. **A minimal chart**: A runnable setup featuring a parent phase, three sequential child tasks, and Finish-to-Start dependencies.
3. **The task record**: Hierarchical fields (`parentId`, `isLeaf`, `collapsed`) and Gantt-specific properties (`duration`, `durationUnit`, `milestone`, `percentDone`).
4. **The dependency record**: Precedence constraints (`fromId`, `toId`, `lag`, `lagUnit`) and link constraint table (`FS`, `SS`, `FF`, `SF`).
5. **The cascade**: Downstream propagation behavior (`cascadeDependencies: true/false`) and cycle breaking.
6. **Working time**: Axis calendar integration (`useWorkingTime`, `nonWorkingDays`, `snapMinutes`).
7. **Interactive links & next steps**: Gesture creation via `dependencyCreation`, `schedule` service, and links to `examples/gantt/basic`.
