## Deltas from ticket
- Replaced `translateY(calc(-62% - 0.5 * var(--neo-textfield-border-top-width)))` with the exact box-independent centerline formula `translateY(calc(-50% - 4px - 0.5 * var(--neo-textfield-border-top-width)))` paired with `align-items: flex-start` on `.neo-center-border`: under `font-size: .7em`, `<label>`'s own reference height shrinks from `16px` to `~11.2px`, where `-62%` would under-shift by `~3px`, whereas `-50% - 4px - 0.5 * border-top-width` centers `<label>` on the top border across any font size or border width (including Material's `0px` top border).
- Declared `flex: 1 0 auto; min-width: calc(11px + var(--neo-textfield-border-inline-width));` as two separate properties on `.neo-right-border` (with `flex: 0 1 auto` on `.label-inline .neo-textfield-label` overriding base `.neo-textfield-label`'s `flex: 0 0 auto`) so an unthemed host without `--neo-textfield-border-inline-width` never triggers `flex` shorthand IACVT (`width: 0`), while themed narrow fields always preserve at least `12px` for the right rounded border cap.
