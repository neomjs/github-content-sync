Resolves #20896

The wheel now zooms toward the pointer. `onWheel` computes the new distance as before (same clamp to `zoom.min`/`zoom.max`), then moves `camera.target` with it so the point of the target's depth plane under the pointer keeps its canvas position. The move comes from a new pure static helper beside `flightStep`, `GraphScene.zoomTarget({aspect, camera, dist, fov, height, width, x, y})`: it shifts the target along the view's right and up axes by `(oldDist - newDist) * tan(fov / 2)` times the pointer's offset from the centre in normalized device coordinates (times the aspect on x). With the pointer at the centre, or a distance the clamp leaves unchanged, the shift is zero, so today's behaviour is the special case. Zooming out reverses the move.

The pointer position comes from `mouse`, which `Base.updateMouseState` fills from the wheel report before it calls `onWheel` (a report without a position keeps the last one). No pointer position yet (idle `mouse`), no `canvasSize`, or the new `zoomToPointer: false` config keeps the old zoom toward the target.
