Resolves #20877

The resource Scheduler pairs locked rows for people, rooms or equipment with bookings on a shared time axis. Editing, keyboard rescheduling, pointer moves and resizing all use one record writer. A second view can observe the same booking in its store.

The Studio Bookings example is under Calendar in the Portal examples index. It keeps edits in browser storage. Move a booking to another studio, wait for “Saved on this device”, then reload to recover its dates and assigned room.

Evidence: L2 (public Engine units and headless Chromium against the source example and its distribution entries) → L2 required for this leaf. The epic steward’s visual read is requested below.

## AC Evidence

- Both Scheduler classes appear in the generated API hierarchy. The theme build includes component and example styles for the two neo themes.
- The browser scenario moves a booking by keyboard, drags it to another resource using the visible proxy, resizes it, and checks the backing record after a full page reload. The unit suite verifies a single record mutation, cancel, resource-key lookup, shared editor and instance lifetimes.
- The catalog links source, ESM, development and production. The Portal browser test opens the new Calendar tab and finds the Scheduler example there.
