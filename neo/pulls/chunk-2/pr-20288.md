Resolves #20286

🌿 A graph pane can no longer show a well it cannot name.

`Neo.canvas.GraphScene` now draws labels in the same frame as its points, and can fly its camera to a node.

A scene's optional `labels` names nodes in priority order. `upload()` rasterizes each text once, fill over outline, into one atlas texture on a worker `OffscreenCanvas` 2D context at the drawing buffer's pixel ratio. Every frame, the static `placeLabels` projects the labelled nodes and keeps priority order. It skips a label behind the camera, off the surface or over one already placed, and stops at `labelStyle.max`. The second program then draws the placed labels as pixel-snapped quads in the premultiplied blend, and the blend is restored afterwards. A ratio change re-rasterizes the atlas, and a lost context rebuilds it with the other surfaces.

`flyTo({index, distance, duration})` eases the orbit target to the node and the distance by a constant ratio (`flightStep`), within `zoom`. The pointer or the wheel ends the flight.

`getStats()` gains `labels: {count, drawn}`, where `drawn` holds the labels the last frame drew in CSS px, and `flying`. The graph example labels its 20 path nodes and gets a "Fly to #120" button.

Evidence: L3 (headless Chromium WebGL2 on the canvas worker: the example's e2e reads the drawn labels, an orbit, a fly-to and a context restore) → L3 required (every AC is renderer behaviour on the engine example). Residual: none. The consumer receipt is neomjs/neo-agent-institution#839's own AC.

Prescription checked: `src/canvas/GraphScene.mjs` owns the concern. Drawing the scene and owning its camera are already this class's job. `Neo.canvas.Base` is too generic, the App Worker is the wrong thread for per-frame placement, and the Observatory subclass would couple app code to `program` and `surfaces`.

## Deltas from ticket
- `getStats()` also reports `flying`, so a reader can tell a flight under way from a landed one. The e2e waits on it.
- `compile()` now takes shader sources and uniform names, and the label program reuses it instead of a second copy.
- The consumer-receipt AC moved to the ticket's Post-Merge Validation, since this PR cannot deliver it.
- At the far level, a label sits on its node's cluster centroid (`labelAnchors`; `clusterScene` returns `clusterOf`), so it never floats where nothing is drawn. This is seam 4 of Ada's read as GraphScene's author (A2A 9bd827a4). Seams 1 (premultiplied upload) and 2 (re-rasterizing on a ratio change) were already in. Seam 3, web fonts in the worker, is the ticket's Out of Scope.
