Resolves #20908

Opening a source tab while its first render is in flight can settle `promiseUpdate()` before that render carries the fetched text. Both highlighting callbacks can then see an empty code element, leaving the later source unformatted. `SourceViewComponent` now waits for mount through `trap(mountedPromise)` before requesting the source-bearing render. Destruction cancels the wait through the existing lifecycle sentinel.

Evidence: L3 — a controlled native first-mount witness reproduces the original missing-line failure before the repair and passes afterward. Required: L3. Residual: none for this leaf. This identifies a concrete race matching the hosted symptom; the original CI traces did not record the callback ordering or its natural frequency.
