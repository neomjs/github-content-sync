Fixes #19878

## Change

`Neo.list.ValuePicker.createPooledItem()` built the option `aria-label` as `<label>, <count> matches` for every count, so a value with one match was announced as "1 matches". It now uses `match` when the count is exactly 1 and `matches` otherwise ("0 matches", "1 match", "2 matches").

The e2e expectations in `test/playwright/e2e/grid/HeaderMenuStateNL.spec.mjs` that asserted `, 1 matches` now assert `, 1 match`.

## Design choice

None. The singular form for a count of one is the only reading of the issue's acceptance criteria.

## Tests
