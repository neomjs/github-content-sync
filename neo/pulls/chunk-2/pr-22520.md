🌿 A dragged header and the tree's sort proxy read four literals that only theme Neo's two copies carried, one a raw black. Now they live once in theme-base, and no theme built on Neo can drag without them.

Cyberpunk declared only the radius, so the other three are `initial` there, and its readers compute what they did before.

Evidence: L2 (the equality run across 5 themes; whole-page frames of a real tree sort drag from built trees) → L2 required (#22519's ACs are equality and frame pairs). Residual: none.
