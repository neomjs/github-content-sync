Resolves #19879

**Draft, diagnosis first.** Scene 5's stack return fails on about half of hosted attempts because its aim leaves main: main's return node is measured at x 2304 while main's window is 1280 wide. These commits make that failure name its own cause. The failure message now carries what main's page reports for itself: scale ratios, the document's and the node parent's scroll widths, every transform still applied to the node or its ancestors, and the node's DOM rect at failure time. That separates three readings: a scaled page, an overflowing dock, or an aim read mid-motion. The driver measures its target once before 180 attempts, and DockFlip's invert is a translate-and-scale, so a current rect that differs from the aimed one convicts the aim. The fix follows in this PR once a hosted failure has printed them.

Evidence: L1 (spec-only instrument, no failure observed with it yet) → L3 required (a hosted failure's printed layout, then ≥ 10 clean hosted shard-10 runs). Residual: AC-2–AC-5, Residual-Owner: this PR while draft.
