Resolves #22398

Compact Grid users can select a contact and open its editor from a floating native Button. Both entry points share the existing Dialog. The floating action gives a selection prompt when the Grid has no active row.

Evidence: L3 (headless Chromium with a touch context and dedicated Neural Link worker readback) → L3 required (AC-1 through AC-3).

Refs #21140

## AC Evidence

| Criterion | Evidence |
| --- | --- |
| AC-1 | CI-covered in `EditInDialogExample.spec.mjs`, compact floating contact action. Touch selects and opens `p03`, and Enter and Space reopen it. After Save, a different row reuses the same Dialog with record `p01`. Cancel returns focus to the floating action. Clearing selection shows feedback. |
| AC-2 | CI-covered in the same compact arm. Cancel and Escape discard drafts, Save changes the selected row, and focus returns to the floating Button. |
| AC-3 | CI-covered in the compact placement assertions and existing wide row-edit case. |

## Deltas from ticket

The compact instructions name both edit routes. The example keeps one editor through concurrent lazy loads and uses the Grid View’s existing selection getter.

## Test Evidence

Full-page 390 × 844 before/after and open-editor frames were captured in headless Chromium. The local case also read contact identity and opener identity through the dedicated Neural Link adapter.

Frame critique: the floating button sits below the grid’s scroll region and the editor fits its viewport. The City column uses horizontal scrolling in both compact frames. The refreshed action has a rounded outline and clear separation from each row’s Edit button.
