Resolves #20907

Drag a booking across the Studio bookings example and its preview follows the pointer. Pull the finish edge and the preview shows the proposed duration. Escape returns the booking to its original place. Every Scheduler gets this behavior with its default settings.

Evidence: L2 (Chromium pointer journeys on the public example and focused Engine unit tests) → L2 required.

In both themes the move test reads the displaced preview and checks that its width stays fixed. The resize test reads its increased width and checks that its left edge stays fixed. Each checks the stored dates and resource before mouseup, cancels with Escape, and verifies the preview disappears and the booking stays put. A separate journey compares the held preview to the released bar, then reloads the saved bookings.

## Contract ledger

`Neo.scheduler.Container#getEventDragZoneDefaults()` enables the existing worker-positioned preview. Explicit `eventDragZoneConfig` values still win, including `useProxy: false`. The example now exercises the default. The Scheduler cancels unfinished setup on Escape, release or destruction. Shared drag setup accepts an optional abort signal so a late response can discard its own work. A startup error clears any partially created preview and propagates to its caller.

## Deltas from ticket

The Scheduler also handles a resize that starts while an earlier move is waiting for setup. Its edge and preview survive the older response. The four images are pinned to the evidence commit.
