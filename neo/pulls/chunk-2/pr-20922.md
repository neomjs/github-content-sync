### 🔬 Depth Floor

- **Challenge — who refreshes the baked `lastmod`?** At this head, no workflow in this repository runs `rebuildContentIndexesAndSeo.mjs` or `generate.mjs`.
  - So a route's `lastmod` only moves when a maintainer or the release path regenerates `seo.json` from full history.
  - If nobody does between releases, the core sitemap keeps serving the dates of the last regeneration while the pages change.
  - Naming the step that regenerates, in the release path or a scheduled job, keeps the dates honest. This is non-blocking: the fallback is correct by construction, and only its cadence is unstated.
