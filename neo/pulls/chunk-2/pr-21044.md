Adds `examples/timeline/basic`: a standalone, runnable example demonstrating `Neo.timeline.Column` mounted in a plain `Neo.grid.Container` with a 24-hour `Neo.timeline.TimeAxis` and an inline `Neo.timeline.store.Events`.

Key details:
- Standalone example (`app.mjs`, `index.html`, `neo-config.json`, `Viewport.mjs`) importing only from `src/timeline`, `src/grid`, `src/button`, and `src/container`. Imports nothing from `src/scheduler` or `src/gantt`.
- Interactive interval shift button (`record.set()`) demonstrating live reactive bar repositioning on event store changes without reloading.
- Added `timeline-basic` to `apps/portal/resources/data/examples.json` and updated SEO metadata.
- Updated `test/playwright/unit/apps/portal/view/examples/TabContainerController.spec.mjs` catalog count (75 -> 76) and family store order.
