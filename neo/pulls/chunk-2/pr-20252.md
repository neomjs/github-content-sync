Resolves #4723

Extends `Neo.component.Splitter`, `Neo.main.draggable.Resize`, and `Neo.main.addon.DragDrop` so splitter drag-and-drop gestures honor `minWidth` and `minHeight` bounds configured on both the resized sibling and the opposite sibling across live and proxy modes.

Evidence: L1 (Playwright unit suite covering `Splitter#getResizeConfig`, `Splitter#applyResize`, `Resize#createState`, and `DragDrop#onDragMove` proxy clamping) → L1 required (all four ACs on `#4723` are unit-testable component/addon contracts).

## AC Evidence
| AC | Evidence |
| :--- | :--- |
| AC-1 | `test/playwright/unit/component/Splitter.spec.mjs` (`forwards sibling minWidth / minHeight and opposite sibling bounds into resizeConfig`, `clamps terminal applyResize against the target sibling configured minWidth or minHeight`) |
| AC-2 | `test/playwright/unit/main/addon/DragDrop.spec.mjs` (`createState caps maxSize against the opposite sibling min bound without mutating the opposite sibling`) |
| AC-3 | `test/playwright/unit/main/addon/DragDrop.spec.mjs` (`deferred proxy mode clamps dragProxyElement position to the resize [minSize, maxSize] window`) |
| AC-4 | `test/playwright/unit/component/Splitter.spec.mjs` and `test/playwright/unit/main/addon/DragDrop.spec.mjs` (48 passed across `DockSplitter.spec.mjs`, `Splitter.spec.mjs`, and `DragDrop.spec.mjs`) |

## Deltas from ticket
- Resolves configured pixel floors (`minWidth` / `minHeight` on the component, `wrapperStyle`, or `style`) in `Splitter#getSiblingMinSize()` so wrapped components with a custom `getVdomRoot()` still contribute their floor to the outer layout wrapper descriptor, while leaving `%` bounds to main-thread `resolveCssBound()` against the measured parent layout box.
