<summary>Changelog</summary>
<p><em>Sourced from <a href="[QUARANTINED_URL: github.com]">monaco-editor's changelog</a>.</em></p>
<blockquote>
<h2>[0.58.0]</h2>
<h3>Breaking Changes</h3>
<ul>
<li>Markdown rendered by the editor (hovers, suggestion details, parameter hints, inline completion warnings, editor messages) no longer loads remote images by default. <code>data:</code> images are still shown. Use the new <code>markdownImages.allowedOrigins</code> editor option to allow images from specific origins (for example <code>['[QUARANTINED_URL: img.shields.io]']</code>), or set it to <code>true</code> to allow all remote images as before.</li>
</ul>
<h3>Fixes</h3>
<ul>
<li>Fires configuration change events when tab focus mode is toggled, and keeps per-editor <code>tabFocusMode</code> overrides (<a href="[QUARANTINED_URL: redirect.github.com]">#4740</a>, <a href="[QUARANTINED_URL: redirect.github.com]">microsoft/vscode#345251</a>, <a href="[QUARANTINED_URL: redirect.github.com]">microsoft/vscode#349316</a>).</li>
<li>Bundles the <code>@vscode/diff</code> backend in the editor worker, so the <code>advanced-external</code> diff algorithm works in bundled applications (<code>advanced-wasm</code> uses the same TypeScript backend in the standalone editor), and falls back to the built-in diff when it fails (<a href="[QUARANTINED_URL: redirect.github.com]">microsoft/vscode#348527</a>, <a href="[QUARANTINED_URL: redirect.github.com]">microsoft/vscode#346266</a>).</li>
<li>Fixes memory leaks in the word highlighter and color picker, and reduces idle CPU usage by disabling the native caret blink in EditContext.</li>
<li>Fixes <code>findWithArgs</code> ignoring empty search strings, UTF-16 column counts in text lengths, stale format-on-type requests, and auto-closed pair tracking for suggestion edits.</li>
<li>Fixes several minimap rendering issues (slider behavior with view zones, section headers, background, sizing on high-DPI screens).</li>
</ul>
<h3>Updates</h3>
<ul>
<li>Updates the editor core to VS Code commit <code>c132f72ae9f5ff80093e7d722c36f03755865b20</code>, validated in <code>0.58.0-rc.2</code>.</li>
<li>Adds <code>@vscode/diff</code> 0.0.2-145 as a dependency.</li>
<li>Updates bundled DOMPurify from 3.4.15 to 3.4.17.</li>
</ul>
</blockquote>
