Resolves #20927

## Problem

A grid whose selection model has `singleSelect: false` lets a person select several rows or cells, but its ARIA root never says so: assistive technology announces a grid in which one item can be selected. Nothing under `src/grid` or `src/selection/grid` wrote `aria-multiselectable`, although the list precedents (`src/list/ValuePicker.mjs`, `src/form/field/Chip.mjs`) do for their multi-select lists.

## Root cause

`aria-multiselectable` belongs to the grid element that `Neo.grid.Container#getAriaRoot()` exposes, but the only party that knows whether several selections are allowed is the View-owned selection model, through its `singleSelect` config. The model registered with the View and never touched the ARIA root.

## Fix

- `Neo.selection.grid.BaseModel#syncAriaMultiselectable()` writes `true` on the ARIA root when the model is multi-select and deletes the attribute otherwise, updating `ariaWrapper` only when the root's state actually changes.
- `register()` calls it, so a model swapped at runtime (`grid.view.selectionModel = {…}`) corrects the announcement; `unregister()` withdraws it, unless the View is being destroyed, matching the existing repaint guard.
- `Neo.grid.Container` calls it once after creating `ariaWrapper`: the View registers its own model while the container is still constructing, before `getAriaRoot()` has a root to write on. This also covers `treegrid` roots.
- `singleSelect` stays a plain config; a runtime change to it on a live model remains out of scope, as the issue states.

## Testing

New spec `test/playwright/unit/grid/AriaMultiselectable.spec.mjs` covers a default grid (no attribute), multi-select `RowModel` and `CellModel` (attribute `true`), a tree grid with a multi-select model, and a runtime swap that writes then withdraws the attribute. Red before the change (4 of 5 failed with the attribute `undefined`), green after.

```
npx playwright test -c test/playwright/playwright.config.unit.mjs grid/AriaMultiselectable.spec.mjs
  5 passed

npx playwright test -c test/playwright/playwright.config.unit.mjs grid
  497 passed
```
