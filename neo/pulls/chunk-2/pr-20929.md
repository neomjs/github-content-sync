### 🔬 Depth Floor

- **Challenge** (three notes, none blocking):
  1. **`Markdown.headOnlyFrontMatterKeys` is a `static`.** A consumer app can change it only by subclassing. A non-reactive config with the same default would let another app adjust it per instance. The default itself (`robots`, `seoDescription`, `seoTitle`) is a sound general convention.
  2. **Two readers for one block.** `extractFrontmatterField` reads YAML with a line regex, while `Neo.component.Markdown` parses the same frontmatter with a YAML parser. A folded or multi-line value, or a trailing comment, would read differently in the two. None of the 18 guides uses one today, and one shared parse would close the gap.
  3. **Colors' "Learn more"** now points to `MultiWindow`. The ITNEXT article it replaces covered sharing real-time WebSocket data across windows, which is exactly #20931's new post. Once that post lands, it may be the better target.
