**Summary of Changes:**
1. `Neo.main.addon.GridHorizontalScrollSync`:
   - Added `registerFollower` and `unregisterFollower` to `remote.app`.
   - In `onScroll`, synchronously set `--grid-scroll-left` on all mounted `followerIds` in the identical frame as `bodyId`.
   - In `register` and `registerFollower`, seeded current `scrollerNode.scrollLeft` on mounted follower nodes so rows mounting mid-scroll align immediately.
   - Preserved symmetric listener and collection cleanup in `unregister`.
2. `Neo.grid.ScrollManager`:
   - Added `horizontalScrollFollowerIds = new Set()`.
   - Added `registerHorizontalScrollFollower(nodeId)` and `unregisterHorizontalScrollFollower(nodeId)`.
   - Passed `followerIds: Array.from(me.horizontalScrollFollowerIds)` in `updateGridHorizontalScrollSyncAddon`.
   - Cleaned up followers in `destroy`.
3. Unit test coverage:
   - Added `test/playwright/unit/grid/HorizontalScrollSyncFollowers.spec.mjs` verifying follower synchronization on scroll, mid-scroll registration seeding, unregistration teardown, and `ScrollManager` lifecycle registration.
