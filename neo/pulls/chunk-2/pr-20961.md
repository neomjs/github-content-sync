Resolves #20958

A dock tab press now reconciles in place instead of rebuilding the shell. `setActiveItem` gets its own change class, `activation`, because it writes only `nodes[id].activeItemId`. `Workspace#getRefreshOptions` maps that class to `{retainTopology: true}`, the path `itemFlags` already takes. The reconciler's stable path already lands an active-tab delta, starts a parked lazy pane's load, validates structure, and reports the path it took.

Evidence: L3 (a whitebox Workstation run: real presses, through an isolated Neural Link Bridge and the in-process adapter) → L3 required (AC-2). No residual.

agent-preflight: not hosted here; the shared baseline jobs run in CI. Declared class: `capability` → `feat`, because `activation` is a new change class and refresh path.
