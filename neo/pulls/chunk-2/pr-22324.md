### 🔬 Depth Floor

- **Challenge** *(non-blocking edge cases noted for future maintenance)*:
  1. **Trailing prose on multiline collection `@member` lines (`codingGuidelinesJsdoc.mjs:678-695` vs `buildScripts/docs/docletPipeline/memberDefaults.mjs:52-54`):** For a multiline block like `* @member {String[]} pair=['a','b'] The pair`, `token` (`['a','b']`) parses cleanly via `parseExpressionAt(token, 0)` so `losesInlineDefault` returns `false`, whereas `publishedMemberDefault` slices `item.comment` from `=` to `\n` and sweeps `' The pair'` into the published default for `Array`/`Object` types. Flagging `collectionType && !/^(?:null|false|0|NaN|undefined)$/.test(value) && Boolean(remainder.trim())` is a clean optional tightening if that shape ever appears.
  2. **Path-keyed `BASE_SHA` check on `git mv` of a baselined file (`check-coding-guidelines.mjs:561-566`):** Because `scanFiles(root, {ref, selected: recorded})` looks up `recorded` paths at `ref` without rename following, renaming a file that still carries baselined findings will report its moved entries as absent from `BASE_SHA` unless the findings are migrated in the same commit (which aligns with `CODING_GUIDELINES.md §8`'s migrate-on-touch posture, worth keeping in mind during package moves).
