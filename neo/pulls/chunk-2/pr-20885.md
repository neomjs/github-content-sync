Resolves #20876

Time-based grid views can now share one axis for date-to-pixel conversion, tick labels, working-calendar arithmetic and snapped edits. The timeline column renders packed events from a store or a bar from the row’s own dates. Horizontal scrolling projects the visible interval and its buffer.

Evidence: L2 (Engine unit configuration, generated API hierarchy and compiled themes). The generated-app journey is tracked by #20874.

## AC Evidence

- All eight `Neo.timeline` classes appear in the generated class hierarchy. The scale and packer operate on dates and model values without reading the DOM.
- The Engine unit configuration ran 39 timeline tests, including day and holiday boundaries across four host time zones, daylight-saving transitions, viewport reprojection, canceling a drag, and committing an edit once. A caller may refuse an edit without mutating the record. The header’s major and minor labels and the editor’s format/parse round trip also use the same custom axis clock.
- `highlightedRecordIds` controls `.neo-timeline-bar-highlighted` and `data-highlighted="true"`. The column test checks marking and clearing the same bar.
- The theme build generated the column, header and editor CSS for the shared style tree and both neo themes. The staged source, test and theme guards passed.

## Contract ledger

`Neo.timeline.TimeAxis` owns the project clock, bounds and working days. `Neo.timeline.model.Event` and `Neo.timeline.store.Events` supply record identity and range queries. `Neo.timeline.util.IntervalPacker` computes lanes without reordering its input. `Neo.timeline.draggable.EventDragZone` changes the record once on drop, or calls the owner’s optional `commitTimelineEdit` hook. `Neo.timeline.EventEditor` uses the same hook and keeps a refused draft open. `Neo.timeline.Column` and `Neo.timeline.TimeAxisHeader` use the same axis as both editing surfaces.

## Deltas from ticket

The timezone conversion helpers live on the axis so the header and editor honor instance overrides. Concrete planning views, guides and the remaining themes have their own leaves under #20874.

## Test Evidence

`npm run test-unit -- test/playwright/unit/timeline`, `npm run generate-docs-json`, and `node buildScripts/build/themes.mjs -f -n -e dev -t all` passed. All nine expected CSS files were present. Verification concerns this timeline family; the generated-app journey covering all planning views belongs to the parent epic.

- [ ] **RA-2:** A bar's lane and height change with the scroll position. `Column` packs only the events `getRangeRecords(visibleStart, visibleEnd)` returns (`src/timeline/Column.mjs:880-909`), and `laneCount` sets every bar's height and top (`:931-933`). - [ ] **RA-3:** Instances created from configs have no owner. `Column#beforeSetEventStore`, `Column#beforeSetTimeAxis` and `TimeAxisHeader#beforeSetTimeAxis` create them through `ClassSystemUtil.beforeSetInstance`, and neither class releases them on replacement or destroy (`TimeAxisHeader` has no `destroy`).
