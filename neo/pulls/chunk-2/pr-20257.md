Resolves #3602

Adds `-M, --createModel <value>` and an interactive `inquirer.prompt` (`Do you want to create a matching data.Model?`) to `buildScripts/create/class.mjs` when `baseClass === 'data.Store'` and the companion `data.Model` file does not yet exist on disk. Singularizes the store class name (`-ies` -> `-y`, trailing `-s` -> singular), resolves the target `model` namespace across `Neo`, `apps/<app>`, and `-d` drop paths, disambiguates `Store` -> `StoreModel` when a store singularizes to `Store`, generates the `data.Model` file when `createModel === 'yes'`, and wires `import <Model> from '<relativePath>'` + `model: <Model>` into the generated `data.Store`.

Evidence: L2 (Playwright unit suite in `test/playwright/unit/buildScripts/createClassModelStore.spec.mjs`) -> L2 required (CLI & interactive `buildScripts/create/class.mjs` companion `data.Model` generation and store linking).
