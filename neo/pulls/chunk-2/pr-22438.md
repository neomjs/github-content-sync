The CSS build compiles widget variable declarations to native `@scope` rules bounded by the registered theme classes. JavaScript consumers that already need a theme name, such as floating tooltips or drag proxies, skip the role-scope marker.

Explicitly themed container items keep their choice when the parent switches through the same theme and back. Ordinary items still inherit.
