Resolves #18113

Extends `Neo.component.Base#nativeDragZone` and `Neo.main.addon.NativeDragSource` with explicit `{record.<field>}` payload template tokens resolved synchronously from a pre-pushed `records` map (`nodeId / data-record-id -> {field: value}`). Components declaring `{record.<field>}` tokens push the projected record-field map on registration and refresh it on store `load` / `recordChange` and `grid.Body` row renders (`createViewData` / `onStoreRecordChange`), decoupling `nativeDragZone` from `useInternalId: false` while keeping existing DOM attribute tokens (`{data-record-id}`) and attribute-only registrations unchanged.

Evidence: L2 (20/20 unit specs in NativeDragSource.spec.mjs and NativeDragZone.spec.mjs green in Playwright Node runner; all 6 ACs are pure in-process component/addon template and store-refresh invariants) → L2 required.
