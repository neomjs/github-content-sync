Resolves #22250

The release checklist in `examples/list/reorder` can now be reordered from the keyboard. With a step focused, Ctrl+Shift+Up or Ctrl+Shift+Down (Cmd+Shift on macOS) moves it one place through `SortZone.moveRecord()`, the same commit a pointer drop uses, as the desktop launcher already does. The list waits for the render, puts the focus back on the moved step and writes its new place into a polite live region next to the list. At either end the order and the focus stay, and the live region says the step is already first or last. The example's intro explains the keys and each step carries `aria-keyshortcuts`. Example-only change: no public API or behaviour change outside the example.

Evidence: L2 (extended `ReorderExampleNL.spec.mjs`, full spec run locally in Chrome with `--repeat-each=4`, 16/16 passed) -> L2 required (ACs ask for the keyboard case and a pointer drag after a keyboard move in that spec).
