### Minimal installed-workspace usage (`AC-1`)

```javascript
import CommandPalette from '../../../node_modules/neo.mjs/src/dialog/CommandPalette.mjs';
import Controller     from '../../../node_modules/neo.mjs/src/controller/Component.mjs';

class MainViewController extends Controller {
    static config = {
        className: 'MyApp.view.MainViewController'
    }

    onComponentConstructed() {
        super.onComponentConstructed();

        this.palette = Neo.create(CommandPalette, {
            owner          : this.component,
            enableShortcuts: true,
            commands       : [
                {id: 'save',  label: 'Save document', handler: () => this.saveDocument()},
                {id: 'theme', label: 'Switch theme',  handler: () => this.toggleTheme()}
            ]
        })
    }

    onOpenCommands() {
        this.palette.show()
    }
}

export default Neo.setupClass(MainViewController);
```

## Deltas from ticket
- Added scoped chord default prevention (`registerPreventDefaultChords` / `unregisterPreventDefaultChords`) and `KeyboardEvent.repeat` serialization (`getKeyboardEventData`) on `Neo.main.DomEvents` so opt-in `CommandPalette` shortcuts (`enableShortcuts: true`) cancel native browser defaults on `Ctrl+K`, `Meta+K`, and `F1` without overwriting `registerPreventDefaultKeys` reservations or closing prematurely on held key auto-repeat.
- Bound `CommandPalette` owner lifecycle exclusively through independent `observeConfig(owner, 'isDestroying' | 'mounted' | 'theme' | 'windowId')` subscriptions (zero method wrapping on `owner`), keeping owner-derived `windowId` coherent across `owner` reassignment and `show()`/`open()`/`toggle()`, catching sync/async command failures (`commandError` + non-focus-stealing `role="alert"` notice + current-opening focus return under `#openGeneration`), and reusing `Neo.collection.SearchFilter` for multi-token cross-field and `keywords` filtering.
- Preserved empirical Engine primitive findings from the prototype phase: (1) `list.Base#useHeaders` mutates `<ul>/<li>` to `<dl>/<dt>/<dd>` and conflicts with `available: 'DESC'` sorting, so `record.group` renders inline inside `<li role="option">`; (2) `list.Base#disabledField` applies `.neo-disabled` (`pointer-events: none`) and excludes items from `Navigator`, so unavailable commands use `aria-disabled="true"` + `.neo-is-unavailable` to remain discoverable with polite refusal explanations; (3) `Navigator#setActiveItem` updates `.neo-navigator-active-item` and `aria-activedescendant` on Main without mutating item `aria-selected`, so `CommandPaletteList#syncActiveSelection` keeps `aria-selected`, `focusIndex`, and `activeIndex` aligned across initial open, navigation, and filtering; (4) `dialog.Base#initVnode` sets `left/top: 'initial'` when `wrapperStyle` lacks explicit coordinates, which `CommandPalette`'s default upper-third `wrapperStyle` satisfies on both `.neo-body-viewport` and plain-`<body>` apps; and (5) `form.field.Text` sets `keys: null` inside the palette so `Escape` reaches `Dialog#onKeyDownEscape`.
