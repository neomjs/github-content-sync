### Minimal installed-workspace usage (`AC-1`)

```javascript
import CommandPalette from '../../../node_modules/neo.mjs/src/dialog/CommandPalette.mjs';
import Controller     from '../../../node_modules/neo.mjs/src/controller/Component.mjs';

class MainViewController extends Controller {
    static config = {
        className: 'MyApp.view.MainViewController'
    }

    onComponentConstructed() {
        super.onComponentConstructed();

        this.palette = Neo.create(CommandPalette, {
            owner          : this.component,
            enableShortcuts: true,
            commands       : [
                {id: 'save',  label: 'Save document', handler: () => this.saveDocument()},
                {id: 'theme', label: 'Switch theme',  handler: () => this.toggleTheme()}
            ]
        })
    }

    onOpenCommands() {
        this.palette.show()
    }
}

export default Neo.setupClass(MainViewController);
```

## Deltas from ticket
- Added scoped chord default prevention (`registerPreventDefaultChords` / `unregisterPreventDefaultChords`) on `Neo.main.DomEvents` so opt-in `CommandPalette` shortcuts (`enableShortcuts: true`) cancel native browser defaults on `Ctrl+K`, `Meta+K`, and `F1` regardless of which element holds focus without overwriting or deleting existing `registerPreventDefaultKeys` reservations (such as `'F8'` on `document.body`).
- Bound `CommandPalette` teardown and focus restoration to the active `owner` and `#openGeneration`: unmounting `owner` hides an open modal, destroying/removing `owner` destroys the palette without leaving orphan DOM or owner references, `hide()` clears `returnFocusId` while direct `show()` captures the active focus origin per opening, and async command handlers that settle after a reopen never pull focus out of the new dialog.
- Preserved empirical Engine primitive findings from the prototype phase: (1) `list.Base#useHeaders` mutates `<ul>/<li>` to `<dl>/<dt>/<dd>` and conflicts with `available: 'DESC'` sorting, so `record.group` renders inline inside `<li role="option">`; (2) `list.Base#disabledField` applies `.neo-disabled` (`pointer-events: none`) and excludes items from `Navigator`, so unavailable commands use `aria-disabled="true"` + `.neo-is-unavailable` to remain discoverable with polite refusal explanations; (3) `dialog.Base#initVnode` sets `left/top: 'initial'` when `wrapperStyle` lacks explicit coordinates, which `CommandPalette`'s default upper-third `wrapperStyle` satisfies on both `.neo-body-viewport` and plain-`<body>` apps; and (4) `form.field.Text` sets `keys: null` inside the palette so `Escape` reaches `Dialog#onKeyDownEscape`.
