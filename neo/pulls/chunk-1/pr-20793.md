Resolves #20783

`Neo.list.Buffered` destroyed pooled row components without unlinking them from its own stored vnode. An ancestor flight that lands before the list's own repaint follows its reference to the list into that vnode, and `VNode.getVnode()` throws on the destroyed row. `unlinkRetiredReferences()` keeps live references unfollowed by design, so nothing caught it. That throw is the `Component not found for id: neo-buffered-list-1__6__component` behind the Institution's red `Isolated Institution`.

`retirePooledComponents()` now records each row's last vnode, destroys the row, and unlinks them all in one walk. This is the pattern `Neo.grid.Body` uses for the rows it retires. `trimComponentPool()` and both `getPooledComponent()` destroy paths go through it.

Evidence: L3 (the Institution's `FleetActivityObserver.spec.mjs`, run locally against the engine npm-installed at this branch, the install path its CI uses) → L3 required (AC-2). AC-3 waits for the merge.
