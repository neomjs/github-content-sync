Resolves #20660

A `type: 'Date'` field now keeps `null`. `RecordFactory.parseRecordValue` converts only values that are not `null` or `undefined`, so loading `{due: null}` or clearing a date with `record.set({due: null})` stores `null` instead of 1970-01-01. `Store#getFilterValues` accepts a raw `null` in a `Date` field as canonical, so a Turbo store with empty dates counts them instead of refusing. The grid and table cell-editing examples render an empty date as empty text.

Evidence: L3 (unit rows plus headless e2e rows on both examples, each red on `a4e508d25e` and green at head) → L3 required (AC-4 is a rendered cell).
