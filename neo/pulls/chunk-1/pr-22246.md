Resolves #22238

Adds a keyboard-accessible **Copy search link** action to the Portal Examples results. A shared URL restores the group, saved query, and selected build in a fresh tab, on reload, and on Back in either routing mode. Clipboard confirmation comes from the originating window, and a denied write exposes the full URL in a read-only field.

Evidence: L3 (real local Portal in headless Chromium, with controlled clipboard responses and desktop/phone frames) → L3 required (#22238 browser and layout acceptance).

Prescription checked: `apps/portal/view/examples/MainContainerController.mjs` owns Find state and link serialization. The results header owns the action and feedback. Main owns history-entry identity and clipboard writes.

## Deltas from ticket

Hash navigation can retain the outer query on an ordinary group link. Main remembers the search association on the browser's history entry, so Back can restore the saved entry even when an ordinary entry has the same URL. The `find` and `catalogMode` keys belong to Portal.

size-guard-growth: src/main/DomAccess.mjs — Keep the confirmed clipboard text write at the originating Main window’s DOM boundary. The Portal uses the Boolean result to choose confirmation or the selectable URL fallback.
