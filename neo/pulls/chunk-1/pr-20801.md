### Summary
Fixes incorrect field value resolution when `getCellValues()` reads raw Turbo Mode rows.

### Changes
- Make `Store#resolveField()` publicly accessible.
- Resolve named model fields through `Store#resolveField()` for raw rows when the model has complex fields.
- Preserve existing behavior for regular Records, dotted paths, and non-model fields.
- Add regression tests for calculated, mapped, and converted fields.
- Verify raw mode, export mode, CSV output, and that reading raw rows does not hydrate Records.
