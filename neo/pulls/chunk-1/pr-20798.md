Resolves #20796

Claude Code doesn't read `autoMode` from project settings, so this block in `.claude/settings.template.json` was never applied. This PR deletes it and nothing else (21 lines).

Where each `hard_deny` rule is still enforced:

| Rule in the removed block | Still covered by |
|---|---|
| No `gh pr merge` | `permissions.deny` `Bash(gh pr merge *)`, and critical gate 1 |
| No direct push or commit to `main`/`dev` | `permissions.deny` push rules for `origin dev`/`origin main` (pushes only), and critical gates 3 and 8 for commits and PR targets |
| No client names in public artifacts | Critical gate 9 only; there is no settings rule for it |
| No Workflows, no fan-out | `permissions.deny` `Workflow`, `permissions.ask` `Agent` and `Task`, and §swarm_topology_anchor |

The gates are the maintainer-audience sections in neo-agent-skills (`agents-md/sections/0401`, `0403`, `0408`, `0409`, `1400`).

Checks: the template is still valid JSON; `jq -S 'del(.autoMode)'` of `dev` equals the branch file; the template assertion in `redirectionGuardHook.spec.mjs` still holds.
