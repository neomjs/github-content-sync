Resolves #20788

The Engine now takes its `AGENTS.md` pointer and the pointer's git filter from `neo-agent-skills` 1.4.0. `generate-agents-md` gains `--pointer`, so the generator registers the required filter before it writes and lets the index re-read the file afterwards. `prepare.mjs` loses its own filter and index steps, and the Engine's copy of the mechanism goes. One file stays: `buildScripts/util/agentsMdPointer.mjs`, now a delegate to the package's pointer, because a worktree of an older commit registers it as the clean command for the whole clone. #20790 retires it.

Evidence: L3 (a real-git probe in scratch clones of this repository, outside CI: installs at the old and the new commit, a fresh worktree, and old and new worktrees sharing one clone's config) → L3 required (AC-1, AC-2, AC-5).

## Deltas from ticket
- **The old clean path stays, as a delegate.** The ticket first rejected a shim there, on the reasoning that the next install closes the window. Probe step D falsified that: the window reopens whenever a worktree of an older commit installs. The ticket body is corrected, and #20790 retires the delegate after the 13.5 cut.
- **The reverse direction stays open, as the ticket's Out of Scope says.** Probe step E: once this branch installs again, the older worktree fails the same way, because its `node_modules` lacks the package's script. An older commit cannot be changed; `npm install` in that worktree recovers it.
- **`package.json` keeps its aligned formatting.** `npm install --save-dev` rewrote the whole file; the commit changes only the two lines.
