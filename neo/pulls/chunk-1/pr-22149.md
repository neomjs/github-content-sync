Resolves #22148

`Portal.view.examples.List#imageBasePath` now returns `'/resources_pub/website/examples'` on GitHub Pages, byte-for-byte the getter neomjs.com runs today as a hand patch (`neomjs/pages` `d0b79b385`). Engine `14.0.0` and `dev` still computed the relative path that made the v14 deploy request its covers under `/dist/resources_pub/` and 404 (#21942). Without this, the next package rebuild (14.0.1 is planned this week) copies the relative path back over the patch. The raw-host branch is unchanged.

Evidence: L2 (unit spec red on `dev`, green at head; the getter is byte-identical to the deployed one) → L3 required (AC-3: covers on neomjs.com after the next package deploy). Residual: AC-3, Residual-Owner: #21942.

Micro-review eligible: contained — one getter returns the value the live site already runs, plus one unit test.

None substantive. `apps/portal/view/news/medium/List.mjs` has a sibling relative `imageBasePath`. It feeds an `<img src>` and an inline `background-image`, which resolve against the document rather than a CSS custom property, and #22148 observed nothing failing there, so it is unchanged.
