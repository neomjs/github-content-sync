<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="[QUARANTINED_URL: github.com]">postcss-selector-parser's releases</a>.</em></p>
<blockquote>
<h2>7.2.0</h2>
<ul>
<li>feat: add the opt-in <code>maxInputLength</code> option, which rejects a selector longer than the limit before parsing it</li>
<li>feat: support the case-sensitive attribute flag <code>s</code> per Selectors Level 4, on <code>Attribute#sensitive</code> and <code>Attribute#sensitiveFlag</code>. <code>[a=b s]</code> previously left <code>insensitive: false</code> and filed the flag in <code>raws.insensitiveFlag</code> (<a href="[QUARANTINED_URL: redirect.github.com]">#327</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​abhu85</code></a>)</li>
<li>docs: add a threat model to <code>SECURITY.md</code>: resource consumption caused by unbounded untrusted input is now handled as a regular bug</li>
<li>docs: document the raw-value helpers (<code>stringifyProperty</code>, <code>valueToString</code>, <code>setPropertyAndEscape</code>, <code>appendToPropertyAndEscape</code>, <code>setPropertyWithoutEscape</code>), the seventeen type guards, and the <code>clone()</code> overrides argument (<a href="[QUARANTINED_URL: redirect.github.com]">#231</a>)</li>
<li>fix: forward the default options given to the parser factory, so <code>parser(fn, { maxInputLength })</code> and the other options take effect there as documented (<a href="[QUARANTINED_URL: redirect.github.com]">#345</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​Aurantium-47</code></a>)</li>
<li>fix: preserve the spaces declared on selector and root containers, through <code>rawSpaceBefore</code> and <code>rawSpaceAfter</code> (<a href="[QUARANTINED_URL: redirect.github.com]">#356</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​Aschenbath</code></a>)</li>
<li>fix: preserve selector delimiters after an escaped backslash, so <code>.a\\.b</code> parses as two classes (<a href="[QUARANTINED_URL: redirect.github.com]">#354</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​wozhenbang2004</code></a>)</li>
<li>fix: escape class values supplied to the constructor, matching what the <code>value</code> setter already did (<a href="[QUARANTINED_URL: redirect.github.com]">#349</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​SAY-5</code></a>)</li>
<li>fix: escape values assigned to an id through the <code>value</code> setter, and replace a stale <code>raws.value</code> on assignment (<a href="[QUARANTINED_URL: redirect.github.com]">#326</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​mahirhir</code></a>)</li>
<li>fix: keep <code>$</code> in an attribute name inside a preprocessor interpolation, so <code>[#{$attr}]</code> in SCSS and <code>[@{attr}]</code> in Less round-trip (<a href="[QUARANTINED_URL: redirect.github.com]">#336</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​theRizwan</code></a>)</li>
<li>fix: reject an attribute selector with no valid attribute name, instead of throwing a raw <code>TypeError</code> or emitting the literal text <code>undefined</code> (<a href="[QUARANTINED_URL: redirect.github.com]">#335</a> by <a href="[QUARANTINED_URL: github.com]"><code>@​theRizwan</code></a>)</li>
<li>fix: keep the processor's entry points usable when destructured, as in <code>const { process } = parser()</code> (<a href="[QUARANTINED_URL: redirect.github.com]">#145</a>)</li>
</ul>
<h3>Behaviour notes</h3>
<ul>
<li><code>className</code> and <code>id</code> values are escaped when passed to a constructor or assigned through <code>value</code>, so an already-escaped value is now escaped twice. <code>setPropertyWithoutEscape()</code> is the escape hatch.</li>
<li><code>[a=b s]</code> sets <code>sensitive: true</code> rather than filing the flag in <code>raws.insensitiveFlag</code>. Serialization is byte-identical for <code>i</code>, <code>I</code>, <code>s</code>, <code>S</code> and non-standard flags.</li>
<li><code>Selector</code> and <code>Root</code> emit their own <code>rawSpaceBefore</code> and <code>rawSpaceAfter</code>, which changes serialization for ASTs that set them.</li>
<li>An attribute selector with no attribute name raises the parser's own error rather than throwing a raw <code>TypeError</code> or serializing the text <code>undefined</code>: <code>[ns|*]</code> and <code>[ * ]</code> are affected. A trailing <code>*</code>, <code>$</code>, <code>^</code>, <code>~</code> or <code>|</code> after a valid name is dropped, as <code>[href=]</code> already was.</li>
</ul>
<h2>7.1.8</h2>
<ul>
<li>fix: parse selectors in linear time on four more kinds of crafted input, closing a CPU exhaustion vulnerability (reported by <a href="[QUARANTINED_URL: github.com]"><code>@​zachariah-mithani</code></a>)</li>
<li>chore: replace the <code>cssesc</code> dependency with an internal copy, whose redundant space removal is linear</li>
</ul>
</blockquote>
