### Summary
- Added a shared UUID utility using `crypto.getRandomValues()` to support UUID generation in insecure HTTP contexts.
- Replaced browser-side `crypto.randomUUID()` calls with the shared utility.
- Updated `CanvasGroups.mint()` to reuse the utility while preserving its existing ID format.
- Added unit tests for UUID uniqueness and version/variant format.
- Added a Playwright component regression test to verify that an app boots successfully on a plain HTTP origin outside localhost.
