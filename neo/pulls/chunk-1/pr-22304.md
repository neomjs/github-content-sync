Resolves #22298

Derives a `themes` (`class → folders`) table in `resources/theme-map.json` from the `.neo-theme-*` selectors declared in each non-`src`, non-`theme-base` folder's `Global.css`, updates `Neo.worker.App` and `Neo.main.addon.Stylesheet` to load `src`, `theme-base`, and mapped theme folders once per sheet without string-stripping class names, and updates `setCssVariable` to resolve target sheets through the map, walk `@layer` blocks (isolating overrides on shared multi-scheme rules), and skip null-`href` `<style>` elements.

Related: #22295, #22296

Decision Record impact: depends-on neomjs/neo#adr:0044-design-system (pre-merge order condition on #22296 / PR #22301 via `blocked_by` edge — satisfied on `dev` at `59b558101f`).

Evidence: L3 (headless Chromium network-request parity across hosted apps/examples + live browser/App-Worker CSSOM & `getComputedStyle` verification) → L3 required (AC-1..AC-4).

agent-preflight: not hosted here; baseline lint-staged guards, unit, component, and e2e checks ran.
