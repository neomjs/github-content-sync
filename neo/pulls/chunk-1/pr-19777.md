Resolves #19772

A grid's locked bodies and locked header toolbars now carry the configs of their center counterparts, for 13.3 (milestone v13.3). With #19774 on `dev`, that includes animated row sorting: a sort moves each record's locked and center rows together.

Since the multi-body layout (#9487, 2026-03-31), `grid.Container#createOrUpdateSubGrids` and `grid.header.Wrapper#updateHeaders` built the locked instances from `...instance.initialConfig`, a property nothing assigns. So every locked column lost the grid's `body` and `headerToolbar` configs: no header filters, no sorting options, no row animation, no modified-cell highlighting.

- `Neo.cloneNeoInstance(instance, config)` takes an optional override object now. The engine's clone from `originalConfig`, without `_id` and `id`, is the record these sites meant to read. Its contract, including the construction-only boundary, is the [Contract Ledger on #19772](https://github.com/neomjs/neo/issues/19772); the JSDoc states that boundary.
- Both sites clone the center instance, with `reference: null` and the region's own `parent`, `store`, `theme` and items. A locked body also keeps the center body's class (a custom body subclass, where the old code always built a plain `GridBody`). `Wrapper.mjs` no longer imports `Toolbar`.
- Net source: +40/−53 lines.

Related: #9487 (introduced the spread) · #6858 / #19774 (where it surfaced; merged) · #9486 (Grid Multi-Body) · #6951 (`Neo.cloneMap`)

Evidence: L2 (unit arms on real grids, mounted vdom, real config resolution) for AC-1 to AC-4, plus a local L3 probe of AC-4's frames → L2 required: AC-4 states every record's offset at both steps of a move, and the arm reads it from all three bodies.

agent-preflight: not hosted here; the Shared PR Baseline jobs run in CI.

## Deltas from ticket

- **The mechanism.** The ticket proposed spreading `originalConfig`. `Neo.cloneNeoInstance` already does exactly that (minus the ids), so it gained the override argument and both sites call it. Its one existing caller, `Neo.clone`, passes no override and is unchanged; the clone test now goes through it too.
- **More now carries over:** any `listeners`, `cls` or `style` in the grid's `body` or `headerToolbar` config reaches the locked instances too, as the other configs do. `reference` does not.
- **`Neo.clone`'s `ignoreNeoInstances` (pre-existing, #6951):** `Neo.clone` hands `cloneMap.NeoInstance` its `deep` flag in that slot, so `Neo.clone(instance, true)` returns the same instance and `Neo.clone(instance, false, true)` a new one. `originalConfig` (`true, true`) shares nested instances either way, so this fix is unaffected. Recorded in the ledger and left out of scope: with the default `ignoreNeoInstances=false`, a fix would make every deep `Neo.clone` copy the instances nested in it.
- **AC-4 needed #19774.** `7e01312043` merges `dev` once #19774 was on it; the arm follows.
- **The pre-commit formatter** aligned the new spec; the commits hold its output.
