Resolves #22310

Locks `globalThis.Neo.config` to a single canonical object reference across the Playwright unit worker lifetime in `test/playwright/setup.mjs` (throwing a `TypeError` at the offending callsite if a spec attempts `Neo.config = {...}` instead of mutating in place, while keeping `Neo.config = Neo.config` in `src/DefaultConfig.mjs` a valid no-op), updates `test/playwright/unit/worker/ConfigBase.spec.mjs` to mutate `Neo.config` in place, and moves `fullyParallel: false` into `buildUnitRunPolicy({isCI})` so `playwright.config.unit.mjs` and `playwright.config.unit-tz.mjs` parallelize across `.spec.mjs` files (`workers: 4` in CI) without splitting individual spec files across `setup()` and `beforeAll`/`afterAll` lifecycles.
