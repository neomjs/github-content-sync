Resolves #22136

Collapsing a column in the planning dashboard's Task Board now gives its width to the open columns. The example had turned the board into a fixed three-track grid (two tracks at phone width), so a collapsed column shrank inside a `1fr` track that kept its share. It is the board's own flex row again: open columns share it, and a collapsed column keeps its narrow width. At phone width the row wraps two open columns per line.

## Deltas from ticket

- The board pins every column at an inline `flex: none` (`Neo.board.Container#createColumnConfig`: "Columns keep their own width and the board scrolls"). A stylesheet can only override it with `!important`; the same file already does so for `.planning-hint`. Open columns override it, and collapsed ones keep it. That is why `flex: 1 1 0` alone moved `Active` left without widening it (measured: `Active` + `Done` 530.7 px where the freed width requires 747.5 px).
- At phone width the hbox's own `.neo-flex-wrap-nowrap` is as specific as the example's block and won, so the wrap sits one class higher (`&.neo-flex-container`).
- On the phone, a column alone on its line now spans the row (`Done` below `Ready` + `Active`) instead of sitting in a half-width track. It follows from the flex row, and the frames show it.
