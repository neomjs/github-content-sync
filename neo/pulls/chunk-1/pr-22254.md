Resolves #22235

Adds `Neo.component.EmptyState` (`ntype: 'empty-state'`) with theme tokens across all four Neo themes and integrates it into File Explorer (`Neo.examples.fileExplorer.DetailPane`) and Portal Examples search (`Portal.view.examples.SearchResults`), removing bespoke empty-state markup and styles while preserving each view's message and recovery ownership.

Evidence: L3 (local Playwright unit, component, and Whitebox E2E suites plus live Chromium 1440×900, 390×844, and 360×800 visual verification; hosted CI runs on PR head) → L3 required (AC-1, AC-2, AC-3, AC-4).
