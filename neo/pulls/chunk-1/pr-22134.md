Resolves #22124

RoundTable now cancels its owned callback before pause, motion-mode changes and graph retirement. A direct repaint retires an outstanding callback before replacing it, and refresh treats handle zero as pending. Moving frames continue to advance the replay; still scenes retain immediate input-triggered repainting. The existing motion test now lets the renderer stop itself instead of manually cancelling its timer first.

Evidence: L3 (real Canvas SharedWorker before/after frame counts and callback ownership, plus the existing hero E2E suite) → L3 required. Both browser checks were run by the contributor in a normal terminal using installed Brave.
