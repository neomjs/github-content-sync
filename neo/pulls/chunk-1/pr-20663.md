Resolves #20661

The Workstation's cold boot and its Reset to default now use the declared `perspectives.shipped`, not the module's `initialDocument`. With no saved main document, `construct` falls back to `me.perspectives.shipped`. `resetTopology` reads the captured baseline once, with `me.perspectiveSelection.document('shipped')`, and uses it both for main's next document and for the set of panes it takes back from other workspaces. A subclass that declares its own shipped arrangement therefore boots to it, reads unmodified, and gets it back from Reset to default and from Start tour. For Engine's own Workstation nothing changes: `Authoring.fromDocument` admits a declared document "byte-for-byte", so the captured baseline equals `initialDocument`.

Evidence: L2 (unit rows red on `a4e508d25e`, green at head) → L2 required (AC-1 to AC-4 are unit-level).
