Resolves #20795
Related: neomjs/neo-agent-skills#354, neomjs/neo-agent-brain#1615

Helper calls now have a narrow runtime guard: `Agent` or `Task` with exact type `Explore` and an explicit `haiku` or `sonnet` model returns no permission decision; other helper calls ask. The guard never grants `allow` and does not count active helpers. Invalid input or a guard error exits 2, and the handler blocks launch failures/timeouts. The template registers it and removes the two blanket ask entries.

Change class: capability (`feat`). Prescription checked: `.claude/hooks/bodyFileGuardHook.mjs` and the sibling `unit/hooks` specs own this stdin/decision/CLI pattern. Intake follows the aligned contract on #20795 (body `71e9abd3`, Nov 11 23:13:14Z).
