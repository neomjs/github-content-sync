Resolves #20766

`afterSetColumnsBuffer` now reads `columnsVisible` instead of the non-existent `visibleColumns`, so `totalColumns` stays `2 * columnsBuffer + columnsVisible` instead of `NaN`. Both `afterSetColumnsBuffer` and `afterSetColumnsVisible` call a new `rebuildColumns()` on runtime changes (`oldValue !== undefined`), which empties the column and header containers, resets `headerCreated` and runs `updateHeader(true, true)` + `updateEvents()`. That covers the ticket's avoided trap: with only the typo fixed, a smaller buffer keeps stale trailing columns and a larger one makes `updateHeader(false)` write into missing columns.

Evidence: L2 (unit spec drives the constructed, mounted week view through config changes) → L2 required (AC-1..AC-3 are covered by the unit spec). Residual: none.
