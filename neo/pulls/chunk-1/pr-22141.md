Resolves #22119

Recognizes version-only release stamps in `package-lock.json` (`lock.version` + `packages[''].version`) and `src/DefaultConfig.mjs` (`config.version` + matching `@default` tag) during ref-to-ref comparison in `classify-test-scope.yml` so release PRs run only reachable E2E shards instead of expanding to all 18 shards, while logging per-file E2E boundary decisions in the CI log on every run.

Evidence: L2 (Playwright unit suite executing the workflow's scope script, `e2eCiSelection.mjs`, and `e2e-engine-gate` bash harness, plus live hosted workflow execution on this PR) → L2 required (AC-1, AC-2, AC-3).
