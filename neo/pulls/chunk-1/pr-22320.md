Resolves #22319

🌿 *Narrowing the window can no longer hide an open editor.*

The Grid contact editor (`examples/grid/nestedRecordFields`) now opts into `Neo.dialog.Base#keepInBoundary` (#21271). When the window narrows while it is open, the dialog moves back inside by the smallest distance. Before, it stayed at its centred desktop position with no part visible. The draft, the focused field, Escape's focus return and Save are unchanged. The new e2e case waits for the open animation to end before it narrows the window. An earlier resize lets the animation centre the dialog in the narrow window and hides the defect: the first version of this case passed on `dev` for exactly that reason.

Evidence: L3 (Chromium e2e red on `dev` and green on the head; a geometry probe through both a viewport resize and a real window resize) → L3 required (AC-1 to AC-3).
