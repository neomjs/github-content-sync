Resolves #22262

Projects boolean `disabled` state in `Neo.form.field.Text#afterSetDisabled` onto the owning native `<input>` / `<textarea>` (`flag: 'neo-real-input'`) via `changeInputElKey('disabled', isDisabled ? true : null, true)` in a single batched VDOM update while clearing transient `neo-focus` / `neo-hovered` classes and empty inline label cut-out width on runtime disable, keeping both existing stylesheets and all trigger classes unchanged and preserving programmatic `field.value`, `FormContainer#setValues`, `StateProvider` bindings, `clear()`, and `reset()`.

Evidence: L3 (unit, component, and Neural Link Whitebox E2E across `/examples/form/field/text/index.html#disabled=true` and `/examples/stateProvider/advanced` multi-window companion flows) → L3 required (AC-1, AC-2, AC-3, AC-4).
