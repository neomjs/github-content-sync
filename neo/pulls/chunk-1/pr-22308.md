Resolves #22300

Adds `npm run theme-equality` (`buildScripts/util/theme-equality.mjs` + `buildScripts/util/themeEqualityMatrix.mjs`) and a deterministic headless Chromium `Neo.app` component stage (`test/playwright/component/apps/theme-equality/`) that validates checkout/worktree roots (`dist/<env>/css` + `resources/theme-map.json`) and portable CSS directories up front, mounts `79` representative component and variant probes across the engine's `29` CSS packages, drives `default`, `hover`, `active`, `focus`, `selected`, `pressed`, `disabled`, `invalid`, and `readonly` states on each state's owning target(s) (with W3C-matching cell-ancestor `:hover`/`:active`/`:focus-within` propagation) in both `inherited` (`body`/viewport) and `scoped` (`component.Base#afterSetTheme` on each component's own root element) passes, compares `24` resolved `getComputedStyle` painted properties across element and `::before`/`::after` pseudo-element parts (`192,000` comparisons per run) across all five shipped themes, and exits non-zero on any undeclared difference or any unmet expected rule.

## The stage's own rule wins once the engine is layered: 950 false `width` differences against #22297

I ran this runner at `08d4218d0a` against #22325 (the cascade-layer leaf, #22297), dev's built tree as `--base` and the branch's as `--head`, from a local merge of both. It reports 1,005 differences in 192,000 comparisons, and 950 of them are one artifact of the stage, not of the change.

**Cause.** `index.html` gives `.neo-eq-cell` an unlayered `display: flex; align-items: flex-start`. Each cell is also a Neo vbox, so on dev the engine's `.neo-flex-container.neo-flex-align-stretch` (0,2,0) beats it and the component stretches to the cell. Once the engine is layered, the unlayered stage rule beats every layer, and each component shrinks to its content: `toast` 432px → 77px, `theme-switcher` 424px → 100px, every button, chip, switch and badge. CDP's matched rules on the theme switcher's cell show the order flip:

```
dev:    display=flex flex-direction=column align-items=stretch   (the .neo-eq-cell rule loses)
branch: display=flex flex-direction=column align-items=flex-start (unlayered .neo-eq-cell beats [neo.rules])
```

**Suggested repair, measured locally:** drop those two declarations from `.neo-eq-cell`. They already lose on dev, so dev against dev stays 0 differences in 192,000. Dev against the layered branch drops to 55, all of which #22325 can declare: the classic themes' size, pressed and start-button re-values now win on a scope-root instance, as ADR 0044 decision 4 says, plus one method artifact of serving one checkout's JS for both trees.

```diff
         .neo-eq-cell {
-            align-items: flex-start;
             contain    : layout style;
-            display    : flex;
             min-height : 48px;
```

It is your stage and your call: a commit here before merge, or a follow-up. Without it, AC-5 (b) of #22297 cannot read green against this runner.
