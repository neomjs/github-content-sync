### Summary
Fixes `TypeError: Cannot read properties of null (reading 'setDate')` in `src/calendar/view/week/Component.mjs` when `currentDate` is `null` during initial component construction.

### Key Changes
1. **Engine Guard:** Added an early return check in `updateHeader()` to defer header construction when `currentDate` is `null`.
2. **Dynamic Header Creation:** Managed `me.headerCreated` dynamically so VDOM nodes are properly instantiated when `currentDate` arrives post-construction via `afterSetCurrentDate`.
3. **Unit Test (AC-2):** Added a Playwright test in `test/playwright/unit/calendar/WeekView.test.mjs` to ensure the calendar weekview page loads cleanly without uncaught page/worker exceptions.

Resolves #19930
