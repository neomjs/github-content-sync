Resolves #22314

A fresh Legit IDE session now displays its seeded files. The file service compares the old and new commit trees by blob ID using the Git reader that backs the Legit SDK. It prunes identical subtrees, keeps ordinary dotfiles and excludes the SDK’s empty-directory marker. The history Store reads its timestamp from `committer.timestamp`.

Evidence: L3 (fresh Chromium, actual shared worker, live SDK, real tree-row clicks and Monaco Save) → L3 required (file selection, immutable snapshots, and saved history).

## Deltas from ticket

The SDK’s snapshot directory listing works, while per-file `stat` and `readFile` on that same commit fail under both available initializers. The service now walks Git entries directly and removes its file-content hashing traversal. This adds an on-demand browser import of `@legit-sdk/isomorphic-git@1.34.2`, the fork used by SDK 0.6.1. The CDN currently transfers about 44 kB gzip for that module before dependencies. Engine package dependencies and its lockfile are unchanged.
