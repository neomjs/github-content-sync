### Summary

Adds 13 unit tests for `Neo.form.field.Currency`, covering its existing parsing, rendering, and default configuration behavior.

The tests cover:
- **`inputValueAdjustor()`** — numeric parsing, rounding, negative values, scientific notation, and edge cases including `NaN`.
- **`inputValueRenderer()`** — null handling and two-decimal formatting.
- **Default configuration** — `maxValue` and `stepSize`.

The tests follow the existing Playwright unit test setup and include a temporary `DomEvents` stub with proper cleanup.

No production code was changed.
