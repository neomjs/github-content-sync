Resolves #22123

The header strand loop now reuses one stream-offset output across samples and frames. `getStreamOffset()` accepts optional caller-owned output storage; omitting it still returns an independent object that callers can retain. All three geometry calculations are unchanged. The renderer documentation distinguishes reused sample storage from per-frame metadata.

Evidence: L3 (before/after allocation sampling and separate GC traces in the real Canvas SharedWorker, fixed-input geometry comparison, native hover/navigation and live reduced-motion E2E) → L3 required.
