## Deltas from ticket

- **Four commits, in the order JSDoc, variables, moves.** The fourth joins three declaration pairs in `Cascade` that `check-order.mjs` found after the move.
- **`@reactive` on six blocks the ticket did not name.** `barMarginPct`, `minBarWidthPx` and `showNonWorkingTime` override configs that are reactive in `Neo.scheduler.Container`; both models' `fields` override `fields_` of `Neo.data.Model`; `TaskStore.rollupParents_` had its tag at the end of a description line, where it is lost. `npm run check-reactive-tags` now reports nothing in `src/gantt`.
- **Config hooks document types and no description**, as the §4 example of the guidelines does, although rule (30) asks for one on every `@param`. That covers 53 parameter lines of `afterSet*` and `beforeSet*` hooks and the root `data` of three events. Every other parameter has a description, read from the method body or from the parent's block.
- **Every class field has a `@member` block**, not only `CascadeMotion`'s. `#private` members carry `@private`, config hooks `@protected`, and four overrides take the `@protected` of their parent: `getBarDragContext`, `getDefaultEditorConfig`, `onBarKeyDown`, `TaskStore#writeRows`.
- **The hoist rule.** A declaration moved to the head of its function when no statement in between writes what its initializer reads, the initializer cannot throw where the original did not run, and the function's main path uses the value. Five members: `DependencyStore.getFinishToStartRefusal` (five names), `DependencyStore##ensureEndpointIndex` (`recordEpochs`), `TaskStore#writeRows` (`changed`), `Container##setKeyboardLinkSource` (`row`, `title`), `Container#rescheduleWorkingTime` (`cycles`, `meta`).
- **Declarations left in place**, listed per member in [the instruments comment](https://github.com/neomjs/neo/issues/22309#issuecomment-7210012855). The reasons: a guard above protects the initializer or returns on the common path; a call above may change what it reads; one branch or loop needs it; or it stands in one of the four large methods (`moveTask`, `runDependencyCascade`, `planWorkingTimeSchedule`, `DependencyLayer#project`), where only the keyword changed and neighbours joined, because `#22306` restructures them.
- **The four defaults.** `keyProperty: 'id'` in both stores (`src/collection/Base.mjs:94`), `parentId: 'document.body'` of the link preview (`src/component/Abstract.mjs:109`), and in the layer's `_vdom` the `div` tag (rule (24)) with the `cls` that `baseCls` sets: the layer's root carries its class once, on the branch and on `dev`.
- **Ten examples, not eight**, and 13 unit spec files import `src/gantt`.
- **One comma moves** in the move commit: in `EventDragZone` the last two config keys swap.
- **The script on the ticket failed with `.` as repository path.** The corrected version, the new `--declarations` mode and five further instruments are in the comment linked above.
- **Left to `#22306`:** class-level descriptions (rule (18)), import order (rule (9)), model field order (rule (37)), `me = this` (rule (34)), one-line method bodies and the module-scope aliases.
