Resolves #19380

🌿 The shell's window policy keeps deciding what the cockpit shows, and now also says where an operator's own click on a pull request lands: in their browser, never in the shell.

ADR 0034 §2.3 item 2 gains one in-place paragraph, in the shape #19237 set for the staging realm: a denied window-open whose URL is `https:` on an allowlisted host (`github.com`; an addition amends the paragraph) and carries no credentials is handed to the system browser with `shell.openExternal`; the in-app window stays denied, `will-navigate` is unchanged, a refused URL still opens nothing. The §5 E3 row names the hand-off beside the allowlist. Nothing else moves. The consumer is neomjs/neo-agent-institution#493, which this amendment unblocks (its order: ADR first).
