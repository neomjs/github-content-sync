Resolves #19413

The claim responder no longer counts a pull request inside a contributor's fork as a hold. `holders` now counts an open closing reference only when its base repository is this one, and the workflow passes each pull request's `repository { nameWithOwner }`. A pull request from a fork into this repository still counts, because its base is this repository.

Evidence: L2 (unit arms on `decideReply`, red on `dev`'s module) plus a live, read-only run of the workflow's new query → L2 required (the rule is a pure function; the workflow only fetches and posts). Residual: none.

agent-preflight: not hosted here; baseline pr-body and the engine CI ran.
