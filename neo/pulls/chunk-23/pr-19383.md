Resolves #19382

ADR-0034 §2.3 item 10 gains the setup card's exit from a run that cannot settle. `setupEvaluate({target, fresh})`: `fresh: true` starts a new run for the target, the shell's form of a CLI run that names no run id. The broker binds a new record and answers `{ok: true, evaluation, retiredRunId}`; the run it held stays on disk as history, and it is the one request a broker still answers when the record it holds cannot be read. The Custody paragraph says the same from its side. It is the authority for neomjs/neo-agent-institution#475, whose PR opens after this one is merged (ADR 0005 §6.5).
