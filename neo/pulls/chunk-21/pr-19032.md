### What this does

Takes the **`data/` directory slice** of #19026. Every `test.describe.serial` in the seven unit-tier data specs becomes `test.describe`.

The unit tier runs `fullyParallel: true` (`test/playwright/playwright.config.unit.mjs`), so `.serial` was the *only* thing forcing these blocks to run in order. Each of the seven specs builds its own fixture per arm — a fresh `Neo.create` inside the test, or a `beforeEach` that rebuilds the subject. No arm depends on state another arm produced: no shared instance built outside the arms, no mutated singleton carried across them, no ordering assumption in the assertions. So `.serial` bought nothing but a truncated report.

Per the ticket's own criterion, this is the *measurement, not the assertion that it was safe*: I injected a deliberately-failing **first** arm into each file and ran it both ways under the sanctioned config.
