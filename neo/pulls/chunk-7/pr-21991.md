Resolves #21959

## Outcome
`show()` mounts a dialog through `initVnode()`, and the lifecycle rename in #7147 (`render` → `initVnode`) left `Neo.dialog.Base`'s override of the offscreen revert on the dead old name. A dialog shown without an `animateTargetId` — `openEventEditor(id)` for a record whose bar is not rendered, `openForRecord(record)`, or any programmatic plain `show()` on a body-rooted dialog — stayed parked at `left/top: -10000px` from `.neo-floating` under its modal mask, with focus trapped in an invisible form.

The override rides `initVnode()` again: same guard (`!me.animateTargetId`), same revert (`wrapperStyle.left/top = 'initial'`), now chained to `super.initVnode(mount)`. The animated path is untouched: `animateShow()` awaits `initVnode(true)` with a target set, so the guard skips the revert there, exactly as before the regression. No public API or config changes.

Evidence: L3 (headless-Chromium live probe of the on-screen rect, red on `dev` and on screen with the fix, plus full unit and e2e tiers) -> L2 required (AC-1/AC-2 ask for red-on-`dev` unit tests; delivered, and exceeded with a live probe).
