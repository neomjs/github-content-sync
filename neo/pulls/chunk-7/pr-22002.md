Resolves #21974

🌿 A payload can no longer call up to date what it never carried.

A container's update now clears `needsVdomUpdate` only on the descendants its payload carries: all of them at depth -1, none at depth 1, one level less per level down, plus the merged children it expands at their own depth. Before, a shallow update of an ancestor cleared the flag of a descendant that still owed an update. That update never ran, and every `promiseUpdate()` merged into it (`VDomUpdate.mergedCallbackMap`) stayed pending: the idle host at `reconcileShellStaged` that holds the Workstation's cold-boot Reset (Sophie's CI receipt, run 45056190253).

Evidence: L3 (the real update path in a unit spec, red without the change; the Workstation component spec in a real browser) → L3 required (AC-2). Residual: none.
