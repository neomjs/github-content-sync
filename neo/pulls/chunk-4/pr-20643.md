Resolves #20642

A Playwright run and the dev server now refuse an install that differs from `package-lock.json`, and name each drifted package and the fix. `buildScripts/util/check-installed-dependencies.mjs` compares the lockfile with npm's own install record, `node_modules/.package-lock.json`, by `version` and `resolved`. The eight Playwright configs call `assertInstallMatchesLock()` at load, so `npx playwright test -c …` stops before a worker starts. `npm run server-start` runs the CLI first (`preserver-start`). Linked packages, and absent optional, `devOptional` or peer packages, are not drift. `findInstallDrift` is exported for Fleet's seat Start, which Grace will key on it after the 13.4 cut.

Evidence: L3 (local: a real off-lock install made by npm, refused by a Playwright run and by the dev server; green across all eight configs on the matching install) → L3 required (the ticket's four ACs). Residual: none.

## Deltas from ticket
None substantive. The module checks the repository it lives in by default, because Playwright never changes directory and `process.cwd()` is wherever the command was typed. `playwright.config.unit-tz.mjs` checks twice, since it also imports the unit config; that costs milliseconds, which is less than a special case. No install hook, per Grace's ruling on #1480's surface.
