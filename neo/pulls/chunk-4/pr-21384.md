Resolves #21189

Adds `examples/grid/serverSide`: a custom connection simulates a server over 100,000 seeded orders and returns one page to the grid’s Store. Paging, sortable headers and the country filter send remote query parameters through the real Pipeline. The request line shows those parameters, returned/total counts and elapsed time, while the native loading mask identifies pending requests.

Includes responsive light/dark layouts, a catalog record and a cover recipe. No engine changes or real backend are added.

Evidence: L3 (live worker inspection, browser gestures, first/pending frames and the official cover producer) → L3 required. Independent design approval and cover publication to Pages remain pre-merge requirements.
