## Deltas from ticket

- **`Neo.code.LivePreview#editorConfig` is a second engine addition** (reactive, default `null`): the configs go to the source editor, to its config object before the items exist and to the editor after. At the editor's default type the code column holds 32 lines on macOS; the home sets a 12px type with a 14px line: 48 lines of 91 characters at 1440×900.
- **The source editor of a side-by-side page hides its horizontal scrollbar.** The scrollbar reserved 12px, which left a 48-line snippet 2px to scroll, so the first wheel tick over the code was swallowed and the page stayed (the planning page at `388d353ed8`). `scrollbar` in the editor's `options` replaces the wrapper's own default, so the home repeats `alwaysConsumeMouseWheel: false`; noted in defect-note `261cba1d`.
- **`Portal.view.home.FeatureSection#learnMoreText`** (reactive, default `'Learn more'`) names the button; the two component pages name their guide.
- **The price flash has two tints of equal weight**, in the engine's stylesheet (`resources/css/src/grid/column/AnimatedCurrency.css`): `rgb(218 54 51 / 60%)` and `rgb(35 134 54 / 60%)` in place of `darkred` and `darkgreen`, whose green was 1.7 times as bright. `apps/finance` flashes with them. The grid's Change column is a plain currency column with a renderer, so green text never sits on a green flash.
- **The footer label carries the row count from the start.** A label that got its first text after the grid had rendered grew the toolbar, and a row's sparkline registered on a node that was gone (a console warning in 3 of 3 runs, in 0 of 4 with the text present); noted in defect-note `0a8f8e62`.
- **No flag column in the grid.** `Neo.grid.column.CountryFlag` loads its images from a third-party host; a failed request is a console error on the front door.
- **The planning page's file and class are renamed** to `parts/Planning.mjs`, `Portal.view.home.parts.Planning`. Its stylesheet sets the board's column width, so four columns fit a pane of 700px.
- **"More in the engine:" is "More components:"**, the design seat's wording.
- **`HomeComponentPreviews.spec.mjs` is adapter-eligible** (`test/playwright/externalBrainSelection.mjs`): it asks the page's own shared App Worker to move a card and a bar, tests no Bridge and imports no Brain service.
- Out of scope, noted in defect-note `be7e2d7d` (a store model given string field names keeps one field named `undefined`) and in defect-note `760e9f36`: `Neo.data.TreeStore` stamps `collapsed: true` on a raw parent row, so `Neo.gantt.TaskModel`'s documented default `false` never applies; the snippet sets `collapsed: false`.
