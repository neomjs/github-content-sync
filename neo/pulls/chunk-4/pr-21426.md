Resolves #21423

🌿 *A popover can no longer open in a corner the page never asked for.*

`Neo.plugin.Popover` now ties the popover to its button with CSS anchor positioning: the button carries `anchor-name`, the popover `position-anchor`, both set inline from one `getAnchorName()`. The plugin's own stylesheet places the popover, with one `position-area` per align value and a flip fallback for a side without room. It replaces the HTML `anchor` attribute and the `@position-fallback` rules in the example's CSS, neither of which current browsers ship. `align` became reactive, and `examples/popover` offers one radio per value. In `examples/popover` at 1024 × 768 the popover moves from x −135, y 8 to centred 8 px above Click Me.

Evidence: L3 (e2e on `examples/popover` in CI, red on `dev`; frames in both themes) → L3 required (AC-1..AC-3). Residual: none.

## Deltas from ticket

- **The surface uses `--neo-background-color`,** which all five themes define globally, instead of new token files per theme. A neutral shadow separates the popover from a page of the same colour.
- **`align` is reactive:** `afterSetAlign` swaps the popover's side class, and the example's radios set it. The AC's "each align value" runs through that UI.
- **`width: max-content`:** without it a popover squeezes into a narrow side and wraps, so the flip never fires.
- **`onOwnerMounted` takes the owner's window.** `plugin.Base` copies `windowId` only when the owner is constructed, and this owner gets its window later, so the stylesheet never loaded. `Neo.plugin.PrefixField` works around the same gap by hand. The generic fix is noted as a defect-note, not done here.
- **`test/playwright/unit/container/InsertDuringCreateItems.spec.mjs`** pinned the removed `vdom.anchor`. It now pins the `anchor-name` / `position-anchor` pair.
- **`buildScripts/util/e2eCiSelection.mjs` runs `test/playwright/e2e/popover`.** The spec opened a directory `RUN_PATHS` did not name, and the selection floor stops every shard on an undeclared one.
- **The stage title reads "Popover".** Its subtitle still names the example component's class (`Neo.container.Base`), as every workbench does.
