Resolves #20890

🌿 A person no longer types a timestamp to move a booking, and the header no longer names a day by its ISO key.

The timeline family now reads to a person. The editor edits each bound with a date field and a time field in the axis' clock and still commits once through `commitTimelineEdit()`. The header's default labels come from `Intl.DateTimeFormat` in the axis' zone and a new `locale_` config: "Mon, Nov 9" for a day, "Nov 8 – 14" for a week, "November 2026" for a month. A day whose start is scrolled out keeps its name at the left edge, and a bar keeps its title the same way. `TimeAxis#now_` (`null` reads the clock) draws one line beneath the bars and marks the ticks that hold it, in the scheduler and the Gantt chart alike. A short finish-to-start link turns on the row boundary next to its source instead of halfway between the rows, so it no longer crosses the titles of bars that start on the same date.

Evidence: L3 (unit specs in CI; frames of both examples and the Workstation's release plan in both neo themes, before on `dev`'s timeline code and after on this head) → L3 required (AC-3, AC-6). Residual: none; AC-6's design read is pending and gates the merge.

## Deltas from ticket
- The stylesheets the ticket cites moved to plain CSS with #21225 (`resources/css/src/timeline/*.css`, `resources/css/src/gantt/Container.css`).
- Point 2 also covers the minor row: week and month ticks printed ISO keys there too.
- Point 3, header: the rows and the major tick use `overflow: clip` instead of `hidden`, so the scrolled toolbar stays the sticky label's scroll container. Body: the label shifts by `--grid-scroll-left` less the column's x (`--neo-timeline-track-x`) and the bar's x (`--neo-timeline-bar-left`), keeping 48 px of the bar.
- Point 4: the instant lives on the shared axis, which `Column` and `TimeAxisHeader` already observe. The line sits beneath the bars so it never crosses a title. With `now: null` it is read when a row renders, so it moves on the next render, not every minute.
- Point 5: stacking the bars above the layer would hide the lines, because rows paint opaque backgrounds, so the route changed instead. The same turn fixes the backward route, whose horizontal ran through the middle row's centre.
- Point 1 uses `Neo.form.field.Time`, whose picker throws on `dev` until #21308 merges; this ticket is `blocked_by` #21307. Typing a time works without it.
- `PlanningStores.spec.mjs`'s `rowBars` helper now keeps only `.neo-timeline-bar` nodes: the now line is a track child, and the Workstation seeds its plan around today.
- Out of scope, noted: a bar's `aria-label` still names its days by ISO key (defect-note cd07d72e); the dependency layer draws over the locked task column while scrolled (defect-note 7bb44bd8).
