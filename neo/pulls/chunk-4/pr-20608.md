<h2>v1.65.0</h2>
<h2>🥟 Run tests with Bun</h2>
<p>The test runner now runs under <a href="[QUARANTINED_URL: bun.com]">Bun</a>. Bun transpiles your TypeScript test files itself, so Playwright does not use Babel or its compilation cache. Pass the <code>--bun</code> flag, because without it <code>bunx playwright test</code> runs on Node.js:</p>
<pre lang="bash"><code>bunx --bun playwright test
</code></pre>
<p>Our CI runs the test runner tests under Bun 1.4.3 on Linux. Some features work differently under Bun:</p>
<ul>
<li>There is no watch mode. UI mode does not run tests again when files change, and <code>--only-changed</code> does not follow imports.</li>
<li>Bun loads modules itself, so <code>--tsconfig</code> and the JSX options in <code>tsconfig.json</code> have no effect, and custom ESM loaders are not supported.</li>
<li>Stack traces do not include async frames, and API names do not include the class name: <code>click</code> instead of <code>locator.click</code>. This changes some step locations, step titles and error messages.</li>
<li>Console output of a test does not get into the trace and UI mode.</li>
</ul>
<h2>🚨 Reports with only failures</h2>
<p>New <a href="[QUARANTINED_URL: playwright.dev]"><code>failures</code></a> reporter prints failures and successful retries as they occur, followed by a summary, without progress output.</p>
<p>New <code>onlyFailures</code> option of the HTML, JSON and JUnit reporters <a href="[QUARANTINED_URL: playwright.dev]">keeps only</a> tests with unexpected outcomes, flaky tests and interrupted tests:</p>
<pre lang="js"><code>// playwright.config.ts
import { defineConfig } from '@playwright/test';
<p>export default defineConfig({
reporter: [
['failures'],
['html', { onlyFailures: true }],
],
});
</code></pre></p>
<h2>🎯 Test runner</h2>
<ul>
<li>
<p>New built-in <code>-exclusive-</code> <a href="[QUARANTINED_URL: playwright.dev]">test lock</a> runs a test only when no other tests are running. All other tests continue to run in parallel with each other:</p>
<pre lang="js"><code>test('restart the server', { lock: '-exclusive-' }, async () =&gt; {
  // No other test runs while this one is running.
});
</code></pre>
</li>
<li>
<p><a href="[QUARANTINED_URL: playwright.dev]">test.skip()</a>, <a href="[QUARANTINED_URL: playwright.dev]">test.fixme()</a>, <a href="[QUARANTINED_URL: playwright.dev]">test.fail()</a> and <a href="[QUARANTINED_URL: playwright.dev]">test.slow()</a> now accept only a description. It is recorded in the test annotation:</p>
<pre lang="js"><code>test('upload a file', async ({ page }) =&gt; {
  test.skip('Not implemented yet');
});
</code></pre>
</li>
</ul>
