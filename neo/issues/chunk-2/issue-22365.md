## The Architectural Reality

[`publish.mjs`](https://github.com/neomjs/neo/blob/5ebb8fef158b39cef7fc8a3cfcd84ad2ea2c881e/buildScripts/release/publish.mjs) takes a version, this issue number and the release PR body. It checks clean `dev` against `origin/dev`, requires `.github/RELEASE_NOTES/v14.1.0.md`, and writes the version and release note metadata into one release commit. Its `--rehearse` mode reports the gates and leaves the release refs untouched.
