# Measure the touch default policy on a physical iPhone before it changes

Owner: Ada (`@neo-opus-ada`), who owns the physical comparison in D#22259 G2. It is the device gate on #22400: no global input default changes before this run reports.

## Context

D#22259 G2 graduated the gesture and replay contract to #22400 ([my G2 signal](https://github.com/neomjs/neo/discussions/22259#discussioncomment-19961924)). Every control behind the proposed policy ran in Chromium. That covers the listener census, the [pre-check](https://github.com/neomjs/neo/discussions/22259#discussioncomment-19949561) that retired a grid-wide `touch-action: none`, and the Helix `pan-y` arm from the [operator's direction](https://github.com/neomjs/neo/discussions/22259#discussioncomment-19949867). Chromium cannot show WebKit's rule, so G2 keeps the global default unchanged until a device run.

## The Problem

On WebKit a `touchmove` cancel works only if a non-passive listener existed at touch start (`src/main/draggable/sensor/Pointer.mjs`, its JSDoc above the listener). A default app has two such listeners before contact:
- the body's (`src/main/DomEvents.mjs`)
- the default DragDrop sensor's window listener

The grid's document listener comes later, from its `touchstart` (`src/main/addon/GridDragScroll.mjs`). So making the body passive can change whether a held grid drag still cancels native scrolling on iOS, and that depends on whether DragDrop is loaded. Hold-to-drag (`touchDelay` 200 ms) depends on the sensor's pre-contact listener as well.

## The Architectural Reality

- Design authority: G2's "Physical iPhone comparison" paragraph and its ownership paragraph, in the D#22259 body at 2026-11-27T21:16:00Z.
- The probe is two local trees, a dev arm and a declared arm, plus a passive recorder, served on the LAN to the device. It worked at Chromium level in the pre-check. It records `touchmove.cancelable`, scroll deltas and the gesture outcome per step.

## The Fix

Run each arm on one iPhone with matched travel and power mode:

| Arm | Change |
| :--- | :--- |
| A | `dev` as is |
| B | passive body listener; `.neo-helix { touch-action: pan-y }` in structural CSS instead of the path test; DragDrop loaded |
| B′ | B without DragDrop (custom `mainThreadAddons`) |
| G | a grid arm with panning off, **only** once a GridDragScroll monitor starts JS scrolling at contact. Until then it is recorded as not run. |

Per arm:
1. Page scroll starts, and the first `touchmove` is cancelable or not.
2. A quick grid stroke scrolls.
3. A held grid drag (a 250 ms rest, then a drag) scrolls exactly once.
4. Hold-to-drag on a draggable claims after the hold.
5. A sideways drag on Helix rotates it and leaves the page still.
6. A vertical drag on Helix scrolls the page.
7. A pinch on Helix leaves the page scale at 1.
8. A viewport pinch elsewhere still zooms.

Report message counts and frame tails with their spread, as G2 asks.
