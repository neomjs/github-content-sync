# The roadmap names a generator command that does not exist

## Context

`ROADMAP.md` on `dev` (`f63d19ce36`) tells a reader twice to run `npx create-neo-app`: in the paragraph "How the number is confirmed" (line 31) and in cornerstone row 5 (line 41). The text came from a review comment of mine that named the command from memory.

## The Problem

- The generator is the package `neo-app`: its `package.json` names it and its `bin`, and its README says `npx neo-app`. npm serves `neo-app@13.4.1`.
- `npm view create-neo-app` answers 404 (read 2026-11-13). A reader who follows the roadmap gets an error.

```text
npm error 404 Not Found - GET https://registry.npmjs.org/create-neo-app - Not found
```

## The Architectural Reality

`ROADMAP.md` is hand-written and is the engine's public plan. The generator lives in `neomjs/create-app`; its release on cut day is neomjs/create-app#61.

## The Fix

Both occurrences become `npx neo-app`. Nothing else in the two lines changes.

## Acceptance Criteria

- [ ] AC-1: `ROADMAP.md` names `npx neo-app` in both places, and `create-neo-app` no longer occurs in the file.
- [ ] AC-2: no other tracked file on `dev` names `create-neo-app` (a tree search with a positive control).
