# One scripted rename gives every component variable its final name

## Context

Step 4 of ADR 0044's migration (`learn/agentos/decisions/0044-design-system.md` §4) and the last step before any package moves to `theme-base`. Names change once, in one cut, with a rename map and no alias layer. The [step-6 map on the epic](https://github.com/neomjs/neo/issues/22295#issuecomment-7217835670) shows what waits behind it: 42 package moves.

unowned-rationale: critical path of the 14.1 cut and cross-repository, so it is for a maintainer seat and carries no contributor labels. Claim by assignee and a `[lane-claim]`. The script and the map can be written today; the merge waits for the two blockers.

## The Problem

A model that styles a component predicts a name. Today one thing has several words, so a plausible guess sets a variable nothing reads. `npm run theme-census` on `dev` at `9380db92d8`, engine component names in `theme-neo-light`:

- A background: `background-color` 174, `background` 46, `bg` 24.
- A text colour: `color` 226, `text-color` 40, `text` 20.
- An icon colour: `glyph-color` 41, `icon-color` 14.
- The state word: last in 195 names, elsewhere in 44.
- 110 names carry `--neo-` without being a palette name or a role (board 44, timeline 31, app 14, gantt 7, scheduler 7, seven singles), and three more are set at runtime (`--neo-duration`, `--neo-easing`, `--neo-tree-level`). ADR 0044 reserves that prefix for what a theme owns.

## The Architectural Reality

- 2,187 custom properties are declared under `resources/css` (five themes and `src`).
- Read by name outside CSS, counted against that set: `src` 42 names in 20 files, `apps` 8 in 3, `examples` 10 in 6, `test` 169 in 74, `buildScripts` 5 in 2, and 27 names in 8 guides under `learn`. At least three names are built from parts (the epic names `DockFlip.mjs:700` and `DomAccess.mjs:1854`), which a text replace cannot see.
- The gate exists: `npm run theme-equality` (`#22300`) compares computed values per component, theme and state, so it is blind to a variable's name and exact about its effect.
- `check-theme-class-prefix` guards the class half of I4. The property half has no guard.
- Workstation and Fleet override 171 and 150 component variables by name (ADR 0044 §1); Fleet lives in `neomjs/neo-agent-institution`.

Design authority: "The rename, one scripted pull request, before any package moves. It unifies the words of the component variables, moves the state word last, and gives the 129 names that carry `--neo-` today without being roles their component names, in CSS, in JavaScript string and template literals, in tests and in guides." (ADR 0044 §4, step 4; the count was 129 at `a22c1a96e9` and is 110 today.) The grammar is decision 4 of the same record.

## The Fix

1. **A map file,** old name to new name, generated by rule and completed by hand, shipped in the pull request. The rules, from decision 4:
   - A name ends with the CSS property that reads it, then at most one state word. `bg`, and a `background` that feeds `background-color`, become `background-color`; a variable the `background` shorthand reads keeps `background`. `text-color` and `text` become `color`.
   - The state word is last, from the closed list `hover`, `active`, `focus`, `selected`, `pressed`, `disabled`, `invalid`, `readonly`.
   - A part word is the component's own class word (`glyph` where the class says glyph).
   - A `--neo-` name that is not a palette name, a role or `--neo-color-scheme` takes its component's name (`--neo-board-…` becomes `--board-…`), the three runtime-set ones included.
2. **A script** that applies the map to `.css`, to string and template literals in `.mjs`, to tests and to guides, reports every name it could not resolve statically, and changes nothing on a second run.
3. **A guard** for the property half of I4: a declared or read `--neo-` name has the shape of a palette name or of a role (the thirteen categories of decision 3), or is `--neo-color-scheme`.

## Acceptance Criteria

- [ ] AC-1 The map is one file in the pull request, and the design seat's read of it is on the pull request before the tree changes are reviewed. Every renamed name follows a stated rule or carries a one-line reason.
- [ ] AC-2 After the run, section 8 of `npm run theme-census` reports for all five themes: no `bg`, no `text-color` or `text` as a text colour, `background` only where the shorthand reads it, and no state word outside the last position.
- [ ] AC-3 No `--neo-` name outside the three allowed shapes is declared or read under `resources/css`, `src`, `apps`, `examples` or `test`. The new guard fails a planted one and runs with the other theme guards.
- [ ] AC-4 `npm run theme-equality` reports no difference between base and head in all five themes, and `WorkstationPaletteBridgeNL` is green.
- [ ] AC-5 A search for every old name over `.css`, `.mjs` and `learn` returns nothing, and the script prints that count. Each name built from parts is listed in the pull request with its edit.
- [ ] AC-6 The script re-runs on a rebase: a second run on the head changes no file.
- [ ] AC-7 Before the merge, each other `neomjs` repository in which an old name appears has an inventory (files and names) and an owner on this ticket. Each follows with one pull request that runs the same script and map.
- [ ] AC-8 Post-merge: the map is linked from the 14.1 release notes (`#22265`).

## Out of Scope

- Binding a variable to a role, and `theme-base`: step 6.
- Theme Neo's `Global.css` and the role names: step 5, filed beside this leaf.
- Class names, and the `--sem-*` tokens (they go at step 8).
- An alias for an old name.

## Avoided Traps

- **A rename per package, by hand.** Ten seats would each choose a word; one map is one decision.
- **An alias layer for old names.** Nobody outside the organization builds on the names yet (ADR 0044 §3).
- **Frames as the proof.** A rename must not move a pixel, and computed values say so exactly.
- **Unifying `glyph` and `icon` blindly.** The part word follows the component's class.
