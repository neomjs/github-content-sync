# The 14.1 roadmap names the design system and touch input

Live latest-open + closed sweep: checked the latest open issues, an open and closed search (roadmap 14.1), open pull requests touching `ROADMAP.md`, the mailbox for claims and my own assignments at 2026-11-26 23:07Z; `#22237` set the 14.1 roadmap and is closed, nothing open covers this change. Backlog band: 44 open (orange); the roadmap has no standing owner ticket, so this is filed.

## Context

The operator widened the 14.1 scope on 26 Nov: a design system that every theme is written against, and touch input as engine events, with a Material theme and mobile components on top if both land. He asked for the roadmap to say so now, so that peers can take those lanes before the weekend cut.

## The Problem

`ROADMAP.md` under `## Next: Engine 14.1` still calls theming an investigation whose implementation "can follow the cut", does not mention touch input at all, and points at the read-only preview investigation, which closed (`#22240`). A peer who reads it cannot tell which design or touch work is open tonight and which waits for a decision.

## The Architectural Reality

- The design system is in the Ideation Sandbox, Discussion #22228; touch input in Discussion #22259. Neither has graduated, so the roadmap names them as the homes of the decisions and may not present an outcome as decided (`update-roadmap`, step 7).
- Work that needs no decision already has tickets: `#22270` (the theme census), `#22276` (the old token export), `#22264` and `#22271` (raw touch defects).
- A roadmap is cornerstones and rationale with a visible deferred set, never an item list (`update-roadmap`).

## The Fix

In `ROADMAP.md`, under `## Next: Engine 14.1`:

1. The opening paragraph names the two foundations and the cut dates (Sunday 29 or Monday 30 November).
2. `### Design and tooling decisions` is replaced by two subsections, one per foundation: what the Discussion decides, what is open now, what starts at graduation and in which order.
3. A capstone paragraph for the Material theme and the first mobile components.
4. The preview-investigation sentence says it is closed and where its outcome continues.
5. `Beyond this cut` gains what follows the theme migration.

## Acceptance Criteria

- [ ] The section names both Discussions as the place of the decisions and presents no ungraduated outcome as decided.
- [ ] It names the tickets that are open now for each foundation.
- [ ] It states the cut dates and what happens to a track that is not through its gate by then.
- [ ] The capstone and the deferred set are visible.
- [ ] No other section of the file changes.

## Out of Scope

- Filing the migration's tickets: after Discussion #22228 graduates.
- Any change to the release gate.
