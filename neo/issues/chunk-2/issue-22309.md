# src/gantt gets its mechanical pass: JSDoc, order, redundant defaults

Design authority: `.github/CODING_GUIDELINES.md` (rule (19) class content order, rule (24) `div` is the default tag, rules (30) to (35) method docs and variable blocks, §12 compact JSDoc blocks), and the split of #22306 that its author accepted ([intake](https://github.com/neomjs/neo/issues/22306#issuecomment-7208460433), [acceptance](https://github.com/neomjs/neo/issues/22306#issuecomment-7208626611)).

Owned: self-assigned at creation, so no curated labels.

## Context

#22306 brings `src/gantt` to the Engine's class standard. Three of its six buckets touch nearly every line of eleven files and change no behaviour; the other three change design. In one pull request a design change hides inside 3,965 lines of moves, which is how two reviews passed this package. This leaf is the first kind alone. #22306 is `blocked_by` it and starts from its result.

## The Problem

Measured at `59b558101f`:

- **Docs that lose what they say.** 91 one-line JSDoc blocks, 58 of them in `Container.mjs`. Eight config blocks there lose metadata in the docs output (lines 30 to 86): `className` and `ntype` lose `@protected`, `baseCls` loses its array default and `@protected`, and `cascadeDependencies_`, `dependencyCreation_`, `dependencyStore_`, `taskColumns_` and `useWorkingTime_` lose `@reactive`, which the parser folds into the description. Most method blocks are one summary line without the parameter lines rule (30) asks for.
- **Order.** The container's 60 methods stand in narrative order (`construct`, the `beforeSet*`, the `afterSet*`, then `bindTimelineSubscriptions` to `moveTask`), where rule (19) asks for alphabetical order after `construct()`. One config pair is out of order as well (`baseCls` before `barMarginPct`).
- **Defaults an ancestor already supplies.** `keyProperty: 'id'` in `DependencyStore.mjs:36` and `TaskStore.mjs:34` (`collection/Base.mjs:94`), `parentId: 'document.body'` in `EventDragZone.mjs:73` (`component/Abstract.mjs:109`), and in `DependencyLayer.mjs:145` a `_vdom` root that writes `tag: 'div'` and repeats `baseCls` in its `cls`.
- **Variable blocks.** 184 `const` declarations across the eleven files, where rules (31) to (35) ask for one aligned, comma-separated `let` block at the top of a method.

## The Architectural Reality

- `npm run generate-docs-json` builds the docs output from the JSDoc. A one-line block with a second tag loses that tag (guidelines §12, the table at line 582).
- Rule (19): static fields in alphabetical order, `static config` last of them, class fields in alphabetical order, `construct()`, then every other method in alphabetical order.
- A moved method or config key changes nothing in a Neo class: `Neo.setupClass` reads `static config` as an object and methods by name. Class fields are the exception, since they initialize in source order.
- 27 Gantt spec files exist under `test/`; `examples/gantt` holds eight examples.

## The Fix

Three commits, so that a reviewer reads one of them line by line. They land in the order JSDoc, variable blocks, moves: the first two then show against today's order in small local hunks, and each proof holds in either sequence.

1. **Moves.** `static config` keys, class fields and methods take the order of rule (19) in all eleven files. A `#private` method sorts by its name without the `#`. Nothing else changes in this commit. Proof: a comparison of the syntax trees of `dev` and this commit (acorn, comments and positions dropped, class members and `static config` keys compared as sets by name) reports no difference.
2. **JSDoc.** A one-line block that §12 does not permit (a second tag, an array or object default, a default with whitespace) becomes a multi-line block; the three compact forms §12 permits stay. Every method documents its parameters and its return value (rule (30)). The eight lossy config blocks get their tags and defaults back. Proof: the same comparison, order-sensitive this time, reports no difference between commits 1 and 2, because only comments changed; the docs output for `src/gantt` shows the restored tags and defaults.
3. **Variable blocks and redundant defaults.** The four redundant defaults go, each with the ancestor line that supplies it. Declarations merge into one aligned `let` block at the top of a method where that cannot change a value: a declaration moves only when nothing between its old and its new place can change what its initializer reads. Alignment is written by `buildScripts/util/check-block-alignment.mjs --fix`, which owns that style.

The comparison script goes into the pull request body as evidence. It is no build script: #22307's guard owns the standing rules.

## Avoided Traps

- **One commit for all three kinds.** A moved method whose body also changed reads as a move.
- **Hoisting a declaration past a statement that changes what it reads.** Rule (31) says "try"; the value comes first.
- **Reordering class fields whose initializers read each other.** Fields initialize in source order.
- **Documenting a parameter from its name.** A parameter line says what the method does with it, read from the body. Where the body is unclear, that is a finding for #22306, not a guess here.

// Proves that a commit only moved things (or only changed comments) in a set of class modules.
//
//     node compare-class-trees.mjs <repo> <base-ref> <head-ref> [--ordered] <file> [<file> …]
//
// Both versions are parsed with acorn; comments, positions and literal spelling are dropped.
// Default mode: the members of a class body and the keys of its `static config` object are compared as
// sets by name, so a pure reorder reports nothing. Everything else stays ordered: statements inside a
// method, array elements, parameters, top-level statements.
// A class field whose initializer reads `this` must keep its place among the fields, since fields
// initialize in source order.
// --ordered: nothing is sorted. Two trees are equal only if nothing but comments and whitespace changed.
//
// Exit code 0: no difference. 1: differences, listed by file and member.
import {execFileSync} from 'node:child_process';
import {createRequire} from 'node:module';
import path           from 'node:path';

const
    [repo, baseRef, headRef, ...rest] = process.argv.slice(2),
    ordered = rest.includes('--ordered'),
    files   = rest.filter(arg => arg !== '--ordered'),
    acorn   = createRequire(path.join(repo, 'package.json'))('acorn'),
    dropped = new Set(['start', 'end', 'loc', 'range', 'raw']);

function read(ref, file) {
    return execFileSync('git', ['-C', repo, 'show', `${ref}:${file}`], {encoding: 'utf8', maxBuffer: 64 * 1024 * 1024})
}

function clean(node) {
    if (Array.isArray(node)) {
        return node.map(clean)
    }

    if (node && typeof node === 'object') {
        if (node instanceof RegExp) {
            return String(node)
        }

        const out = {};

        for (const [key, value] of Object.entries(node)) {
            if (!dropped.has(key)) {
                out[key] = typeof value === 'bigint' ? `${value}n` : clean(value)
            }
        }

        return out
    }

    return node
}

function keyName(key) {
    return key.type === 'PrivateIdentifier' ? `#${key.name}` : key.type === 'Identifier' ? key.name : JSON.stringify(key.value)
}

function memberName(member) {
    if (member.type === 'StaticBlock') {
        return 'static {}'
    }

    return `${member.static ? 'static ' : ''}${member.kind && member.kind !== 'method' ? member.kind + ' ' : ''}${keyName(member.key)}`
}

function readsThis(node) {
    return JSON.stringify(node ?? null).includes('"type":"ThisExpression"')
}

// Returns {classes: {<name>: {members: Map, config: Map|null, fieldOrder: String[]}}, rest: String}
function describe(source, file) {
    const
        tree    = clean(acorn.parse(source, {ecmaVersion: 'latest', sourceType: 'module'})),
        classes = {};

    JSON.stringify(tree, (key, node) => {
        if (node && (node.type === 'ClassDeclaration' || node.type === 'ClassExpression')) {
            const
                name    = node.id?.name || `${file}#anonymous`,
                members = new Map(),
                entry   = {members, config: null, fieldOrder: []};

            for (const member of node.body.body) {
                const id = memberName(member);

                if (members.has(id)) {
                    throw new Error(`${file}: ${name} declares ${id} twice`)
                }

                if (id === 'static config' && member.value?.type === 'ObjectExpression') {
                    entry.config = new Map(member.value.properties.map(property => [
                        property.type === 'SpreadElement' ? `...${JSON.stringify(property.argument)}` : keyName(property.key),
                        JSON.stringify(property)
                    ]));

                    members.set(id, 'static config {…}')
                } else {
                    members.set(id, JSON.stringify(member))
                }

                if (member.type === 'PropertyDefinition' && !member.static && readsThis(member.value)) {
                    entry.fieldOrder.push(id)
                }
            }

            classes[name] = entry;

            // the class body is compared member by member; keep the rest of the module ordered
            return {type: node.type, id: node.id, superClass: node.superClass, body: `<class ${name}>`}
        }

        return node
    });

    const rest = JSON.stringify(tree, (key, node) =>
        node && (node.type === 'ClassDeclaration' || node.type === 'ClassExpression')
            ? {type: node.type, id: node.id, superClass: node.superClass}
            : node
    );

    return {classes, rest}
}

function compareMaps(label, base, head, findings) {
    for (const [name, value] of base) {
        if (!head.has(name)) {
            findings.push(`${label}: ${name} is gone`)
        } else if (head.get(name) !== value) {
            findings.push(`${label}: ${name} changed`)
        }
    }

    for (const name of head.keys()) {
        if (!base.has(name)) {
            findings.push(`${label}: ${name} is new`)
        }
    }

    if (ordered && [...base.keys()].join('\n') !== [...head.keys()].join('\n')) {
        findings.push(`${label}: the order changed`)
    }
}

let failed = false;

for (const file of files) {
    const
        findings = [],
        base     = describe(read(baseRef, file), file),
        head     = describe(read(headRef, file), file);

    if (base.rest !== head.rest) {
        findings.push('module scope: a statement outside the class bodies changed')
    }

    for (const name of new Set([...Object.keys(base.classes), ...Object.keys(head.classes)])) {
        const a = base.classes[name], b = head.classes[name];

        if (!a || !b) {
            findings.push(`class ${name} ${a ? 'is gone' : 'is new'}`);
            continue
        }

        compareMaps(`${name}`, a.members, b.members, findings);

        if (a.config || b.config) {
            compareMaps(`${name}.config`, a.config || new Map(), b.config || new Map(), findings)
        }

        if (a.fieldOrder.join('\n') !== b.fieldOrder.join('\n')) {
            findings.push(`${name}: class fields whose initializers read \`this\` changed their order`)
        }
    }

    failed ||= findings.length > 0;

    console.log(`${findings.length ? 'DIFF ' : 'same '} ${file}`);
    findings.forEach(finding => console.log(`       ${finding}`))
}

process.exit(failed ? 1 : 0);

//
//     node compare-class-trees.mjs <repo> <base-ref> <head-ref> [--ordered] <file> [<file> …]
//
// Both versions are parsed with acorn; comments, positions and literal spelling are dropped.
// Default mode: the members of a class body and the keys of its `static config` object are compared as
// sets by name, so a pure reorder reports nothing. Everything else stays ordered: statements inside a
// method, array elements, parameters, top-level statements.
// A class field whose initializer reads `this` must keep its place among the fields, since fields
// initialize in source order.
// --ordered: nothing is sorted. Two trees are equal only if nothing but comments and whitespace changed.
// --declarations: proves a commit that only rewrites variable declarations. `const` and `let` count as one
// kind and a declaration list counts as its single declarations in place, so a changed keyword or a merge of
// neighbours reports nothing. A member that still differs is reported as "moved" when each of its functions
// holds the same declarations and the same other statements in the same order, which is what a hoist leaves
// behind, and as changed otherwise. Combine it with --ordered.
//
// Exit code 0: no difference (moved members are listed, they do not fail). 1: differences, by file and member.

    declarations = rest.includes('--declarations'),
    files        = rest.filter(arg => !arg.startsWith('--')),
    acorn   = createRequire(path.resolve(repo, 'package.json'))('acorn'),
    dropped = new Set(['start', 'end', 'loc', 'range', 'raw']);

    return execFileSync('git', ['-C', repo, 'show', `${ref}:${file}`], {encoding: 'utf8', maxBuffer: 64 * 1024 * 1024})
}

function clean(node) {
    if (Array.isArray(node)) {
        return node.map(clean)
    }

    if (node && typeof node === 'object') {
        if (node instanceof RegExp) {
            return String(node)
        }

        const out = {};

        for (const [key, value] of Object.entries(node)) {
            if (!dropped.has(key)) {
                out[key] = typeof value === 'bigint' ? `${value}n` : clean(value)
            }
        }

        return out
    }

    return node
}

// --declarations: one keyword, and a declaration list as single declarations in place
function flatten(node) {
    if (Array.isArray(node)) {
        return node.flatMap(item => {
            const flat = flatten(item);

            return flat?.type === 'VariableDeclaration' && flat.declarations.length > 1
                ? flat.declarations.map(declaration => ({...flat, declarations: [declaration]}))
                : [flat]
        })
    }

    if (node && typeof node === 'object') {
        const out = {};

        for (const [key, value] of Object.entries(node)) {
            out[key] = flatten(value)
        }

        if (out.type === 'VariableDeclaration') {
            out.kind = 'let'
        }

        return out
    }

    return node
}

// The same tree with the declarations of each function lifted out of its statements into a sorted list.
// A loop head keeps its declaration: only statements are lifted.
function lift(node, lifted) {
    if (Array.isArray(node)) {
        const out = [];

        for (const item of node) {
            if (item?.type === 'VariableDeclaration') {
                lifted.push(...item.declarations.map(declaration => JSON.stringify(lift(declaration, lifted))))
            } else {
                out.push(lift(item, lifted))
            }
        }

        return out
    }

    if (node && typeof node === 'object') {
        const
            isFunction = /Function/.test(node.type || ''),
            own        = isFunction ? [] : lifted,
            out        = {};

        for (const [key, value] of Object.entries(node)) {
            out[key] = lift(value, own)
        }

        if (isFunction) {
            out.lifted = own.sort()
        }

        return out
    }

    return node
}

                const member = declarations ? flatten(original) : original, id = memberName(member);

                declarations && entry.lifts.set(id, JSON.stringify(lift(member, [])));

                if (members.has(id)) {
                    throw new Error(`${file}: ${name} declares ${id} twice`)
                }

                if (id === 'static config' && member.value?.type === 'ObjectExpression') {
                    entry.config = new Map(member.value.properties.map(property => [
                        property.type === 'SpreadElement' ? `...${JSON.stringify(property.argument)}` : keyName(property.key),
                        JSON.stringify(property)
                    ]));

                    members.set(id, 'static config {…}')
                } else {
                    members.set(id, JSON.stringify(member))
                }

                if (member.type === 'PropertyDefinition' && !member.static && readsThis(member.value)) {
                    entry.fieldOrder.push(id)
                }
            }

            classes[name] = entry;

            // the class body is compared member by member; keep the rest of the module ordered
            return {type: node.type, id: node.id, superClass: node.superClass, body: `<class ${name}>`}
        }

        return node
    });

    const rest = JSON.stringify(tree, (key, node) =>
        node && (node.type === 'ClassDeclaration' || node.type === 'ClassExpression')
            ? {type: node.type, id: node.id, superClass: node.superClass}
            : node
    );

    return {classes, rest}
}

function compareMaps(label, base, head, findings, moved, baseLifts, headLifts) {
    for (const [name, value] of base) {
        if (!head.has(name)) {
            findings.push(`${label}: ${name} is gone`)
        } else if (head.get(name) !== value) {
            if (baseLifts?.has(name) && baseLifts.get(name) === headLifts.get(name)) {
                moved.push(`${label}: ${name}`)
            } else {
                findings.push(`${label}: ${name} changed`)
            }
        }
    }

    for (const name of head.keys()) {
        if (!base.has(name)) {
            findings.push(`${label}: ${name} is new`)
        }
    }

    if (ordered && [...base.keys()].join('\n') !== [...head.keys()].join('\n')) {
        findings.push(`${label}: the order changed`)
    }
}

// - an @member default that is an array or object in a one-line block, or that contains whitespace
// - @param lines that are not block-aligned (type column, name column, description column)
// - `@return` instead of `@returns`
// - an empty line between the description and the first @param
// - a method whose top-level @param count differs from its signature, or whose named params differ

function splitParam(text) {
    // text starts with `{`: returns [type, name, description]
    let depth = 0, end = -1;

    for (let i = 0; i < text.length; i++) {
        if (text[i] === '{') depth++;
        if (text[i] === '}' && --depth === 0) { end = i; break }
    }

    if (end < 0) return null;

    const
        type  = text.slice(0, end + 1),
        after = text.slice(end + 1),
        rest  = after.trimStart();

    let name, description;

    if (rest.startsWith('[')) {
        let d = 0, close = -1;

        for (let i = 0; i < rest.length; i++) {
            if (rest[i] === '[') d++;
            if (rest[i] === ']' && --d === 0) { close = i; break }
        }

        name        = rest.slice(0, close + 1);
        description = rest.slice(close + 1)
    } else {
        const space = rest.search(/\s/);

        name        = space < 0 ? rest : rest.slice(0, space);
        description = space < 0 ? '' : rest.slice(space)
    }

    return {type, name, description: description.trim(), raw: text, gapAfterType: after.length - rest.length}

function returnsValue(node) {
    let found = false;

    (function walk(n, top) {
        if (!n || typeof n !== 'object' || found) return;

        for (const key of Object.keys(n)) {
            if (key !== 'loc') walk(n[key], false)
        }
