# An open cell edit survives its grid's move to another window

## Context

`Neo.grid.plugin.CellEditing` keeps an edit as a logical session in the App Worker and projects its editor into whichever cell renders it. The epic that built it left one case out on purpose: #18762 lists "cross-window editing" under Out of scope, and its design record #17832 lists "no cross-window editing" under its non-goals.

A docked grid can change windows while an edit is open and without a click from the person typing: a pop-out or a perspective applied through the Neural Link, a keyboard command, any layout transaction another actor starts. A click on the pane's own pop-out button is a different case: the click moves focus first, and that commit is the designed one.

@neo-gemini-julia read the seams from source on 2026-11-12 (`defect-note`); the browser run below measures them and corrects two of her three predictions.

## The Problem

Measured on `dev` at `be8d0b0340`, 2026-11-12, headless Chrome, `apps/workstation`. The `scale` grid (100,000 rows) gets cell editing at runtime (`cellEditing: true`, the `name` column `editable`), is scrolled to 6,000 px, an edit is opened by double-click on record 125, and the pane is popped out with `popOutDockItem({itemId: 'scale', pane: null})` through the Neural Link, so nothing takes the editor's focus before its DOM leaves.

| | a valid draft | an invalid draft (`editor: {required: true}`, emptied) |
|---|---|---|
| The session after the move | gone | still open |
| The record | holds the draft: `name` went from `Echo 000125` to the typed text with no Enter, Tab or click | unchanged |
| The editor | destroyed | rendered in the new window with its draft, without focus; its `windowId` is still the old window's while the grid's is the new one |
| Finishing in the new window | nothing left to finish | a click into the field, then typing and Enter commit; Tab commits and edits record 126, whose new editor carries the new `windowId` |
| Scroll position | 6,000 px in the engine and in the DOM, before and after | the same |
| Console errors | none | none |

The valid arm ran three times and the invalid arm three times (twice finished with Enter, once with Tab), with the same result each time. A control without a move shows the same Tab behaviour in the opener.

So one move writes one draft into the store and keeps the other open, and the surviving editor names a window it is no longer in.

## The Architectural Reality

- `Design authority:` "projection loss by itself is neutral—never commit and never cancel. Projection marks the session `suspending` before embodiment removal, so the resulting DOM focus-leave is classified as projection loss and cannot invoke the user focus-leave terminal." (#17832, the resolved contract.) The plugin's class JSDoc carries it as "Losing the projection is neutral: scrolling never commits and never cancels" (`src/grid/plugin/CellEditing.mjs:22`) and names three losses: a scroll that rebinds the row, a column leaving the mounted range, a column lock change. A change of window is not among them, because #18762 excluded it.
- `CellEditing#onEditorFocusLeave` (`:431`) commits when the session is embodied and no blur is owed. `isEmbodied` (`:363`) asks whether the record is in the row pool and the column in the mounted range. It does not ask whether the grid is mounted. Inferred, not measured: the leave that the old window's unmount causes arrives while `isEmbodied` still answers true.
- The editor is created with `windowId: owner.windowId` (`:752`). `grid.Body#afterSetWindowId` (`src/grid/Body.mjs:689`) hands a new window to its rows, and `grid.Row#forwardToCells` (`src/grid/Row.mjs:142`) hands it to the row's cell components only. The session's editor is not one of them.
- A hold already exists for the one structural change the epic covered: `holdEdit` and `releaseEdit` keep the editor out of every cell while a column changes body (`:338`, `:637`; the caller is `grid.Container#onColumnLockChange`, `src/grid/Container.mjs:1326`).
- `grid.Container#afterSetWindowId` (`src/grid/Container.mjs:847`) and `restoreLostScroll` (`:1710`) are why the scroll position survives.
- Tab's prevent-default registration is made for the view's window when a session starts (`:694`). The run found no Tab defect in the new window; the registration is named here only so a fix does not break it.

## The Fix

Treat the grid's change of window as a fourth projection loss:

1. The leave that the old window's unmount causes is neutral for a valid and for an invalid draft: no commit, no cancel.
2. The session's editor follows the grid's `windowId`.
3. Once the grid is mounted in the new window, the cell that proves the session embeds the editor again, and focus returns to it if the editor had focus when the move began. `onEditorReprojected` already applies that rule after a scroll.
4. The class JSDoc names the window change beside the other three losses.

Two seams to weigh, the choice is the implementer's: the existing hold around the move, or `isEmbodied` answering false while the grid is not mounted.

## Acceptance Criteria

- [ ] After a grid with an open edit and a valid draft moves to another window, the record holds its old value, the session is open, and the editor shows the draft in the new window.
- [ ] The same holds for an invalid draft.
- [ ] In both cases the editor's `windowId` equals the grid's.
- [ ] An editor that had focus before the move has it after the move. Enter commits, Escape cancels, and Tab commits and edits the next editable cell, all in the new window.
- [ ] A click on another cell, before or after the move, still commits a valid draft: the user's own terminal is unchanged.
- [ ] An e2e spec with a real second window covers both drafts (`test/playwright/e2e/`, the `neuralLink` fixture; the probe in the first comment is a starting point). `test/playwright/component/grid/CellEditing.spec.mjs` stays green.
- [ ] The class JSDoc of `Neo.grid.plugin.CellEditing` lists the window change among the projection losses.

## Out of Scope

Editing one record from two windows at once. The Table plugin. What a pane's own pop-out button does to an open edit. Changes to the dock.

## Avoided Traps

- Keeping the commit and calling it "focus left": the person did not leave, the DOM did.
- Fixing only the valid draft: the invalid one already survives, with a stale `windowId` and without focus.

import {test, expect} from '../../fixtures.mjs';

/**
 * UNTRACKED PROBE, not a spec of record.
 *
 * Question: a docked grid with a scroll position and an OPEN cell edit moves into a tear-out window
 * without a click (the pop-out is called through the Neural Link, so nothing takes the editor's
 * focus before its DOM leaves). What survives the move: the scroll position, the session, the draft?
 *
 * Run: NEO_NL_PORT=<free port> NEO_AGENTOS_RUNTIME_ROOT=<abs path to neo-agent-brain> NEO_E2E_PORT=<free port> \
 *      npx playwright test workstation/ZzProbeEditorAcrossWindowsNL -c test/playwright/playwright.config.e2e.mjs --workers=1
 */
const
    ITEM    = 'scale',
    DRAFT   = 'DRAFT-PROBE',
    ARMS    = [
        {name: 'valid draft, move',                 draft: DRAFT, editor: null,             hop: true,  finishKey: 'Enter'},
        {name: 'invalid draft, move, Enter',        draft: '',    editor: {required: true}, hop: true,  finishKey: 'Enter'},
        {name: 'invalid draft, move, Tab',          draft: '',    editor: {required: true}, hop: true,  finishKey: 'Tab'},
        {name: 'control: no move, Tab in the opener', draft: DRAFT, editor: null,           hop: false, finishKey: 'Tab'}
    ],
    asArray = value => Array.isArray(value) ? value : (value?.instances ?? value?.items ?? []),
    flatten = entries => asArray(entries).map(entry => ({id: entry.id, ...(entry.properties ?? entry)})),
    safe    = async fn => { try { return await fn() } catch (e) { return {error: String(e?.message || e).slice(0, 300)} } };

test.describe('PROBE: an open cell edit and a scroll position across a tear-out', () => {
    test.setTimeout(180000);
    test.use({viewport: {width: 1600, height: 900}});

    for (const arm of ARMS) test(arm.name, async ({page, neuralLink}) => {
        const consoleErrors = [];

        page.on('console', msg => msg.type() === 'error' && consoleErrors.push(`opener: ${msg.text().slice(0, 300)}`));
        page.on('pageerror', err => consoleErrors.push(`opener pageerror: ${String(err).slice(0, 300)}`));

        await page.goto('/apps/workstation/index.html');
        await page.waitForSelector('.workstation-dock-host',               {timeout: 60000});
        await page.waitForSelector('.neo-tab-header-button.neo-draggable', {timeout: 60000});

        const
            app         = await neuralLink.connectToApp('Workstation'),
            workspaceId = flatten(await app.findInstances({className: 'Workstation.view.Workspace'}, ['id']))[0]?.id,
            dockModel   = (await app.getComponent(workspaceId, ['dockModel'])).dockModel,
            nodeId      = Object.entries(dockModel.nodes || {}).find(([, node]) => node.type === 'tabs' && node.items?.includes(ITEM))?.[0],
            gridId      = await app.callMethod(workspaceId, 'getPaneIdentity', [ITEM]),
            chrome      = await app.callMethod(workspaceId, 'getTabChromeIdentity', [nodeId]);

        await page.locator(`#${chrome.buttons[ITEM]}`).click();
        await expect(page.locator(`#${gridId}`)).toBeVisible({timeout: 15000});

        // Editing on: the plugin behind the grid's own config, one column opted in.
        await app.setProperties(gridId, {cellEditing: true});

        const columnId = (await app.callMethod(gridId, 'columns.get', ['name']))?.id;

        expect(columnId, 'the name column resolves to an instance').toBeTruthy();
        await app.setProperties(columnId, {editable: true, ...(arm.editor ? {editor: arm.editor} : {})});

        await expect.poll(async () => !!(await safe(() => app.callMethod(gridId, 'getPlugin', ['grid-cell-editing'])))?.id,
            {message: 'the cell-editing plugin is installed', timeout: 15000}).toBe(true);

        const
            pluginId = (await app.callMethod(gridId, 'getPlugin', ['grid-cell-editing'])).id,
            box      = await page.locator(`#${gridId}`).boundingBox();

        // A scroll position the engine knows.
        await page.mouse.move(box.x + box.width / 2, box.y + box.height / 2);
        await page.mouse.wheel(0, 6000);
        await expect.poll(async () => (await app.getComponent(gridId, ['scrollManager.scrollTop']))['scrollManager.scrollTop'],
            {message: 'the engine holds a scroll position', timeout: 15000}).toBeGreaterThan(1000);
        await page.waitForTimeout(600);

        const viewId = (await app.getComponent(gridId, ['view.id']))['view.id'];

        const readScroll = async target => ({
            engine: await app.getComponent(gridId, ['scrollManager.scrollTop', 'windowId', 'mounted']),
            dom   : await safe(() => target.evaluate(id => document.getElementById(id)?.scrollTop ?? null, viewId))
        });

        const readSession = async () => {
            const
                session  = await safe(() => app.getComponent(pluginId, ['session.dataField', 'session.recordId', 'session.held', 'session.blurOwed', 'session.refocus', 'session.editor.id'])),
                editorId = session?.['session.editor.id'];

            return {session, editor: editorId ? await safe(() => app.getComponent(editorId, ['value', 'windowId', 'mounted', 'parentId'])) : null}
        };

        const readName = async recordId => (await safe(() => app.callMethod(gridId, 'store.get', [recordId])))?.name ?? null;

        const domEditors = async target => safe(() => target.evaluate(id => {
            const grid = document.getElementById(id);

            return {
                gridInDom: !!grid,
                editors  : grid ? [...grid.querySelectorAll('.neo-grid-editor input')].map(input => ({value: input.value, focused: document.activeElement === input})) : []
            }
        }, gridId));

        // A `name` cell of a row in the middle of the viewport.
        const nameCellId = await page.evaluate(id => {
            const
                grid = document.getElementById(id),
                rect = grid.getBoundingClientRect(),
                midY = rect.top + rect.height / 2,
                row  = [...grid.querySelectorAll('[role="row"]')].find(r => { const b = r.getBoundingClientRect(); return b.top <= midY && b.bottom >= midY && r.querySelector('[role="gridcell"]') });

            return row?.querySelector('[role="gridcell"][aria-colindex="2"]')?.id ?? null
        }, gridId);

        expect(nameCellId, 'a name cell is in the viewport').toBeTruthy();
        await page.locator(`[id="${nameCellId}"]`).dblclick();

        const editorInput = page.locator(`#${gridId} .neo-grid-editor input`).first();

        await expect(editorInput, 'the editor opens in the opener').toBeVisible({timeout: 10000});
        await editorInput.fill(arm.draft);
        await page.waitForTimeout(300);

        const
            before         = await readSession(),
            recordId       = before.session?.['session.recordId'],
            openerWindowId = await page.evaluate(() => Neo.worker.Manager.windowId),
            receipt        = {arm: arm.name, openerWindowId, before: {...before, name: await readName(recordId), scroll: await readScroll(page), dom: await domEditors(page)}};

        expect(before.session?.['session.dataField'], 'an edit session is open before the move').toBe('name');

        let target = page;

        if (arm.hop) {
            const
                actionsId    = flatten(await app.findInstances({className: 'Neo.dashboard.dock.plugin.HeaderActions'}, ['id']))[0]?.id,
                popupPromise = page.waitForEvent('popup', {timeout: 30000}),
                popOutResult = await safe(() => app.callMethod(actionsId, 'popOutDockItem', [{itemId: ITEM, pane: null}])),
                popup        = await popupPromise;

            popup.on('console', msg => msg.type() === 'error' && consoleErrors.push(`popup: ${msg.text().slice(0, 300)}`));
            popup.on('pageerror', err => consoleErrors.push(`popup pageerror: ${String(err).slice(0, 300)}`));

            await popup.waitForSelector('.workstation-viewport', {timeout: 30000});
            await expect(popup.locator(`#${gridId}`), 'the popup renders the live grid').toBeVisible({timeout: 20000});

            const popupWindowId = await popup.evaluate(() => Neo.worker.Manager.windowId);

            await expect.poll(async () => (await app.getComponent(gridId, ['windowId'])).windowId,
                {message: 'the grid belongs to the popup window', timeout: 15000}).toBe(popupWindowId);
            await popup.waitForTimeout(1500);

            target        = popup;
            receipt.after = {popOutErrors: popOutResult?.errors ?? popOutResult?.error ?? null, popupWindowId, ...(await readSession()), name: await readName(recordId), scroll: await readScroll(popup), dom: await domEditors(popup)}
        }

        // If an editor is there, can the person finish the edit with the keyboard in that window?
        if ((await domEditors(target))?.editors?.length) {
            const input = target.locator(`#${gridId} .neo-grid-editor input`).first();

            await input.click();
            await input.fill(`${DRAFT}-FINISHED`);
            await target.keyboard.press(arm.finishKey);
            await target.waitForTimeout(1000);

            receipt.finish = {key: arm.finishKey, ...(await readSession()), name: await readName(recordId), dom: await domEditors(target)}
        }

        receipt.consoleErrors = consoleErrors;
        console.log(`PROBE_RECEIPT ${JSON.stringify(receipt)}`)
    })
});
