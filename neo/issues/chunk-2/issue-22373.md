# Decompose Gantt moveTask into @protected seams and reactive keyboardLinkSource_

Owned maintainer slice of #22306 (`ai` + architecture/refactoring labels; curated contributor labels omitted because this is an active Engine 14.1 `3/10` focus slice self-assigned immediately).

## Context

`src/gantt/*` was rated `3/10` as Neo Engine classes in the 2026-11-27 architectural audit (#22306). Pass 1 (#22309 / PR #22317), Criterion 2 (#22343 / PR #22348), and Criterion 3 Slice A (#22366 / PR #22367) have landed on `dev` (`8d0276127c`). Per the Criterion 3 design on [#22306 (comment 7222112719)](https://github.com/neomjs/neo/issues/22306#issuecomment-7222112719), this ticket delivers **Slice B**: decomposing `Neo.gantt.Container#moveTask` (`275` LOC, `8` exits) into focused `@protected` policy and lifecycle seams, deduplicating `rescheduleWorkingTime`'s write/publish tail, converting `Container`'s six remaining `#private` methods into documented `@protected` methods (`publishTaskChange` taking one options object), and turning `#keyboardLinkSource` / `#setKeyboardLinkSource` into a reactive `keyboardLinkSource_` config.

## The Problem

In `src/gantt/Container.mjs` (`1,676` LOC at `8d0276127c`):

1. **Monolithic `moveTask` (`Container.mjs:965-1239`, `275` lines, `8` return sites):** Date coercion, minimum-duration enforcement, working-calendar snapping/preservation, visible-axis clamping, field-patch construction, derived-parent & schedule-service refusal checks, external service consultation, store/cascade writes, and `taskChange` publication live inline in one method. A subclass cannot customize minimum duration, working-time adjustment, or axis clamping without copying `moveTask`.
2. **Duplicated write & publish tail in `rescheduleWorkingTime` (`Container.mjs:1444-1476`):** `rescheduleWorkingTime` repeats `_movingTask` guarding, analysis invalidation, `moveCascade`, `syncDependencyLayer()`, `dependencyCycle` emission, and `publishTaskChange`.
3. **7 `#private` methods & imperative `#keyboardLinkSource` state blocking `Neo.overwrites` and subclassing:** `#ensureKeyboardLinkStatus`, `#motion`, `#moveCascade`, `#publishServiceResult`, `#publishTaskChange` (taking 8 positional arguments), `#setKeyboardLinkSource`, and `#usesService` are `#private` (`CODING_GUIDELINES.md` §8 rule 29a), while `#keyboardLinkSource` is mutated imperatively across 4 call sites instead of reactive `core.Base` config hooks.

## The Architectural Reality

Design authority: *"Put replaceable behavior in public or `@protected` methods so subclasses, mixins, and `Neo.overwrites` can specialize it."* (`.github/CODING_GUIDELINES.md` §8 rule 29a), `src/core/Base.mjs` (`beforeSet*` / `afterSet*` reactive config lifecycle), `learn/guides/fundamentals/ExtendingNeoClasses.md`, and [#22306 comment 7222112719](https://github.com/neomjs/neo/issues/22306#issuecomment-7222112719).

- `Neo.scheduler.Container` (`src/scheduler/Container.mjs`) exposes `@protected` timeline edit hooks (`normalizeMoveEventArgs`, `resolveEventRecord`, `commitTimelineEdit`) without colliding with Gantt's task-edit seam names.
- `EventDragZone`'s `linkTarget_` reactive config (planned in Criterion 4) shares the exact reactive endpoint pattern needed for `keyboardLinkSource_` on `Neo.gantt.Container`: setting `this.keyboardLinkSource = record ? {record, barId} : null` resolves the mounted row in `beforeSetKeyboardLinkSource` and updates `#keyboardLinkStatus.text` plus old/new row VDOM in `afterSetKeyboardLinkSource`.
- `_movingTask` shrinks from 4 `try/finally` sites to at most 2 (the write seam and external service consultation); replacing `_movingTask` itself remains Criterion 4 scope on #22306.

## The Fix

1. **Decompose `moveTask` into six `@protected` template steps + three date-policy sub-seams (`src/gantt/Container.mjs`):**
   - Preserve `moveTask(taskIdOrRecord, changes={}, meta={})`'s exact public signature, return values, and events.
   - Factor its body into six `@protected` seams:
     - `resolveTaskEditDates(record, changes, meta)` — resolves proposed/previous timestamps and flags, delegating to `@protected` `getMinimumTaskDurationMs(record, axis)`, `applyWorkingTimeToTaskDates(span, meta, axis)`, and `clampTaskDatesToAxis(span, meta, axis)`.
     - `buildTaskUpdates(record, changes, resolvedDates)` — builds the normalized `updates` map (including derived `duration` when task dates change).
     - `getTaskEditRefusal(record, updates)` — returns `{status: 'refused', message}` for derived parents or mismatched schedule services, else `null`.
     - `consultScheduleService(record, updates, meta)` — handles `schedule.moveTask` consultation, `_movingTask` fencing, synchronous `publishServiceResult`, and `onDecisionSettled` registration.
     - `writeTaskEdit(record, updates, meta)` / shared batch writer — applies `rollupParents` (`store.updateRows`) or direct `record.set` + `cascade.runDependencyCascade` under `_movingTask`, invalidates `#analysis`, triggers `moveCascade`, syncs `dependencyLayer`, and fires `dependencyCycle` (reused by `rescheduleWorkingTime` to eliminate its duplicated tail).
     - `publishTaskChange({cascaded, cycles, endMs, meta, previous, record, startMs, updates})` — replaces the 8-argument `#publishTaskChange` with one object parameter, shared across `moveTask`, `publishServiceResult`, and `rescheduleWorkingTime`.
2. **Convert Container's remaining `#private` methods & `#keyboardLinkSource`:**
   - Convert `#ensureKeyboardLinkStatus`, `#motion`, `#moveCascade`, `#publishServiceResult`, `#publishTaskChange`, and `#usesService` to documented `@protected` methods (`ensureKeyboardLinkStatus`, `motion`, `moveCascade`, `publishServiceResult`, `publishTaskChange`, `usesService`) in alphabetical order.
   - Replace `#keyboardLinkSource` and `#setKeyboardLinkSource` with reactive config `keyboardLinkSource_: null` (`@protected`), normalizing `{record, barId, row}` in `beforeSetKeyboardLinkSource` and updating `#keyboardLinkStatus.text` + previous/current row VDOM in `afterSetKeyboardLinkSource`.

## Acceptance Criteria

- [ ] AC-1 `Neo.gantt.Container#moveTask` keeps its signature, return values, and events while delegating to the six `@protected` template seams (`resolveTaskEditDates`, `buildTaskUpdates`, `getTaskEditRefusal`, `consultScheduleService`, `writeTaskEdit`, `publishTaskChange`) plus the three `@protected` date-policy seams (`getMinimumTaskDurationMs`, `applyWorkingTimeToTaskDates`, `clampTaskDatesToAxis`).

- [ ] AC-3 `#ensureKeyboardLinkStatus`, `#motion`, `#moveCascade`, `#publishServiceResult`, `#publishTaskChange` (single object parameter), and `#usesService` become documented `@protected` methods in alphabetical order, `#keyboardLinkSource` / `#setKeyboardLinkSource` become reactive `keyboardLinkSource_` with `beforeSet`/`afterSet` hooks, and `grep -n -E '^\s+#[a-zA-Z]+\(' src/gantt/Container.mjs` prints nothing.
- [ ] AC-4 All existing Gantt unit specs (`test/playwright/unit/gantt/*.spec.mjs`) pass with their assertions unchanged, plus a new `Neo.gantt.Container` subclass spec arm that overrides minimum duration and axis clamping without copying `moveTask`, and `npm run generate-docs-json` + `pr-baseline` guards pass.

## Avoided Traps

- **Turning `#setKeyboardLinkSource` into a Java-style setter method:** `#22306#issuecomment-7222112719` explicitly makes it a reactive `keyboardLinkSource_` config (rule 2's first exception), matching Criterion 4's `linkTarget_` pattern.
- **Reading `#private` fields inside policy seams:** Policy methods a subclass replaces (`getMinimumTaskDurationMs`, `applyWorkingTimeToTaskDates`, `clampTaskDatesToAxis`, `buildTaskUpdates`, `getTaskEditRefusal`) take explicit inputs and return values without touching `#` fields.
- **Keeping 8 positional arguments on `publishTaskChange`:** Replaced by one destructured options object so subclass wrappers/overrides stay readable and order-independent.
