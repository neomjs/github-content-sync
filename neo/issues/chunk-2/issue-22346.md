# themeEqualityMatrix targets retired .neo-theme-switcher class on dev

## Context

Fixes the `dev-red` CI regression in `components (1/3)` caused by cross-in-flight merge skew between #22308 (`2026-11-27T10:32:03Z`, adding `buildScripts/util/themeEqualityMatrix.mjs`) and #22327 (`2026-11-27T10:39:50Z`, renaming `Neo.button.ThemeSwitcher` classes from `.neo-theme-switcher` to `.neo-themeswitcher` for #22326). Promoted from `@neo-gemini-maryam`'s `defect-note` (`MESSAGE:37089299`) and split out ahead of #22344 (#22299) so `dev` turns green immediately for in-flight `components`-tier PRs (#22325, #22323).

## The Problem

Both #22308 and #22327 passed CI against their respective pre-merge `dev` bases and merged 7 minutes apart without an intermediate rebase. On current `dev`, every PR run triggering `components (1/3)` (`test/playwright/component/buildScripts/ThemeEquality.spec.mjs`) fails with:

```text
Error: Unmatched DOM selectors in theme-equality stage:
  - theme-switcher: missing stateTargetSelector ".neo-theme-switcher"
```

## The Architectural Reality

- Design authority: `"The class prefix neo-theme- is reserved. neo-theme-<name> is a theme; neo-theme-scope is a scope that keeps its theme."` (`learn/agentos/decisions/0044-design-system.md` §2.7 & §2.10 I4; `src/button/ThemeSwitcher.mjs:29` `baseCls: ['neo-button', 'neo-themeswitcher']`).
- Prescription checked: `buildScripts/util/themeEqualityMatrix.mjs` — owns the concern. Repo-wide `git grep -n "neo-theme-switcher" origin/dev` confirms lines `205` and `207` of `buildScripts/util/themeEqualityMatrix.mjs` are the sole remaining runtime/probe occurrences outside negative test fixtures in `test/playwright/unit/buildScripts/util/check-theme-class-prefix.spec.mjs`.
- Decision Record impact: aligned-with `adr:0044-design-system`

## The Fix

Update the `theme-switcher` probe entry in `buildScripts/util/themeEqualityMatrix.mjs`:
- Line `205`: `stateTargetSelector: '.neo-themeswitcher'`
- Line `207`: `parts: ['.neo-themeswitcher', '.neo-button-glyph']`

## Acceptance Criteria

- [ ] `buildScripts/util/themeEqualityMatrix.mjs` lines `205` and `207` target `.neo-themeswitcher` instead of retired `.neo-theme-switcher`.
