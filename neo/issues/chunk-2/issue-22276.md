# Delete the unconsumed design-token export in resources/design-tokens

Live latest-open + closed sweep: checked the latest 20 open issues, an open and closed search (design tokens, json export, delete, remove), open pull requests naming the folder, the mailbox for claims since 22:10Z, one Memory Core query and my own assignments at 2026-11-26 22:43Z; no equivalent or prior exclusion found. Backlog band: 43 open (orange); no ticket or epic owns theming, so this is filed.

## Context

`resources/design-tokens/json/` holds `component.json`, `core.json` and `semantic.json`: a Figma token export from 2023, last touched on 2024-02-18. Its content was moved into the Neo themes' `Global.css` long ago. The operator asked for the folder to go (26 Nov): core and semantic tokens stay, as CSS, and the `--cmp-*` layer does not.

## The Problem

Three files read like a token source and are none. A model or a contributor who finds them takes them for the authority, edits them, and nothing changes: no script reads them. The design-system work in the Ideation Sandbox makes that worse, because it is about to change the token layers these files describe.

## The Architectural Reality

- No tracked file outside the folder contains the string `design-tokens` (`git grep` on `dev` at `0c1cc8eb58`).
- The converter that once read the export, `buildScripts/helpers/convertDesignTokens.mjs`, no longer exists; only archived ticket titles mention it.
- `package.json` has no `files` field and `.npmignore` does not name the folder, so the three files ship in the npm package today.

## The Fix

`git rm -r resources/design-tokens`. Nothing else.

## Acceptance Criteria

- [ ] `resources/design-tokens/` is gone from `dev`.
- [ ] `git grep design-tokens` returns nothing in tracked files.
- [ ] The theme guards and the package-contents spec stay green.

## Out of Scope

- The `--cmp-*` block in the Neo themes' `Global.css` and its 146 reads in 22 files: the design-system migration's first leaf, after the Discussion graduates.
- `neomjs/neo-agent-institution`'s `convert-design-tokens` script, which points at the converter that no longer exists: a `defect-note` for that repository.

## Decision Record impact

None. The Discussion's option of a generated token source would start from a new source, not from this export.
