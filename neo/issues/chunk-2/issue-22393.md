## Context

That is the accent's hue, not the brand's. Theme Neo keeps chrome neutral: the `tab` indicator reads `background-inverse`, the grid's header label `text-muted`. Accent marks what acts (a link, a selection, the focus), brand marks identity, and a title in either colour reads as one of those.

- `--neo-dialog-icon-color` reads `text-muted`: 9.64 · 5.46.

An accent title is a theme's per-widget line; the Material pair may write one.

**1. Light reads 32 % black. Dark keeps 50 % black.**

The dimmed page against the page (`background-surface`), measured with the palette check's functions:

| Mask | Light | Dark |
| :--- | ---: | ---: |
| Today's `rgba(100, 100, 100, .5)` | 2.10:1 | 1.67:1, lighter than the page |
| Black 16 %, the role as landed | 1.45:1 | |
| Black 32 % | 2.23:1 | |
| Black 50 % | 3.94:1 | 1.05:1 |

- **16 %** dims the page 1.45:1 where today's mask dims it 2.10:1. In the frame the page's title and toolbar keep their full weight, and nothing says the page is blocked.
- **32 %** is today's weight within 0.13. Black leaves dark text dark, where the grey mask lifts it toward grey. The move changes the tone and keeps the weight.
- **50 %** nearly doubles today's weight. On a dense desktop screen every dialog would drop the page to mid-grey.
- **Dark:** today's grey lifts the page above the dialog's own surface. Black 50 % dims the content and leaves the background where it is, so the dialog is carried by its edge and its raised header. That is the role as landed, and it stands.

**2. The palette gains a step, in order.** Four lines in `theme-neo/Global.css`:

```css
--neo-palette-shade-4        : rgb(0 0 0 / .32);
--neo-palette-shade-5        : rgb(0 0 0 / .5);
--neo-color-background-scrim : light-dark(var(--neo-palette-shade-4), var(--neo-palette-shade-5));
--neo-color-shadow           : light-dark(var(--neo-palette-shade-3), var(--neo-palette-shade-5));
```

`PALETTE_EXTRAS` in `themeNameShapes.mjs` gains `'--neo-palette-shade-5'`. On `dev` at `68823a94c7` the old `shade-4` has two readers, both dark values (the scrim and the shadow), and both move to `shade-5`. The only paint that changes is the light scrim.
