# A theme census script reports layers, dead tokens and literals

Live latest-open + closed sweep: checked the latest 20 open issues, open and closed searches (theme census, custom properties, css variables, tokens, theme guard, unused css variables, dead tokens; `Out of Scope` and `Avoided Traps` read on `#18145`, `#18107`, `#20591`), the mailbox for claims since 21:36Z, one Memory Core query and my own assignments at 2026-11-26 21:44Z; no equivalent or prior exclusion found. Backlog band: 40 open (orange); no ticket or epic owns theming, so this is filed.

## Context

The design system for 14.1 is being decided in the Ideation Sandbox from counts of `resources/css`. On 26 Nov three seats counted the same tree with private scripts and published different numbers for the same questions:

- `--cmp-*` properties no CSS reads: 34 (the Discussion body, at `7cc7dfe9a3`), 33 (Maryam, six repositories), 34 (mine, at `0e54f119e6`). The difference is one commented-out declaration.
- Structural reads that no file resolves: 13 / 271 / 608 (Maryam) against 4 / 46 / 349 (mine), from two miss rules. I first published 10 / 52 / 355 and corrected it: six properties are set at runtime.

A count that decides a contract needs one instrument in the repository that any reviewer can run.

## The Problem

The four theme guards in `buildScripts/util` answer pass or fail on four rules: `check-theme-var-references` (a fallback-free `var()` inside a theme file resolves), `check-theme-value-files` (theme files declare variables, never selectors), `check-theme-coverage` (a package is themed in both Neo themes) and `check-theme-surfaces` (parity and token-only colours for Workstation). None of them reports the shape of the tree: how many properties each layer holds, how values are routed, what a light and dark pair really differs in, which tokens nothing reads. Every proposal therefore re-derives those counts, and nobody can re-run another seat's number.

## The Architectural Reality

- `resources/css/src/**` holds the structural rules, `resources/css/theme-*/**` the value files. A theme folder also carries `apps/` and `examples/` files (Neo pair: 91 engine, 28 app and 38 example files each), so every count needs that split.
- `buildScripts/util/check-theme-var-references.mjs` is the sibling to follow and to reuse: a pure collector over an injectable root (`collectThemeVarReferenceFailures`), `cssFiles`, comment stripping that keeps line numbers, a thin CLI, and the isolated spec `test/playwright/unit/buildScripts/checkThemeVarReferences.spec.mjs`.
- Its `RUNTIME_PROPERTIES` lists one property a third-party stylesheet sets (`--fa-style-family-classic`). Five more are set from JavaScript and read by structural rules: `--desktop-app-color`, `--neo-duration`, `--neo-easing`, `--neo-tree-level`, `--upload-progress`.

## The Fix

`buildScripts/util/theme-census.mjs`: a pure `collectThemeCensus({root})` and a CLI behind `npm run theme-census` (a Markdown table by default, the object with `--json`). Read-only: no baseline, no failing exit code on a finding, no workflow.

Per theme, split into engine, app and example files:

1. Files, and unique custom properties per layer (palette and `--core-*`, `--sem-*`, `--cmp-*`, component).
2. What a component value is made of: `--sem-*`, `--cmp-*`, a palette value, another variable, a colour literal, another literal.
3. Per light and dark pair: shared names, identical and differing values, per layer.
4. Component names shared by all full themes.
5. Declared and never read by any CSS under the root, per layer.
6. Structural reads without a fallback that neither the theme nor a structural file declares, minus the runtime list.
7. Colour literals in structural rules, per file.
8. Naming: the words in use for a background, a text colour and an icon colour, and where a state word sits.

Reference counts for the first run are rows 1 to 9 of [this comment](https://github.com/neomjs/neo/discussions/22228#discussioncomment-19933845); the scripts that produced them follow below as a comment.

- **Folding the report into a guard.** A guard answers pass or fail and carries a baseline; this informs a decision that is not made yet.

```python
#!/usr/bin/env python3
"""Theme census for the design-system proposal. Usage: census.py <neo checkout>"""
import collections
import os
import re
import sys

ROOT = sys.argv[1]
CSS  = os.path.join(ROOT, 'resources', 'css')

COMMENT = re.compile(r'/\*.*?\*/', re.S)
DECL    = re.compile(r'(?<![\w-])(--[A-Za-z0-9_-]+)\s*:\s*([^;{}]+);')
READ    = re.compile(r'var\(\s*(--[A-Za-z0-9_-]+)\s*([,)])')
COLOR   = re.compile(r'#[0-9a-fA-F]{3,8}\b|\brgba?\(|\bhsla?\(')

PRIMITIVE = re.compile(r'^--(core-|gray-|purple-|green-|red-|orange-|yellow-|blue-|spacing-|height-|borderradius-|white|black|Transparent)')


def files(base):
    for d, _, names in os.walk(base):
        for n in names:
            if n.endswith('.css'):
                yield os.path.join(d, n)


def text(path):
    with open(path, encoding='utf-8') as f:
        return COMMENT.sub('', f.read())


def layer(name):
    if name.startswith('--sem-'):  return 'sem'
    if name.startswith('--cmp-'):  return 'cmp'
    if PRIMITIVE.match(name):      return 'core'
    if name.startswith('--neo-') or name.startswith('--global-'): return 'global'
    return 'component'


def theme_decls(theme):
    """name -> list of (relative file, value)"""
    out  = collections.defaultdict(list)
    base = os.path.join(CSS, theme)
    n    = 0
    for p in files(base):
        n += 1
        rel = os.path.relpath(p, base)
        for name, value in DECL.findall(text(p)):
            out[name].append((rel, ' '.join(value.split())))
    return out, n


themes = sorted(t for t in os.listdir(CSS) if t.startswith('theme-'))
decls  = {}

print('== 1. per theme: files, unique custom properties, by layer')
for t in themes:
    d, n = theme_decls(t)
    decls[t] = d
    by = collections.Counter(layer(k) for k in d)
    print(f'{t:18} files={n:4} unique={len(d):5} core={by["core"]:4} sem={by["sem"]:4} cmp={by["cmp"]:4} global={by["global"]:3} component={by["component"]:5}')

print('\n== 2. what a component-layer value is made of (first declaration per name)')
for t in themes:
    kinds = collections.Counter()
    for name, rows in decls[t].items():
        if layer(name) != 'component':
            continue
        value = rows[0][1]
        refs  = [r for r, _ in READ.findall(value)]
        if not refs:
            kinds['literal-color' if COLOR.search(value) else 'literal-other'] += 1
            continue
        ls = {layer(r) for r in refs}
        if   'cmp' in ls:       kinds['via cmp'] += 1
        elif 'sem' in ls:       kinds['via sem'] += 1
        elif 'core' in ls:      kinds['via core primitive'] += 1
        elif 'global' in ls:    kinds['via neo/global'] += 1
        else:                   kinds['via another component var'] += 1
    total = sum(kinds.values())
    print(t, total, dict(kinds.most_common()))

print('\n== 3. pairs: how much of the component layer is identical between a light and a dark sibling')
for a, b in (('theme-neo-dark', 'theme-neo-light'), ('theme-dark', 'theme-light')):
    da = {k: v[0][1] for k, v in decls[a].items() if layer(k) == 'component'}
    db = {k: v[0][1] for k, v in decls[b].items() if layer(k) == 'component'}
    both  = set(da) & set(db)
    same  = sum(1 for k in both if da[k] == db[k])
    print(f'{a} vs {b}: both={len(both)} identical={same} differ={len(both) - same} only-{a}={len(set(da) - set(db))} only-{b}={len(set(db) - set(da))}')
    # of the differing ones, how many are literal colours on both sides
    lit = sum(1 for k in both if da[k] != db[k] and not READ.search(da[k]) and not READ.search(db[k]))
    print(f'   of the differing: literal on both sides={lit}')
    for lay in ('sem', 'cmp', 'core'):
        sa = {k: v[0][1] for k, v in decls[a].items() if layer(k) == lay}
        sb = {k: v[0][1] for k, v in decls[b].items() if layer(k) == lay}
        bo = set(sa) & set(sb)
        print(f'   {lay}: both={len(bo)} identical={sum(1 for k in bo if sa[k] == sb[k])} differ={sum(1 for k in bo if sa[k] != sb[k])}')

print('\n== 4. naming grammar over the component layer of theme-neo-dark')
STATES = ('hover', 'active', 'disabled', 'pressed', 'selected', 'focus', 'focused', 'checked', 'invalid', 'readonly', 'empty', 'open', 'dragover', 'over')
names  = [k for k in decls['theme-neo-dark'] if layer(k) == 'component']
end = mid = none = 0
mid_examples = []
for n in names:
    parts = n[2:].split('-')
    idx   = [i for i, p in enumerate(parts) if p in STATES]
    if not idx:
        none += 1
    elif idx[-1] == len(parts) - 1 and len(idx) == 1:
        end += 1
    else:
        mid += 1
        if len(mid_examples) < 12:
            mid_examples.append(n)
print(f'names={len(names)} no-state={none} state-as-last-word={end} state-elsewhere-or-twice={mid}')
print('   examples:', ', '.join(mid_examples))
tails = collections.Counter()
for n in names:
    parts = [p for p in n[2:].split('-') if p not in STATES]
    tails['-'.join(parts[-2:])] += 1
print('   distinct two-word property tails:', len(tails))
print('   top tails:', tails.most_common(14))
syn = collections.Counter()
for n in names:
    for word in ('background-color', '-bg-', '-bg', 'surface', '-color', 'text-color', '-fg', 'font-color', 'glyph-color', 'icon-color'):
        if word in n:
            syn[word] += 1
print('   synonyms in use:', dict(syn))

print('\n== 5. structural CSS (resources/css/src, engine only, without apps/ and examples/)')
src      = os.path.join(CSS, 'src')
reads    = collections.Counter()
nofall   = set()
literals = 0
lit_files = collections.Counter()
nfiles   = 0
for p in files(src):
    rel = os.path.relpath(p, src)
    if rel.startswith(('apps' + os.sep, 'examples' + os.sep)):
        continue
    nfiles += 1
    t = text(p)
    for name, close in READ.findall(t):
        reads[name] += 1
        if close == ')':
            nofall.add(name)
    # colour literals outside custom-property declarations
    body = DECL.sub('', t)
    c = len(COLOR.findall(body))
    if c:
        literals += c
        lit_files[rel] = c
print(f'files={nfiles} distinct vars read={len(reads)} read without fallback={len(nofall)}')
for t in themes:
    missing = [n for n in nofall if n not in decls[t]]
    print(f'   {t}: read without fallback and not declared by the theme = {len(missing)}')
print(f'colour literals in structural rules={literals} in {len(lit_files)} files; top:', lit_files.most_common(8))
dead = [k for k in decls['theme-neo-dark'] if layer(k) == 'component' and k not in reads]
allreads = set(reads)
for t in themes:
    for p in files(os.path.join(CSS, t)):
        for name, _ in READ.findall(text(p)):
            allreads.add(name)
for p in files(src):
    for name, _ in READ.findall(text(p)):
        allreads.add(name)
dead = [k for k in decls['theme-neo-dark'] if k not in allreads]
by = collections.Counter(layer(k) for k in dead)
print(f'theme-neo-dark: declared and never read by any CSS under resources/css = {len(dead)}', dict(by))

print('\n== 6. apps and examples re-valuing engine variables in CSS (resources/css/src/apps|examples)')
engine = set()
for t in themes:
    for k, rows in decls[t].items():
        if any(not r[0].startswith(('apps' + os.sep, 'examples' + os.sep)) for r in rows):
            engine.add(k)
for area in ('apps', 'examples'):
    per = collections.Counter()
    allv = set()
    for p in files(os.path.join(src, area)):
        rel = os.path.relpath(p, os.path.join(src, area)).split(os.sep)[0]
        for name, _ in DECL.findall(text(p)):
            if name in engine:
                per[rel] += 1
                allv.add(name)
    print(f'{area}: {sum(per.values())} declarations of {len(allv)} engine variables in {len(per)} folders; top:', per.most_common(8))

print('\n== 7. theme folders that carry app or example files')
for t in themes:
    base = os.path.join(CSS, t)
    for area in ('apps', 'examples'):
        d = os.path.join(base, area)
        if os.path.isdir(d):
            print(f'   {t}/{area}: {sum(1 for _ in files(d))} files in {len(os.listdir(d))} folders')
```

```python
#!/usr/bin/env python3
"""Second pass: distinct colours, state-word position, undeclared reads, sample rows. Usage: census2.py <neo checkout>"""
import collections
import os
import re
import sys

ROOT = sys.argv[1]
CSS  = os.path.join(ROOT, 'resources', 'css')

COMMENT = re.compile(r'/\*.*?\*/', re.S)
DECL    = re.compile(r'(?<![\w-])(--[A-Za-z0-9_-]+)\s*:\s*([^;{}]+);')
READ    = re.compile(r'var\(\s*(--[A-Za-z0-9_-]+)\s*([,)])')
HEX     = re.compile(r'#[0-9a-fA-F]{3,8}\b')
FUNC    = re.compile(r'\b(?:rgba?|hsla?)\([^)]*\)')
PRIMITIVE = re.compile(r'^--(core-|gray-|purple-|green-|red-|orange-|yellow-|blue-|spacing-|height-|borderradius-|white|black|Transparent)')


def files(base):
    for d, _, names in os.walk(base):
        for n in names:
            if n.endswith('.css'):
                yield os.path.join(d, n)


def text(path):
    with open(path, encoding='utf-8') as f:
        return COMMENT.sub('', f.read())


def layer(name):
    if name.startswith('--sem-'):  return 'sem'
    if name.startswith('--cmp-'):  return 'cmp'
    if PRIMITIVE.match(name):      return 'core'
    return 'component'


def norm(c):
    c = c.lower().replace(' ', '')
    if c.startswith('#') and len(c) == 4:
        c = '#' + ''.join(ch * 2 for ch in c[1:])
    return c


themes = sorted(t for t in os.listdir(CSS) if t.startswith('theme-'))
decls  = {}
for t in themes:
    d = collections.defaultdict(list)
    base = os.path.join(CSS, t)
    for p in files(base):
        rel = os.path.relpath(p, base)
        for name, value in DECL.findall(text(p)):
            d[name].append((rel, ' '.join(value.split())))
    decls[t] = d

print('== A. colour literals in the component layer: declarations and distinct colours (engine files only, no apps/examples)')
for t in themes:
    n = 0
    colours = collections.Counter()
    for name, rows in decls[t].items():
        if layer(name) != 'component':
            continue
        for rel, value in rows:
            if rel.startswith(('apps' + os.sep, 'examples' + os.sep)):
                continue
            found = HEX.findall(value) + FUNC.findall(value)
            if found and not READ.search(value):
                n += 1
            for c in found:
                colours[norm(c)] += 1
    top = sum(c for _, c in colours.most_common(24))
    print(f'{t:18} literal-colour declarations={n:5} distinct colours={len(colours):4} the 24 most used cover {top} of {sum(colours.values())} uses')

print('\n== B. where the state word sits (component layer, theme-neo-dark, engine files only)')
STATES = ('hover', 'active', 'disabled', 'pressed', 'selected', 'focus', 'focused', 'checked', 'invalid', 'readonly')
names  = set()
for name, rows in decls['theme-neo-dark'].items():
    if layer(name) == 'component' and any(not r[0].startswith(('apps' + os.sep, 'examples' + os.sep)) for r in rows):
        names.add(name)
last = notlast = 0
ex_last, ex_mid = [], []
for n in sorted(names):
    parts = n[2:].split('-')
    idx   = [i for i, p in enumerate(parts) if p in STATES and i > 0]
    if not idx:
        continue
    if idx[-1] == len(parts) - 1:
        last += 1
        if len(ex_last) < 4: ex_last.append(n)
    else:
        notlast += 1
        if len(ex_mid) < 8: ex_mid.append(n)
print(f'engine component names={len(names)} with a state word: last={last} not-last={notlast}')
print('   last:', ', '.join(ex_last))
print('   not last:', ', '.join(ex_mid))
bg = collections.Counter()
for n in names:
    if re.search(r'-background-color(-|$)', n): bg['background-color'] += 1
    elif re.search(r'-background(-|$)', n):     bg['background'] += 1
    elif re.search(r'-bg(-|$)', n):             bg['bg'] += 1
    elif re.search(r'-surface(-|$)', n):        bg['surface'] += 1
print('   words for a background:', dict(bg))
fg = collections.Counter()
for n in names:
    if re.search(r'-text-color(-|$)', n):   fg['text-color'] += 1
    elif re.search(r'-font-color(-|$)', n): fg['font-color'] += 1
    elif re.search(r'-fg(-|$)', n):         fg['fg'] += 1
    elif re.search(r'-text(-|$)', n):       fg['text'] += 1
    elif re.search(r'(?<!background)(?<!border)(?<!glyph)(?<!icon)-color(-|$)', n): fg['color'] += 1
print('   words for a text colour:', dict(fg))
ic = collections.Counter()
for n in names:
    if re.search(r'-glyph-color(-|$)', n):  ic['glyph-color'] += 1
    elif re.search(r'-icon-color(-|$)', n): ic['icon-color'] += 1
print('   words for an icon colour:', dict(ic))

print('\n== C. engine structural reads no theme file and no structural file declares')
src     = os.path.join(CSS, 'src')
reads   = {}
srcdecl = set()
for p in files(src):
    rel = os.path.relpath(p, src)
    t = text(p)
    for name, _ in DECL.findall(t):
        srcdecl.add(name)
    if rel.startswith(('apps' + os.sep, 'examples' + os.sep)):
        continue
    for name, close in READ.findall(t):
        reads.setdefault(name, set()).add(close)
nofall = {n for n, c in reads.items() if c == {')'}}
for t in themes:
    miss = sorted(n for n in nofall if n not in decls[t] and n not in srcdecl)
    print(f'   {t}: {len(miss)}', '· e.g.', ', '.join(miss[:5]))

print('\n== D. sample: component names whose value differs between neo-dark and neo-light, literal on both sides')
a = {k: v[0][1] for k, v in decls['theme-neo-dark'].items() if layer(k) == 'component'}
b = {k: v[0][1] for k, v in decls['theme-neo-light'].items() if layer(k) == 'component'}
shown = 0
for k in sorted(a):
    if k in b and a[k] != b[k] and not READ.search(a[k]) and not READ.search(b[k]):
        print(f'   {k}: {a[k]}  |  {b[k]}')
        shown += 1
        if shown == 8:
            break
fam = collections.Counter()
for k in a:
    if k in b and a[k] != b[k] and not READ.search(a[k]) and not READ.search(b[k]):
        fam[decls['theme-neo-dark'][k][0][0].split(os.sep)[0]] += 1
print('   by folder:', fam.most_common(12))

print('\n== E. sem and cmp tokens never read by any CSS under resources/css (theme-neo-dark)')
allreads = set()
for base in [src] + [os.path.join(CSS, t) for t in themes]:
    for p in files(base):
        for name, _ in READ.findall(text(p)):
            allreads.add(name)
for lay in ('sem', 'cmp'):
    names_l = [k for k in decls['theme-neo-dark'] if layer(k) == lay]
    dead    = [k for k in names_l if k not in allreads]
    print(f'   {lay}: {len(dead)} of {len(names_l)} never read')
```

```python
#!/usr/bin/env python3
"""Third pass, engine files only (theme files outside apps/ and examples/). Usage: census3.py <neo checkout>"""
import collections
import os
import re
import sys

ROOT = sys.argv[1]
CSS  = os.path.join(ROOT, 'resources', 'css')

COMMENT = re.compile(r'/\*.*?\*/', re.S)
DECL    = re.compile(r'(?<![\w-])(--[A-Za-z0-9_-]+)\s*:\s*([^;{}]+);')
READ    = re.compile(r'var\(\s*(--[A-Za-z0-9_-]+)\s*([,)])')
COLOR   = re.compile(r'#[0-9a-fA-F]{3,8}\b|\brgba?\(|\bhsla?\(')
PRIMITIVE = re.compile(r'^--(core-|gray-|purple-|green-|red-|orange-|yellow-|blue-|spacing-|height-|borderradius-|white|black|Transparent)')
AREAS   = ('apps' + os.sep, 'examples' + os.sep)


def files(base):
    for d, _, names in os.walk(base):
        for n in names:
            if n.endswith('.css'):
                yield os.path.join(d, n)


def text(path):
    with open(path, encoding='utf-8') as f:
        return COMMENT.sub('', f.read())


def layer(name):
    if name.startswith('--sem-'):  return 'sem'
    if name.startswith('--cmp-'):  return 'cmp'
    if PRIMITIVE.match(name):      return 'core'
    return 'component'


themes = sorted(t for t in os.listdir(CSS) if t.startswith('theme-'))
eng, area_files = {}, {}
for t in themes:
    d = {}
    base = os.path.join(CSS, t)
    cnt  = collections.Counter()
    for p in files(base):
        rel = os.path.relpath(p, base)
        a   = 'apps' if rel.startswith(AREAS[0]) else 'examples' if rel.startswith(AREAS[1]) else 'engine'
        cnt[a] += 1
        if a != 'engine':
            continue
        for name, value in DECL.findall(text(p)):
            d.setdefault(name, ' '.join(value.split()))
    eng[t] = d
    area_files[t] = cnt

print('== files per theme by area, and engine-only unique custom properties')
for t in themes:
    by = collections.Counter(layer(k) for k in eng[t])
    print(f'{t:18} engine={area_files[t]["engine"]:3} apps={area_files[t]["apps"]:3} examples={area_files[t]["examples"]:3} | unique={len(eng[t]):5} core={by["core"]:3} sem={by["sem"]:3} cmp={by["cmp"]:3} component={by["component"]:5}')

print('\n== engine-only component layer: what a value is made of')
for t in themes:
    kinds = collections.Counter()
    for name, value in eng[t].items():
        if layer(name) != 'component':
            continue
        refs = [r for r, _ in READ.findall(value)]
        if not refs:
            kinds['colour literal' if COLOR.search(value) else 'other literal'] += 1
            continue
        ls = {layer(r) for r in refs}
        if   'cmp' in ls:  kinds['via cmp'] += 1
        elif 'sem' in ls:  kinds['via sem'] += 1
        elif 'core' in ls: kinds['via core'] += 1
        else:              kinds['via another component or neo var'] += 1
    print(f'{t:18} {sum(kinds.values()):5}', dict(kinds.most_common()))

print('\n== engine-only pairs')
for a, b in (('theme-neo-dark', 'theme-neo-light'), ('theme-dark', 'theme-light')):
    da = {k: v for k, v in eng[a].items() if layer(k) == 'component'}
    db = {k: v for k, v in eng[b].items() if layer(k) == 'component'}
    both = set(da) & set(db)
    same = sum(1 for k in both if da[k] == db[k])
    lit  = sum(1 for k in both if da[k] != db[k] and not READ.search(da[k]) and not READ.search(db[k]))
    col  = sum(1 for k in both if da[k] != db[k] and (COLOR.search(da[k]) or COLOR.search(db[k])))
    print(f'{a} vs {b}: shared names={len(both)} identical={same} differ={len(both) - same} (literal on both sides={lit}; a colour literal on either side={col})')

print('\n== variables the two neo themes and the two classic themes share by name (engine-only, component layer)')
neo     = {k for k in eng['theme-neo-dark'] if layer(k) == 'component'}
classic = {k for k in eng['theme-dark'] if layer(k) == 'component'}
cyber   = {k for k in eng['theme-cyberpunk'] if layer(k) == 'component'}
print(f'neo={len(neo)} classic={len(classic)} cyberpunk={len(cyber)} neo∩classic={len(neo & classic)} neo-only={len(neo - classic)} classic-only={len(classic - neo)} cyberpunk∩neo={len(cyber & neo)}')
```
