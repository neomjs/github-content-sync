# Decouple archive sitemaps, bake git lastmod, and prune sitemap-core bloat

## Context

Google Search Console (`sc-domain:neomjs.com`, inspected 2026-11-14) shows `181` of `471` routes (`38.4%`) in `sitemap-core.xml` stuck in **`Discovered - currently not indexed` (`Last crawled: N/A`)** — including `7/7` (`/learn/comparisons/*`), `9/9` (`/learn/gettingstarted/*`), `6/6` (`/learn/tutorials/*`), `44/57` (`/learn/guides/*`), and `14/20` technical `/news/blog/*` articles — while `122` historical `v8–v12` release notes occupy `51.3%` of the `238` indexed core pages.

Ownership: self-assigned to `@neo-gemini-julia` as Steward of #20671 (`good first issue` / `help wanted` omitted: active urgent Engine v14 crawl-unblock lane).

## The Problem

Three compounding defects in `buildScripts/docs/seo/generate.mjs` and `buildScripts/docs/seo/seoJson.mjs` (`neomjs/neo` `origin/dev` @ `a07f581f13`, deployed in `neomjs/pages` @ `b0014738a6`) starve crawl budget on `neomjs.com`:

1. **`sitemap.xml` submits `20,002` `noindex` URLs (`98.2%` of `sitemap-archive.xml`):** `middleware-v2#48` added `X-Robots-Tag: noindex, follow` to `/news/tickets/*` and `/news/pulls/*`, yet `generate.mjs:742-744,779-781,1044-1049` still bundles `12,759` ticket routes and `7,243` PR routes alongside `365` indexable `/news/discussions/*` routes inside `sitemap-archive.xml` and links `sitemap-archive.xml` from `sitemap.xml` because `middleware-v2/src/build.mjs:413-424` (`fetchDynamicRoutes`) consumes `sitemap.xml` as its SSG build manifest.
2. **Zero `<lastmod>` tags in `neomjs/pages/sitemap-core.xml` (`0` of `480` `<url>` entries):** `generate.mjs:241,378` (`hasReliableGitHistory`) returns `false` when `neomjs/pages/buildScripts/enhanceSeo.mjs` executes inside `node_modules/neo.mjs` (npm tarball without `.git`), dropping all `<lastmod>` elements.
3. **`sitemap-core.xml` bloat and canonical mismatches:**
   - Emits `/home` (`TOP_LEVEL_ROUTES`) instead of `/` even though `/home` canonicalizes to `https://neomjs.com/`, and includes `/apps/portal/index.html` (`generate.mjs:543`).
   - Emits `4` `hidden: true` `learn/tree.json` entries (`guides/specificfeatures/MultiWindow`, `guides/specificfeatures/TearOutPortabilityMatrix`, `guides/specificfeatures/Mixins`, `tutorials/RSP`) and `5` `<500 B` `type: redirect` moved-ADR stubs (`0020`, `0032`, `0034`, `0037`, `0038`).
   - Emits all `172` `/news/releases/*` notes (`v8.1.0`–`v13.4.0`), relying on `<priority>` decay (`RELEASE_PRIORITY_BY_DELTA`) which Google's sitemap parser ignores.
   - `apps/portal/resources/data/seo.json` on `origin/dev` @ `a07f581f13` is missing `/news/blog/json-ld-xss-json-stringify-in-a-script-tag` (present in `blog.json`).

**Instrument receipts (`origin/dev` @ `a07f581f13` & `neomjs/pages` @ `b0014738a6`):**
- `neomjs/pages/sitemap-archive.xml` (`b0014738a6`, regex `<loc>` count by prefix): `20,367` `<url>`s (`12,759` `/news/tickets/*`, `7,243` `/news/pulls/*`, `365` `/news/discussions/*`), `0` `<lastmod>` tags in `neomjs/pages/sitemap-core.xml` (`480` `<loc>`s; positive control: `<loc>` matches `480`).
- `origin/dev` @ `a07f581f13` `learn/tree.json` (`JSON.parse` filter `n.hidden === true`): `4` nodes (`MultiWindow`, `TearOutPortabilityMatrix`, `Mixins`, `RSP`); `learn/agentos/decisions/*.md` frontmatter `type: redirect`: `5` files (`0020`–`0038`).

## The Architectural Reality

`Design authority: "Recency-tiered priority for /news/releases/ routes, indexed by delta from the newest release-note major... so the sitemap <priority> stays a useful crawl-budget hint instead of a flat wall of release notes."` (`buildScripts/docs/seo/generate.mjs:140-144`, `132-134`). Google Search documentation specifies that Google ignores `<priority>` and `<changefreq>` while consuming `<lastmod>`; relying on `<priority>` left `122` historical patch notes dominating `sitemap-core.xml` indexing while `0` `<lastmod>` tags survived tarball installation.

## The Fix

1. **Split indexable discussions from `noindex` SSG archive routes (`buildScripts/docs/seo/generate.mjs`, `rebuildContentIndexesAndSeo.mjs`, `copy.mjs`, `verify.mjs`):**
   - Emit indexable `/news/discussions/*` routes into `sitemap-discussions.xml` and reference `['sitemap-core.xml', 'sitemap-discussions.xml']` in `getSitemapIndexXml()` (`sitemap.xml`), removing `sitemap-archive.xml` (`noindex` tickets/PRs) from public `sitemap.xml`.
   - Emit `apps/portal/resources/data/ssg-archive-routes.json` alongside unlinked `sitemap-archive.xml` on disk so `middleware-v2` SSG rendering continues uninterrupted.
2. **Pre-bake git `<lastmod>` metadata (`seoJson.mjs`, `generate.mjs`):**
   - Persist per-route `lastmod` (`YYYY-MM-DD`) in `apps/portal/resources/data/seo.json` during git-backed `rebuildContentIndexesAndSeo.mjs` runs, and fall back to `seo.json[route].lastmod` in `generate.mjs` when `hasReliableGitHistory(root)` returns `false`.
3. **Prune `sitemap-core.xml` & mark non-canonical stubs `noindex, follow` (`seoJson.mjs`, `generate.mjs`, `verify.mjs`):**
   - Replace `/home` with `/` in `sitemap-core.xml` (`TOP_LEVEL_ROUTES`), exclude `/apps/portal/index.html` from `collectExampleRoutes`, filter `node.hidden === true` and frontmatter `type: redirect` stubs out of `sitemap-core.xml` (setting `robots: 'noindex, follow'` in `seo.json`), keep only current + previous major (`>= maxReleaseMajor - 1`, i.e. `v13+` / `v14+`) in `sitemap-core.xml` while setting `robots: 'noindex, follow'` on older `v8–v12` patch notes in `seo.json`, and regenerate `seo.json` (picking up `/news/blog/json-ld-xss-json-stringify-in-a-script-tag`).

## Acceptance Criteria

- [ ] `sitemap.xml` references `sitemap-core.xml` and `sitemap-discussions.xml` and no longer advertises `noindex` `/news/tickets/*` or `/news/pulls/*` routes to crawlers.
- [ ] Running `generate.mjs` against a directory without `.git` (`hasReliableGitHistory === false`) still emits `<lastmod>` tags on `sitemap-core.xml` routes via packaged `seo.json` metadata.
- [ ] `sitemap-core.xml` contains `/` (not `/home`), excludes `/apps/portal/index.html`, excludes `hidden: true` `learn/tree.json` entries and `type: redirect` moved-ADR stubs, and restricts `/news/releases/*` entries to `>= maxReleaseMajor - 1`.
- [ ] `apps/portal/resources/data/seo.json` includes `/news/blog/json-ld-xss-json-stringify-in-a-script-tag` and marks excluded historical releases and redirect stubs with `robots: 'noindex, follow'`.
- [ ] `verify.mjs` enforces these invariants and unit tests under `test/playwright/unit/buildScripts/docs/seo/` pass.

## Out of Scope

- `neomjs/middleware-v2` server redirects and `SsrService` changes (tracked in companion `middleware-v2` ticket).
- Rewriting `/learn/*` or `/` `<title>` / `<h1>` copy (tracked in sibling #20671 leaf).

## Avoided Traps

- **Deleting `sitemap-archive.xml` on disk before `middleware-v2` switches `fetchDynamicRoutes()`:** Keep `ssg-archive-routes.json` / unlinked `sitemap-archive.xml` emitted on disk until `middleware-v2` consumes the new SSG manifest so scheduled builds never drop archive snapshots.
