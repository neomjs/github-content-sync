# Re-anchor Portal, learn, blog, and example titles and H1s to search intent

## Context

Across the last 28 days (`2026-10-14` – `2026-11-10`), `sc-domain:neomjs.com` recorded **`0` named non-brand clicks** (`19` total non-brand impressions across `/learn/`, `/news/blog/`, and `/examples/` combined). Auditing all `316` core non-release routes in `neomjs/neo` shows **`0` `<title>` or `<h1>` tags** containing the plain-English problem terms developers actually search.

`unowned-rationale: Open for maintainer self-selection in coordination with #20682 (Home section steward @neo-fable-clio); good first issue omitted because front-door positioning requires cross-epic alignment.`

## The Problem

1. **Zero developer keyword-intent coverage in `<title>` and `<h1>`:**
   - Across all `316` core non-release routes (`origin/dev` @ `a07f581f13`, `apps/portal/resources/data/seo.json` + `learn/tree.json` + `blog.json` + `{apps,examples}/**/index.html`; positive control: `"Multi-Threaded"` matches `68` `seo.json` titles):
     - Exact `"JavaScript data grid"` in `<title>` or `<h1>`: **`0`** (`1` body hit)
     - `"100k rows"` / `"100,000 rows"` in `<title>` or `<h1>`: **`0`** (`6` body hits)
     - `"virtual scrolling"` in `<title>` or `<h1>`: **`0`** (`2` body hits)
     - `"Web Worker"` (any casing) in `<title>` or `<h1>`: **`0`** (`24` body hits)
     - `"OffscreenCanvas"` in SSR `<title>` or `<h1>`: **`0`** (`examples/component/canvas/index.html` `<title>Neo OffscreenCanvas</title>` is overwritten to `"Component Canvas"` by SSR fallback)
     - `"GitHub Workflow MCP"` / `"Live Browser DOM MCP"` in `<title>` or `<h1>`: **`0`**
2. **Homepage `<title>`, `5` `<h1>` tags, and off-domain link leaks:**
   - `apps/portal/index.html:10` sets `<title>Neo.mjs - An Agent Institution</title>`. Live Google SERPs classify `"agent institution"` under Indian BBPS payment-intermediary banking law (`setu.co`, `lawinsider.com`), while on `"multithreaded javascript ui framework"` Google ranks `bestofjs.org` and `dev.to` articles *about* Neo.mjs ahead of `neomjs.com/` because `/` dropped `"Multi-Threaded JavaScript UI"` from `<title>`.
   - Live `/` renders **`5` separate `<h1>` tags** (`Neo.mjs` + section headings), navbar links Home to `/home` instead of `/`, `apps/portal/view/home/parts/Colors.mjs:28` links `"Learn More"` off-domain to `itnext.io`, and Brain homepage links point off-domain to `github.com/neomjs/neo-agent-brain/blob/dev/...` instead of `neomjs.com` routes.
3. **Vague `<h1>` stems in `/learn/*` bypass or dilute section suffixes (#20715):**
   - Pages such as `/learn/benefits/body/WhyEnhance` (`<h1>Why Enhance? A Look Beyond Incremental Improvements</h1>` > 45 chars -> skips qualifier suffix completely!), `/learn/benefits/body/Speed` (`Extreme Speed`), `/learn/guides/datahandling/GridContainer` (`The Grid Container`), and `/learn/agentos/NeuralLink` (`Neural Link: The Possession Interface`) lead with internal metaphors instead of searchable engineering problems.

## The Architectural Reality

`Design authority: "Every canonical route in sitemap-core.xml — home, /learn/* guides, /examples/* component-family overviews (#20498), /news/blog/*, /news/releases/*, and /apps/* — resolves a distinct, non-generic <title>, <meta name=\"description\">... naming the engineering capability the page proves."` (#20671 Intended solution shape §1). Putting unsearched coined metaphors in `<title>` / `<h1>` while keeping searchable terms in body prose inverts search packaging: `<title>` and `<h1>` must name the developer's problem in plain terms, while body prose teaches Neo's coined architecture (`Application Engine`, `Object Permanence`, `Neural Link`, `Model Experience`).

## The Fix

1. **Homepage `/` & `apps/portal` head + internal link hygiene (`apps/portal/index.html`, `seoJson.mjs`, `apps/portal/view/home/**`, `apps/portal/view/HeaderToolbar.mjs`):**
   - Add canonical `/` entry in `apps/portal/resources/data/seo.json` and `apps/portal/index.html` with a problem-anchored dual-hemisphere `<title>` (e.g. `Neo.mjs — Multi-Threaded JavaScript UI Engine & AI Agent OS`) and rich `<meta name="description">` naming Web Workers, `SharedWorker` multi-window apps, `100k+`-row Data Grids, MIT Gantt/Scheduler/Kanban, and persistent AI Agent OS / MCP servers (aligned with #20682).
   - Demote secondary homepage section `<h1>`s to `<h2>` so `/` carries exactly `1` `<h1>`.
   - Point header Home navigation to `/` (not `/home`) and route homepage `Colors.mjs` / Brain CTA links to canonical `neomjs.com` `/learn/*` and `/examples/*` routes instead of `itnext.io` / `github.com` blobs.
2. **Search-intent `<title>` & `<h1>` upgrades across high-value `/learn/*`, `/news/blog/*`, and `/examples/*` routes (`learn/**/*.md`, `seoJson.mjs`):**
   - Support explicit frontmatter `seoTitle` / `seoDescription` overrides in `extractMarkdownSeoMetadata` (`seoJson.mjs`) so blog posts and guides keep expressive editorial `<h1>`s when desired while serving search-intent `<title>`s (e.g. `a-data-grid-in-a-web-worker` `<title>`: `JavaScript Data Grid in a Web Worker: 100k+ Rows Off the Main Thread | Neo.mjs`).
   - Update vague `<h1>`s / `seoTitle`s on core engine & Agent OS guides (`GridContainer`, `Grids`, `PooledGridAnimation`, `OffTheMainThread`, `MultiWindow`, `CanvasArchitecture`, `WhyEnhance`, `NeuralLink`) and key standalone examples (`examples/grid/bigData/index.html`, `examples/component/canvas/index.html`) so `"JavaScript Data Grid"`, `"100k Rows"`, `"Virtual Scrolling"`, `"Web Worker"`, `"SharedWorker"`, `"Multi-Window JavaScript Apps"`, `"OffscreenCanvas"`, and `"Live Browser DOM MCP"` appear in `<title>` / `<h1>`.

## Acceptance Criteria

- [ ] `apps/portal/index.html` and `seo.json['/']` carry a problem-anchored dual-hemisphere `<title>` and `<meta name="description">`, and rendered `/` contains exactly `1` `<h1>`.
- [ ] `seoJson.mjs` supports frontmatter `seoTitle` / `seoDescription` overrides and emits explicit developer search-intent `<title>`s across flagship Grid, Web Worker, SharedWorker, Multi-Window, OffscreenCanvas, and Neural Link / MCP routes (`>= 12` target routes verified by unit spec).
- [ ] Portal header Home navigation links to `/` rather than `/home`, and `Colors.mjs` no longer leaks its primary `"Learn More"` CTA to `itnext.io`.
- [ ] `node buildScripts/docs/rebuildContentIndexesAndSeo.mjs` and SEO unit specs pass cleanly.

## Out of Scope

- Redesigning the visual layout or narrative prose of the Home view (#20682).
- New v14 Board / Scheduler / Gantt overview pages and AG Grid / Bryntum comparison guides (tracked in sibling #20671 leaf).

## Avoided Traps

- **Erasing Neo's identity in body copy:** Keep `Agent Institution`, `Application Engine`, `Object Permanence`, `Neural Link`, and `MX Loop` strong in hero/body prose — only `<title>`, `<meta description>`, and vague `1–3`-word `<h1>`s shift from opaque internal shorthand to developer search vocabulary.
