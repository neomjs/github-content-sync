# Add Board, Scheduler, and Gantt SEO overview routes and comparison guides

## Context

Engine v14 (`2026-11-23`, #20874) ships MIT-licensed `Neo.board` (#20875), `Neo.timeline` (#20876), `Neo.scheduler` (#20877), and `Neo.gantt` (#20878) alongside Neo's `100k+`-row Web Worker `Neo.grid.Container`. Today (`origin/dev` @ `a07f581f13`), `neomjs.com` has **`0` routes, `<title>`s, or comparison guides** targeting `"JavaScript Gantt chart"`, `"JavaScript Scheduler"`, `"JavaScript Kanban board"`, `"AG Grid alternative"`, or `"Bryntum MIT alternative"`.

`unowned-rationale: Open for maintainer self-selection once #20875 (Board family) joins #20877 (Scheduler) and #20878 (Gantt) on dev; good first issue omitted because cross-family technical benchmarks and v14 API accuracy require maintainer verification.`

## The Problem

1. **Missing Portal `/examples/<family>` SEO doors for v14 planning components:**
   - `apps/portal/view/examples/TabContainer.mjs` (`origin/dev` @ `a07f581f13`) defines `featured`, `grid`, `forms`, `multi-window`, `calendar`, `components`, and `state`, with **no** overview route/tab for `board` (Kanban), `scheduler`, or `gantt` (or a populated `planning` / per-family route set emitted into `seo.json` and `sitemap-core.xml`).
   - Live SERP analysis (`2026-11-14`) shows Page-1 winners (`dhtmlx.com`, `ag-grid.com`, `rv-grid.com`, `frappe.io`) rank via dedicated `1,500+`-word component overview pages (`<h1>Free JavaScript Gantt Chart - MIT Licensed</h1>`, runnable demo cards, `npx` quickstart, and `SoftwareApplication` / `FAQPage` JSON-LD).
2. **Comparison guides omit data-grid & planning-suite evaluators:**
   - `learn/comparisons/` (`7` files on `origin/dev` @ `a07f581f13`: `Overview`, `NeoVsReact`, `NeoVsAngular`, `NeoVsVue`, `NeoVsNextJs`, `NeoVsSolid`, `NeoVsExtJs`) compares general SPA UI libraries only. Evaluators searching `"ag grid web worker alternative"`, `"javascript data grid 100k rows"`, or `"open source bryntum alternative"` find `0` comparison pages on `neomjs.com`.

## The Architectural Reality

`Design authority: "On neomjs.com, someone who has never seen Neo... finds each component family through runnable examples that say what they show, and builds a first app from a guide that holds together."` (`ROADMAP.md` Engine 14 release gate, `origin/dev` @ `a07f581f13`). Under #20727 (`seoJson.mjs:338-385`), populated family tabs in `Portal.view.examples.TabContainer` automatically gain dedicated `CollectionPage` entries in `seo.json`, `sitemap-core.xml`, and `llms.txt` once catalog entries exist in `apps/portal/resources/data/examples.json`.

## The Fix

1. **Populate Engine v14 Board, Scheduler, and Gantt Portal example family overviews (`apps/portal/resources/data/examples.json`, `apps/portal/view/examples/TabContainer.mjs`, `buildScripts/docs/seo/seoJson.mjs`, `generate.mjs`):**
   - Register runnable `scheduler` (#20877), `gantt` (#20878), `board` (#20875), and `workstation` planning (#20884) showcase entries in `examples.json` with clear problem-first captions and screenshots.
   - Expose dedicated crawlable overview route(s) (`/examples/gantt`, `/examples/scheduler`, `/examples/board` — matching `neomjs/middleware-v2` `PORTAL_EXAMPLE_ROUTES`) with search-intent `<title>`, `<meta name="description">`, and `CollectionPage` / `SoftwareApplication` JSON-LD in `seo.json` and `sitemap-core.xml`.
2. **Author `NeoVsAgGrid.md` and `NeoVsBryntum.md` in `learn/comparisons/` + `learn/tree.json`:**
   - **`learn/comparisons/NeoVsAgGrid.md`:** Evidence-backed architectural comparison for `100k+`-row / `200`-column streaming JavaScript Data Grids (App/Data/VDom Web Worker isolation, `0ms` main-thread long-task blocking from `neomjs/benchmarks#5`, `SharedWorker` multi-window tear-off, MIT licensing vs enterprise locks, and honest trade-offs where AG Grid's pivot/Excel export ecosystem leads today).
   - **`learn/comparisons/NeoVsBryntum.md`:** Evidence-backed architectural comparison for JavaScript Gantt, Resource Scheduler, and Kanban Board suites (shared time-axis & multi-body grid on Web Workers + `SharedWorker` multi-window state vs main-thread component suites, MIT license scope, and honest trade-offs).
   - Link both in `learn/comparisons/Overview.md` and `learn/tree.json`.
