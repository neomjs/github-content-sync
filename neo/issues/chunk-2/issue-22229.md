# Preserve omitted routerBasePath in dist builds and migrate remaining Portal #/ routes

`owned-rationale: Claimed immediately by @neo-gemini-julia to resolve the dev root-mount routerBasePath regression from #22211 before the next neomjs.com deploy (curated labels intentionally omitted).`

## Context

Part of #22169 (graduated from [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145)). Exploring `apps/portal/view/home/parts/Grid.mjs`'s `'#/examples/...'` links and `https://neomjs.com`'s `/dist/production/apps/portal/#/examples/grid` hover preview surfaced both unmigrated `'#/...'` route configs in `apps/portal/view/**` and a `dev` regression introduced when `#22211` (`324d6bc52f`) merged after `#22214` (`37f8828b0c`).

## The Problem

1. **`rewritePathnameConfig` clobbers omitted and `''` `routerBasePath` configs (`#22211` vs `#22214`):**
   - `#22214` (`#22175`, `37f8828b0c`) omitted `routerBasePath` from `apps/portal/neo-config.json` and added `DomEvents#resolveRouterBasePath()` (`src/main/DomEvents.mjs:1333-1356`) + `Neo.hasExplicitRouterBasePath` (`src/Neo.mjs:1291`) so `<base href>` is adopted as `routerBasePath` **only** when `location.pathname` starts with it (`/apps/portal/*` or `/dist/production/apps/portal/*`), while root `spaRoot` mounts (`https://neomjs.com/*` or `fileServer.mjs --spa-root dist/production/apps/portal`) keep `routerBasePath: ''`.
   - `#22211` (`#22173`, `324d6bc52f`) added `rewritePathnameConfig` (`buildScripts/util/esmDistTransforms.mjs:198-201`), unconditionally writing `"routerBasePath": "/dist/<tier>/apps/portal"` into emitted `neo-config.json` whenever `routerMode === 'pathname'`.
   - Because `Object.hasOwn(Neo.config, 'routerBasePath')` becomes `true`, `DomEvents#resolveRouterBasePath()` short-circuits at `src/main/DomEvents.mjs:1336` even at `/`. If `dev` were deployed to `neomjs.com` (or served via `--spa-root dist/production/apps/portal`), `StringUtil.toRouteHref('/examples/grid')` would emit `href="/dist/production/apps/portal/examples/grid"` and `DomEvents#setRoute` would `history.pushState` to `/dist/production/apps/portal/examples/grid` instead of `/examples/grid`. It also overwrites explicit `"routerBasePath": ""` root-mount overrides documented in `learn/tutorials/Routing.md:343`.
2. **Legacy `'#/...'` route configs in `apps/portal/view/**` & `'#/'`-only predicate in `Markdown` / `app.content.Component`:**
   - Five Home stage views (`Grid.mjs`, `Planning.mjs`, `Features.mjs`, `How.mjs`, `AiToolchain.mjs`) and prototype VDOM seeds in `AudienceDoors.mjs` and `services/Container.mjs` still carry `'#/...'` route strings instead of clean `'/...'` routes.
   - Seven Portal content views (`view/content/Component.mjs`, `view/learn/Component.mjs`, `view/news/{blog,discussions,pulls,release,tickets}/Component.mjs`) still declare `contentRoute: '#/learn/'` / `'#/'` and `issuesUrl: '#/news/tickets/'` because `src/component/Markdown.mjs:173-176, 417` and `src/app/content/Component.mjs:409` only pass `'#/'`-prefixed strings through `StringUtil.toRouteHref(..., windowId)`.

## The Architectural Reality

- `Design authority: "routerBasePath: Sub-path prefix stripped before route matching (explicit '' forces root mounting; when omitted, DomEvents#resolveRouterBasePath() adopts the <base href> pathname if location.pathname starts with it)."` (`learn/tutorials/Routing.md:343`, `src/main/DomEvents.mjs:1329-1331`).
- In `src/Main.mjs:8-10`, singleton `DomEvents` constructs (`DomEvents.mjs:177-183`, calling `resolveRouterBasePath()`) **before** `WorkerManager#construct()` (`src/worker/Manager.mjs:176, 293`) clones `Neo.config` into the App/SharedWorker (`Neo.windowConfigs[windowId]`). Leaving `routerBasePath` omitted in emitted `neo-config.json` when the source omitted it (while `rewritePathnameHtml` still rewrites `<base href="/dist/<tier>/<appSubPath>/">`) lets one build resolve `routerBasePath = '/dist/<tier>/apps/portal'` on sub-path dist mounts AND `routerBasePath = ''` on root `spaRoot` mounts.

## The Fix

1. **`buildScripts/util/esmDistTransforms.mjs` (`rewritePathnameConfig`) & `learn/tutorials/Routing.md`:**
   - Rewrite `config.routerBasePath` to `'/' + outputDirectory` only when `config.routerMode === 'pathname' && Boolean(config.routerBasePath)` (preserving explicit sub-path configs like `'/apps/myapp'` while leaving omitted `routerBasePath` omitted and explicit `''` untouched).
   - Update `learn/tutorials/Routing.md:345` to reflect that `rewritePathnameConfig` rewrites non-empty sub-path `routerBasePath` values while preserving omitted/`''` configs for runtime `<base href>` / `spaRoot` resolution.
2. **`src/component/Markdown.mjs` & `src/app/content/Component.mjs`:**
   - Recognize both `'#/...'` and root-relative `'/...'` (excluding protocol-relative `'//...'`) in `Markdown#afterSetWindowId`, `Markdown#modifyMarkdown` (`issuesUrl`), and `app.content.Component#rewriteLinks` (`contentRoute`) so clean `'/...'` route prefixes resolve per-`windowId` across `'pathname'` (root and sub-path) and `'hash'` windows while external `https://...` URLs remain untouched.
3. **`apps/portal/view/**`:**
   - Migrate remaining `'#/...'` route configs and VDOM seeds to clean `'/...'` routes across `Grid.mjs`, `Planning.mjs`, `Features.mjs`, `How.mjs`, `AiToolchain.mjs`, `AudienceDoors.mjs`, `services/Container.mjs`, `content/Component.mjs`, `learn/Component.mjs`, and `news/{blog,discussions,pulls,release,tickets}/Component.mjs`.

- [ ] `PathnameRoutingNL.spec.mjs` verifies both (a) Portal Home links (`Grid.mjs` `'More grids'` → `href="/examples/grid"`, `AudienceDoors` proof links) at `/` and (b) mounting a built dist Portal shell under `spaRoot` at `/` vs under `/dist/.../apps/portal/` (`--no-spa-root`), confirming `routerBasePath: ''` + `href="/examples/grid"` at `/` and `routerBasePath: '/dist/.../apps/portal'` + `href="/dist/.../apps/portal/examples/grid"` on the sub-path mount.

## Out of Scope

- Deploying the updated `neo.mjs` release to `neomjs/pages` / `neomjs.com` (tracked under `neomjs/pages#211` and `neomjs/middleware-v2#109` post-publish).
- Modifying `buildScripts/util/fileServer.mjs` request-precedence rules (already working cleanly from `#22211` / `#22214`).

## Avoided Traps

- **Removing `<base href>` rewriting from `rewritePathnameHtml`:** `<base href="/dist/<tier>/apps/portal/">` is required so `./neo-config.json` and `../main.js` resolve on deep routes (`/examples/grid`, `/learn/...`) when `index.html` is served at `/`; only `neo-config.json`'s `routerBasePath` must stay omitted when the source omitted it.
- **Changing `issuesUrl: '/news/tickets/'` or `contentRoute: '/learn/'` in Portal without updating `Markdown.mjs` / `app/content/Component.mjs`:** `startsWith('#/')` alone would skip `StringUtil.toRouteHref`, breaking sub-path `routerBasePath` prefixing and `'hash'`-mode SharedWorker windows.
