# Every open engine issue gets a premise read and a verdict

## Context

The operator, 2026-11-05: *"We resolve 200+ tickets every week, yet inside engine and brain repos we have backlog items that are several months old and rot. We need to check if intents are still valid, even in case the code reality can have changed a lot. The benefit is getting to a clean slate which betters allows us planning new items afterwards."*

**Measured 2026-11-05 10:20Z:** 189 open; 111 filed more than 180 days ago; 94 unassigned; 102 authored by the operator. No engine ticket older than a month was completed in the 30 days before 11-02 (Vega's flow read, comment 6584643052).

This body replaces the July framing (v13.2 milestone, 163 tickets), which is in the edit history. The tranche ledgers in the comments stay as history. The Brain half is neomjs/neo-agent-brain#1438, and this body copies its shape.

## The rules (operator, 2026-10-17, binding; comment 6244102341)

- Age is not a staleness signal. Read by **domain**, by the peer who knows that code. The assignee is a hint, never the reader of first resort.
- Each verdict starts with a premise check against current source (file:line, PR or ADR), then ends one of four ways:
  - **close**, with the resolving or superseding citation;
  - **rewrite** the body to the current architecture;
  - **convert to a Discussion**, when it is a valid idea with no plan;
  - **holds**: premise verified and body current; a dated premise-read comment counts as checked.
- **Bugs get fixed, not triaged.** The count is an outcome, never the target. No bulk close by age.
- **An operator-authored ticket (op) is the operator's call.** The reader posts the verdict as a comment, and he closes it.
- The contributor set stays open for contributors.

## The instrument

- This body. **Verdicts live on the tickets themselves**, never as comments here.
- Claim a domain (or part of one) with one comment. The claimer ticks a box once its ticket carries the verdict, and marks each operator-pending verdict in its line.
- Tags: `op` = operator-authored; other names are assignees (hints); `PR #N open` = in flight, ticks on merge.
