# Guard unit Neo.config identity and run spec files contiguously

## Context

Owned immediately by `@neo-gemini-julia` to harden the Engine `unit` runner after diagnosing 5 consecutive `Engine Tests / unit` failures on `PR #22304`; curated `good first issue` / `help wanted` labels omitted per `ticket-create §4`.

Across five consecutive `Engine Tests / unit` CI runs on `PR #22304` (`819e8a83ee394e5ebe203cd3dc31ed6b60ef3912`, touching zero `vdom/` files), the `unit` job failed on a **different** `useDomApiRenderer: false` spec slice each time while sibling tests in the same `.spec.mjs` file passed:

- [Job `140284980289`](https://github.com/neomjs/neo/actions/runs/45931492204/job/140284980289) & [Job `140291028297`](https://github.com/neomjs/neo/actions/runs/45931492204/job/140291028297) & [Job `140296872205`](https://github.com/neomjs/neo/actions/runs/45931492204/job/140296872205): `test/playwright/unit/vdom/Advanced.spec.mjs:250` (`Wrapping nodes multiple times`) failed attempt 1 (`outerHTML` missing, `vnode` emitted instead), passed retry 1 in a fresh worker (`1 flaky`), failing CI via `failOnFlakyTests: true`.
- [Job `140287648569`](https://github.com/neomjs/neo/actions/runs/45931492204/job/140287648569): `test/playwright/unit/vdom/FragmentHelper.spec.mjs:36` (`Index calculation with simple fragment sibling`) failed attempt 1 (`expect(deltas[0].outerHTML).toContain('id="new-span"')` received `undefined` while `:23`, `:68`, `:101` passed).
- [Job `140294145931`](https://github.com/neomjs/neo/actions/runs/45931492204/job/140294145931): `test/playwright/unit/vdom/Advanced.spec.mjs:127` (`Add, Move & Edit multiple Events`) failed attempt 1 (`- "outerHTML": Any<String>` while `:20`, `:250`, `:344` passed).

Deterministic 3-file reproduction (`1.0s`):
```bash
npx playwright test -c test/playwright/playwright.config.unit.mjs \
  test/playwright/unit/button/Base.spec.mjs \
  test/playwright/unit/main/addon/Stylesheet.spec.mjs \
  test/playwright/unit/vdom/Advanced.spec.mjs --workers=1
```

## The Problem

Two unit-harness weaknesses compound to turn a deterministic single-spec teardown mistake into an opaque rotating casualty 4,000 tests later:

1. **Silent `Neo.config` object-identity detachment (`test/playwright/setup.mjs`):**
   Engine singletons (`src/vdom/Helper.mjs:7`, `src/main/DeltaUpdates.mjs:6`, `src/worker/Manager.mjs:13`) bind `const NeoConfig = Neo.config` once at module evaluation time for hot-loop property access. When a unit spec saves and restores config via `Neo.config = Neo.clone(Neo.config, true)` or `Neo.config = {...}` (`test/playwright/unit/worker/ConfigBase.spec.mjs:63`, and `PR #22304`'s initial `Stylesheet.spec.mjs`), `globalThis.Neo.config` points to a **new object** while `VdomHelper`'s `NeoConfig` stays permanently bound to the old object (`useDomApiRenderer: true`). The offending spec passes 100% locally and in CI, while every later `setup({neoConfig: {useDomApiRenderer: false}})` in that worker mutates the detached `globalThis.Neo.config` object and fails inside `VdomHelper#insertNode` with an unrelated stack trace.
2. **Intra-file slice splitting across `setup()` and `beforeAll`/`afterAll` lifecycles (`playwright.config.unit.mjs` / `unit-tz.mjs`):**
   `test/playwright/setup.mjs` (`priorNeoConfigOverrides`, lines `36–41` and `106–127`) and `694` unit spec files (`230` configuring `useDomApiRenderer`) execute `setup(...)` **once at module top-level**, assuming a worker runs each `.spec.mjs` file's tests contiguously before importing the next spec file. However, `playwright.config.unit.mjs:48` and `playwright.config.unit-tz.mjs:51` set `fullyParallel: true` (the only 2 configs out of 9 in `test/playwright/` to do so). Under `fullyParallel: true` with `workers: 4`, Playwright splits individual `.spec.mjs` files across workers and slices: a single poisoned worker fails 1 test out of 4 in `Advanced.spec.mjs` while the other 3 workers pass, and within one worker a second slice of an already-cached module re-runs `beforeAll`/`afterAll` without re-running top-level `setup()` (`#19217`, `ResizeObserver.spec.mjs:190`).

## The Architectural Reality

- `test/playwright/setup.mjs:3-6, 106-110` (`Design authority:` *"Cross-file isolation in the single shared worker: restore whatever the PREVIOUS spec file's `neoConfig` overrides replaced BEFORE applying this file's."*) — defines `Neo.config` initialization and file-granular `setup()` isolation in shared workers.
- `src/DefaultConfig.mjs:3` — `Neo.config = Neo.config || {};` (self-assignment `value === Neo.config` during `src/Neo.mjs` bootstrap must remain a valid no-op).
- `src/vdom/Helper.mjs:7`, `src/main/DeltaUpdates.mjs:6`, `src/worker/Manager.mjs:13` — `const NeoConfig = Neo.config;` hot-path bindings that require `globalThis.Neo.config` object identity to remain invariant across a worker's lifetime.
- `test/playwright/unit/worker/ConfigBase.spec.mjs:63` — sole existing spec on `dev` that reassigns `Neo.config = {...}` after `setup()` instead of mutating `Neo.config` in place.
- `test/playwright/playwright.config.unit.mjs:24-36, 48` & `playwright.config.unit-tz.mjs:51-52` — `buildUnitRunPolicy({isCI})` centralizes `workers: isCI ? 4 : undefined`, `retries`, `failOnFlakyTests`, `forbidOnly`, and `reporter`. Setting `fullyParallel: false` in `buildUnitRunPolicy` preserves 4-worker **file-level** parallelism across `694+` spec files while running each file's tests contiguously.

## The Fix

1. **Lock `globalThis.Neo.config` object identity in `test/playwright/setup.mjs`:**
   Install an accessor on `globalThis.Neo` whose getter returns the canonical `neoConfig` object and whose setter permits self-assignment (`value === neoConfig`, preserving `src/DefaultConfig.mjs:3`) while throwing a descriptive `TypeError` whenever a spec attempts to replace `Neo.config` with a different object reference (`Neo.config = {...}`), pointing authors to `setup({neoConfig})` / `Object.assign(Neo.config, ...)`.
2. **Update `test/playwright/unit/worker/ConfigBase.spec.mjs:63`:**
   Mutate `Neo.config` in place (`Object.assign(Neo.config, ...)`) instead of replacing the `Neo.config` reference.
3. **Move `fullyParallel: false` into `buildUnitRunPolicy({isCI})` (`test/playwright/playwright.config.unit.mjs` + `playwright.config.unit-tz.mjs`):**
   Remove the `fullyParallel: true` overrides from both unit configs so `unit` and `unit-tz` inherit `fullyParallel: false` from `buildUnitRunPolicy({isCI})` alongside all 7 sibling Playwright configs.
4. **Pin both contracts in unit specs (`test/playwright/unit/test/unitRunPolicy.spec.mjs`):**
   Assert `fullyParallel: false` on `buildUnitRunPolicy` (`isCI: true` and `isCI: false`), `playwright.config.unit.mjs`, and `playwright.config.unit-tz.mjs` (in a child process so `process.env.TZ` in the UTC worker stays untouched), and assert that reassigning `Neo.config = {...}` throws immediately while self-assignment (`Neo.config = Neo.config`) and `setup({neoConfig})` keep `VdomHelper`'s `NeoConfig` reference synchronized.

## Decision Record impact

`none` — enforces existing `NeoConfig` reference identity in tests and aligns unit runner scheduling granularity with `setup.mjs` and all 7 sibling Playwright configs.

## Acceptance Criteria

- [ ] AC-1: `test/playwright/setup.mjs` keeps `globalThis.Neo.config` bound to one object reference across the worker lifetime: `Neo.config = Neo.config` (`DefaultConfig.mjs`) and `setup({neoConfig})` / `Object.assign(Neo.config, ...)` succeed, while reassigning `Neo.config = {...}` throws a descriptive `TypeError` at the reassignment site (covered by unit test).
- [ ] AC-2: `buildUnitRunPolicy({isCI})` returns `fullyParallel: false` for both `isCI: true` and `isCI: false`, and both `playwright.config.unit.mjs` and `playwright.config.unit-tz.mjs` export `fullyParallel: false` (verified in `unitRunPolicy.spec.mjs` without mutating the UTC worker's `process.env.TZ`).
- [ ] AC-3: `npm run test-unit` (including `ConfigBase.spec.mjs` and `CI=1` 4-worker execution) and `npm run test-unit-tz` pass with `0 flaky` tests, with measured 4-worker wall-clock runtime recorded in the PR body.

## Out of Scope

- Replacing `const NeoConfig = Neo.config` in `src/vdom/Helper.mjs`, `src/main/DeltaUpdates.mjs`, or `src/worker/Manager.mjs` (production workers never reassign `Neo.config`, and module-local binding avoids hot-loop property lookups).
- Changing `workers: 4` or `retries: 2` in CI (`#15861`).

## Avoided Traps

- **Patching only the victim specs (`Advanced.spec.mjs`, `FragmentHelper.spec.mjs`):** leaves `Neo.config = ...` free to silently detach `NeoConfig` in future specs and fail 4,000 tests later.
- **Using `writable: false` data descriptor on `Neo.config`:** breaks `src/DefaultConfig.mjs:3` (`Neo.config = Neo.config || {}`), which self-assigns `Neo.config` in strict ESM mode; an accessor permitting `value === neoConfig` handles bootstrap cleanly while catching every foreign object replacement.
- **Importing `playwright.config.unit-tz.mjs` directly inside a UTC unit spec:** mutates `process.env.TZ = 'Pacific/Kiritimati'` for subsequent specs in that worker; inspect it in a child Node process instead.
