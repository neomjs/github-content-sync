# Add a floating Edit contact action to the mobile Grid example

Owned by @neo-gpt-sophie on the Engine 14.1 mobile examples path.

## Context

The [adaptive contact-editor baseline](https://github.com/neomjs/neo/discussions/22259#discussioncomment-19935919) calls for a floating Edit action that uses the existing editor. The full mobile component and example work is part of 14.1 under #22391. This is a runnable consumer under the [mobile components epic #22414](https://github.com/neomjs/neo/issues/22414). Grace’s [reusable FAB #22415](https://github.com/neomjs/neo/issues/22415) owns taking over the compact placement in its PR or a follow-up, using the tested record and opener contract.

## Problem

The compact Grid exposes editing only through each row’s Edit button. Its handler derives the contact and focus-return target from that row button. A floating action needs to use the selected Grid record and pass its own Button as the opener. [Current handler](https://github.com/neomjs/neo/blob/5ff17dedc8b4ec652d1729fc6c9ac05eafd78eda/examples/grid/nestedRecordFields/ViewportController.mjs#L38)

## Architectural reality

Design authority: [the adaptive example direction in D#22259](https://github.com/neomjs/neo/discussions/22259#discussioncomment-19935919) calls for an accessible floating Edit using the existing handler. `grid.view.selectedRecords` exposes the current Grid selection. The existing `EditUserDialog#getFocusReturnTarget()` prefers the component identified by `animateTargetId`. [Grid selection](https://github.com/neomjs/neo/blob/5ff17dedc8b4ec652d1729fc6c9ac05eafd78eda/src/grid/View.mjs#L353) · [Dialog focus return](https://github.com/neomjs/neo/blob/5ff17dedc8b4ec652d1729fc6c9ac05eafd78eda/examples/grid/nestedRecordFields/EditUserDialog.mjs#L111)

## Fix

Expose a native floating Edit contact Button in the example’s existing compact layout. Resolve the selected record on activation and pass it with the actual opener to the common Dialog path. Give the user a selection prompt when no row is selected. Keep the row’s Edit action available. Use the example’s existing controller, stylesheet, Dialog and browser spec. The example uses the current Button and Dialog while the reusable adaptive components and native gesture contracts proceed on their own release work.

## Acceptance criteria

- [ ] At 390 × 844, touch and keyboard activation open the selected contact, including after selecting a different row. Clearing Grid selection keeps the editor closed and gives actionable feedback.
- [ ] Save updates only that contact. Cancel and Escape discard drafts and restore focus to the visible floating opener.
- [ ] The action is absent in the wide layout, where the existing row Edit path and focus behavior still pass. The compact action stays inside the viewport and clear of Grid content.
