# Build along: observe a data pipeline on both workers

## Problem and intended outcome
Teach a reader to construct and inspect a data pipeline rather than merely seeing a finished demonstration. `examples/data/pipeline/MainContainer.mjs` already runs a fictional orders report with a connection, interceptor, normalizer and per-stage telemetry on App or Data worker. Reuse its source and contract; no new pipeline architecture or performance promise is presumed.

- [ ] A registered Learn build-along progresses from payload and Store to pipeline, interceptor and telemetry, explains workerExecution and the observed stage/worker data using current APIs, with a runnable failure case.
