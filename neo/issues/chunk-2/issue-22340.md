# The coding-guidelines check fails on dev: 36 retired rows, one new

Live latest-open + closed sweep: checked latest 20 open + open and closed search (coding guidelines baseline; no Out of Scope or Avoided Traps on the one closed hit, #22307) at 2026-11-27T10:41Z; 45 open (orange band), no owning open ticket (#22307 is closed by its merge); no in-flight claim in the mailbox since 10:36Z; one Memory Core query on the symptom, no equivalent; my open assignments read. Not offered as a contributor issue: `dev` is red, urgent and owned.

## Context

`check-coding-guidelines` landed on `dev` at 10:38Z on 27 Nov (#22307, PR #22324), within a minute of two other merges it had not seen: #22317 (the mechanical pass over `src/gantt`) and #22320 (the Grid edit dialog). Its baseline was written before both.

## The Problem

On `dev` at 83f7f3101f, `node buildScripts/util/check-coding-guidelines.mjs` exits 1 with 37 lines:

- **36 retired baseline occurrences**, all in `src/gantt`, which #22317 cleaned: `compact-jsdoc-loss` 20, `local-reactive-tag` 6, `missing-config-jsdoc` 5, `static-config-order` 4, `redundant-vdom-div` 1, across `Container` 15, `TaskStore` 8, `DependencyLayer` 6, `EventDragZone` 4, `Cascade` 1, `CascadeMotion` 1, `Column` 1.
- **One new violation:** `examples/grid/nestedRecordFields/EditUserDialog.mjs:20 [missing-config-jsdoc] EditUserDialog.keepInBoundary`, added by #22320.

The `coding guidelines` step of `pr-baseline` runs the same command, so every pull request's next run fails on it, and lint-staged runs it with `--staged`.

## The Architectural Reality

- Owner: `buildScripts/util/check-coding-guidelines.mjs` with `buildScripts/util/check-coding-guidelines-baseline.json`. The check fails closed on a retired row on purpose, so the baseline cannot overstate the debt; `--write-baseline` rewrites it from the tree.
- The order was known and agreed before the merges: #22317 first, then a baseline rewrite on #22324 ([the author response on #22317](https://github.com/neomjs/neo/pull/22317#issuecomment-7212890046)). Both merged within a minute, so the rewrite never ran.
- `keepInBoundary_` is a reactive config of `Neo.dialog.Base` (`src/dialog/Base.mjs:111`); the example overrides its value.

## The Fix

1. `examples/grid/nestedRecordFields/EditUserDialog.mjs`: a JSDoc block on `keepInBoundary`, with `@reactive`. A new config is documented, not added to the baseline.
2. `node buildScripts/util/check-coding-guidelines.mjs --write-baseline`. The baseline's diff removes the retired rows and adds none.
