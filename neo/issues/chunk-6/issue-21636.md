# Give the current header link a connected double helix

## Context

The Portal already routes the selected link through `Toolbar.activeId`, including direct loads, and exposes it through `aria-current="page"`. Both foreground strands bend around the buttons. The current canvas overlay redraws the same path with a brighter white stroke; hover also redraws the same path. The operator finds the current route hard to pick out and wants the flowing waves retained.

## Intended result

Give the selected navigation item a recognizable connected double-helix treatment that remains legible in one still frame. Preserve the open space around the label, the ordinary wave around neighboring items, the independent hover and keyboard-focus cues, and existing phone layout. The renderer owns the change; any host change must serve actual configuration or motion delivery. Selection stays route-owned.

- [ ] Only the route's current visible button gets the connected motif; hover or pointer exit cannot move it, and an unmatched route clears it.
- [ ] The selected item is recognizable in both Neo themes, including compact navigation, without painting through the text or badge.
- [ ] Reduced-motion behavior preserves a recognizable selection. Check actual Portal header frames and the activeId regression.
- [ ] Scope stays independent of Maryam’s phone layout issue.

**Design authority:** operator’s November 20 visual read; [original active-view intent](https://github.com/neomjs/neo/issues/8660) and [the route/ARIA contract](https://github.com/neomjs/neo/pull/21545). The existing renderer, `src/canvas/Header.mjs`, is the owner of the active paint. The original helix/ribbon work is [here](https://github.com/neomjs/neo/issues/8636).
