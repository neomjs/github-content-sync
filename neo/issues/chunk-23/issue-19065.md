# NL e2e pages ignore NEO_NL_PORT, so a seat cannot opt into its own bridge

## Context

**Sharing one bridge is the default, and it is a feature:** peers on the same bridge can join the same app runtime and collaborate (@tobiu, 2026-09-23; tried months ago, promising). A separate bridge per seat is an **option** on top of that. Every seat works in its own clone, with its environment sourced from its own tree, so every seat *can* run its own bridge when it needs isolation. The Brain already supports this: `port: leaf(8081, 'NEO_NL_PORT', 'port')` in `ai/mcp/server/neural-link/configBase.mjs:54`. Tonight seven seats still shared one `:8081` bridge, and NL e2e runs had to be serialized by hand with "native slot" broadcasts.

## The Problem

`test/playwright/fixtures.mjs` points only the **agent** side at the seat's port: `bridgePort: aiConfig.port` (`:234`), and the NL services load from `NEO_AGENTOS_RUNTIME_ROOT`. The **page** under test enables its AI client from its own `neo-config.json` (`useAiClient: true` in `apps/workstation`, `apps/portal` and `apps/shareddialog`), and `Neo.config.neuralLinkUrl` defaults to `ws://127.0.0.1:8081` (`src/DefaultConfig.mjs:183`; `src/ai/Client.mjs:165`).

So the option is broken for e2e. A seat that sets `NEO_NL_PORT=8091` gets its test agent on 8091 and its page on 8081, which may be another seat's bridge. That either breaks the run or, worse, cross-wires two seats' runs.

## The Architectural Reality

`test/playwright/e2e/core/AiClientLateBridge.spec.mjs:65` already does the page half for itself: it routes the page's config request and answers with `neuralLinkUrl: ws://127.0.0.1:${port}`. Popups load their own config, so the route belongs on the browser context, not the page.

## The Fix

When `aiConfig.port` is not the default, the shared fixture injects `neuralLinkUrl: ws://127.0.0.1:${aiConfig.port}` into every `neo-config.json` its context loads. With the port unset, nothing changes.

## Acceptance Criteria

- [ ] **AC-1** — With `NEO_NL_PORT` unset, NL specs behave exactly as today: the page dials the shared `:8081`, and seats keep meeting on one bridge. *(Amended 2026-09-23: the route is installed either way, and the default rewrite is the identity.)*
- [ ] **AC-2** — With `NEO_NL_PORT=<non-default>`, an NL spec's page, **including a popup it opens**, connects to that port. The witness is a spec passing while a different bridge holds `:8081`.
- [ ] **AC-3** — Two seats run NL specs at the same time on different ports, and neither run sees the other's apps.

## Out of Scope

- Changing the default port, or making separation the default. Sharing stays the default.
- Per-seat values in the seat `.env` files, which are operator-owned.
- The Brain-side bridge spawn.
