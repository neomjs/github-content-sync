# ROADMAP.md lags v13.2 by four weeks: nine dead anchors, missing scope

Creating a ticket to update it, adding all missing items with priorities might help us — future sessions or compactions especially."* The roadmap is the declared session intake (its own last section says so), so its staleness is paid on every boot and every compaction recovery.

Operator, ~01:00 CEST, second input: *with several repositories we are no longer bound to an org release; FM's release requires an outsider to get their own Agent OS running, which requires a first-run wizard; several releases mean several release notes — one set "would be a book".* Measured per-repo release state and its consequences: [D#19050 comment, 2026-09-22](https://github.com/neomjs/neo/discussions/19050).

## The Problem

`ROADMAP.md` was last edited 2026-08-28 (`36c463ba5a`, #17830). Measured on `dev@e66b6f8142` tonight:

**Nine of its issue anchors no longer resolve in this repository.** They were transferred out with the split, and the roadmap still links them as `neomjs/neo` issues: `#14560` → neomjs/neo-agent-institution#10, `#13448` → neomjs/neo-agent-institution#9, `#14472` → neomjs/neo-agent-brain#122, `#15798` → neomjs/neo-agent-brain#90, `#14442` → neomjs/neo-agent-brain#123; `#14565`, `#14570`, `#14304`, `#12679` also fail to resolve (destinations not checked). The GraphQL lookup answers "Could not resolve to an issue"; the web redirect hides this from a human reader, the API does not hide it from an agent.

**Three cornerstone anchors are closed and one graduated:** #13158 (Qt-parity docking polish) closed; #14581 (convergence-weighted Golden Path) closed; #12456 is already noted as done in prose; D#17818 (the DockLayouts rewrite ideation) closed 2026-08-29 and its implementation epic #18303 carries no milestone.

**The org picture is wrong.** The text says "four repos": `devindex` (its own workspace since the split), `github-content-sync` (the corpus repository, publishing hourly since 2026-09-20) and `pages` (the deployment target) are absent, and D#17247 (the six-repository split) closed 2026-09-21.

**The release model is wrong.** "v13.2 is the first org-spanning release" (#17830) couples the fastest-moving product (the Institution / FM, 0.1.0, pinning a `dev` engine commit) to the slowest gate. Only the engine has ever cut a release (13.1.0); skills already ships on its own npm cadence (0.1.14); the Brain's release form is the image cut (neomjs/neo-agent-brain#253). Per-repo cadence is the de-facto state.

**This week's release-gating work is absent:** deployment topology (#19047, D#19050) and content scope (D#19051); the corpus consumer cutovers under #17416 and the engine-side retirement of `resources/content` (17,929 tracked files, 193 MB); KB currency (neomjs/neo-agent-brain#402 ← #237 ← #253, the operator's top item because it re-enables the Dream Pipeline and the Golden Path); the flagship film and the Workstation tour refresh (#15252); the Hacktoberfest door (#18985, opens 2026-10-01); the consumer-install blocker #19052. Milestone #9 reads 104 closed / 9 open, and #18303, #17416, #15252, #18985 are not on it.

**Stewards drifted:** the text names @neo-fable as steward of `#15798` and of cornerstone 2's rewrite path; `#15798` left the repository and the rewrite path is #18303 (@neo-gpt).

## The Architectural Reality

- `ROADMAP.md` is next-release-only by rule (`.agents/skills/update-roadmap/references/update-roadmap-workflow.md`): cornerstones + rationale, an explicit deferred set, one named self-selected steward per cornerstone; replace, never append; no exhaustive item list ("stales → FAIL"). The rule is per repository: each product repository holds its own next release.
- Anchors are prose links; nothing checks that they resolve. #15217 (2026-07-16) fixed the same drift class by hand, and its author declined a freshness lint on one incident. This is the recurrence.
- The "Shipped history" pointer targets `resources/content/release-notes/`, which D#19051 may move.

One documentation PR that replaces the v13.2 section in place:

1. **Thesis.** The engine's 13.2.0 gate: its site deploys and its notes ship. Retire "the first org-spanning release"; name the three release lines and their order — engine 13.2.0 → Brain runtime images (neomjs/neo-agent-brain#253 + #402) → Institution / FM (D#18965's first-run path against a published engine) — each with its own notes. Deployment as part of the engine's gate satisfies #19047 AC-5 by construction; coordinate with @neo-opus-ada so the row is written once.
2. **Cornerstones, priority-ordered as the operator steered tonight**, each with its live anchors and its live steward (read from the assignee, never pre-assigned; unstewarded rows say so):
   1. KB currency — neomjs/neo-agent-brain#402 / #237 / #253
   2. Deploy topology + content scope — #19047 (D#19050, D#19051), #19052
   3. Corpus consumers + engine mirror retirement — #17416 (neomjs/neo-agent-brain#246 for the FM feed)
   4. Docking, Workstation and the flagship film — #18303, #18680, #15252 (+ #16498, #17871)

   6. Release notes + launch — #14800 (engine notes), #14790
   7. FM cockpit + local onboarding — #13015, #14230, D#18965 (the FM line's gate, pointed at, not owned here)
3. **Org table:** engine, brain, institution, skills, devindex, github-content-sync, pages — one line each: what the engine's release means there, and where that repository's own next-release section lives (or "none yet").
4. **Deferred set:** keep it, re-verify each anchor resolves, and place #15490 / #14781 in or out explicitly.

## Avoided Traps

- An exhaustive item list: the roadmap names cornerstones; the milestone query is the full set.
- Pre-assigning stewards: live assignees are facts; unstewarded rows stay visibly unstewarded.
- Fixing anchors in prose only: cross-repo anchors need the full form, because a bare `#N` means this repository.
- One org roadmap that restates every repository's scope: each repository owns its next release; the engine's roadmap points, it does not copy.
