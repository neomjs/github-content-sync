# The portal's content generators derive resources/content from the working directory

## Context

#19158's census ([IC 5815306776](https://github.com/neomjs/neo/issues/19158#issuecomment-5815306776)) lists the engine's build readers that derive the frozen mirror:
- **From the working directory** (`ROOT_DIR = process.cwd()`):
  - `buildScripts/docs/index/tickets.mjs:31-33`, `pulls.mjs:30-32`, `discussions.mjs:22-24`;
  - `buildScripts/docs/seo/generate.mjs:10,634-695`, its conversation globs.
- **From `__dirname`:** `buildScripts/release/analyzeClosedSinceRelease.mjs:29-32`.

The portal's runtime read, `Neo.config.basePath + path` in `apps/portal/view/content/Component.mjs:188`, fetches whatever `path` those indexes write.

## The Problem

D#19051 adopted C1. `<corpus-root>` is a declared location (ADR 0004 §2.1.1), and deriving it from the working directory is what §5.8 forbids.

For v13.2, the pages build copies the pinned corpus to where these generators look (neomjs/pages#10), which keeps them working while the mirror exists. Once #19159 deletes the mirror:
- a local run of any of these generators reads an absent tree;
- the engine's dev portal fetches paths that are no longer there.

## The Fix

- **Generators:** the four generators and `analyzeClosedSinceRelease` take the corpus root as an input, with no working-directory default. The index paths they write are relative to a served content base, not the engine root.
- **Portal:** it fetches conversation bodies from that base, which is a config value. The pages build sets it to where it serves the pinned checkout, and a developer's server serves a local corpus checkout there.
- **Release notes:** `release.mjs` and the release-note globs stay with #19157.
- **Baseline:** these rows leave `check-content-root-derivations-baseline.json` in the same PR.

**Decision Record impact:** aligned with ADR 0004 §2.1.1 and §5.8, and D#19051 C1.

## Acceptance Criteria

- [ ] **AC-1:** Each generator run without the corpus-root input fails and names the input. With the input, it writes the same index as today from the same corpus commit.
- [ ] **AC-2:** The portal renders an active and an archived ticket body from the served base.
- [ ] **AC-3:** The rows above leave the guard's baseline.

## Out of Scope

- Origin-qualified routes for non-`neo` origins (D#19051 acknowledgment AC 3), which is its own leaf.
- Release notes (#19157) and the deletion (#19159).
