# Point the portal's four devindex example entries at the deployed app

## Context

D#19050 graduated on 2026-09-23 with **C′**. devindex gets its own Pages site, and `neomjs/middleware-v2` serves it at `neomjs.com/devindex/`. The graduation ledger lives in #19047.

## The Problem

The portal's four `apps/portal/resources/data/examples_*.json` files list devindex at engine-relative paths: `apps/devindex/index.html` and `dist/{development,esm,production}/apps/devindex/index.html`. They resolve today only because `pages` still carries the committed 13.1.0 build, which the 13.2 rebuild deletes (#19047).

## The Fix

Point all four entries at the deployed app. Use its canonical URL, `https://neomjs.com/devindex/`, so a local portal links out rather than 404ing on a path it does not serve. ~~Land this after the middleware route is live.~~ *(Amended 2026-09-24: `neomjs.com` picks up the registries only with the 13.2 `pages` build, which #19047 AC-4 sequences after the middleware deploy, so the registry change may merge first. The live route stays validated on #19047.)*

## Acceptance Criteria

- [ ] All four `examples_*.json` devindex entries point at the canonical URL `https://neomjs.com/devindex/` (pinned in `TabContainerController.spec.mjs`).
- [ ] The canonical URL serves the deployed app `[L3-deferred — operator handoff needed]`. Owned by #19047 once this closes: at 2026-09-24 16:57Z it does not yet (neomjs/middleware-v2 #24 carries the route).
- [ ] No other entry changes.
