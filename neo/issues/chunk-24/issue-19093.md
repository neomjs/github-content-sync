# Move the 59 concept files out of the generated content root

`[PROVISIONAL_UNGRADUATED: D#19096]` — **scope provisional; do not assign, claim or start.** This ticket was filed 2026-09-23 09:0xZ with a destination decided by the engine's convenience (`learn/concepts/`). The operator's constraint the same hour — *"other projects / companies / human operators want to run their own neo agent os versions … ingesting their target repos … they will get auto-generated concepts too"* — turns the destination into a per-tenant contract, which is D#19096's question. The premise below stands; the prescription waits for graduation.

## Context

Roadmap cornerstone 3 (#17416) ends with the engine no longer carrying the `resources/content` mirror. One family under that root has no successor in the published corpus: `resources/content/concepts/` — **59 authored Markdown files** (`name`, `tier`, `uniqueToNeo`, `tags`, `verifiedAt` frontmatter + one paragraph each), written once in #11373 (2026-05-15), never regenerated. They are the explanation layer of the concept ontology (ADR 0023 §2; ADR 0024 §6 keeps their unification with the JSONL records as a follow-up), sitting under a root ADR 0004 §1.3 defines as a regeneratable cache. Epic-review census row: https://github.com/neomjs/neo/issues/17416#issuecomment-5791980653.

## The Problem (verified premise)

1. **The split Brain already reads nothing.** `ConceptSource` resolves `path.resolve(aiConfig.projectRoot, sourcePaths.ConceptSource)` with `projectRoot = process.cwd()` (Brain `ai/configBase.mjs:13`). Probe on Brain `dev@5027afc` with the Neo global loaded: `<brain>/resources/content/concepts exists: false` → 0 chunks, silently; `<brain>/node_modules/neo.mjs/resources/content/concepts exists: true, 59 files`, unread. The plane still answers `query_documents type:concept → vectorSources: 59` only because it runs the monorepo build (`467fd122`). neomjs/neo-agent-brain#282 lists Concept among the five default sources needing a post-split route.
2. **The graph half is misplaced the same way.** `nodes.jsonl` (65) and `edges.jsonl` (182) are tracked in the engine at `.neo-ai-data/concepts/`, while a plane's live store is plane data (`ConceptService.defaultConceptsDir = path.join(AiConfig.plane.dataRoot, 'concepts')`, Brain `ai/daemons/orchestrator/daemon.mjs:452`).
3. **The obvious repair dies with the mirror.** A pin-relative route (`node_modules/neo.mjs/resources/content/concepts`) works until cornerstone 3 deletes `resources/content`.

## Divergence (inline, pre-quorum reservation per ticket-create §1d)
