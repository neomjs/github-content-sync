# Six guides describe the Sass theme sources that 14.0 removes

Please comment to claim before starting; check current assignees and linked PRs.

## Context

#21217 (PR #21225) turns the engine's theme sources into plain CSS: `resources/scss/**/*.scss` becomes `resources/css/**/*.css`, the theme build copies the sheets instead of compiling them, Sass leaves the engine, and a package names its sheets with `"neo": {"css": "<dir>"}` instead of `"neo": {"scss": "<dir>"}`. Its Contract Ledger leaves the guides to a follow-up leaf. This is that leaf.

## The Problem

Six files under `learn/` still describe the Sass tree on `dev`: `guides/uibuildingblocks/StylingAndTheming.md` (25 mentions: the theme tree, file paths, "built with SCSS"), `guides/uibuildingblocks/DockLayoutsStyling.md` (2), and `guides/uibuildingblocks/DockLayouts.md`, `guides/uibuildingblocks/DockLayoutsAdoption.md`, `guides/fundamentals/CodebaseOverview.md` and `tutorials/Earthquakes.md` (1 each). Once #21217 merges, a reader who follows them looks for files that no longer exist.

## The Architectural Reality

- Theme sources: `resources/css/{src,theme-*}/**/*.css`, one file per class per theme, plain CSS with native nesting. The built output and its URLs do not change: `dist/<env>/css/<folder>/<class>.css`, mapped by `resources/theme-map.json`.
- A workspace keeps its own sheets in `resources/css`; a package names its root with `"neo": {"css": "<dir>"}`.
- `buildScripts/build/themes.mjs` copies the sources through postcss (autoprefixer, plus cssnano for esm and production).
- The motion vocabulary is declared once in `src/Global.css`, for every `neo-theme-*` root.

## The Fix

Rewrite each mention to the plain-CSS tree: `resources/scss/…/*.scss` becomes `resources/css/…/*.css`, and "SCSS" becomes "CSS". Any Sass-only syntax a guide shows (variables, mixins, `@import`, `//` comments) becomes its plain-CSS form: custom properties, nesting, block comments. Where `StylingAndTheming.md` explains how a theme is built, it describes the copy build and the package field.

## Acceptance Criteria

- [ ] `git grep -niE "resources/scss|\.scss\b|\bsass\b" -- learn ':!learn/blog'` prints nothing.
- [ ] Every path the six files name exists on `dev` after #21217 has merged.
- [ ] `StylingAndTheming.md` describes the copy build and the `"neo": {"css": "<dir>"}` field.

## Out of Scope

Blog posts under `learn/blog/` (they describe their own time) · release notes · the generated workspace's scaffold (neomjs/create-app#61) · the engine change itself (#21217).
