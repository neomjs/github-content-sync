# No hook enforces the ban on Bash redirection and sed -i writes

## Context

`CLAUDE.md` `§file_editing_tool_selection` bans Bash redirection (`>`, `>>`, `cat << EOF`) and stream editors (`sed -i`) as ways to modify files. Every write goes through Write or Edit, so the harness can track and diff it (origin #9473). Nothing enforces the ban mechanically.

One seat's own record counts 20 breaches between 2026-10-03 and 2026-11-06:
- most are output captured into scratch files (`cmd > scratchpad/x.log`);
- the rest are `sed -i` and heredoc-authored scripts;
- several came within minutes of the seat writing the rule down.

A rule that keeps losing to a habit needs a guard, not another reminder.

## The Architectural Reality

`.claude/settings.template.json` (tracked; each seat's untracked `.claude/settings.json` is hydrated from it) already registers narrow `PreToolUse` Bash guards in `.claude/hooks/`, each refusing with an explanatory message: `rgReplaceGuardHook`, `bodyFileGuardHook` and `harnessIdGuardHook`. `rgReplaceGuardHook.mjs` carries a quote-aware shell tokenizer, so an operator inside quoted program text stays one token.

## The Fix

A `redirectionGuardHook` beside them, registered in `.claude/settings.template.json`, with a `.gitignore` exception so the hook file is tracked like its siblings (ADR 0040 §2.7: Engine-only contributor guards stay Engine-owned). It refuses:
- an unquoted `>` or `>>` whose target is a path;
- `sed -i` and `perl -i`.

`tee` stays allowed. The rule names redirection and stream editors, and the e2e battery recipe in `test/playwright/playwright.config.e2e.mjs` persists its run log with `| tee`.

The refusal names the alternative: pipe the output (`cmd 2>&1 | tail`), or use Write or Edit for an authored file. It reuses the sibling's tokenizer and fails open on a malformed payload, as its siblings do.

## Acceptance Criteria

- [ ] Refuses `cmd > file`, `cmd >> file`, `cat > file <<'EOF'` and `sed -i '' 's/a/b/' file`.
- [ ] Allows `2>&1`, `>/dev/null`, `&>/dev/null`, `>&2`, the here-string `<<<`, a heredoc feeding a reading command (`python3 - <<'EOF'`), and `>` inside quoted program text (`awk '$2>5'`, `jq 'select(.n > 1)'`, `python3 -c 'a > b'`).
- [ ] A unit spec beside the siblings' covers each arm, including the fail-open path.

## Out of Scope

- Other harnesses' rule files.
- Changing the rule's text.
