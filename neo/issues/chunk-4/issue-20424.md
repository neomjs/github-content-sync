# Manual Neural Link entries outside Codex omit the Brain runtime root

## Context

#20417 / PR #20419 fix the manual Codex template, whose Neural Link command never passed `--cwd <YOUR_BRAIN_REPO_PATH>`. Without that flag, `Server.boot()` never sets `ConnectionService.cwd`, so the server never auto-connects to its Bridge (Brain `ai/mcp/server/neural-link/Server.mjs`, the `if (ConnectionService.cwd && aiConfig.autoConnect)` guard). #20417 scoped other harnesses out. Reviewing #20419 surfaced two manual surfaces with the same gap:

1. **`.github/AI_QUICK_START.md`, Core Configuration (Antigravity 2.x).** The `neo-mjs-neural-link` command runs `exec <YOUR_NODE_PATH> <YOUR_BRAIN_REPO_PATH>/ai/mcp/server/neural-link/mcp-server.mjs` with no `--cwd`. The Claude Desktop section says to use "the same four entries as the Antigravity block above", so Claude Desktop users copy the same gap.
2. **`.claude/claude_desktop_config.example.json`.**
   - All four entries point at `<YOUR_NEO_REPO_PATH>/ai/…`, and the Engine has had no `ai/` since the Brain extraction (ADR 0040).
   - Its Neural Link entry passes `--cwd <YOUR_NEO_REPO_PATH>`. That names the target repository as the Bridge runtime root, the conflation #20417's design authority rejects (`agentosRuntimeRoot` ≠ `targetRepoRoot`).
   - No tracked doc references this file any more. Closed #16205 last refreshed its MC/KB entries, before the extraction.

## The Fix

1. Append `--cwd <YOUR_BRAIN_REPO_PATH>` to the Quick Start's JSON Neural Link command, matching the Codex template after #20419.
2. For the example file, either point every entry at `<YOUR_BRAIN_REPO_PATH>/ai/…` with `--cwd <YOUR_BRAIN_REPO_PATH>`, or delete it, since nothing references it. The PR states which and why.

Fleet-managed seats already receive the flag from provisioning (`prepareManagedAgentWorkspace.mjs`, `seatRuntimeRecord.mjs`) and need nothing here.

## Acceptance Criteria

- [ ] The Quick Start's JSON Neural Link entry passes `--cwd <YOUR_BRAIN_REPO_PATH>` and keeps the target checkout as the shell's working directory.
- [ ] No tracked file points a manual Claude config at `<YOUR_NEO_REPO_PATH>/ai/`, and no tracked entry names the target repository as the Neural Link `--cwd`.
- [ ] Evidence in the shape of #20419's: an isolated launch of the corrected JSON command from an unrelated cwd connects to a loopback test Bridge, and the old command does not. #20419's Test Evidence has the recipe. No live config, credential or seat is touched.
