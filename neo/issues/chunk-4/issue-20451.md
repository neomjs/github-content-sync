# The Brain-gated e2e tier retires once no Engine spec needs the bridge

## Context

@tobiu, 2026-11-06, verbatim: "NL is split to the engine side (processing arriving tool calls), and the brain side: bridge and tool definitions. both sides on their own can get tested inside each repo (we already do this). a full e2e cycle: i can not see any reasonable way, that is not heavy hitting on CI."

The Brain-gated tier (`test-e2e-brain.yml`) is that full cycle. Every Engine run of it checks out the Brain and drives Neural Link specs through the Brain's bridge. In #20328's baseline it holds 66% of Engine CI runner-minutes. Discussion D#18775 already chose the replacement: an off-socket adapter, so that Neural Link specs drive the page's own App Worker with no bridge and no Brain checkout. #20370 owns that track:
- dedicated-worker adapter: merged in #20372 / #20373;
- selection: #20374;
- SharedWorker apps: #20376.

## The Problem

None of those leaves removes the tier itself. Without a retirement task, the workflow, the Brain checkout and the Brain-only selection code would stay after their last spec moves. That is the pattern this morning's rule forbids: logic needs a task that uses it and then retires it.

## The Fix

Once #20374 and #20376 have landed:
- Every Neural Link spec that still needs the bridge is either ported to the off-socket adapter or retired with its reason. The Brain tests its own bridge and tool definitions.
- Delete `.github/workflows/test-e2e-brain.yml` and the classifier's `e2e_brain_tier` output.
- Delete the Brain-only selection and receipt code in `buildScripts/util/e2eCiSelection.mjs` (`BRAIN_*`, `brain*` functions) and the exclusion in `test/playwright/externalBrainSelection.mjs`, together with their specs.
- Remove any remaining Brain checkout from Engine workflows.

## Acceptance Criteria

- [ ] No Engine workflow checks out `neomjs/neo-agent-brain`. A `git grep` over `.github/workflows` shows it, with a control.
- [ ] Every Neural Link spec runs off-socket in the engine tier or is retired with a written reason.
- [ ] The Brain-only selection, receipt and exclusion code is deleted together with its specs. The deletion commits carry `spec-retired:` accounts.
- [ ] Engine CI runner-minutes per PR drop measurably against #20328's baseline.

## Out of Scope

- The off-socket adapters themselves (#20370, #20374, #20376).
- Brain-side bridge and tool-definition tests, which belong to the Brain repository.
