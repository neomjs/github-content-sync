# The Brain-gated e2e tier retires once no Engine spec needs the bridge

## Context

@tobiu, 2026-11-06, verbatim: "NL is split to the engine side (processing arriving tool calls), and the brain side: bridge and tool definitions. both sides on their own can get tested inside each repo (we already do this). a full e2e cycle: i can not see any reasonable way, that is not heavy hitting on CI."

The Brain-gated tier (`test-e2e-brain.yml`) is that full cycle. Every Engine run of it checks out the Brain and drives Neural Link specs through the Brain's bridge. In #20328's baseline it holds 66% of Engine CI runner-minutes. Discussion D#18775 already chose the replacement: an off-socket adapter, so that Neural Link specs drive the page's own App Worker with no bridge and no Brain checkout. #20370 owns that track:
- dedicated-worker adapter: merged in #20372 / #20373;
- selection: #20374;
- SharedWorker apps: #20376.

## The Problem

None of those leaves removes the tier itself. Without a retirement task, the workflow, the Brain checkout and the Brain-only selection code would stay after their last spec moves. That is the pattern this morning's rule forbids: logic needs a task that uses it and then retires it.

## The Fix

Once #20374 and #20376 have landed:
- Every Neural Link spec that still needs the bridge is either ported to the off-socket adapter or retired with its reason. The Brain tests its own bridge and tool definitions.
- Delete `.github/workflows/test-e2e-brain.yml` and the classifier's Brain outputs: `e2e_brain_tier`, plus `e2e_brain_paths`, `e2e_brain_matrix` and `e2e_brain_shards` from #20411. Delete the `brain` branch of `tierSelection()` and `FULL_SHARDS.brain` with them.
- Delete the Brain-only selection and receipt code in `buildScripts/util/e2eCiSelection.mjs` (`BRAIN_*`, `brain*` functions) and the exclusion in `test/playwright/externalBrainSelection.mjs`, together with their specs.
- Remove any remaining Brain checkout from Engine workflows.

## Acceptance Criteria

- [ ] No Engine workflow checks out `neomjs/neo-agent-brain`. A `git grep` over `.github/workflows` shows it, with a control.
- [ ] Every Neural Link spec runs off-socket in the engine tier or is retired with a written reason. At `dev` `268b527d30`, `selectExternalBrainSpecs` still gates 70 of 207 e2e specs. By the markers in their source:
  - **45 drive real windows** (`open_component_window`, `close_window`, `position_window`, `focus_window`, `get_window_topology` or popups), which the adapter's eligibility rules exclude. One is `workstation/WorkstationFilmTourNL`, still quarantined. Its hop 4 refusal was classified as film-harness timing (#19919: the hop claimed 8/8 locally, 4 of them under 4× CPU throttling). Probe commit `bc5c0036e6` on branch `agent/19919-hop4-classify` makes a refused hop print its pointer, window rect, zone and indicator hit points.
  - **4 hold multi-writer Bridge sessions** (`bridgePort`, `waitForSession`), and **2 import Brain services** (`loadNeuralLinkModules`).
  - **19 carry none of these markers.** Three are #20461's measured residuals:
    - `workstation/DockSplitterZoneIdNL`: "3 consecutive boots" fails off-socket 3/3 (the dock host is never visible after a re-boot, since the SharedWorker handle does not survive re-boots) and passes over the Bridge 2/2.
    - `workstation/WorkstationNestedColumnResizeNL`: the reverse-cancel arm flaked once in 4 off-socket runs with 2 workers; 9/9 on the repeat.
    - `workstation/WorkstationMaximizeTabOverflowNL`: carries an open hosted-flake note (11-06).

    The other 16 are the first candidates for the adapter list: `core/SourceMoveWorkspaceNL`, `dashboard/DemoATourNL`, `dashboard/DockOperationsNL`, `dashboard/DockStandaloneThemingNL`, `list/AnimateMembershipNL`, `rendering/NativeSelectNL`, `rendering/NestedComponentsNL`, and in `workstation/`: `WorkstationDockFlipResizeNL`, `WorkstationDockSplitChromeNL`, `WorkstationDragTextSelectionNL`, `WorkstationFocusedTabOverflowNL`, `WorkstationGridRepaintNL`, `WorkstationRootEdgeCornerNL`, `WorkstationStarvedTourNL`, `WorkstationTabRestoreNL`, `WorkstationTourActivationNL`.
- [ ] The Brain-only selection, receipt and exclusion code is deleted together with its specs. The deletion commits carry `spec-retired:` accounts.
- [ ] Engine CI runner-minutes per PR drop measurably against #20328's baseline.
