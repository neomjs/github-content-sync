# Engine 13.4.0 release notes, written once the under-25 gate holds

## Context

13.4 is the householding release (`ROADMAP.md`, *Next: Engine 13.4*). Its gate is fewer than 25 open Engine issues at the cut, and the cut is set for Saturday 2026-11-07 in the evening, or Sunday at the latest (#20465).

The operator added a second gate on 2026-11-06 at ~23:5xZ: the header groups (#20379, merged as #20397 during the sweep) must be finished. That means #20501 is merged, Maryam's verification matrix on #20379 is green, and every defect the matrix finds is fixed before the tag. The same rule covers any other feature merged during the sweep: it is either finished or named as a residual in these notes. `publish.mjs` reads `.github/RELEASE_NOTES/v<version>.md`, and its prepare step blocks while that file is absent (`buildScripts/release/publish.mjs:63`, `readPrepareBlockers` at `:156`).

**Sequencing (operator, 2026-11-06 ~22:38Z):** the notes are written once the open count is under 25. The release's headline chapter is the householding itself, so writing it while the count still moves means rewriting it. This ticket replaces the multi-iteration epic #20496 (closed, folded here): one ticket, one notes PR at the gate, and a cross-family read before it merges. 13.3.1's #20023 had the same shape.

## The Problem

The window since 13.3.1 (published 2026-10-23T23:27:07Z) is large. GitHub search at 2026-11-06T22:36Z, with `dev` at `2f6e04b2ad`, counted:
- 256 merged pull requests;
- 315 closed issues: 266 as completed, 48 as not planned and 1 as a duplicate;
- 105 closed issues filed before 2025, 92 of them as completed. The oldest is #26, closable tabs, filed in November 2019.

The open count stood at 189 on 2026-11-05 at 10:20Z (#15000's measurement) and at 45 a day and a half later. Beside the householding, the window carries:
- Engine CI that starts only the test tiers a change can reach (#20328);
- the single-app Neural Link specs running in hosted CI without a Bridge (#20370);
- grid columns under shared group headers (#20379) and CSV export (#20380);
- a long run of component and form requests.

"Householding" names the gate. It must not shrink the story (release-notes §1, rule 4).

## The Architectural Reality

- **Location.** Notes are flat files in `.github/RELEASE_NOTES/`, one per version. `dropReleasedNotes` (`publish.mjs:71–80`) removes older notes at each cut, so `dev` holds only `v13.3.1.md`. The precedent set is read from GitHub Releases: 13.3.0, 12.1.0, 11.24.0, 11.23.0, 11.22.0 and 13.0.0.
- **Title.** `finish` releases the merged note with its frontmatter stripped. Its first H1 becomes the GitHub release title.
- **Guards.**
  - `test/playwright/unit/buildScripts/release/PublishReleaseNoteOrphan.spec.mjs` pins the authored path and the flat layout.
  - The release-note link scan in `test/playwright/unit/buildScripts/docs/seo/Generate.spec.mjs` refuses mutable GitHub links.
- **Scope.** The corpus count is `buildScripts/release/analyzeClosedSinceRelease.mjs <cutoff> --corpus-root <github-content-sync clone>/neo`. The release-notes skill's §2 recipe predates `--corpus-root` (#19408) and fails as written; a defect note is out. The cut-head numbers come from live GitHub search.

## The Fix

Write `.github/RELEASE_NOTES/v13.4.0.md` in one pass once the gate holds, to the precedent bar (release-notes §5). The document carries:
- **The header.** `Release Type` and `Stability` as the operator confirms them, and the `Upgrade Path`.
- **The summary.** A TL;DR, then "13.4 in 2 Minutes" with who built it and what changed.
- **The clean-slate chapter.** It comes from #15000 (the operator's ask and rules) and the counts at the cut head.
- **Chapters for the mined arcs.** CI tiers by reach (#20328), Neural Link specs without a Bridge (#20370), the grid work, and the requests that had waited years.
- **Honest bounds.** "Completed" covers both work delivered in the window and premise reads that found it already shipped. The issues that left by transfer or conversion are inferred from the counts.
- **Upgrading from 13.3.1.** Each behaviour change is verified against the merged code. The known candidates are `Neo.Responsive`'s removal (#20334), Button `editRoute` defaulting to `false` (#20342), the grid-cell components' new path (#20470) and StateProvider store entries defaulting to `Neo.data.Store` (#20214). If #20561 merges in the window: a Function selector in `un()` / `removeListener()` matches the registered function by identity, so a hot-patched handler is removed through the original function or its subscription id, and removal by method name uses the object form, `un({change: {fn: 'onChange', scope: this}})`, because `un('change', '…')` reads that String as a subscription id (Ada's optional echo on the review; Sophie's input, 2026-11-07).
- **What comes next,** and the grouped Full Changelog, regenerated at the cut head.

The §3 mining for the arcs other than the householding does not depend on the count, so it runs before the gate.
