## Context

neomjs/neo#19096 graduated option E′ into neomjs/neo-agent-brain#471: concepts are tenant-scoped plane data, and neomjs is one instance of that mechanism. This ticket was the provisional shell for the engine's half. Under E′ the engine copies are imported, which is a no-op while they are equal, and then deleted, never moved. Roadmap cornerstone 3 (#17416) ends with the engine no longer carrying the `resources/content` mirror, and this is that family's leaf.

## The Problem

The engine still carries both halves of neomjs' concepts:
- **The explanations:** 59 files in `resources/content/concepts/`, under a root that ADR 0004 §1.3 defines as a regeneratable cache and that neomjs/neo#19159 deletes.
- **The graph copy:** `nodes.jsonl` (65 rows) and `edges.jsonl` (182) at `.neo-ai-data/concepts/`. It is a strict, field-identical subset of the plane store, per @neo-opus-ada's row-by-row check (neomjs/neo#19096 fact 9), and the npm package ships it.

## The Architectural Reality

- **The copies are equal today.** 59 docs against 65 nodes: 0 missing, 0 mismatches (@neo-gpt, DC 18565631). The engine JSONL holds 65 of 65 nodes and 182 of 182 edges, field-identical to the plane store.
- **Package surface** (@neo-opus-grace's `STEP_BACK`, point 2):
  - `.gitignore:108` and `.npmignore:140` negate `.neo-ai-data/concepts/`.
  - `buildScripts/util/check-package-contents.mjs:65` allows it.
  - `test/playwright/unit/buildScripts/checkPackageContents.spec.mjs` (L67–68, L154–155) and `gitignoreNegationReachability.spec.mjs` pin it.
  - `buildScripts/util/check-chore-sync.mjs:102` names the concepts root.
- **No engine code reads either copy.** The content-root guard baseline (#19167) has no concept rows. The Brain's interim route over the engine pin retires in neomjs/neo-agent-brain#474.

## The Fix

- **Equality receipt, taken at execution time.** Compare each engine node by `id`, and each edge by `source|target|type`, with the newest plane bundle. The Markdown files are gone, and the JSONL rows carry the same descriptions.
  - If they are equal, the import is a no-op.
  - Any difference is a source-authority conflict. Report it; never let a frozen engine file overwrite a newer plane description.
- **Delete, never move:**
  - `resources/content/concepts/` (59 files), delivered by neomjs/neo#19159;
  - `.neo-ai-data/concepts/` (2 files).

  The PR re-runs the id-by-id comparison against the newest bundle and prints the counts as its receipt.
- **Package surface.** Remove both negations, the allow entry and the spec cases that pin them, and update the `check-chore-sync.mjs:102` comment.
