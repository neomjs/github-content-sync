# Open two Portal examples at their compiled entrypoints

## Context

The v14.1 release gate covers the shipped Portal. On the public catalog, **Open live** for Table Filtering and Contact Editor Dialogs can land on the Portal home page. A Chrome check selected ESM in the visible build selector and clicked the real control on each card. Both popups reached `/home`.

## The Problem

Each record has a directory URL for Development, ESM and Production. A browser request with the selected theme follows a 301 to the slashless path. The next response is HTTP 200 with the Portal shell. All six explicit `index.html` requests return 200 directly with the expected example title and build-specific MicroLoader.

## The Architectural Reality

The per-group catalog JSON owns the mode targets. The card title and Open live control use `Example.href`, which reads the selected URL and adds the current theme query. [Example.href](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/apps/portal/model/Example.mjs#L126-L156)

Design authority: “The address a record opens in a build mode: its explicit external link, or its path below `baseUrl`.” The earlier components overview also called out this exact directory behavior for Dialog before that overview was superseded. [Example.href](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/apps/portal/model/Example.mjs#L126-L130) · [Prior Dialog finding](https://github.com/neomjs/neo/issues/20694#issuecomment-6925655432)

## The Fix

Give the three compiled URLs in `grid-table.json` for `table-filtering` and the three in `dialogs.json` for `dialog-drag-drop` their explicit `index.html` filenames.

| Surface | Authority | Behavior | Fallback | Docs | Evidence |
| --- | --- | --- | --- | --- | --- |
| Two Portal cards | Group JSON and `Example.href` | Each compiled choice opens its example with the selected theme query | Dev Mode keeps its existing source route | Existing catalog mode selector | Browser clicks and final example title, path and loader |

Prescription checked: the group JSON owns both targets. The catalog connection reads these files directly and the existing link helper already forwards the selected URL and theme.

## Acceptance Criteria

- [ ] Open live on each of the two cards opens its example in Development, ESM and Production. Record each final document and loader.
- [ ] All card metadata outside those six URL fields is identical to the baseline. The selected theme query still reaches each compiled target.
## Post-Merge Validation

- [ ] After rollout, repeat the six public launches on `neomjs.com` from the actual catalog.

Server routing policy, cover assets and new catalog records.
