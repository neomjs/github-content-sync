# Make modified grid values themeable until their edits are accepted

Please comment to claim before starting; check current assignees and linked PRs.

## Context and problem

In Clio’s “pencil until kept” design a modified value is slanted graphite with a corner mark. On acceptance it returns to upright ink. Both cold readers had mistaken the earlier unsaved styling for placeholder text. [Clio’s cold reads and hooks](https://github.com/neomjs/neo/discussions/22418#discussioncomment-19964363)

## The architectural reality

With tracking enabled, [Row](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/src/grid/Row.mjs#L277) projects `record.isModifiedField(dataField)` as `neo-is-modified` when `highlightModifiedCells` is enabled. [Body.css](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/resources/css/src/grid/Body.css#L7) already paints the corner. A real tracked-record probe exposed a second gap: after A → B, `record.reset({field: 'B'})` can leave the field modified despite accepting its current value. Resetting to a different supplied value clears it. [Record.reset and its baseline](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/src/data/RecordFactory.mjs#L339)

## The fix

Give themes component variables for modified value text color and font style. Preserve the existing corner. Ensure the native record baseline and the rendered mark agree when the application accepts the current edited value. Use native tracking, write and refresh paths; keep unrelated modified fields intact.

## Acceptance criteria

- [ ] Edit one tracked cell and leave the editor. The real rendered value can become italic and take a theme-defined color while its corner remains. Demonstrate readable modified text on ordinary and selected cells, including cell selection, without losing focus or selection feedback.
- [ ] On native reset/accept of the same edited value, isModifiedField and the visible style both clear; other dirty fields remain dirty. Cover revert-to-original and a different accepted value. A baseline-only acknowledgment must not invent a business-value change.
- [ ] Scroll a modified cell out of and back into a buffered grid. Its styling follows its record and field, and recycled clean cells remain clean. Without opt-in, existing text and corner behavior remain the visual control.
