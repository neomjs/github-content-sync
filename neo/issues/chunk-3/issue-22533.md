# theme-base: bind timeline's 3 sheets (31 variables) to roles

Owner: Ada (`@neo-opus-ada`). This is the `timeline` row of #22484, the parent of #22295's step 6.

## Context

Step 6 declares each engine package's variables once in `theme-base`, bound to theme Neo's roles (`resources/css/theme-neo/Global.css`). `timeline` has three sheets per scheme with 34 declarations of 31 names: the track (`Column.css`, 13), the event editor (`EventEditor.css`, 12) and the time axis header (`TimeAxisHeader.css`, 9). The header sheet repeats three of the track's names: the non-working shade, its border and the now marker.

#22490's triage of run 2 reported the timeline header darker than the locked column headers beside it in dark ([the note on #22484](https://github.com/neomjs/neo/issues/22484#issuecomment-7232601468)). At `76d743e589` the two agree again, measured on the painted elements of `scheduler/basic` and `gantt/basic`: `rgb(22, 28, 38)` in dark and `rgb(233, 237, 242)` in light, as on the released site. `src/scheduler/Container.css` binds the locked headers to the timeline tokens (#21703), so this row moves both. They read `background-surface-raised`, as a standalone grid's header does since rule 18.

## The Problem

Both `theme-neo-{light,dark}/timeline/*.css` hold literals, for example `--neo-timeline-header-background: #e9edf2` and `#161c26`. No role carries any of them. A theme written against the roles, or one generated with `--base theme-neo`, paints the timeline with none of these values, and the header cannot follow the bar it sits in.

## The Architectural Reality

- **Design authority:** #22295's rules, with ADR 0044 behind them.
  - Rule 1: binding by ending, by hand for a name two properties read.
  - Rule 3: dialogs read `radius-extra-large`.
  - Rule 16: a move binds and does not resize.
  - Rule 17: chrome is neutral.
  - Rule 18: a bar is raised, and its separators read `border-default`.
  - Rule 25: accent marks the hovered, selected or focused item.
- **Readers** (`resources/css/src/timeline/*.css`, `dev` at `76d743e589`):
  - Each colour name has one property reader, except `--neo-timeline-now-color` (the now line's `background` and the header label's `color`) and `--neo-timeline-editor-accent-color` (the Save button's `background` and `border-color`, which rule 1 names).
  - `--neo-timeline-gridline-step` is an input that the gridline gradient computes with (rule 11).
  - `--neo-timeline-header-height` is coupled to the grid header row beside it.
- **The header family:**
  - The scheduler and Gantt locked headers were matched to the timeline header in #21703.
  - The header's bottom edge reads the grid container's border since #21806. Its tier and tick lines keep the timeline's tokens, and so does the scheduler's vertical separators.
- **Classic themes:** `theme-light`, `theme-dark` and `theme-cyberpunk` declare all 31 names in their own three sheets, so they need no `initial` lines.

**Changes this row lists for #22490:**
- The header and the locked headers beside it turn raised: white in light, `#252834` in dark.
- Bars, focus and Save move from the timeline's own sky and teal to theme Neo's accent, and Save's dark label turns white.

### For the design seat (rule 13)

- **Q1, the bar's hover border, a state pair.** The bar rests on `border-accent`. No border role is one grade away. My recommendation is a new `border-accent-hover`, one grade toward the text in each scheme, as `border-strong-hover` is to `border-strong` (rule 22). The alternative, `focus-ring`, would make hover and focus look alike.
- **Q2, the non-working shade.** It is a translucent neutral band behind the bars and over the gridlines. `background-neutral-hover` holds the same paint (black 5 % · white 5 %, released 4.5 % · 3 %), but it is named for a state. `background-disabled` is opaque and would hide the gridlines. My recommendation: bind to `background-neutral-hover` and record "a translucent neutral band" as its second job, or name a role for it.
- **Q3, the now marker, bound by hand.** One name paints the now line and its header label. `text-danger` reads 7.46 · 7.24 on the raised header and keeps the released red, but the now marker is no status (rule 23's argument). My recommendation is `text-danger` by hand. In light, the frames show `text-danger` (`#a51e21`) painting the line darker than the released crimson (`#e11d48`). `border-danger` (`#ca2429` · `#ed756c`, 5.51 · 5.12 on the raised header) stays closer and still carries the label. Splitting by reader would need a new variable.
- **Q4, the editor's Cancel fill.** The button package paints a secondary button `transparent` at rest, while the released editor fills Cancel grey. Following the package leaves Cancel outlined by `--neo-timeline-editor-border-color`. My recommendation: follow the package.
