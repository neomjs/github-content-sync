# examples/grid/issues: muted id and date text reads 4.17:1 in dark

Owner: Ada (`@neo-opus-ada`). Found by #22490's run 4 (`dev` `76d743e589` against neomjs.com), the only `broken` verdict among its 2,155 rows.

## Context

The runner now keeps an unchanged colour when only its backdrop crosses a contrast floor (#22491). In `examples/grid/issues` in Neo Dark, the issue numbers in the locked id column and the dates in the last column keep their colour, `--examples-grid-issues-muted-color: #7f7a93`. What lies under them changed.

## The Problem

Each backdrop was measured on the painted page:

| Side | Backdrop under the muted text | Contrast |
| :--- | :--- | :--- |
| 14.0.0 (neomjs.com) | the theme's opaque cell fills, `#0d0f12` and the zebra `#11141c` | 4.67:1 and 4.48:1 |
| `dev` `76d743e589` | the example's own grid fill, `--examples-grid-issues-surface: #1c1a25`; hovered rows `#211e2b` | 4.17:1 and 3.97:1 |

The theme's cell fills no longer cover the example's surface since the `grid` move (#22389, rules 15 and 18: no zebra, and the locked cells read the grid's fill). The example's own palette, which applies since #22358, now paints under its muted text. The muted value was tuned for the old cell fills, and even there it reached only 4.48:1 on the zebra rows.

## The Architectural Reality

- The value lives in `resources/css/theme-neo-dark/examples/grid/issues/MainContainer.css`. It is read in `src/examples/grid/issues/MainContainer.css` by the header button labels and glyphs and by the id and date cells.
- Light is unaffected: run 4 found no crossing there.
- Moving the example's variables to the grammar is rule 12's work for the example's group move, not this fix.

## The Fix

Raise the dark value to `#938ea9`. It keeps the hue and stays dimmer than the body text (`#b3aec6`, 8.00:1). It clears 4.5:1 on every fill it meets:

| Fill | Contrast |
| :--- | :--- |
| the surface `#1c1a25` | 5.46:1 |
| a hovered row `#211e2b` | 5.20:1 |
| a raised header `#252834` | 4.67:1 |
| the page `#15131c` | 5.85:1 |

## Acceptance Criteria

- [ ] AC-1: In Neo Dark on a built tree, the muted id and date text of `examples/grid/issues` measures at least 4.5:1 on its painted backdrop, at rest and on a hovered row.
- [ ] AC-2: Frames of the example in Neo Dark, released against head.
- [ ] AC-3: A release-compare run of the example reports no `broken` row.

## Out of Scope

The example's rename to the grammar, and its other colours.
