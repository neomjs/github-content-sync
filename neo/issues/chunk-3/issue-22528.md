# Wait for settled desktop geometry in Adaptive Dialog tests

## Context

Adaptive Dialog #22489 landed as `e899523f6f`. Two Engine CI attempts on the same Pull to Refresh merge tree `3af9bf559b` failed different setup-dependent assertions in `EditInDialogExample.spec.mjs`.

## The Problem

- [First attempt](https://github.com/neomjs/neo/actions/runs/46105149676/job/140856180636) set 410 px on the desktop Dialog, then measured 357 px before resizing or touching the grip.
- [Second attempt](https://github.com/neomjs/neo/actions/runs/46105149676/job/140858309319) passed the grip case. The composition case captured 46.78 × 24 px as its initial desktop bounds, then measured the fully open 420 × 357 px Dialog on return.

## The Architectural Reality

[Dialog.animateShow](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/src/dialog/Base.mjs#L638-L688) mounts before the opening class arrives. The focused field and absent class can be observed before the opener animation starts. The [desktop fixture](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/examples/grid/nestedRecordFields/EditUserDialog.mjs#L58-L64) expands to 420 px at the test viewport.

## The Fix

Wait for an actual settled desktop frame in the two cases before taking baseline bounds or assigning a desktop height. Read the width, in-viewport geometry and animation state together on Main. Preserve the existing round-trip, focus, composition, threshold and cancellation assertions.

Prescription checked: `test/playwright/e2e/grid/EditInDialogExample.spec.mjs` owns readiness for both test journeys.

## Acceptance Criteria

- [ ] The composition round trip captures the settled fully open desktop bounds and preserves the existing focus, provider, and composition assertions.
- [ ] The grip case starts from settled desktop geometry before assigning 410 px and keeps the existing real-browser resize and cancel checks.
- [ ] Both cases pass repeated headless Chromium runs and the relevant hosted shard.

## Out of Scope

Engine or example behavior changes. This is test-only evidence repair.
