# theme-base: bind draggable's 3 sheets (4 variables) to roles

Owner: Vega (`@neo-opus-vega`). This is the `draggable` row of #22484, the parent of #22295's step 6.

## Context

Step 6 declares each engine package's variables once in `theme-base`, bound to theme Neo's roles. `draggable` has three sheets with 4 variables: the opacity of a dragged grid or table header button, and the tree sort proxy's shadow and radius.

## The Problem

`theme-neo-light/draggable/` and `theme-neo-dark/draggable/` declare the same four literals, among them the raw colour `rgba(0, 0, 0, .25)` in the proxy's shadow. No role carries any of them, so a theme generated with `--base theme-neo` declares none, and every reader computes to nothing.

## The Architectural Reality

- Design authority: #22295's rules. Rule 5: optical values stay listed literals and no raw colour stays in `theme-base`. Rule 6 reserves `opacity-disabled` for the disabled state, which a drag is not.
- Readers: `resources/css/src/draggable/grid/header/toolbar/SortZone.css:39` and `table/header/toolbar/SortZone.css:21` read the opacities, and `tree/SortZone.css:3-4` reads the radius and the shadow. None has a fallback.
- `theme-light` and `theme-dark` declare all 4. `theme-cyberpunk` declares only the radius, so the row declares the other three as `initial` there, and its readers keep what they compute today.

## The Fix

| Variable | Before (light · dark) | Binds to | After (light · dark) |
| :--- | :--- | :--- | :--- |
| `--neo-grid-header-button-dragging-opacity` | `0.7` | listed literal (rule 5) | `0.7` |
| `--neo-table-header-button-dragging-opacity` | `0.7` | listed literal (rule 5) | `0.7` |
| `--neo-tree-sort-proxy-box-shadow` | `0 2px 8px rgba(0, 0, 0, .25)` | `0 2px 8px var(--neo-color-shadow)` | black 16 % · 50 % |
| `--neo-tree-sort-proxy-border-radius` | `4px` | `radius-small` | `4px` |

The proxy's shadow takes the same shape as the dashboard row's drop chips (#22504). If the design seat answers that row's question 2 with `elevation-2`, this row follows it.

## Acceptance Criteria

- [ ] `resources/css/theme-base/draggable/` declares the 4 variables once, per the table. The six `theme-neo-{light,dark}/draggable/` sheets are deleted, and `theme-cyberpunk` declares the three it lacked as `initial`.
- [ ] `npm run theme-equality` passes against a `dev` build with every moved value declared.
- [ ] Frame pairs of a tree sort drag (`dev` and head) in theme Neo light and dark.

## Out of Scope

- The structural sheets under `resources/css/src/draggable/`.
