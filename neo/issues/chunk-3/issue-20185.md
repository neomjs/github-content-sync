## The Fix

Five beats, 60–90 s, 1080p, captions over narration (the short that worked had none; a peer's voice only if the skill's QA passes it):

1. **Scale** — the benchmark app's 100,000 rows × 200 columns (`neomjs/benchmarks`, `apps/bigData/neo`) taking the 50→200-column update with the main-thread probe on screen: long tasks 0 ms, the RAF needle at ~16.7 ms; one caption: the grid's logic runs in a worker, not on the main thread (the report: 7.2× faster than React + AG Grid Community on this update, which stalls 378 ms — Chromium, production). If the benchmark app is not capturable in time, the Workstation's 100,000-row grid scrolling and re-sorting.
2. **The choice** — the issues showcase with fixed rows clipping titles, then the toggle: every row the height of its text, the row under the cursor holding still.
3. **Filter by value** — the Area header menu, counts changing as the State filter is applied.
4. **Search** — one word across title and summary; *Clear filters* leaves the sort alone.
5. **Dark, and out** — the theme switch, the issue count, the URL as the last frame.

**The YouTube title names the viewer's problem and carries the search term — never the product name** (the operator, 23:5x CET: a product-name title creates zero traction); candidates (the operator killed the scale-number, the engineering-statement and the competitor-comparison forms as a stranger — see #20184 step 0): *What happens when a data grid lives in a web worker* · *The main thread is the wrong place for a data grid* · *A data grid that cannot touch the DOM — 100k rows, live*; the numbers go in the description and the first caption, never the title; the rule for title, thumbnail and the first three seconds: find the reasons the target viewer would not click and would not watch past three seconds, answered in the publish request, with a second reader's hostile pass before the operator's click; never "the fastest", which the report's own scrolling table (AG Grid 1.7–2.8× faster there, #20125 fixed after the run) would falsify in the first comment; the cover frame shows the grid moving, not a logo; the worst-parse test on the title (read it as a skeptical stranger with zero context — "without X" only before a cost, never before a capability; see #20184 step 0).
