# Let a theme set the typeface of grid values and picker options

Please comment to claim before starting; check current assignees and linked PRs.

## Context and problem

Clio’s record uses one face for a stored value and another for the words around it. A grid header or field label should keep its voice when an author sets values in monospace. Open picker options are values too. [The “record’s own face” brief](https://github.com/neomjs/neo/discussions/22418#discussioncomment-19964363)

## The architectural reality

The [grid body](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/resources/css/src/grid/Body.css) styles data cells independently of header buttons. The [ComboBox](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/src/form/field/ComboBox.mjs#L505) creates a List with option rows; the popup can live outside the field’s DOM subtree. #22445 already splits text-input and native Select typography into per-property variables. #22465 owns the existing list bindings. Coordinate with those owners and reuse the field/Select hooks.

## The fix

Provide the missing component font-family bindings at the actual grid value and picker-option readers. Use the existing sans/mono roles and the ADR 0044 split between structural rules and value sheets. Show how a theme can keep record data mono and labels, commands and headings sans. Keep the choice opt-in.

## Acceptance criteria

- [ ] A theme can set grid data text and the actual opened ComboBox options to the mono family while grid headers, field labels, buttons, and an ordinary navigation/menu list retain their configured fonts. A text field and a native Select reuse the form migration’s existing surface.
- [ ] Demonstrate the choice in both schemes, including a floating picker launched from a differently themed inner container. Verify the rendered typeface on text and that icon fonts/component renderers keep their own styling.
- [ ] Stock themes retain existing typography; provide one dense, fixed-width grid comparison showing the effect on clipping or available width. Document the hooks and how an author can limit a custom face to chosen columns using existing customization where available.
