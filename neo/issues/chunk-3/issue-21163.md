# The big data grid shows the scale its title claims

Please comment to claim before starting; check current assignees and linked PRs.

## Context

Row 1 of the Grid & Table slate ([#21142](https://github.com/neomjs/neo/issues/21142#issuecomment-6924949418)), a leaf of #21140. `examples/grid/bigData` is where the home page's grid door leads (`apps/portal/view/home/parts/AudienceDoors.mjs:25`) and the family's lead card. It is one of six examples to renew before the read of Fri 20 Nov.

## The Problem

A first-time visitor cannot tell how big the grid is.

- The page title says "100k Rows & 200 Columns" (`examples/grid/bigData/index.html:6`).
- The catalog record `grid-big-data` is named "Buffered Data Grid with 5M cells" (`apps/portal/resources/data/examples.json`).
- The grid opens at 20,000 rows and 50 columns, one million cells (`MainStore.mjs:24`, `:19`). The larger sizes sit in a panel behind a menu button (`ControlsContainer.mjs:73` to `:81`), and the only count on screen, "Filtered rows: 20000", is inside that panel.
- The headers read "Increase Counter", "Nested Cell" and "Number 7". They name a fixture and say nothing about what the column proves.

The cold look on the family's tab found the same contradiction in the card's caption, and that the new cover no longer shows a size a reader can check ([#20679](https://github.com/neomjs/neo/issues/20679#issuecomment-6924155374)).

## The Architectural Reality

- `examples/grid/bigData/`: `index.html`, `MainStore.mjs` (`amountRows_`, `amountColumns_`), `MainModel.mjs`, `GridContainer.mjs` (the columns), `ControlsContainer.mjs` (the panel), `MainContainer.mjs`.
- `Neo.grid.footer.Toolbar` (`src/grid/footer/Toolbar.mjs`) is the engine's place for a store-bound status line. No example uses it yet.
- 24 files under `test/playwright/` load this folder: e2e specs such as `e2e/grid/BigDataNL.spec.mjs`, `ScrollPagesNL.spec.mjs` and `HeaderMenuStateNL.spec.mjs`, and unit specs that pin the page title for search (`unit/buildScripts/docs/seo/Generate.spec.mjs`, `Verify.spec.mjs`). `grep -rlF "examples/grid/bigData/" test` lists them.
- Design authority: "Every renew and every new row is then filed as its own leaf under #21140" (#21142), row 1 of its Grid & Table table; the bar is the one #21140 names: "an example resets, works at phone width, in both themes, by keyboard".

## The Fix

1. **The title stays.** It is tuned for search and pinned by specs. The record's name and the default state follow it.
2. **The scale is on screen without a click:** rows × columns = cells, updated when the panel changes a size. The footer toolbar is the intended home; a line in a header is acceptable if the footer costs more than this leaf.
3. **The default state supports the title.** Measure the first paint at 100,000 × 200 on a mid-range laptop. If it stays near one second, open there. If not, keep a smaller default and let the status line say both, for example "20,000 × 50 · 1,000,000 cells · up to 100,000 × 200 in Settings". The PR states the measurement.
4. **Headers name what the column proves**, for example "Button in a cell" and "Live value". Field names and the specs' selectors need not change.
5. The catalog record gets a name that matches, with `feature` and `lookFor` to suit.

## Acceptance Criteria

- [ ] Title, record name and the on-screen status agree on the size, or the status names both the default and the maximum.
- [ ] Rows, columns and cells are readable in the first frame at 1440 × 900 and at 390 × 844, without opening the panel.
- [ ] No header reads as a fixture name.
- [ ] The specs that load the folder pass (`npm run test-unit -- <file>`, `npm run test-e2e -- <file>` for the files of the list above). A spec that depended on the old default sets its size itself.
- [ ] Both themes of the panel still work.
- [ ] **Look:** the first frame at both sizes is on the PR beside today's frame, and the design seat reads the pair before code review.
- [ ] The catalog cover is re-shot from the new default state with the producer of #20679, or the PR names the change that brings it.

## Out of Scope

Grid performance work; new columns or features; the workbench (#21143); the short video that films this example (#20185).

## Avoided Traps

- **Changing the page title to fit the default.** The title is a search asset.
- **A count that lives only in the panel.** That is today's state.
- **Opening at the maximum without measuring.** A slow first paint is a worse proof than a smaller grid.
