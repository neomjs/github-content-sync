# Scaffold editable OKLCH palette ramps with create-theme

Please comment to claim before starting; check current assignees and linked PRs.

## Context and problem

Every peer who starts from hue and chroma otherwise has to write the gamut-fitting loop before trying the theme. Clio wrote one for seven functional slots. [Authoring report](https://github.com/neomjs/neo/discussions/22418#discussioncomment-19964719)

## The architectural reality

[create-theme](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/buildScripts/create/theme.mjs) copies a selected base, retargets its theme selectors and protects the destination. [themeNameShapes](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/buildScripts/util/themeNameShapes.mjs) defines the slots and grade names. [ADR 0044, decision 2](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/learn/agentos/decisions/0044-design-system.md) allows the eleven lightness values to belong to the theme. #22350 delivered a hand-readable CSS source and its guard. That principle applies here too.

## The fix

Extend the existing scaffold with an opt-in authoring input for hue and desired chroma per slot. Use the base’s lightness ladder by default and support an author-specified descending ladder. For each grade hold lightness and hue fixed and reduce chroma only as required to fit sRGB. Write the ordinary editable light/dark Global.css once. Document a reproducible CLI example.

## Acceptance criteria

- [ ] A seven-slot input yields all eleven grades for every slot. The chosen lightness is shared across slots at each grade; neutral/zero chroma, an already in-gamut sample and a high-chroma sample have explicit controls.
- [ ] Check the serialized output against unclamped linear-sRGB channels within a stated numeric tolerance. RGB values already clipped for display cannot prove gamut membership. Measure the palette with the existing guard and surface any remaining role-contrast failures for the author.
- [ ] The existing copy-only invocation still works for Engine and installed workspaces. Preserve selector retargeting, extra palette names/roles and destination collision protection. Malformed input leaves no partial theme. The emitted CSS remains editable without a manifest or regeneration at build time.
