# Let a Gallery choose one spatial neighbor on horizontal swipe

## Context

[GalleryModel](https://github.com/neomjs/neo/blob/5ff17dedc8/src/selection/GalleryModel.mjs#L102) already resolves left/right neighbors; copying that selection algorithm into the viewport would make controls disagree. A [Chromium prototype](https://github.com/neomjs/neo/discussions/20308#discussioncomment-19930940) selected one neighbor without swallowing a vertical scroll or normal tap.

## The Fix

Make horizontal swiping a declarative, reusable Gallery interaction. Use the new semantic swipe and the same spatial selection logic used by keyboard controls. Keep target policy structural and preserve ordinary page gestures. Exercise it on the existing live Gallery example.

## Acceptance Criteria

- [ ] AC-1 One accepted horizontal swipe advances exactly one spatial neighbor in each supported direction, including boundaries. Vertical, slow and canceled gestures leave the selection intact.
- [ ] AC-2 Tap selects once. Vertical page scroll, accessible keyboard navigation and a visible alternative still work in the example.
- [ ] AC-3 Use the shared trace through the Engine and browser routes; assert actual selection and the native scroll outcome with the appropriate provider.
