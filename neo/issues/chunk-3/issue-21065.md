# Web desktop: launcher icons reorder by drag and drop

## Context

Leaf of #21061. The operator named drag and drop as part of a real web desktop. Builds on the permission shell (#21063).

## The Problem

Launcher icons appear in catalog order. On a desktop the arrangement belongs to the user, and nothing lets them move an icon.

## The Architectural Reality

Design authority: n/a — new app behavior; it calls no existing behavior wrong.

- `Neo.draggable.list.DragZone` (`src/draggable/list/DragZone.mjs`) drags list items with a proxy. `Neo.draggable.list.SortZone` (`src/draggable/list/SortZone.mjs`) is an empty subclass today, so list items have no sort-on-drop yet.
- `Neo.draggable.container.SortZone` (`src/draggable/container/SortZone.mjs`) sorts a container's component items, not store records; the launcher is store-bound per the app gate.
- With the order as a record field, a drop writes data and the launcher re-renders from the store's sort, so the store stays the only source of truth.

## The Fix

- An `order` field on the app model; the apps store sorts by it within each group.
- A drag zone on the launcher, starting from `draggable.list.DragZone`: a drop before or after another icon of the same group writes the affected `order` values.
- The arrangement persists per account across reloads (the `LocalStorage` main-thread addon, as `apps/workstation` uses).
- If sort-on-drop needs an engine seam (for example a working `list.SortZone`), it is filed as its own engine ticket under #21061, not patched inside the app.

## Acceptance Criteria

- [ ] Dragging an icon before or after another icon of its group reorders them (real-browser witness).
- [ ] The drop writes the records' `order` fields and the launcher re-renders from the store; a unit test proves no DOM-only move.
- [ ] The arrangement survives a reload, per account.
- [ ] A keyboard path moves the focused icon, so reordering is not pointer-only.
- [ ] Permission changes keep the order of the remaining icons.

## Out of Scope

- Moving icons between groups, into folders or onto the taskbar.
- Free placement on a pixel grid.
