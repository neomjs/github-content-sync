# The v13.2 launch playbook: the demo-first release sequence that produces measured strangers

> Rewritten 2026-09-24 by the assignee on the author's hand-over ([comment](https://github.com/neomjs/neo/issues/14790#issuecomment-5818974455)). The earlier text is in the edit history.

## Context

The win condition stands: **traction, or revenue sufficient for the frontier tier.** The ROADMAP puts this playbook on the 13.2 path. Cornerstone 6's done signal is *"notes staged for the cut; the launch playbook's gates named and dated"*.

This body names each gate and dates it relative to **T**, the day 13.2.0 is cut. T is the operator's call. Once it is set it is recorded here, and every date below becomes a calendar date.

Two things changed since the first version:
- **The measurement gate is gone.** The series this sequence was gated on was retired on 2026-07-05 (#14842; #14782 closed as not planned), because create-work does not wait on instruments. The baseline now comes from signals that already exist, and it never gates anything.
- **The FM outward door moved.** It belongs to the Institution line and is off the 13.2 path (see the ROADMAP's deferred set).

## The playbook

**Phase 0: Baseline (T−1; recorded, never a gate).** Read the free signals and record them here, together with N and M (see Phase 4):
- npm weekly downloads of `neo.mjs`;
- GitHub 14-day views and uniques, stars and forks;
- outside contributors with a merged PR in the last 30 days.

On 2026-09-24 they read:
- 3,583 downloads/week (09-15 to 09-21);
- 4,155 views and 920 uniques over 14 days;
- 3,282 stars and 241 forks;
- 4 outside contributors with 13 merged PRs.

These baselines include our own traffic. Thresholds are set against them, never against zero.

**Phase 1: The flagship, once (T).** All three parts of the gate must hold:
1. 13.2.0 is published: the release page and the npm package.
2. The site serves 13.2 with the docking demos current (the release gate). The Dock Layouts card's `hidden` flag comes off in all four examples registries once its URLs return 200 (the #17436 release gate).
3. The film is published (#15252, cornerstone 4), recorded with its tour mode and #14780's motion standards.

What ships:
- one film;
- the live URL, meaning the Workstation and Dock Layouts on the 13.2 site;
- one "how it's built" post, which is the 13.2 notes' Dock chapter (#14800).

Channels, in order:
1. **Canonical home, on T:** the 13.2.0 release page plus the portal's release view, SEO-first.
2. **X thread with the film, on T.**
3. **HN Show with the live URL, on the next weekday.** Prepare for the "another JS thing?" objection with the one-runtime-many-windows differentiator.
4. **dev.to and r/javascript as syndication, after HN.**

**One flagship, not a barrage.** Using the engine needs no door of its own, because from T the published package is the call to action.

**Phase 2: The doors (no earlier than max(T+7, 2026-10-01)).** From this date the channels point strangers at contributing:
- **Contribute without a Brain.**
  - Gate: cornerstone 5's done signal (#18985): a good-first-issue supply, and a PR path a contributor completes without a Brain.
  - Hacktoberfest opens this door on 2026-10-01 on its own calendar. This phase decides only when the launch channels point at it.
- **Run the Agent OS locally.**
  - Gate: cornerstone 7's done signal (#14230): the supported local path reaches a running Agent OS without hand-edited config.
  - It joins the call to action in the week that signal holds, and never before this phase's date.

**Phase 3: Story beats (weekly from T+14).** One beat a week, each linking back to the flagship:
- the 13.2 notes' other chapters, one per beat;
- the second public demo with its deterministic tour mode (cornerstone 4);
- last, the institution angle: the PRs here are written by a persistent agent team, with the evidence linked. The engine's notes tell the engine's story, so the organism's story gets its own beat.

A beat's gate is that its material is public and every claim in it links its evidence.

**Phase 4: The fold (T+7, T+14, T+21, T+28).**
- **Weekly comment.** Each week a comment on this ticket reads the Phase 0 signals against N and M:
  - **N** is the GitHub 14-day uniques at T+14.
  - **M** is the number of outside contributors with a merged PR by T+28.
- **No moving goalposts.** The owner sets N and M at T−1, and neither changes afterwards.
- **Destination.** The T+28 fold is the reach input to the post-release `/update-roadmap` round, which scopes the next release in `ROADMAP.md`.

## Acceptance Criteria
