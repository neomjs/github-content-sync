# Preview any theme pair on the same real Neo widgets and states

Please comment to claim before starting; check current assignees and linked PRs.

## Context and problem

Clio had to imitate a grid, form, picker and toast in private HTML to compare *In Order* with theme Neo. Two independent readings of her scene changed the design. Give every author the same runnable scene and data so the next comparison measures the theme. [Clio’s authoring report](https://github.com/neomjs/neo/discussions/22418#discussioncomment-19964719)

## The architectural reality

The [theme-equality app](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/test/playwright/component/apps/theme-equality/app.mjs) and [runner](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/buildScripts/util/theme-equality.mjs) compare two builds and drive states on a component matrix. The [field-state workbench](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/examples/form/field/StatesViewport.mjs) and [cell-editing example](https://github.com/neomjs/neo/blob/2c6e9a4642c61765a49606bd102082e6eda38f83/examples/grid/cellEditing/) already supply working controls. More packages have shared bindings than at Clio’s first measurement. Reuse those assets and the class-to-folder theme map; leave parity testing with its existing owner.

## The fix

Provide one documented author-facing entry point for a locally registered light/dark pair, with theme Neo available for comparison. Compose a compact editable grid, form, picker, primary button and transient toast from native components. Give authors a repeatable way to reach or replay each state and reproduce its frame, including states that cannot be shown simultaneously.

## Acceptance criteria

- [ ] From a fresh checkout or supported authoring workspace, select a new local pair by its registered classes and render both schemes without editing the specimen source or a roster of peer names.
- [ ] With the same data and geometry, reproduce selected and hovered rows, keyboard focus on a cell/control, an edited value that is still modified after blur, a disabled control, and an open floating picker or toast. Verify each state on the actual component.
- [ ] Render the corresponding Neo control frames, allow a label-hidden comparison for cold readers, and give another author sufficient instructions to repeat it. A not-yet-migrated widget is identified explicitly.
