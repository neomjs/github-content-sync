# The ESM contact editor cannot load its country data

## Context

The v14.1 mobile epic uses **Edit a Row in a Dialog** as the adaptive form example. A phone-width run from the Portal's Open live action exposed the ESM data failure on a compiled development package based on `dev@76d743e589`. Production worked at the host root. [Mobile acceptance](https://github.com/neomjs/neo/issues/22414) · [Portal work](https://github.com/neomjs/neo/issues/22548)

## The Problem

Open the ESM example at 390 × 844 and activate the first row's Edit button. Its App Worker reports an uncaught object and the country request fails.

```text
GET /dist/resources/examples/data/countries.json?page=1&pageSize=0 404
```

The asset ships at `/resources/examples/data/countries.json`. With the same compiled package mounted under `/published/engine/`, both unmodified builds returned 404. ESM requested `/published/engine/dist/resources/...` and Production requested `/published/resources/...`. The same worker-relative literal is present in the 14.0.0 source. [Earlier nested-hosting observation](https://github.com/neomjs/neo/issues/21142#issuecomment-6924949418)

## The Architectural Reality

The example's `ViewportStateProvider` owns this Store URL. The ESM worker sits under `dist/esm/src/worker`, one directory deeper than the current relative path assumes. The worker already receives the registered page base in `Neo.config.url.base`. [Store declaration](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/examples/grid/nestedRecordFields/ViewportStateProvider.mjs#L19-L25) · [Worker configuration](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/src/worker/Manager.mjs#L303-L326)

## The Fix

Resolve `Neo.config.basePath + 'resources/examples/data/countries.json'` against the registered page base when declaring the Store URL. A scratch ESM run with that exact expression returned HTTP 200 in both schemes, rendered Nigeria from the loaded records, and preserved the focused draft through the sheet-to-desktop round trip. On the patched nested mount, both builds read the JSON below `/published/engine/resources/`, opened the picker, and saved Ghana to the first row.

## Acceptance Criteria

- [ ] In compiled ESM and Production, the adaptive editor fetches the shipped countries JSON with HTTP 200 and displays the country name from the loaded Store. Verify Light and Dark and collect browser exceptions.
- [ ] At phone width, opening the editor and resizing to desktop and back preserves the focused input and its draft.

## Out of Scope

Other example data stores, shared Store URL rules, Portal metadata and physical IME acceptance.
