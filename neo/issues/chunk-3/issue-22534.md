# Bind Learn and Docs content styles to theme-base roles

## Context

The [Material package census](https://github.com/neomjs/neo/issues/22484#issuecomment-7233945527) identifies 13 unresolved reads from `app/content`. At exact Engine `76d743e589440a8381d1875a92b1a346a0a821cc`, its five Neo stylesheet pairs declare 17 distinct properties. Learn and Docs exercise its real drawer, sections, tree and Previous/Next controls.

## The Problem

The pair supplies its component values only through the legacy Neo folders. A generated theme can paint the content shell while missing toolbar, drawer and tree values. The pager labels also read the legacy global sans name directly. The mobile Sections button currently uses a disabled fill and half opacity together.

## The Architectural Reality

[ADR 0044](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/learn/agentos/decisions/0044-design-system.md) and the package rules in #22295 govern the move. `resources/css/src/app/content` owns structural readers. `src/app/content/SectionsContainer.mjs` disables its mobile control when there are no sections. The shared bindings belong in `resources/css/theme-base/app/content`. Rules 6 and 18 supply the disabled cue and raised drawer surface.

## The Fix

Move `Container`, `PageContainer`, `SectionsContainer`, `SectionsList` and `TreeList` to the shared binding layer. The two new hooks cover typography and the existing opacity reader. Keep the current shadow geometry and match the 16 px inset and 8 px radius. Retain compatibility through the legacy font/opacity fallbacks and the existing per-theme override paths.

### Material census: the pager’s legacy font fallback

The last `--neo-core-fontfamily-sans` finding in Sophie’s [CSS composition](https://github.com/neomjs/neo/issues/22484#issuecomment-7237206024) comes from the Previous and Next Page labels. [Previous label](https://github.com/neomjs/neo/blob/25031b98ae0c1c662702778d65245c0c4176ea9b/resources/css/src/app/content/PageContainer.css#L51) · [Next label](https://github.com/neomjs/neo/blob/25031b98ae0c1c662702778d65245c0c4176ea9b/resources/css/src/app/content/PageContainer.css#L63)

```css
font-family: var(--neo-app-content-toolbar-font-family, var(--neo-core-fontfamily-sans, inherit));

In a disposable composition including Grace’s partial Component branch, the existing census went from 122 to 121 in each Material scheme. The only name removed was `--neo-core-fontfamily-sans`.
