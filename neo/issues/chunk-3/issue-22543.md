# Bind Context Files to shared theme roles

## Context

Step 6 includes one Context Files stylesheet pair with six light and dark values. The live 14.0 example still paints its own pair. On the selected Budget row in the right-click menu state, file names measured 3.98:1 in Light and 3.53:1 in Dark. The Documents label measured 4.36:1 and 2.74:1.

## The Problem

The example's canvas, text, dividers, folder chips and glyphs have values only in the two Neo skins. A theme generated from the Neo roles cannot inherit those example values. File and folder text also inherit the shared List's selected text, which is too faint on the example's paints.

## The Architectural Reality

[ADR 0044](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/learn/agentos/decisions/0044-design-system.md) assigns example rules to `neo.apps`. `resources/css/src/examples/menu/contextFiles/MainContainer.css` owns every paint read in this row. `FileList.mjs` already carries the distinct filled/outlined glyphs and their labels.

Design authority: [ADR 0044 §2.1](https://github.com/neomjs/neo/blob/76d743e589440a8381d1875a92b1a346a0a821cc/learn/agentos/decisions/0044-design-system.md#2-decision) says “A rule reads component variables only. A component variable reads roles only.” [Rules 12, 17 and 18](https://github.com/neomjs/neo/issues/22295) govern the separate app/example rename map, passive glyphs and raised header.

## The Fix

Move both value sheets into `theme-base/examples/menu/contextFiles/MainContainer.css`. Start the app and example rename map with these six one-to-one names. Keep the folder's tint and reserve row selection for the shared List. The named file and folder labels use the example's default text hook even when selected. Keep the header on the raised role above the canvas.

| Old `--context-files-` suffix | New `--neo-context-files-` suffix | Role suffix `--neo-color-` | Reader |
| --- | --- | --- | --- |
| `background` | `background-color` | `background-canvas` | Example canvas |
| `text` | `color` | `text-default` | Page, file name and folder label |
| `muted` | `detail-color` | `text-muted` | Hint and action status |
| `rule` | `border-color` | `border-default` | Row separator |
| `chip` | `folder-background-color` | `background-accent-subtle` | Existing passive folder tint |
| `accent` | `icon-color` | `text-muted` | File glyph and both star states |
| New | `header-background-color` | `background-surface-raised` | Header bar |

Prescription checked: the example structural and shared value sheets own these readers. The shared List and detached Menu own the selection and menu behavior.

The selected file and folder text meet 4.5:1. The filled and outline glyphs remain distinct, and the real right-click menu offers the same file actions.
- [ ] A generated Neo theme supplies all seven values on the actual example. The Engine computed-style matrix and Workstation palette checks cover the other surfaces.
