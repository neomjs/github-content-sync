# Bind Gantt’s ten theme variables to shared roles

Part of #22484. The v14.1 Material and generated Neo themes need the complete Gantt Container theme, including the styles used outside the chart while dragging.

## Context

`resources/css/src/gantt/Container.css` reads ten Gantt variables. Each shipped legacy scheme defines them in `gantt/Container.css`. The Neo pair keeps those declarations in its individual theme trees, and the package has no `theme-base` sheet. The Material composition census finds four unresolved reads in this package: `--neo-gantt-highlight-color`, `--neo-gantt-milestone-label-border-radius`, `--neo-gantt-task-proxy-box-shadow`, and `--neo-gantt-task-proxy-milestone-filter`.

## The architectural reality

The Dependencies example uses the arrow hook for its legend and the engine uses that same hook for links, the terminal and the body-rooted link preview. The Milestones example uses the summary and milestone hooks in its legend. `src/gantt/Container.mjs` can also give schedule-analysis output to the emphasized connector and milestone stroke readers. Ordinary-task and milestone drag proxies share a structural selector with separate box and shape shadows.

Design authority: [ADR 0044](https://github.com/neomjs/neo/blob/dev/learn/agentos/decisions/0044-design-system.md) and the binding rules in #22295, especially rules 1 and 16. The acting design seat owns the mixed-reader choices. The table records proposed values for that read.

## The fix

Declare all ten hooks once in `resources/css/theme-base/gantt/Container.css`. Remove the two Neo `gantt/Container.css` copies. The Classic pair and Cyberpunk keep their own declarations. The Gantt examples continue to consume the shared hooks.

| Gantt variable | Proposed binding | Readers |
| --- | --- | --- |
| `--neo-gantt-divider-border-color` | `--neo-color-border-default` | Locked-column divider |
| `--neo-gantt-arrow-color` | `--neo-color-text-info` | Dependency stroke and arrowhead, legend, link terminal and preview |
| `--neo-gantt-highlight-color` | `--neo-color-border-danger` | Emphasized dependency stroke and arrowhead, emphasized milestone stroke |
| `--neo-gantt-summary-background` | `--neo-color-background-surface` | Summary interval fill and its legend |
| `--neo-gantt-summary-border-color` | `--neo-color-border-strong` | Summary interval edge and its legend |
| `--neo-gantt-milestone-fill` | `--neo-color-background-warning-subtle` | Milestone interior and its legend |
| `--neo-gantt-milestone-stroke` | `--neo-color-border-warning` | Milestone outline and its legend |
| `--neo-gantt-task-proxy-box-shadow` | `--neo-elevation-2` | Body-rooted ordinary-task proxy |
| `--neo-gantt-task-proxy-milestone-filter` | `drop-shadow(0 4px 10px var(--neo-color-shadow))` | Body-rooted milestone proxy |
| `--neo-gantt-milestone-label-border-radius` | `3px` | Milestone label geometry |

A disposable role preview on the existing Dependencies and Milestones examples checked both Neo schemes. The dependency legend and arrow kept the same computed colour. A real link drag committed `translate → emails`, and body-rooted link, ordinary-task and milestone proxies resolved their styles. Arrow-to-canvas contrast was 6.45:1 Light and 10.06:1 Dark. With the direct surface role, the summary edge measures 3.64:1 Light and 3.84:1 Dark. The compiled Material and Timeline composition paints a solid 1px edge and a matching legend swatch at 5.34:1 and 7.15:1. The Light milestone edge rose from 2.86:1 to 4.53:1, with Dark at 5.36:1. A second headless check registered schedule-analysis output for the shipped link `d-spec-g1` and milestone `gate-spec`. The connector stroke, referenced arrowhead fill and milestone stroke all resolved to the same proposed role, `oklch(0.544 0.2 26)` in Light and `oklch(0.7 0.15 26)` in Dark. Releasing the registration restored the original styling in both schemes.

The compiled shared sheet was also rehearsed in the Material composition. Each Material scheme went from four unresolved Gantt reads to zero. The Neo, Material and freshly generated Neo-derived pairs each resolved all ten hooks and drew both body-rooted task drag shapes. The two Material and two generated examples loaded the shared Gantt sheet, matched the dependency legend, arrow and preview, and committed `translate → emails`. Classic Light, Classic Dark and Cyberpunk retained all ten computed values and both task-proxy paints, independently and nested inside Neo Light. In the nested Dependencies control, the link preview inherited the outer body theme both before and after the move, while the chart and legend used the inner theme. Both cases committed the link.

Decision Record impact: none. This package applies ADR 0044 using the existing roles and component variable names.

## Out of scope

Timeline package CSS (#22533), Scheduler bindings, and Gantt layout or behaviour changes.

## Avoided traps

Treating the four Material census gaps as the entire Gantt package leaves six hooks without a shared owner. A rectangular elevation shadow would change the milestone drag proxy silhouette. The raised fill leaves the summary edge at 2.93:1 in Neo Dark. The direct surface role clears 3:1 and follows ADR 0044 decision 4. [Binding guard](https://github.com/neomjs/neo/issues/22571)
