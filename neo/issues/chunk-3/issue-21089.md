# Blog series part 3: why our codebase RAG ranks a guide above the code

## Context

#20278 maps the memory series *How an AI team remembers* in eight parts. Parts 1 and 2 are published (#20226, #20562). The map gives part 3 its slice, "What the repository knows: a knowledge base for coding agents", the candidate term `codebase knowledge base mcp`, and the Brain guide `learn/agentos/KnowledgeBase.md` as its source. #20278 §3 says each part gets its own ticket when its work starts; this is part 3's.

## The Problem

A coding agent that works on a repository with years of guides, tickets and pull requests has to know what exists in the code now, and which source proves it. Indexing everything and retrieving the closest text does not answer that, and neither does grep: both return what matches. A guide that drifted from its code matches very well.

We have that failure on our own record. In June 2026 our guide and README still said the Knowledge Base embeds through one remote provider, while the code selected local or remote providers (#14319). The maintainer who rewrote the guide asked the Knowledge Base how it works and got the stale claim back as a cited answer (PR #14346, section "I Used It To Write This Guide" of the guide).

Two findings from the demand read of 2026-11-16 shape the post:

- The map's candidate term returns a first page of directory listings for installable servers. A reader of that query wants a tool to install, and this post is not one, so the term does not lead the title.
- The open conversations are stale documentation for coding agents and grep versus RAG. The pages found name ranking as the remedy. None shows a receipted incident, the ranking numbers, or who repairs the document an agent finds stale. That is what this post adds.

## The Architectural Reality

Read on neo-agent-brain `dev` at `1f884fed`:

- **Three tools** (`ai/mcp/server/knowledge-base/openapi.yaml`): `ask_knowledge_base` answers with references, `query_documents` returns ranked source paths, `get_class_hierarchy` returns the inheritance map.
- **Ranking by kind of source** (`ai/services/knowledge-base/QueryService.mjs`, weights in `ai/mcp/server/knowledge-base/configBase.mjs`): a broad query draws its 100 candidates from four pools, 65 % source, guides, concepts, skills and ADRs, 20 % apps, examples and tests, 10 % tickets, pull requests, discussions, release notes and blog posts, 5 % custom kinds. The scorer then subtracts 70 for a ticket, 250 for a pull request and 50 for a release note, adds 50 to a guide for each word of the question, and passes 80 points up a matched class's parent chain, times 0.6 per level.
- **What ranking cannot see:** the pools and weights sort kinds of sources. A current guide that contradicts the code beside it is still a guide, and it keeps its bonus.
- **The ask path** (`ai/services/knowledge-base/SearchService.mjs`): the top five files are read whole from the checkout and the answer is synthesized from those only. When synthesis is unavailable the references still return, marked `degraded`. When the context budget cuts a document, the server appends the notice itself.
- **The repair:** #14319 and PR #14346 rewrote the guide from the source, corrected the README line and left a guard sentence in `learn/agentos/tooling/KnowledgeBaseMcpApi.md`. The same provider question, asked on 2026-11-16, answers local by default.
- **Post mechanics:** `learn/blog/<slug>.md` plus an entry in `apps/portal/resources/data/blog.json`; images in `neomjs/pages` under `resources_pub/website/blog/<slug>/`.
