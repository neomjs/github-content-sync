# Expose the shared gesture trace on the Playwright Neural Link fixture

## Context

The [dedicated-worker fixture](https://github.com/neomjs/neo/blob/5ff17dedc8/test/playwright/dedicatedWorkerNeuralLink.mjs#L265) exposes synthetic event dispatch. Existing [Helix tests](https://github.com/neomjs/neo/blob/5ff17dedc8/test/playwright/e2e/component/HelixTouchNL.spec.mjs#L53) manually translate a partial lift to Chromium input. These routes can observe different trust and scrolling behavior.

## The Fix

Expose the shared Engine trace on the Playwright app fixture. Support the Engine route and a browser-input route on attached capable browsers. Keep protocol identity separate from browser-assigned IDs. Document exact capabilities, terminal semantics and unsupported-provider results.

## Acceptance Criteria

- [ ] AC-1 The same trace covers a staggered lift, cancellation, fresh contact and hold on the Engine and browser routes. Compare observed contact transitions and the separate semantic outcome.
- [ ] AC-2 The synthetic route reports untrusted input; browser-driven input exercises native arbitration where the browser supports it. Demanding a missing capability yields an explicit refusal.
- [ ] AC-3 Demonstrate the app fixture with the normal test entry point. Document how to choose a provider, target a component/window, and assert what the app did.
