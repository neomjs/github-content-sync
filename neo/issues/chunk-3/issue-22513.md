# theme-base: bind tree's list sheet (4 variables) to roles

Owner: Vega (`@neo-opus-vega`). This is the `tree` row of #22484, the parent of #22295's step 6.

## Context

Step 6 declares each engine package's variables once in `theme-base`, bound to theme Neo's roles (`resources/css/theme-neo/Global.css`). `tree` is one sheet with 4 variables: the list's text, a menu item's text and the two indents.

## The Problem

`theme-neo-light/tree/List.css` copies the classic light theme's literals (`#666`, `#1c60a0`), and `theme-neo-dark/tree/List.css` reads the old tokens `--neo-sem-color-text-neutral-default` and `--neo-sem-color-text-primary-default`. No role carries any of the four, so a theme written against the roles, or one generated with `--base theme-neo`, paints the tree with none of them.

## The Architectural Reality

- Design authority: #22295's rules, with ADR 0044 behind them. Rule 1 binds by ending, so both colours bind to text roles. Rule 17 makes chrome neutral: the menu item colour paints the collapse-all and expand-all glyphs (`.neo-treelist-menu-item-content:before`), which read `text-muted` at rest, where dark read the old primary token. Rule 16: a move binds and does not resize.
- Readers: `resources/css/src/tree/List.css` reads both colours as `color`. `resources/css/src/app/content/TreeList.css` computes the padding from both indents with `calc()`, and the indents are spacing. No `.mjs` file reads any of them.
- `theme-light` and `theme-dark` declare all 4. `theme-cyberpunk` declares none, so every reader there falls back today. The row re-declares the four as `initial` in a new `theme-cyberpunk/tree/List.css`, so Cyberpunk keeps exactly that.

## The Fix

### Binding table (`dev` at `06ae0f7796`, values resolved per scheme by the palette check's resolver)

| Variable | Before (light · dark) | Binds to | After (light · dark) |
| :--- | :--- | :--- | :--- |
| `--neo-tree-list-color` | `#666` · `#f0f1f4` (`text-neutral-default`) | `text-default` (18.37 · 17.08 on `background-surface`) | `#0e0f13` · `#f1f2f4` |
| `--neo-tree-list-menu-item-color` | `#1c60a0` · `#5472e4` (`text-primary-default`) | `text-muted` (rule 17: the collapse-all and expand-all glyphs are chrome; 9.23 · 7.17) | `#3e4458` · `#979eb2` |
| `--neo-tree-list-indent-base` | `16px` | `space-4` | `16px` |
| `--neo-tree-list-indent-step` | `16px` | `space-4` | `16px` |

The list text keeps its dark value; in light it moves from the classic grey to theme Neo's default text. The two glyphs move from blue to muted in both schemes (rule 17). This row lists both changes for #22490.
