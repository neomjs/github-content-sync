# Give Header Groups modern themes and a visible theme switch

## Context

The Header Groups example is the visible demonstration for the new group-header interaction. The quality discussion around #20626 and #20627 identified a bounded presentation opportunity: use the modern light/dark themes, expose the switch, and explain the two drag gestures.

The operator invited a team challenge, not an additional mandatory release blocker. Sophie and Vega agreed this small pass can join the current review window; if it cannot, it goes after the cut. The broader family-based kitchen-sink catalog remains #20498 / #20500.

## The Problem

`examples/grid/headerGroups/neo-config.json` declares no themes and `MainContainer.mjs` contains only the full-width grid. The previous Issues showcase already offers modern themes and a visible root-theme button. A newcomer currently has no explanation of group-versus-leaf dragging or way to compare the new feature in both modern skins.

## The Architectural Reality

Design authority: n/a — an example-specific usability enhancement, not a claim that the legacy themes are invalid.

- `examples/grid/issues/neo-config.json` lists `neo-theme-neo-light` and `neo-theme-neo-dark`; its `MainContainer#onThemeButtonClick` changes the root theme and the button icon.
- `examples/grid/headerGroups/MainContainer.mjs` owns the example's Viewport and its grid. Its documented column widths, groups and locked regions are the existing browser fixture contract.
- Example styles belong beside the Issues precedent, under `resources/scss/src/examples/grid/<example>/MainContainer.scss`.
- `examples/ConfigurationViewport.mjs` includes a broad configuration pane and a different theme list. Retrofitting that entire shell is unnecessary for one toggle.

Prescription checked: the example Viewport and boot config own this concern; shared Grid or drag classes do not.

## The Fix

Declare both modern themes at boot. Add a compact heading/instruction area and visible theme button above the grid, using the existing Component/Container/Button and root-theme pattern. Keep the grid at full available width and preserve every column, width, group and lock configuration. The button stays outside the grid header rows.

Explain that a group moves its leaves as a unit and a leaf reorders within its group. That instruction is delivered with #20627's working gesture, never as a promise before its integration.

## Out of Scope

## Avoided Traps
