## Context

Three sampled frames carried a populated row pool entirely outside the visible wrapper. The run recovered later; final state was not the failure.

Live latest-open and A2A claim sweeps found no equivalent owner before filing. Closed #16402 remains the nearest historical symptom predecessor, not a presumed shared cause.

## The Problem

One full Workstation tour painted a transient blank 100k Matrix after the midpoint cue. The existing monitor accumulated blank frames for the **entire remaining tour**, so the receipt proves a user-visible blank but does not identify which later beat caused it.

The current evidence supports an intermittent update-collision class:

- worker-first / native-old is reproducible only when the projection barrier is deliberately omitted;
- the original production red was native-new / rows-old;
- properly settled midpoint and full-tour controls are currently green.

The bug is therefore “a later full-tour projection can lose continuity of an already-scrolled pooled grid,” not “the midpoint scroll command is broken.”

## The Architectural Reality

- `src/grid/View.mjs#syncBodies` owns the worker-side row-pool projection and vertical-scroll SSOT.
- `src/grid/ScrollManager.mjs` ingests native scroll events and routes settled scroll state.
- `src/main/addon/GridRowScrollPinning.mjs` protects explicit thumb-drag lag; it is not active for this programmatic cue.
- `apps/workstation/view/Workspace.mjs#scrollScaleGrid` updates View scroll + pooled rows in one VDOM cycle.
- `Workspace#settleTourStep` is a load-bearing barrier between surface cues and later dock projections.
- `WorkstationNL.spec.mjs` samples the grid throughout the whole tour; its unbanded counter cannot assign a later blank to the midpoint merely because midpoint happened first.

## The Fix

Diagnosis first:

1. Keep the non-invasive rAF census identity-agnostic across the entry projection.
2. Tag every sample with tour caption/progress plus native scroll, row ids/rects, and pin offset.
3. Capture the first **production-path** blank and name the exact later beat.
4. At that beat, add worker View/Body/mounted-range state and the relevant VDOM delta/update-collision receipt.
5. Repair only the first layer that regresses from the already-settled midpoint state.

No source patch is justified while the properly settled path remains green.
