- **Root Cause (`src/grid/View.mjs:832, 868, 1114-1137`, verified in `1-trace.trace`):**
  1. In `beforeEach` (`Snapshot 24`, `ts = 39748.65 ms`), `View#runAheadMeasure()` renders `neo-grid-body-1__row_measure` at `generation = 1` with `text` column `width: 240px` (`neo-grid-row-2__measure_1_0_1__text`).
  2. When the spec resizes `textColumnId` to `213.5px` (`lines 79-81`, `Snapshot 38`, `ts = 39923.28 ms`), `Body#afterExecuteVdomUpdate()` chains `measureRowHeights().then(() => measureAheadRows())` ([`View.mjs:1144`](https://github.com/neomjs/neo/blob/058e374357/src/grid/View.mjs#L1144)). `measureRowHeights()` updates row heights (`21665px` → `21790px`, `Snapshot 40`) and synchronously calls `me.update()` (`View.mjs:1293`), setting `me.isVdomUpdating = true` so the chained `runAheadMeasure()` returns early at [`View.mjs:832`](https://github.com/neomjs/neo/blob/058e374357/src/grid/View.mjs#L832).
  3. At `39931 ms`, `view.resetRowHeights()` ([`View.mjs:1114-1137`](https://github.com/neomjs/neo/blob/058e374357/src/grid/View.mjs#L1114-L1137)) clears `me.#measureKeys` and resets `rowGeometry` back to the `32px` estimate (`totalHeight = 9632px`, `Snapshot 45`, `ts = 39965.40 ms`), **without clearing `body.rowMeasureVdom` (`clearMeasureProjection()`) or `me.#measureLayout = []`** (unlike `updateRowGeometry()` at `View.mjs:1323`). Consequently, `hidden.waitFor({state: 'attached'})` (`line 86`) resolves immediately to the stale `generation = 1` (`240px`) node.
  4. Because `resetRowHeights()` resets all row heights to the `32px` estimate in `Snapshot 45`, `body.mountedRows` expands to **`[0, 29]`** (`29` visible rows `0..28`). When `Snapshot 45` lands, `measureRowHeights()` runs first on all `29` mounted rows (`0..28`), populates `me.#measureKeys` with `width: '213.5px'` for **every index `0..28`**, and calls `setRowHeights(heights)` — which shrinks `body.mountedRows` back to **`[0, 15]`** (`Snapshot 52`, `ts = 39987.38 ms`, hiding rows `15..28` with `display: none`) while setting `me.isVdomUpdating = true`. Fix: clear `#measureLayout` + `clearMeasureProjection()` in `View#resetRowHeights()`, and evict/skip `#measureKeys` entries for rows outside the post-`setRowHeights` `mountedRows` window.
