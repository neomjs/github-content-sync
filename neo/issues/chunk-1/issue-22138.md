# Route root '/' and internal links cleanly in pathname routerMode

Curated contributor labels (`good first issue`, `help wanted`) omitted: operator-approved active v14 regression lane owned by `@neo-gemini-maryam`.

## Context

Reported by `@tobiu` on live `v14.0.0` (`https://neomjs.com`):
1. Navigating to `https://neomjs.com/learn` and clicking the `Neo.mjs` header logo (`route: '/'`) updates the address bar to `https://neomjs.com/` via `history.replaceState`, **but the Portal stays stuck on `/learn`** (`activeIndex = 1`, `document.title` unchanged).
2. Cold-booting `https://neomjs.com/` immediately mutates the URL to `https://neomjs.com/home` via `history.pushState`, creating a dead `/` history entry behind `/home`.
3. Under `<base href="/dist/production/apps/portal/">` + `routerMode: 'pathname'` (enabled in `neomjs/pages#154` and `neomjs/middleware-v2#21`), internal route anchors still render `href="#/..."`: `Cmd/Ctrl+Click`, Middle-Click, and `Open Link in New Tab` resolve against `<base>` to `https://neomjs.com/dist/production/apps/portal/#/learn` instead of `https://neomjs.com/learn`.
4. Clicking canonical `https://neomjs.com/...` internal links authored inside Release Notes (`v14.0.0.md`) and Blog posts triggers a **full browser document reload** (destroying `Neo.Main`, all 14 main-thread addons, and the App/Data/VDom/Canvas workers) instead of client-side History API routing.

## The Problem

When opt-in History API pathname routing landed (`#20917` / `#21117`), `DomEvents` and `Button` kept three hash-era assumptions:
- **`DomEvents#getRoute` returns `''` at `'/'` (`src/main/DomEvents.mjs:454`):** In `'hash'` mode, `location.hash === ''` meant "no hash yet" while `'#/'` yielded `'/'`. In `'pathname'` mode there is no `#` delimiter — the root URL **is** `'/'`. Returning `''` causes `DomEvents#sendRoute` to emit `hashString: ''` when clicking the Logo (`#/`) or pressing Back to `/`, which fails `Portal.view.ViewportController`'s `'/': 'onHomeRoute'` regex (`/^\/$/`) and hits the empty `onNoRouteFound()` stub. On cold boot at `/`, `getRouteConfig()` returns `null`, causing `Controller.Base#initAsync` to push `ViewportController.defaultHash` (`'/home'`).
- **Hash-prefixed `href` emission in `'pathname'` mode:** `Neo.button.Base#updateTag` (`src/button/Base.mjs:887-889`) and Portal view links emit `href="#/..."`. Under `<base href="/dist/production/apps/portal/">`, RFC 3986 §5.2.2 resolves `#/...` relative to `<base>`, forcing `neomjs/pages/buildScripts/enhanceSeo.mjs` to inject an inline `<script>` click workaround that only intercepts unmodified left-clicks and leaves `Cmd/Ctrl+Click`, status-bar hover URLs, and context-menu `Copy Link Address` broken.
- **No main-thread click interception for same-origin route links:** `DomEvents#onClick` (`src/main/DomEvents.mjs:586-593`) never intercepts `<a>` clicks in `'pathname'` mode, so clean pathname `href`s (`/learn`, `/examples/grid`) and canonical `https://neomjs.com/...` links in Markdown trigger full multi-worker reloads instead of `DomEvents#setRoute` (`history.pushState` — verified live on `neomjs.com` to preserve 14/14 `Neo.main.addon.*` singletons with `===` identity and zero network re-fetches).

## The Architectural Reality

- `Design authority: "'pathname' uses the path after routerBasePath and moves it with the History API, so a route is a clean URL. The server then has to answer every route path with the app, and routes have to be paths (/learn/Intro). The App worker receives the same hashChange message in both modes."` (`src/DefaultConfig.mjs:248-251`; paired with `apps/portal/view/HeaderToolbar.mjs:30` `route: '/'` and `apps/portal/view/ViewportController.mjs:55` `'/': 'onHomeRoute'`).
- `Neo.config.routerMode` defaults to `'hash'` (`src/DefaultConfig.mjs:257`), which **must remain 100% unchanged** for dev mode, standalone `examples/**`, `docs/`, and `file://` consumers.
- In `'pathname'` mode, root-relative `href="/..."` (or `${routerBasePath}/...`) is an RFC 3986 §4.2 absolute-path reference: the browser resolves it against `location.origin` rather than `<base href="/dist/production/apps/portal/">`, fixing hover URLs, `Copy Link Address`, and `Cmd/Ctrl+Click` natively while `DomEvents#onClick` synchronously calls `event.preventDefault()` + `setRoute()` on unmodified primary clicks.
- Not every same-origin path on a host belongs to the SPA router (e.g. `/dist/*`, `/raw/*`, `/resources/*`, standalone `/apps/*`, runnable `/examples/<group>/<app>/`, legacy `/docs/*`, or static file extensions `.html`, `.md`, `.json`, `.xml`, `.txt`). Keeping an engine-level `Neo.config.routerIgnorePaths` (`String[]`) in `src/DefaultConfig.mjs` and declaring Portal's exclusions in `apps/portal/neo-config.json` keeps `src/main/DomEvents.mjs` completely free of Portal-specific path rules (and flows automatically into `neomjs/pages` via `enhanceSeo.mjs`).

## The Fix

1. **`src/DefaultConfig.mjs`:** Add `routerIgnorePaths: []` (`String[]` of path prefixes or `^...` regex patterns excluded from `'pathname'` link interception).
2. **`src/util/String.mjs` (`toRouteHref`):** Add static `Neo.util.String.toRouteHref(route)` returning `'#...'` unchanged in `'hash'` mode and `(Neo.config.routerBasePath || '') + '/' + route.replace(/^#?\/+/, '')` in `'pathname'` mode.
3. **`src/main/DomEvents.mjs`:**
   - `getRoute()`: in `'pathname'` mode, normalize empty, `'/'`, or `'/index.html'` after `routerBasePath` to `'/'` and strip trailing slashes on non-root paths so routes match `Controller.Base` regexes (`getRouteConfig()` emits `{hash: {'/': ''}, hashString: '/', windowId}`, plus optional `fragment` when `location.hash` carries an anchor).
   - `setRoute(route, replace=false)`: parse optional `?query` and `#anchor` on `'pathname'` routes, normalize non-root trailing slashes, deduplicate root `'/'` and unchanged routes cleanly, and preserve `#anchor` in the History URL while keeping search and hash out of `getRoute()`.
   - `onClick(event)`: in `'pathname'` mode, intercept unmodified primary clicks (`!event.defaultPrevented && event.button === 0 && !event.metaKey && !event.ctrlKey && !event.shiftKey && !event.altKey`) on `<a>` elements without `download`, non-`_self` `target`, or `rel~="external"`:
     - `#/...` links -> `event.preventDefault()`, route into pathname via `setRoute`.
     - `#section` in-page fragments -> `event.preventDefault()`, update `location.hash` in place without `<base>` pathname reload.
     - Same-origin links under `routerBasePath` without static file extensions (except `/index.html`) and not matching `Neo.config.routerIgnorePaths` -> `event.preventDefault()`, navigate via `setRoute`.
4. **`src/controller/Base.mjs`:** In `onHashChange`, when `Neo.config.routerMode === 'pathname' && !bestMatch && !me.defaultRoute && value.hashString === '/' && me.defaultHash && me.defaultHash !== '/'`, redirect via `Neo.Main.setRoute({replace: true, value: me.defaultHash, windowId: me.windowId})` so `'pathname'` apps without an explicit `'/'` route handler still honor `defaultHash` via `replaceState` while `'hash'` mode continues invoking `onNoRouteFound`.
5. **`src/button/Base.mjs`, `src/component/Markdown.mjs`, `src/app/content/Component.mjs`, and `apps/portal/**`:**
   - Format `Button#updateTag`, `ContentComponent#rewriteLinks`, `Markdown` internal `issuesUrl` detection (`startsWith('#') || (routerMode === 'pathname' && startsWith('/'))`), and Portal internal `href` / `route` emitters (`ContentBox`, `Util.mjs`, `learn/Component`, `learn/MainContainerController`, `GroupIndex`, `SearchResults`, `AudienceDoors`, `services/Container`, `news/tickets/Component`) through `StringUtil.toRouteHref`.
   - Set `ViewportController.defaultHash = '/'` and configure `routerIgnorePaths` in `apps/portal/neo-config.json`.

## Acceptance Criteria

- [ ] `'hash'` mode (`Neo.config.routerMode === 'hash'`, the default) remains 100% unchanged across `DomEvents`, `Button#updateTag`, `Markdown`, and all existing unit and E2E suites.
- [ ] In `'pathname'` mode, `DomEvents#getRoute()` returns `'/'` at the root (`'/'`, `''`, `'/index.html'` after `routerBasePath`), cold-booting Portal at `/` stays on `/` (`onHomeRoute`) without pushing `/home`, and clicking the Neo.mjs header logo (`route: '/'`) from `/learn` or `/examples` updates the URL to `/` and renders the Home view without reloading the document.
- [ ] In `'pathname'` mode, `Button#updateTag` and Portal internal links emit root-relative clean paths (`/`, `/learn`, `/examples/grid`, `/news/tickets/...`) that resolve cleanly even under `<base href="/apps/portal/">` or `<base href="/dist/production/apps/portal/">`.
- [ ] In `'pathname'` mode, unmodified primary clicks on internal pathname links, canonical same-origin links inside Markdown (e.g. `/examples`, `/learn/...`), `#/...` links, and `#section` anchors route client-side without reloading `Neo.Main` or main-thread addons, while `Meta/Ctrl/Shift/Alt` clicks, `target="_blank"`, `download`, static asset extensions, and `routerIgnorePaths` matches are never hijacked.
- [ ] Unit tests (`test/playwright/unit/main/DomEvents.spec.mjs` + `String` / `Button` / `Portal` unit coverage) and Playwright E2E specs (`test/playwright/e2e/core/PathnameRouting.spec.mjs` + Portal pathname E2E spec) pass cleanly.

## Out of Scope

- Removing the now-redundant inline `#` click `<script>` in `neomjs/pages/buildScripts/enhanceSeo.mjs` — tracked in a companion `neomjs/pages` follow-up issue once this Engine change syncs to `neomjs/pages`.
- Modifying `neomjs/middleware-v2` routing rules (`middleware-v2` already serves the `200 OK` Portal shell for human requests on canonical SPA routes).

## Avoided Traps

- **Mutating `Neo.config.routerMode` default away from `'hash'`:** Would break standalone `examples/**`, `docs/`, and `file://` builds without server rewrite rules.
- **Evaluating `Neo.config.routerMode` inside `static config = {...}` at module import time:** Breaks unit/E2E runtime mode switching and lazy worker config hydration; always resolve `toRouteHref` at instance/render time.
- **Hardcoding Portal path exclusions (`/examples/*/*`, `/docs/`, `/dist/`) inside `src/main/DomEvents.mjs`:** Violates Engine/App separation; keep `DomEvents` driven by `Neo.config.routerIgnorePaths` and configure Portal's patterns in `apps/portal/neo-config.json`.
- **Intercepting modified clicks (`metaKey`, `ctrlKey`, `shiftKey`, `altKey`, `button !== 0`) or `target="_blank"`:** Breaks browser `Open in New Tab` / `Open in New Window` semantics.
