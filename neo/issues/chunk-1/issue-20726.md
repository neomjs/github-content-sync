## The two gates, passed before any draft

1. **Ours.** The surface is the Fleet Manager (`neomjs/neo-agent-institution`), an application on the Engine. The reader learns what its roster may and may not claim about an agent, and sees it on the installed application.
2. **Unsolved.** Two first-page searches on 2026-11-10:
   - *How to manage several AI coding agents from one dashboard:* answered many times. One vendor's command line ships an agent view, and at least six open-source dashboards do the same job. A post that leads with "one dashboard for all your agents" is closed.
   - *An agent dashboard shows the wrong status:* open. The page holds bug reports of a `Running` badge over an idle session in several products, and write-ups that end on heuristics for one harness: read the pane, time the status, do not trust a single label.

   What this post adds that none of them has: a rendering contract for a dashboard over agents it does not run. Every fact names its source, absence renders as absence, a rejected fact renders as invalid, and no surface speaks for another. The post shows it state by state on a running team of agents from several labs.

## The Problem

- **Reader:** a developer or lead who runs two or more coding agents and has looked at a status badge that was wrong.
- **Hardest read:** "another agent dashboard". The first screen therefore holds no product. It holds a badge that says `Running` over an idle session and asks which fact that badge was ever entitled to.
- **Why the existing answers fall short:** a heuristic repairs one label in one harness. A team that runs agents in harnesses it does not own has four independent facts per agent (presence, wake route, runtime, throttle), and a dashboard that folds them into one word has to invent the missing ones.

## The Fix

One post, written for a reader who has never heard of Neo.mjs.

- **Headline (candidates, demand-checked before the draft):** *A status badge for AI agents that is allowed to say unknown* · *"Running" was not a fact: what a dashboard may claim about agents it does not run*. Not "The cockpit that refuses to lie": it is our own phrase, and row 2 has not passed its installed walk.
- **Arc:** the badge that lies → why one word cannot hold four facts → the contract, five rules, each with the frame that shows it → how each rule was earned (the operator's live falsifications and the pull requests that repaired them) → what is not finished, row by row → try it → what Neo.mjs and the Fleet Manager are, the call to action, both repositories.
- **Try it, in the reader's order:** the five rules applied to their own dashboard first, no stack of ours needed. Then the Institution's browser quickstart from a fresh clone, which lands on the cold "not answered yet" state: the contract's first rung, on their machine. Then the connected cockpit through the Brain's local Agent OS.
