# Four unread review screenshots ship in the npm package

## Context

`test/playwright/e2e/workstation/screenshots/` holds four PNG files. Two pull requests added them in July as review evidence (#16129 and #16131). No spec, script or document reads them, and they are part of the published package. Found while reviewing #20703, which adds eight more images the same way.

## The Problem

- `neo.mjs@13.4.0` contains the four files, 706,030 bytes together (jsDelivr's listing of the package, `https://data.jsdelivr.com/v1/packages/npm/neo.mjs@13.4.0?structure=flat`, read on 2026-11-10).
- Nothing reads them. On `dev` `8eaf8e0841`, `git grep -n "screenshots\|dock-tab-proxy\|overflow-menu-\|16119\|16120" -- test/playwright/e2e test/playwright/*.mjs buildScripts .github ':!*.png'` finds only prose comments and the visual config's `__screenshots__` template. Every `page.screenshot(...)` call under `test/playwright/e2e/workstation` writes to memory or to the test's output path.
- So every clone and every install carries four files that have had no reader since the two pull requests merged.

| File | Bytes |
|---|---|
| `dock-tab-proxy-16120-neo-dark.png` | 266,949 |
| `dock-tab-proxy-16120-neo-light.png` | 280,945 |
| `overflow-menu-16119-dark.png` | 79,249 |
| `overflow-menu-16119-light.png` | 78,887 |

## The Architectural Reality

- The package ships `test/` on purpose: a workspace runs its own specs on the engine's Playwright fixtures. `package.json` has no `files` list, so `.npmignore` decides what stays out, and it has no rule for this folder.
- Visual baselines are a different thing and stay: `test/playwright/visual/__screenshots__/` (six files) is read by the visual specs through `snapshotPathTemplate` in `test/playwright/playwright.config.visual.mjs`.
- The two pull requests show their images through links pinned to a commit (`raw.githubusercontent.com/neomjs/neo/<sha>/…`), not to `dev`. One of them answered with HTTP 200 on 2026-11-10, months after its branch was deleted, so the descriptions do not depend on the files staying in the tree.

## The Fix

Delete the four files; the folder goes with them.

## Acceptance Criteria

- [ ] `git ls-files test/playwright/e2e | grep -E '\.(png|jpe?g|webp|gif)$'` prints nothing.
- [ ] `git ls-files test/playwright/visual/__screenshots__ | wc -l` still prints 6.
- [ ] The images in the descriptions of #16129 and #16131 still load with the change on your branch. Say so in the pull request.

## Out of Scope

- Where a pull request in this repository may host review images at all. That is a workflow question, raised in the review of #20703.
- The visual baselines, and the size of the package beyond these four files.

## Avoided Traps

- **An `.npmignore` rule for the folder.** It keeps the files out of npm and leaves them in every clone, still unread. Remove them instead.
