# Retire the AGENTS.md clean-command delegate after the transition

## Context

#20788 moves the Engine's `AGENTS.md` pointer and its git filter to `neo-agent-skills` 1.4.0. It keeps one file of the old mechanism: `buildScripts/util/agentsMdPointer.mjs`, now a delegate to the package's pointer.

The delegate exists because commits before #20788 register `node buildScripts/util/agentsMdPointer.mjs` as the filter's clean command. Git keeps filter settings per clone, and every worktree reads them, so an `npm install` in a worktree of such a commit registers the old command for the newer checkouts too. Without the delegate, `git status` in a newer checkout then fails with `fatal: AGENTS.md: clean filter 'neo-agents-md' failed` once `AGENTS.md` changes on disk. #20788's pull request shows this failing and then passing in a scratch clone.

The delegate fails the same way in one window: a checkout that pulled #20791 without `npm install` still runs the old command, and the delegate's import of `neo-agent-skills/agents-md/pointer` fails against 1.3.7 with `ERR_PACKAGE_PATH_NOT_EXPORTED`. `npm install`, which a Fleet Start runs, closes the window. It gets no code fix: each clone passes it once, and this ticket deletes the file. The package's own clean command has the permanent form of the problem, in any worktree without the package: neomjs/neo-agent-skills#353.

## The Problem

Nothing needs the delegate once no worktree checks out a commit from before #20788. From then on, the file and its spec are dead code beside the package's own clean command.

## The Fix

Delete `buildScripts/util/agentsMdPointer.mjs` and `test/playwright/unit/buildScripts/util/agentsMdPointer.spec.mjs`.

## Acceptance Criteria

- [ ] Done no earlier than the 13.5 cut (2026-11-23), and only when no open pull request in this repository has a base older than #20788's merge commit.
- [ ] Both files are gone, and no file in the repository names `agentsMdPointer.mjs`.
