# The visual components, canvas and wrappers get their overview

## Context

The 13.5 gate asks that a stranger finds each component family's examples as an overview in which every example names what it proves (`ROADMAP.md`). `/examples/grid` is the pattern: 21 captioned Grid and Table demonstrations (#20500). The steward's map on #20498 ([comment](https://github.com/neomjs/neo/issues/20498#issuecomment-6757406109)) lists the families. Components at `/examples/components` is the largest and is delivered by two leaves on one tab; this is the second: the components a visitor looks at.

## The Problem

`examples/` holds 30 demonstrations of visual components, canvas, charts and wrappers around third-party libraries. Four have a catalog record (`helix`, `covid-helix`, `covid-gallery`, `gallery`), none has a caption, and 26 can be reached only by typing their URL. Two external records (`offscreen-canvas`, `liquid-glass`) belong to the same family and are uncaptioned too.

## The Architectural Reality

- One record per example in `apps/portal/resources/data/examples.json`; the record's shape is documented on `apps/portal/model/Example.mjs:16-27`. The 21 records with `"family": "grid-table"` are the reference for the length and tone of a caption.
- A family's tab appears with its first record (#20690), and a unit spec fails on a family record without `feature` or `lookFor`.
- Inventory at `62f75736ba`, each path under `examples/` with its own `neo-config.json`: under `component/`: `canvas`, `carousel`, `chip`, `circle`, `clock`, `coronaGallery` (record `covid-gallery`), `coronaHelix` (record `covid-helix`), `gallery` (record `gallery`), `graphScene`, `helix` (record `helix`), `magicmovetext`, `markdown`, `mwc/button`, `mwc/buttons`, `mwc/textField`, `mwc/textFields`, `process`, `process/realWorldExample`, `progress`, `splitter`, `statusbadge`, `timer`, `toast`, `video`, `wrapper/cesiumJS`, `wrapper/googleMaps`, `wrapper/monacoEditor`, `wrapper/openStreetMaps` · `charts` · `videoMove`.
- The four `wrapper/` demos and `charts` load a third-party library; some need a key or a network service. The record's `scope` field exists for that.
- `videoMove` moves a video component between two containers of one window without destroying it (`examples/videoMove/MainContainer.mjs:64-66`); whether the playback survives the move is for the caption's author to observe.
- Design authority: n/a — adds catalog records, calls no existing behavior wrong.

## The Fix

For every demonstration of the inventory: run it (`npm run server-start`, then its `index.html`), read its view and controller, and decide. It publishes when one sentence can say what it proves; otherwise it stays out and the pull request says why. A published demonstration gets one record: a stable string `id`, `name`, `"family": "components"`, `component`, `feature` (what it proves), `lookFor` (one action and what to observe), `scope` where it needs a key, a network service or has a limit, the four `urls`, `sourceUrl`, and `image: null` unless a cover exists. The six existing records get the family and their captions in place. Insert the new records as one block directly after the record `gallery`, so that parallel family pull requests touch different lines.

## Acceptance Criteria

- [ ] Every path of the inventory is a record of family `components` or is named in the pull request with its reason for staying out; `offscreen-canvas` and `liquid-glass` carry the family, `feature` and `lookFor`.
- [ ] Each `feature` and `lookFor` was checked in the running example; the pull request names the build and the browser. A demonstration that needs a key or a service says so in `scope`, or stays out when a visitor would see an error.
- [ ] A caption states no number the example does not show and names no commercial feature.
- [ ] Every URL of a record answers 200 on neomjs.com, where the examples are deployed in all four builds, or that build is omitted on the record.
- [ ] `npm run test-unit -- test/playwright/unit/apps/portal/view/examples` passes with the new counts.
- [ ] The pull request shows `/examples/components` at 1440×900 from a real browser.

## Out of Scope

Buttons, containers, lists, menus, tabs, toolbars and trees (the first Components leaf); new examples; covers (the typographic fallback is allowed, #20679 is the pattern for real ones); an engine fix for an example that turns out broken: file it and leave the example out.

## Avoided Traps

- A caption taken from a directory name: the grid map on #20498 checked configured views, controllers and stores, and several names promised more than the example shows.
- A wrapper published while it shows a missing-key error on the public site.
- Moving the existing records: the showcase order is delivered intent (#19640).
