# AGENTS.md is three rule changes behind the skills package it pins

## Context

Measured 2026-11-10 at `0d1170fe22`, with `neo-agent-skills` 1.3.3 installed, the pinned version:

```bash
diff <(node node_modules/neo-agent-skills/scripts/generate-agents-md.mjs --repo neo,neo-agent-brain) AGENTS.md
```

11 lines differ. The tracked file is the `neo,neo-agent-brain` variant, three rule changes behind:

| Rule | What the package emits | Tracked file | Shipped by |
|---|---|---|---|
| `§mailbox_check_protocol` | `list_messages({status:'unread', projection:'counts'})` | no projection, so the tool's default `full` page | `neomjs/neo-agent-skills#326` |
| `§verify_before_assert` | the scope by claim class | the older, unscoped text | `neomjs/neo-agent-skills#262` |
| `§critical_gates` 1 | the `machine_merge` line for Dependabot's own pull requests | absent | `neomjs/neo-agent-skills#154` |

`AGENTS.md` last changed on 2026-10-29 (`3918aa1474`). The pin has moved three times since, each time through Dependabot: `2676040727` (0.1.90), `d9796c9ab3` (1.1.0), `f0a1e8d0d2` (1.3.3, 2026-11-10).

## The Problem

`.claude/CLAUDE.md` links to `AGENTS.md`, so every session rooted here loads the tracked file. A rule fix that merged and released upstream reaches no seat in this repository. The mailbox line is the costly one: it runs at every turn start, and `neomjs/neo-agent-skills#326` measured a full page of 50 rows at 36 KB against about 0.55 KB for `counts`.

This is the third sighting of the class after #19036 and #19390. The command that produces the file, and the repository set it is emitted for, are written down nowhere in this repository.

## The Architectural Reality

- `agents-md/sections/*.md` in `neo-agent-skills` is the source. `scripts/generate-agents-md.mjs` (bin `neo-agent-skills-agents-md`) emits one variant per repository set and audience, under a 23,800 B budget.
- The set variant is 23,408 B at 1.3.3; the tracked file is 23,285 B.
- Three harnesses load the file: Claude Code through `.claude/CLAUDE.md` (a link to it), Codex from the repository root, Antigravity through the pointer in `.agents/ANTIGRAVITY_RULES.md`.
- Design authority: "Generated copies (`AGENTS.md` sections, `.claude/CLAUDE.md`) are never hand-edited; they regenerate from the package." (`neomjs/neo-agent-skills#140`)
- Prescription checked: `node_modules/neo-agent-skills/scripts/generate-agents-md.mjs` — owns the concern. The generator is the only writer of this file; the hop that should call it at every bump is `neomjs/neo-agent-skills#335`.

## The Fix

1. Regenerate `AGENTS.md` from the installed package for the set `neo,neo-agent-brain` and commit the output byte for byte.
2. Record the command as the npm script `generate-agents-md`, so the set is written down and the next regeneration is one command.
