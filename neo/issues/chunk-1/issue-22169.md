# Official opt-in pathname routing across Engine, fileServer, and Portal

Terminal predicate: any Neo.mjs app opting into `routerMode: 'pathname'` navigates, edits `?search` query parameters, formats links per `windowId` in SharedWorkers, and serves deep routes without mocks across `fileServer.mjs`, dist builds, and local/deployed Portal while `routerMode: 'hash'` stays the zero-config default.

`unowned-rationale: Umbrella Epic coordinated via linked leaf tickets; maintainers and contributors claim individual unblocked leaves.`

## Problem Scope

Graduated from [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) (`Scope: high-blast`, 3-family quorum at `body updatedAt 2026-11-24T22:41:55Z`; listed in `ROADMAP.md` beside the Engine 14 follow-up gate).

In `#22138` (`PR #22140`), clicking the `Neo.mjs` logo on `https://neomjs.com/learn` failed to return to Home and Markdown guide links triggered full main-thread reloads while all `38/38` Engine CI jobs stayed green. Auditing `origin/dev` across `src/`, `buildScripts/`, `apps/portal/`, `neomjs/pages`, `neomjs/create-app`, and `neomjs/middleware-v2` surfaced five coupled Engine gaps that force `PathnameRoutingNL.spec.mjs` and `PathnameRouting.spec.mjs` to mock routing via Playwright `page.route()`:

1. **Zero SPA fallback in `buildScripts/util/fileServer.mjs:246-264`:** Deep routes `404` and indexless directories (`/learn`, `/examples`, `/examples/grid`) `301`-redirect to directory listings, while `run({argv, open, opener})` (`line 381`) is a cross-repo contract consumed by `neomjs/create-app`.
2. **Externalized `<base href>` & multi-tier `routerBasePath` patching:** `apps/portal/neo-config.json` runs `'hash'` locally and is mutated to `'pathname'` only inside `neomjs/pages/buildScripts/enhanceSeo.mjs`; `esmDistTransforms.mjs` and `webpack.config.appworker.mjs` (`development` & `production`) do not rewrite `<base href>` or `routerBasePath`.
3. **Broken `?search` parsing, `Main#editRoute`, last-key removal & same-path deduplication:** `DomEvents#parseHash('/examples/grid')` + `Main#editRoute({view: 'compact'})` pushes `/%2Fexamples%2Fgrid=&view=compact`, `DomEvents#sendRoute` and `HashHistory#push` deduplicate on `hashString` alone, and `DomEvents#setRoute` omits `location.search` from `currentKey` when `query` is empty (dropping last-key `null` removals).
4. **Worker-global `Neo.config` reads in `SharedWorker` mode:** `App#onLoadApplication` deletes worker-global `Neo.config.hash` after Window 1 boots, `controller/Base.mjs` (`initAsync` + root-fallback) reads global `Neo.config`, and `String.toRouteHref`, `button/Base`, `app/content/Component`, `component/Markdown`, `apps/portal/Util.mjs`, and `10` Portal views format links without `windowId`.
5. **Local-vs-deployed Portal split:** Local `apps/portal` and Portal E2E specs run `#/...` URLs while `neomjs.com` serves clean paths at `/`.

**Why an Epic:** Delivering un-mocked parity spans four distinct subsystems — core worker/main-thread routing, `fileServer.mjs` + dist/webpack build transforms, `apps/portal` configuration/callers + E2E migration (which depends on both core and server/build support), and `learn/` developer documentation — plus coordinated post-publish companions in `neomjs/pages#211` and `neomjs/middleware-v2#109`.

## Intended Solution Shape

1. **`routerMode: 'hash'` remains the Engine default (`src/DefaultConfig.mjs:268`):** Zero-server-config static portability (`206` examples, `file://` shells, standalone static directories) stays 100% unchanged.
2. **Shared pure route predicate (`2A + 2D` — `src/util/Route.mjs`):** Zero-global ES module (`STATIC_ASSET_EXTENSIONS`, `isManagedRoutePath`, `normalizeRoutePathname`, `parseQueryParams`) evaluating raw `pathname` (trailing `/` intact) in fixed order: `(1)` physical non-`spaRoot-index` file / `STATIC_ASSET_EXTENSIONS`, `(2)` `routerIgnorePaths` (`apps/portal/neo-config.json` tightened to `"^/examples/[^/]+/"`), `(3)` trailing-slash canonicalization for managed routes only.
3. **Dual-mode `fileServer.mjs` & multi-tier `<base href>` pipeline (`1C + 4A`):** `package.json` `"neo": {"spaRoot": "apps/portal"}` (overridable via `--spa-root <dir>` / `--no-spa-root`, logged at startup, keeping `run({argv, open, opener})` backward-compatible for `neomjs/create-app`) mounts `apps/portal` at `/` (`routerBasePath: ''`, `<base href="/apps/portal/">`), `301`-redirects direct visits to `/<spaRoot>`, `/<spaRoot>/`, and `/<spaRoot>/index.html` to `/${search}` (preserving client `#/...` fragments for `upgradeHashRoute()`), and automatically mounts sub-path `pathname` apps (`/apps/route/*`, `/dist/{esm,development,production}/apps/portal/*`). `esmDistTransforms.mjs` and `webpack.config.appworker.mjs` (`development` & `production`) rewrite `<base href>` and `routerBasePath` to `/dist/{esm,development,production}/<appSubPath>`.
4. **`?search` query parity & per-`windowId` `SharedWorker` routing (`3A + 3D`):** `hashString` stays pure pathname while `URLSearchParams` populates `hash`, `query`, and `search` (preserving repeated keys `tag=a&tag=b` → `['a', 'b']`), `DomEvents#setRoute` includes `location.search` unconditionally in `currentKey` so `editRoute({key: null})` removes the final query key while preserving `#fragment`, and `DomEvents#sendRoute` + `HashHistory#push` deduplicate on `hashString + '?' + search`. `App#onLoadApplication` and `controller/Base.mjs` (`initAsync` + root-fallback) resolve per-window config from `Neo.windowConfigs[windowId]` (global fallback only when no `windowConfigs[windowId]` snapshot exists) and skip delayed seed if a live route arrived; all `3` Engine link producers and `apps/portal/Util.mjs` + all `10` Portal view callers pass explicit `windowId`.
5. **Human-core parity vs. crawler/archive hosting boundary:** Engine parity covers the **human interactive routing core only**. Crawler `isbot(UA)` → `dist/seo` snapshots, `LEARN_ROUTE_GONE` (`410`s), `LEARN_ROUTE_REDIRECTS`, `/blog` → `/news/blog` aliases, and bot `dist/*` `301`s remain exclusively in `neomjs/middleware-v2`. Any test probing `https://neomjs.com` directly sets a non-`HeadlessChrome` `userAgent`.
6. **Cross-repository sequencing:** Linked Engine sub-issues land on `dev` (with the Portal sub-issue `blocked_by` the core and server/build sub-issues via `update_issue_relationship`). Immediate production group-route hotfix shipped in `neomjs/middleware-v2#107` (`PR #108`). After the next `neo.mjs` npm publish, `neomjs/middleware-v2#109` and `neomjs/pages#211` complete production cutover.

## Avoided Traps

- **Sub-path-only local Portal mount (`Option 1A`, `/apps/portal/learn`):** Leaves `routerBasePath: ''` untested locally; rejected as primary mount in favor of `1C`.
- **Booting private `neomjs/middleware-v2` in Engine E2E (`Option 1D`):** Falsified (`neomjs/middleware-v2` is `PRIVATE`, breaking public CI and fork PRs, and leaves `npx neo-app` dev-server support unsolved).
- **Accept-header-only SPA fallback (`Option 2B`) or duplicate CLI route tables (`Option 2C`):** `2B` breaks `Accept: */*` probes and returns `200` shells on `hash`-app typos; `2C` duplicates `neo-config.json` across two files.
- **WHATWG Navigation API dual-plumbing (`Option 3B`) or repo-wide `RouteHistory` rename (`Option 3C`):** `3B` doubles main-thread/test plumbing; `3C` touches `76` controllers + Neural Link for naming churn (`AGENTS.md §self_evolving_systems` Accretion Defense).
- **Stripping `<base href>` (`Option 4B`) or rewriting HTML in `fileServer.mjs` (`Option 4C`):** Chromium + WebKit compositor pixel probes proved Gantt SVG `marker-end="url(#...)"` (`src/gantt/DependencyLayer.mjs:551`) paints `[255, 0, 0, 255]` under `<base href>` after `pushState`; `4C` breaks `ETag` and byte-range streaming.
- **Relying on `Neo.bootingWindowId` after synchronous `onStart()`:** `Neo.bootingWindowId` is cleared immediately after `module.onStart()` (`src/worker/App.mjs:710-712`), so async renders and `timeout(5)` route seeds must resolve `Neo.windowConfigs[windowId]` via explicit `windowId`.
