# The examples search e2e calls allLink, which #22166 renamed

## Context

`dev` at `e20420cf73` fails `test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs`, test "1440×900 search results: ArrowDown walks from one result list into the next, keeping one ring", with:

```
ReferenceError: allLink is not defined
> 1851 |         await allLink(page).focus();
```

Reproduce: `npx playwright test test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs -c test/playwright/playwright.config.e2e.mjs --workers=1 -g "search results: ArrowDown walks"` → 1 failed.

## The Problem

#22160 (merged 2026-11-25T01:02Z) added this test and called the shared helper `allLink`. #22166, merged after it, renamed that helper to `startLink` together with the link's label. The two PRs changed different lines of the spec, so both merged cleanly, and neither PR's CI ran with the other's change. I named the hazard in my review of #22166, but pushed the fix to #22160's branch after that PR had already merged, so it never reached `dev`.

## The Architectural Reality

- `test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs:1597`: `const startLink = page => page.locator(SIDEBAR).getByRole('link', {name: /^Start here\b/});`
- `ExamplesCatalogNL.spec.mjs:1851`: `await allLink(page).focus();`
- Design authority: n/a — a test calls a helper that no longer exists.

## The Fix

Line 1851 becomes `await startLink(page).focus();`, as in the file's other uses.

- [ ] The search test passes on the fix branch, and so do the file's side-nav-keys tests.
- [ ] No `allLink` reference remains in the spec.
