# Add pathname SPA fallback to fileServer and rewrite dist <base href>

Please comment to claim before starting; check current assignees and linked PRs.

`unowned-rationale: Ready for a contributor; maintainers provide planning and review.`

## Context

Part of #22169 (graduated from [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) `OQ-1`, `OQ-2`, `OQ-4`, and Step-Back Rows `2(a)`, `3(b)`, `5`). Owns the `4`-file server and build-pipeline slice: config-driven `'pathname'` SPA fallback + `spaRoot` mounting in `buildScripts/util/fileServer.mjs`, `<base href>` and `routerBasePath` rewrites across `dist/esm`, `dist/development`, and `dist/production`, and un-mocking `test/playwright/e2e/core/PathnameRouting.spec.mjs`.

*Note:* If picked up before #22170 merges, import `src/util/Route.mjs` once #22170 lands (or coordinate merge order via #22170); `esmDistTransforms.mjs` and webpack transforms have zero runtime dependency on #22170.

## The Problem

1. **`buildScripts/util/fileServer.mjs:246-264` has zero SPA fallback:** Deep `'pathname'` URLs (`/apps/route/users/42`, `/learn/Introduction`) return `404` or `301`-redirect to `sendListing()`, forcing `test/playwright/e2e/core/PathnameRouting.spec.mjs:19-38` to mock HTML responses via `page.route()`.
2. **`run({argv, open, opener})` (`fileServer.mjs:381`) is a cross-repo contract:** `neomjs/create-app` (`tasks/createServerScript.mjs`) imports `fileServer.mjs` and calls `run({open})`; new `spaRoot` behavior must remain 100% backward-compatible.
3. **Direct `/apps/portal/` contributor bookmarks under root `spaRoot`:** When `spaRoot` mounts `apps/portal` at `/` (`routerBasePath: ''`), visiting `/apps/portal/`, `/apps/portal`, or `/apps/portal/index.html` directly without a `301` causes `DomEvents#getRoute()` (`src/main/DomEvents.mjs:441-459`) to read the route as `/apps/portal`.
4. **Dist builds do not rewrite `<base href>` or `routerBasePath`:** `esmDistTransforms.mjs:169-184` and `webpack.config.appworker.mjs` (`development` & `production`) leave `<base href>` and `routerBasePath` pointing at source `/apps/<name>/`, breaking deep reloads under `/dist/{esm,development,production}/apps/<name>/*`.

## The Architectural Reality

- `Design authority:` `buildScripts/util/fileServer.mjs:14-15, 246-264, 381`, `buildScripts/util/esmDistTransforms.mjs:169-184`, and [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) (`Options 1C + 2A + 2D + 4A`).
- Chromium and WebKit compositor pixel probes (`DC_kwDODSospM4BLyjW`) verified that Gantt's inline SVG `marker-end="url(#...)"` (`src/gantt/DependencyLayer.mjs:551`) paints `[255, 0, 0, 255]` under `<base href>` after `history.pushState`, validating build-time `<base href>` synchronization (`4A`) without runtime HTML streaming transforms.

## The Fix

1. **`buildScripts/util/fileServer.mjs`:**
   - Keep `export function run({argv = process.argv, open, opener} = {})` backward-compatible.
   - Read optional `"neo": {"spaRoot": "<appDir>"}` from the served root's `package.json`, overridable via `--spa-root <dir>` and disabled via `--no-spa-root`; log active `spaRoot` on startup when enabled.
   - Discover `neo-config.json` files (`mtimeMs`-cached) where `routerMode === 'pathname'`.
   - Resolve `GET`/`HEAD` requests in fixed deterministic precedence using `src/util/Route.mjs`:
     1. Existing physical file (excluding the active `spaRoot`'s own `index.html` at `/<spaRoot>/index.html`) or `STATIC_ASSET_EXTENSIONS` → serve file (`200`/`206`) or `404` when missing.
     2. Active `spaRoot` direct folder/index paths (`/<spaRoot>`, `/<spaRoot>/`, `/<spaRoot>/index.html`) → `301` redirect to `/${search}` (browser preserves `#/...` hash fragments).
     3. Sub-path `pathname` app mount (`/apps/route/*`, `/dist/{esm,development,production}/apps/<name>/*`) where raw relative path passes `isManagedRoutePath` → canonicalize trailing slash (`301` preserving `?search`) or serve that mount's `index.html` (`200 text/html`).
     4. Active `spaRoot` `/` mount where raw pathname passes `isManagedRoutePath` → canonicalize trailing slash (`301` preserving `?search`) or serve `<spaRoot>/index.html` (`200 text/html`).
2. **`esmDistTransforms.mjs` & `webpack.config.appworker.mjs` (`development` & `production`):**
   - When an app's `neo-config.json` has `routerMode === 'pathname'`, rewrite `routerBasePath` in the emitted `neo-config.json` and `<base href="...">` (inserting into `<head>` if absent) in the emitted `index.html` to `/dist/{esm,development,production}/<appSubPath>` (with trailing `/` on `<base href>` and no trailing `/` on `routerBasePath`).

- [ ] `test/playwright/unit/buildScripts/util/fileServer.spec.mjs` verifies: (a) missing asset `GET /apps/route/Missing.mjs` → `404`; (b) sub-path `pathname` deep route `GET /apps/route/users/42` → `200` `apps/route/index.html`; (c) `spaRoot` `/<spaRoot>`, `/<spaRoot>/`, and `/<spaRoot>/index.html?view=compact` → `301` `/?view=compact`; (d) `routerIgnorePaths` exclusion (`GET /examples/tree/` vs `GET /examples/tree` under `spaRoot`); (e) `--no-spa-root` restores directory listing at `/`; and (f) `run({open})` compatibility.
- [ ] `esmDistTransforms.spec.mjs` (and webpack build verification) confirms `<base href>` and `routerBasePath` rewrite cleanly for `routerMode === 'pathname'` while leaving `'hash'` apps untouched, including local sub-path dist control `/dist/production/apps/portal/learn?view=compact` when built with `routerMode: 'pathname'`.
- [ ] `apps/route` (`test/playwright/e2e/core/PathnameRouting.spec.mjs`) runs green against live `fileServer.mjs` with its HTML shell `page.route()` mock removed.

## Out of Scope

- Switching `apps/portal/neo-config.json` to `routerMode: 'pathname'` and enabling `"neo": {"spaRoot": "apps/portal"}` in root `package.json` (owned by the Portal parity leaf under #22169 so E2E URL expectations migrate atomically).
- Crawler `isbot` SSR, `410`s, and `/blog` redirects (`neomjs/middleware-v2` only).

## Avoided Traps

- **On-the-fly HTML rewriting inside `fileServer.mjs` (`Option 4C`):** Violates `fileServer.mjs:14-15` static-streaming design and breaks `ETag` / `206` byte-range responses.
- **Letting physical-file lookup match `/<spaRoot>/index.html` before the `spaRoot` `301` redirect:** Would leave `/apps/portal/index.html` serving at `/apps/portal/index.html` where `routerBasePath: ''` parses the route as `/apps/portal`.
