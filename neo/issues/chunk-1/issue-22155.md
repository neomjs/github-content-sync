# README links open neomjs.com; the Engine section leads with agents

## Context

On 2026-11-24 the operator read the Engine README and asked for polish, not a rewrite. He raised three points:

1. The Engine section opens with *"Here for the AI maintainers? Jump to An agent institution."* That can read as "come meet our maintainers". The reader it should catch wants AI peers on their own codebase, or Agent Institution for their own projects.
2. Learn links should open neomjs.com. Its learning section has live code previews, an ordered tree nav and a side nav for sub-headings. The repository's `learn/` folder has none of that, and GitHub lists its files unordered.
3. neomjs.com titles the engine guide "The Application Engine for the AI Era". The operator reads that as the pre-AI-era trap: it persuades humans to dive into code. The page should hit hard on the fact that agents understand the engine, excel with it and build on it.

## The Problem

On `dev` `e2ec8a1a8a`:
- 21 README links point at markdown in `./learn/`, covering 13 targets. Two more point at the source folder `./examples/grid/bigData`, not at the running example.
- Every other neomjs.com link uses the `#/` form. The live site redirects each one to a clean path.
- The README's agent claim is buried. "Coding agents read and write Neo.mjs blueprints natively" is the last sentence of "The Runtime". "The Engine" opens with the class count and the Angular/React/Vue comparison.
- The deployment section labels Brain work with an Engine version ("v13 turns it outward", "v13 runs it as a cloud deployment"), and v14.0.0 has shipped.

## The Architectural Reality

- `README.md` is a Class 1 identity surface (`.agents/skills/neo-identity-update/references/affected-areas-map.md`). Its lead cluster (the label, the ladder sentence and the apex paragraphs) stands word for word under #21564 AC-3, and this ticket leaves it alone.
- `test/playwright/unit/apps/portal/view/home/AudienceDoors.spec.mjs` reads the README and asserts the `` `N` classes across `M` namespaces`` line, `## The Engine`, `## Who This Is For` and `npx neo-app@latest`. All four stay.
- The roster follows the operator's ruling on #19346 (2026-10-01): benched seats keep their row. This ticket does not touch it.
- All 13 learn and blog targets are on neomjs.com: 11 in `learn/tree.json`, two in `apps/portal/resources/data/blog.json` under `/news/blog/<id>`. On 2026-11-24 each `#/` and clean-path URL was probed with a desktop Chrome user agent (the site serves bots a scriptless snapshot). Each returned 200, booted the app and showed the document's H1. The clean paths also answered 200 when opened directly.

## The Fix

`README.md` only:
1. Replace the jump line with two doors: run AI peers on your own codebase (the deployment section) and meet the team that builds this engine (the maintainer table).
2. Open "The Engine" with what coding agents get. The app is JSON blueprints, the format models read and write. Components are persistent objects that an agent inspects and changes live through the Neural Link. Development needs no build step. Remove the JSON-first sentence that "The Runtime" would then repeat.
3. Point every learn and blog link at its neomjs.com page by clean path, with page titles as link text instead of file names. Move the existing `#/` links to their clean paths. Point the 100,000-row link at the live example.
4. Drop the "v13" labels from the deployment section's Brain claims.

## Acceptance Criteria

- [ ] AC-1: The Engine section's first line offers both doors, and both anchors resolve on GitHub's render.
- [ ] AC-2: "The Engine" opens with what coding agents get from the engine, and "The Runtime" no longer repeats the JSON-first sentence.
- [ ] AC-3: No README link targets `./learn/` or `./examples/`. Every neomjs.com link uses a clean path. Each one returns 200 for a desktop Chrome user agent, boots the app and shows its page; the probe receipt goes in the PR.
- [ ] AC-4: The lead cluster and the maintainer table are unchanged. `AudienceDoors.spec.mjs` and `npm run check-relative-links` pass.
- [ ] AC-5: The deployment section's claims carry no Engine version label.

## Out of Scope

- **Retitling `learn/benefits/body/ApplicationEngine.md`,** its SEO title in `apps/portal/resources/data/seo.json` and its tree node. That is the operator's label to pick first. It gets a follow-up ticket with his pick.
- The roster (#19346), the dated record line and its counts (a Class 5 snapshot refreshed in lock-step), and learn links in other repository docs.

## Avoided Traps

- **Keeping the `#/` form for consistency with #21564 AC-4.** That AC was written before neomjs.com served clean paths. The router still redirects `#/` links, so old links keep working, but the clean path is the canonical one: it is what the address bar and the SEO snapshots show.
