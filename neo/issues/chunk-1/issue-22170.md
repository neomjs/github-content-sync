# Support ?search query parity and per-windowId pathname routing in core

Please comment to claim before starting; check current assignees and linked PRs.

`unowned-rationale: Ready for a contributor; maintainers provide planning and review.`

## Context

Part of #22169 (graduated from [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) `OQ-2`, `OQ-3`, `OQ-5`). Owns the `11`-file Engine runtime slice: pure `src/util/Route.mjs` extraction, `?search` query-parameter parity (`Main#editRoute`, `DomEvents`, `HashHistory`), Neural Link route-tool JSDoc/fields, and per-`windowId` `SharedWorker` pathname/hash resolution across Engine bootstrap, controllers, and generic link producers.

## The Problem

1. **`Main#editRoute`, `?search` parsing, last-key deletion & same-path deduplication break in `'pathname'` mode:**
   - `DomEvents#parseHash('/examples/grid')` (`src/main/DomEvents.mjs:1194-1215`) treats the path as a `key=` entry (`value = ''`), so `Main#editRoute({view: 'compact'})` (`src/Main.mjs:269-287`) pushes `/%2Fexamples%2Fgrid=&view=compact`.
   - `DomEvents#sendRoute` (`line 1333`) and `HashHistory#push` (`src/util/HashHistory.mjs:103`) deduplicate on `hashString` alone, dropping same-path `?search` transitions (`?view=full` → `?view=compact`).
   - `DomEvents#setRoute` (`line 1382`) omits `location.search` from `currentKey` when `query` is empty, so `editRoute({view: null})` from `/examples/grid?view=compact#details` makes zero `History` writes.
2. **`DomEvents#isManagedRoutePath` is trapped inside main-thread `DomEvents`:** `fileServer.mjs` and `neomjs/middleware-v2` cannot import a pure zero-global route predicate without pulling `Neo.core.Base`.
3. **`SharedWorker` apps read worker-global `Neo.config` instead of `Neo.windowConfigs[windowId]`:**
   - `App#onLoadApplication` (`src/worker/App.mjs:701-719`) reads and deletes worker-global `Neo.config.hash` after Window 1 boots, losing Window 2's cold-boot route.
   - `controller/Base.mjs` reads worker-global `Neo.config` in `initAsync()` (`line 134`, suppressing or firing the wrong window's `defaultHash`) and in its `'pathname'` root-fallback (`line 217`).
   - `String.toRouteHref` (`src/util/String.mjs:100-112`), `button/Base.mjs` (`line 885`), `app/content/Component.mjs` (`line 381`), and `component/Markdown.mjs` (`lines 396-397`) format links or classify `routerMode` from worker-global `Neo.config` without `windowId`.

## The Architectural Reality

- `Design authority:` `src/DefaultConfig.mjs:246-268` (`routerMode`, `routerBasePath`, `routerIgnorePaths`) and [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) (`Options 2A + 2D + 3A + 3D`).
- Pre-Flight (structural fast-path): authoring `src/util/Route.mjs` matches sibling pattern of `src/util/Random.mjs` and `src/util/UUID.mjs` in `src/util/` (pure, zero-global ES function modules importable by both browser/worker runtime modules and Node `buildScripts/util/*.mjs` without `Neo` global initialization, matching `buildScripts/util/templateBuildProcessor.mjs` and `movePlan.mjs`); sibling-file-lift applies; no novel directory choice; Map-maintenance: not-needed.

## The Fix

1. Create pure, zero-global `src/util/Route.mjs` exporting `STATIC_ASSET_EXTENSIONS`, `isManagedRoutePath(pathname, routerIgnorePaths=[])`, `normalizeRoutePathname(pathname, routerBasePath='')`, and `parseQueryParams(search='')` (`URLSearchParams` preserving repeated keys `tag=a&tag=b` → `['a', 'b']`). Evaluate raw `pathname` (with trailing `/`) in strict order: static asset extension check → `routerIgnorePaths` match → trailing-slash canonicalization for managed routes only.
2. Update `src/main/DomEvents.mjs`, `src/Main.mjs`, and `src/util/HashHistory.mjs`:
   - Delegate `isManagedRoutePath` to `src/util/Route.mjs`.
   - Keep `hashString` as pure pathname (`/examples/grid`), parse `location.search` into `hash` + `query` + `search` (`'view=compact'`), preserve `#fragment` and repeated keys in `Main#editRoute` (`null`/`undefined` deletes keys), include `location.search` unconditionally in `DomEvents#setRoute` `currentKey` so removing the final query key writes history and emits `search: ''` once, and deduplicate `DomEvents#sendRoute` + `HashHistory#push` on `hashString + '?' + (search || '')` (keeping `#anchor`-only hops suppressed).
3. Update `src/worker/App.mjs`, `src/controller/Base.mjs`, `src/util/String.mjs`, `src/button/Base.mjs`, `src/app/content/Component.mjs`, `src/component/Markdown.mjs`, and `src/ai/client/RuntimeService.mjs` per the Contract Ledger and Binding Inventory below.

## Discussion Criteria Mapping & Leaf Slice

Owns the `11` Engine core modules in `core-and-build-modules` plus `OQ-2` (predicate half), `OQ-3`, and `OQ-5` (Engine half):

<!-- binding-inventory: core-and-build-modules -->
- `src/util/Route.mjs` — Pure, zero-global function module (`STATIC_ASSET_EXTENSIONS`, `isManagedRoutePath`, `normalizeRoutePathname`, `parseQueryParams`) evaluating raw `pathname` before slash canonicalization.
- `src/main/DomEvents.mjs` — Delegates `isManagedRoutePath` to `src/util/Route.mjs`, parses `location.search` via `URLSearchParams` (preserving repeated keys) into `hash` + `query` + `search` in `'pathname'` mode while keeping `hashString` pure pathname, includes `location.search` unconditionally in `setRoute` `currentKey` (fixing last-key removal), and deduplicates `#lastRoute` on `hashString + '?' + search`.
- `src/Main.mjs` — Fixes `editRoute(data)` in `'pathname'` mode over `URLSearchParams` (`null` removes keys, repeated keys preserved, `#fragment` preserved).
- `src/util/HashHistory.mjs` — Deduplicates `push(data)` on both `hashString` and `search` per `windowId`.
- `src/worker/App.mjs` — Seeds initial route from `Neo.windowConfigs[windowId]` (global `Neo.config` fallback only when no `windowConfigs[windowId]` snapshot exists) and skips delayed seed if a live route for `windowId` already arrived.
- `src/controller/Base.mjs` — Reads `Neo.windowConfigs?.[windowId]` (with global fallback only when absent) in both `initAsync()` default-route suppression (`line 134`) and `'pathname'` root-fallback (`line 217`), plus JSDoc for `'pathname'` + `?query`.
- `src/util/String.mjs` — Extends `toRouteHref(route, windowId)` to resolve `routerMode` and `routerBasePath` from `(windowId != null && Neo.windowConfigs?.[windowId]) || Neo.config`.
- `src/button/Base.mjs` — Passes `me.windowId` to `StringUtil.toRouteHref(route, me.windowId)` in `updateTag()` (`line 885`).
- `src/app/content/Component.mjs` — Passes `me.windowId` to `StringUtil.toRouteHref(contentRoute, me.windowId)` in `rewriteLinks(html)` (`line 381`).
- `src/component/Markdown.mjs` — Passes `me.windowId` to `StringUtil.toRouteHref(me.issuesUrl, me.windowId)` and resolves `routerMode` from `(me.windowId != null && Neo.windowConfigs?.[me.windowId]) || Neo.config` when classifying internal `#ticket` links (`lines 396-397`).
- `src/ai/client/RuntimeService.mjs` — Documents `'pathname'` mode `set_route` (`hash` route/path parameter) and additive `search`/`query` fields on `get_route_history` stack entries.

## Acceptance Criteria

- [ ] `src/util/Route.mjs` is pure (zero `Neo` global or `Base` imports) and `test/playwright/unit/util/Route.spec.mjs` pins raw-pathname evaluation across `/examples/tree` (managed), `/examples/tree/` (ignored by `"^/examples/[^/]+/"`), `/examples/tree/index.html` (static `.html`), missing `.mjs` assets, and repeated `URLSearchParams` keys.
- [ ] In `'pathname'` mode, `Main#editRoute({view: 'compact'})` on `/examples/grid` writes `/examples/grid?view=compact` (keeping `hashString === '/examples/grid'`), `setRoute('/examples/grid?view=compact&tag=a&tag=b#details')` from `?view=full` dispatches to the worker, `editRoute({view: null})` from `/examples/grid?view=compact#details` writes `/examples/grid#details` and dispatches once with `search: ''` (idempotent on repeat), Back/Forward recovers both states, and `#anchor`-only hops stay suppressed (`test/playwright/unit/main/DomEvents.spec.mjs`).
- [ ] A dual-window `SharedWorker` unit spec boots a `'pathname'` window (`routerBasePath: '/alpha'`) and a `'hash'` window (plus a hashless child exercising `defaultHash`) in both boot orders, verifying isolated route seeding, no clobber when a live route arrives before `timeout(5)`, stock `Neo.button.Base` `href` (`/alpha/learn` vs `#/learn`), `Neo.app.content.Component` `.md` link rewriting, and `Neo.component.Markdown` `#ticket` link formatting per `windowId`.
- [ ] `src/ai/client/RuntimeService.mjs` JSDoc documents `'pathname'` paths on `setRoute` and additive `search`/`query` stack entries on `getRouteHistory`.

## Out of Scope

- `buildScripts/util/fileServer.mjs` and dist/webpack `<base href>` transforms (sibling server/build leaf under #22169).
- `apps/portal/**` `windowId` call sites and `neo-config.json` switch (sibling Portal leaf under #22169).
- `learn/` tutorials and getting-started guides (sibling docs leaf under #22169).

## Avoided Traps

- **Mutating `hashString` to include `?search`:** Would break `controller/Base.mjs` route-pattern matching across `76` existing controllers; keep `hashString` pure pathname and carry query data in `hash`/`query`/`search`.
- **Relying on `Neo.bootingWindowId` after `module.onStart()`:** Cleared synchronously at `src/worker/App.mjs:712`; always read `Neo.windowConfigs[windowId]`.
- **Stripping trailing `/` before `routerIgnorePaths`:** Makes `/examples/tree/` indistinguishable from `/examples/tree`.
