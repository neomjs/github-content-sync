# Add Neo.main.addon.Clipboard for worker copy, cut, and paste

## Context

In Neo.mjs's multi-threaded runtime, logical component state, store records, and selection models live in the App Worker, while user clipboard gestures (`copy`, `cut`, `paste`, and keyboard shortcuts such as `Cmd/Ctrl+C`, `Cmd/Ctrl+X`, `Cmd/Ctrl+V`) originate synchronously on the main thread. Today, the engine's only clipboard helper is `Neo.main.DomAccess#execCommand({command: 'copy'})` paired with `DomAccess#selectNode` (`src/main/DomAccess.mjs:355`, `src/form/field/trigger/CopyToClipboard.mjs:96-104`), which copies live DOM text from an already-rendered `<input>` node using deprecated `document.execCommand('copy')` and cannot serialize worker-owned data (such as off-DOM buffered rows or multi-cell selections) or deliver pasted clipboard payloads to the App Worker without a permission prompt.

To determine which main-thread bridge shape survives browser transient user-activation limits across a worker round trip without test-granted clipboard permissions, a standalone Playwright probe (`http://localhost`, `isSecureContext === true`, zero permission overrides, Dedicated Worker payload round trip) measured two write shapes across four worker delays (`50 ms`, `500 ms`, `2000 ms`, `5000 ms`) plus synchronous `paste` forwarding in **Chromium `157.0.8103.39`**, **WebKit `27.2`**, and **Firefox `159.0`**:

## The Problem

1. **Post-reply writes fail once transient user activation expires:** Contrary to older assumptions that Chromium allows unprompted `navigator.clipboard.write` without user activation, both **Chromium `157.0.8103.39`** and **WebKit `27.2`** enforce transient user activation and throw `NotAllowedError` once `navigator.userActivation.isActive` flips to `false` (`5000 ms` row under Shape B). Any large serialization, lazy store fetch, or heavy worker turn that crosses the transient activation window fails if `navigator.clipboard.write` waits until the App Worker replies.
2. **Deferred `ClipboardItem` Promise writes succeed across all three engines (`12/12`):** Opening `navigator.clipboard.write([new ClipboardItem({'text/plain': blobPromise})])` synchronously on the main thread inside the user gesture captures activation at call time in Chromium, WebKit, and Firefox (`50 ms`–`5000 ms`), even after `navigator.userActivation.isActive` has expired to `false` by the time the Worker resolves `blobPromise`.
3. **Inbound `paste` requires zero `navigator.clipboard.readText()` permission prompt:** Reading `event.clipboardData.getData('text/plain')` synchronously inside a main-thread `paste` listener and forwarding it to the App Worker succeeds in `0–3 ms` across all three engines with zero permission prompt (and without needing a custom `beforepaste` `preventDefault()` in WebKit when focusing a non-editable `tabindex="0"` container).

## The Architectural Reality

- **On-demand main-thread addon pattern (`src/main/addon/`):** Main-thread browser bridges that are not needed by every application extend `Neo.main.addon.Base` (`src/main/addon/Base.mjs`) and load on demand via `await Neo.currentWorker.getAddon('Clipboard', windowId)` (`src/Main.mjs:463-494`), matching `Neo.main.addon.FileDownload` (`src/main/addon/FileDownload.mjs`), `Neo.main.addon.NativeDragSource` (`src/main/addon/NativeDragSource.mjs`), and `Neo.main.addon.ResizeObserver` (`src/main/addon/ResizeObserver.mjs`). `Neo.config.mainThreadAddons` (`src/DefaultConfig.mjs:180`) stays unchanged (`['DragDrop', 'Navigator', 'Stylesheet']`).
- **Component DOM event routing (`src/main/DomEvents.mjs`, `src/manager/DomEvent.mjs`):** On `dev`, `'copy'`, `'cut'`, and `'paste'` are native DOM event names that `DomEvents#addDomListener` mounts locally via generic `DomEvents#domEventListener` (`src/main/DomEvents.mjs:256`) rather than `globalDomEvents` (adding them to `globalDomEvents` would suppress local mounting for components that never register with `Neo.main.addon.Clipboard`). Instead, `globalDomEvents` stays unchanged and `DomEvents#domEventListener` yields when `Neo.main.addon?.Clipboard?.claimsEvent?.(event)` is `true` so unregistered components receive plain local `copy`/`cut`/`paste` events identically to `dev` while registered roots deliver a single enriched addon payload (deduplicated across nested registered roots via capture-phase `WeakSet` tracking).
- **Native editable control partition:** Inside a registered container (e.g., a grid with an active cell editor `<input>` or filter field), native copy/cut/paste inside `<input>` (text-bearing types), `<textarea>`, or `[contenteditable]` must remain owned by the browser unless explicitly opted in, mirroring `NativeDragSource`'s partition contract (`src/main/addon/NativeDragSource.mjs:56-73`).

## The Fix

1. Author `src/main/addon/Clipboard.mjs` (`Neo.main.addon.Clipboard` extending `Neo.main.addon.Base`):
   - **Registration (`register` / `unregister`):** Components register `{componentId, id, mimeTypes = ['text/plain'], ignoreEditableTargets = true, pendingTimeoutMs = 10000}` in capture phase (retrying target lookup up to `registerAttempts` like `ResizeObserver#register` if VDOM mount is still settling, deduplicating nested registered roots innermost-first via `#handledEvents`, and cleaning up listeners + pending requests on `unregister` / `destroy`).
   - **Outbound gesture capture (`copy`, `cut`):** When a non-editable gesture fires within one or more registered roots:
     - Deduplicate the DOM `event` once across nested registered roots, call `event.preventDefault()`, allocate a monotonic `requestId`, create per-MIME controllable Promises (`new Blob([value], {type})`), and invoke `navigator.clipboard.write([new ClipboardItem(itemMap)])` **synchronously inside the gesture** (tracking `writeSettled` so cancelled/timed-out/rejected writes never cause unhandled promise rejections and leave prior clipboard contents intact).
     - Forward `{action: 'domEvent', eventName: event.type, data: {componentId, id, mimeTypes, path, requestId}}` anchored at the innermost matching registered component via `Neo.worker.Manager.sendMessage('app', ...)` so `Neo.manager.DomEvent#fire` bubbles once per listening component.
   - **Worker fulfillment (`fulfillWrite` / `cancelWrite`):** `async fulfillWrite` returns `Promise<Boolean>`, validating that every declared MIME type in `mimeTypes` was supplied before resolving `Blob` entries (rejecting all pending MIME promises with `AbortError` and resolving `false` if any declared type is omitted) and returning `await pending.writeSettled` (`true` only when `navigator.clipboard.write(...)` accepted the write); `cancelWrite({requestId})` / `pendingTimeoutMs` expiry rejects cleanly when nothing is selected.
   - **Inbound paste (`paste`):** On `paste` inside a registered root (when not targeting an ignored editable element), deduplicate across nested roots, read requested MIME types synchronously from `event.clipboardData` (default `'text/plain'`), call `event.preventDefault()`, and dispatch `{action: 'domEvent', eventName: 'paste', data: {componentId, id, items, path, text}}` to the App Worker.
2. Update `src/main/DomEvents.mjs`:
   - Have `DomEvents#domEventListener` (`src/main/DomEvents.mjs:256-263`) yield on `'copy'`, `'cut'`, and `'paste'` when `Neo.main.addon?.Clipboard?.claimsEvent?.(event)` returns `true`, leaving `src/manager/DomEvent.mjs` `globalDomEvents` untouched so unregistered component `domListeners` continue mounting and firing locally as on `dev`.
3. Add unit tests (`test/playwright/unit/main/addon/Clipboard.spec.mjs`, `test/playwright/unit/main/DomEvents.spec.mjs`), component browser tests (`test/playwright/component/main/ClipboardAddon.spec.mjs`), and an opt-in 3-engine Playwright real OS-clipboard spec (`test/playwright/clipboard/ClipboardAddon.spec.mjs`) verifying worker-fulfilled copy, cut, omitted-type / unsupported-type `false` outcomes, cancellation (preserving prior clipboard), editable `<input>` pass-through, and zero-prompt paste across `chromium`, `webkit`, and `firefox`.

## Acceptance Criteria

- [ ] `src/main/addon/Clipboard.mjs` (`Neo.main.addon.Clipboard` extending `Neo.main.addon.Base`) is loadable on demand via `Neo.currentWorker.getAddon('Clipboard', windowId)` without adding `Clipboard` to default `Neo.config.mainThreadAddons`.
- [ ] Outbound `copy` and `cut` on a registered component root open `navigator.clipboard.write([new ClipboardItem(...)])` synchronously inside the main-thread gesture (once per gesture even across nested registered roots) and resolve asynchronously via `fulfillWrite({requestId, ...})` (`Promise<Boolean>`, answering `true` only when all declared MIME types were supplied and the browser accepted the write); `cancelWrite({requestId})` (or timeout) preserves the prior clipboard without unhandled promise rejections.
- [ ] Inbound `paste` on a registered component root reads `event.clipboardData` synchronously on the main thread and delivers the payload (`text`, `items`, `path`) to the App Worker's `domListeners` with zero `navigator.clipboard.readText()` permission prompt, while plain local `copy`, `cut`, and `paste` `domListeners` on unregistered components continue firing as on `dev` (`src/manager/DomEvent.mjs` `globalDomEvents` unchanged).
- [ ] Native copy, cut, and paste inside editable descendants (`<input>`, `<textarea>`, `[contenteditable]`) pass through untouched when `ignoreEditableTargets` is `true` (default).
- [ ] Unit spec (`test/playwright/unit/main/addon/Clipboard.spec.mjs`), component browser spec (`test/playwright/component/main/ClipboardAddon.spec.mjs`), and Playwright 3-engine real OS-clipboard coverage (`test/playwright/clipboard/ClipboardAddon.spec.mjs`) pass across `chromium`, `webkit`, and `firefox`.

## Out of Scope

- Component-specific serialization formats (e.g., grid/list TSV, CSV, or HTML table formatting — owned by consuming components/controllers).
- Replacing `Neo.form.field.trigger.CopyToClipboard`'s existing synchronous single-input copy behavior (can migrate in a separate follow-up once `Clipboard` ships).
- Arbitrary binary/image file clipboard paste (`DataTransferItem.getAsFile()`), beyond keeping `items` extensible by MIME type.

## Avoided Traps

- **Calling `navigator.clipboard.write` or `writeText` after the App Worker replies:** Fails with `NotAllowedError` in both Chromium `157.0.8103.39` and WebKit `27.2` once `navigator.userActivation.isActive` expires (measured at `5000 ms`), whereas opening `new ClipboardItem({'text/plain': blobPromise})` synchronously inside the gesture passes `12/12` across Chromium, WebKit, and Firefox.
- **Calling `navigator.clipboard.readText()` for paste:** Triggers browser permission UI or fails in ungranted contexts; synchronous `event.clipboardData.getData('text/plain')` inside the main-thread `paste` event delivers in `0–3 ms` across all three engines with zero permission prompts.
- **Attaching global `copy`/`cut`/`paste` `preventDefault()` on `document.body`:** Would break native text selection copy and `<input>`/`<textarea>` editing across the entire document. Scoping listeners to registered roots and passing through editable descendants keeps native text interactions intact.
