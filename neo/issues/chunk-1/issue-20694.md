# Buttons, containers, lists, menus and trees get their overview

## Context

The 13.5 gate asks that a stranger finds each component family's examples as an overview in which every example names what it proves (`ROADMAP.md`). `/examples/grid` is the pattern: 21 captioned Grid and Table demonstrations (#20500). The steward's map on #20498 ([comment](https://github.com/neomjs/neo/issues/20498#issuecomment-6757406109)) lists the families. Components at `/examples/components` is the largest and is delivered by two leaves on one tab; this is the first: the building blocks of an application's structure.

## The Problem

`examples/` holds 28 demonstrations of buttons, containers, layouts, lists, menus, panels, tabs, toolbars and trees. Two have a catalog record (`tab-container`, `dialog-drag-drop`), none has a caption, and 26 can be reached only by typing their URL. A stranger cannot see that the engine ships these batteries.

## The Architectural Reality

- One record per example in `apps/portal/resources/data/examples.json`; the record's shape is documented on `apps/portal/model/Example.mjs:16-27`. The 21 records with `"family": "grid-table"` are the reference for the length and tone of a caption.
- A family's tab appears with its first record (#20690), and a unit spec fails on a family record without `feature` or `lookFor`.
- Inventory at `62f75736ba`, each path under `examples/` with its own `neo-config.json`: `button/base`, `button/effect`, `button/split` · `container/accordion`, `container/base`, `container/fragment` · `dialog` (record `dialog-drag-drop`) · `layout/card`, `layout/cube` · `list/animate`, `list/base`, `list/buffered`, `list/chip`, `list/circle`, `list/color` · `menu/context`, `menu/list`, `menu/panel`, `menu/tree` · `panel` · `popover` · `tab/container` (record `tab-container`) · `tabs` · `toolbar/breadcrumb`, `toolbar/paging` · `tree` · `treeAccordion` · `viewport`.
- The record's `component` field names the component a card shows ("List", "Menu", "Tree"); the cards of one component stand together in catalog order.
- Design authority: n/a — adds catalog records, calls no existing behavior wrong.

## The Fix

For every demonstration of the inventory: run it (`npm run server-start`, then its `index.html`), read its view and controller, and decide. It publishes when one sentence can say what it proves; otherwise it stays out and the pull request says why. A published demonstration gets one record: a stable string `id`, `name`, `"family": "components"`, `component`, `feature` (what it proves), `lookFor` (one action and what to observe), `scope` where it has a limit, the four `urls`, `sourceUrl`, and `image: null` unless a cover exists. The two existing records get the family and their captions in place. Insert the new records as one block directly after the record `dialog-drag-drop`, grouped by component, so that parallel family pull requests touch different lines.

## Acceptance Criteria

- [ ] Every path of the inventory is a record of family `components` or is named in the pull request with its reason for staying out.
- [ ] Each `feature` and `lookFor` was checked in the running example; the pull request names the build and the browser. A caption states no number the example does not show and names no commercial feature.
- [ ] Every URL of a record answers 200 on neomjs.com, where the examples are deployed in all four builds, or that build is omitted on the record.
- [ ] `npm run test-unit -- test/playwright/unit/apps/portal/view/examples` passes with the new counts.
- [ ] The pull request shows `/examples/components` at 1440×900 from a real browser.

## Out of Scope

The visual components, canvas, charts and wrappers (the second Components leaf); new examples; covers (the typographic fallback is allowed, #20679 is the pattern for real ones); an engine fix for an example that turns out broken: file it and leave the example out.

## Avoided Traps

- A caption taken from a directory name: the grid map on #20498 checked configured views, controllers and stores, and several names promised more than the example shows.
- A scaffold-level example published for completeness (`viewport`, `container/base`): it enters only if a visitor learns something from running it.
- Moving the two existing records: the showcase order is delivered intent (#19640).
