# Cold Workstation Reset stalls behind a pending shell update

## Context

The stock `WorkstationBoot.spec.mjs` failed on unmodified `dev` at `73e620799910041c267820ae3122cdd0746759e3`. The run ran six repeats per test through the existing component workflow. The ordinary cold-boot Reset case failed on component shard 1; that shard reported 15 passes and one failure.

[Hosted failure](https://github.com/neomjs/neo/actions/runs/45580274350/job/139088376322) · [Failure snapshot](https://github.com/neomjs/neo/actions/runs/45580274350/artifacts/15007020477)

## The Problem

The unmodified case boots Workstation with a retained Feed pane, uses the existing **Reset to default** control, and expects the resulting pane to render. The pane never appeared. The attachment shows Reset queued behind the prior projection (`waitedForTail: true`). That projection was awaiting `reconcileShellStaged`; the refresh was pending while the host reported `updating: false`, `needsUpdate: false`, and all five overflow strips were idle. Both scheduled and model state still reported Feed. No artificial hold was injected.

## The Architectural Reality

`WorkstationBoot.spec.mjs:349` exercises the real Workstation SharedWorker path. The projection queue waits for the prior shell update. The snapshot names the wait but does not show the writer or callback transfer that caused it. [Stock test](https://github.com/neomjs/neo/blob/73e620799910041c267820ae3122cdd0746759e3/test/playwright/component/workstation/WorkstationBoot.spec.mjs#L349)

## The Fix

Trace the real cold boot through projection, shell reconciliation, and host update settlement, using this failing job and healthy repeats on the same tree. Find the first missing transition and verify the owning boundary. If the evidence requires a change to the VDOM update path, start with an ADR describing the end-to-end update model, alternatives, and measured hot-path cost. [Operator ruling](https://github.com/neomjs/neo/pull/22178#issuecomment-7157404019)

Reproduce through **Engine Tests** with `suite=components`, `specs=test/playwright/component/workstation/WorkstationBoot.spec.mjs`, `repeatEach=6`.
