# Remove retired ai:* scripts and prepare claims from Engine setup docs

## Context

After the Agent OS / Brain repository split (`#17791`) and contributor onboarding updates (`#18999`, `#20709`), `CONTRIBUTING.md:79-86` accurately reflects what `neomjs/neo` runs on `npm install`. However, two adjacent Engine docs — `.github/AI_QUICK_START.md` and `buildScripts/README.md` — still instruct contributors and agents to expect pre-split `prepare` behavior and run retired `npm run ai:*` scripts from an Engine checkout.

## The Problem

1. **`.github/AI_QUICK_START.md` contradicts its own line-3 repository-boundary callout and `buildScripts/util/prepare.mjs`:**
   - Step 3.1 (`:48-65`, `Automatic Initialization (Recommended)`) claims that running `npm install` in the Engine root executes a `prepare` script that downloads a pre-built Knowledge Base artifact (`✅ Download complete`, `🎉 Knowledge Base is ready!`) and creates a `.neo-ai-data` directory in the Engine root, then tells users at `:63` to run `npm run ai:download-kb` (which fails in `neomjs/neo` with `npm error Missing script: "ai:download-kb"`).
   - Lines `:107` and `:124` reference `npm run ai:sync-kb` without scoping it to a `neomjs/neo-agent-brain` checkout (`--prefix <YOUR_BRAIN_REPO_PATH>`), and `:115` points to `ai/mcp/server/knowledge-base/config.mjs` (`config.template.mjs` lives in `neomjs/neo-agent-brain`, not `neomjs/neo`).
   - Section `8.5` (`:315-336`) invokes `node ai/scripts/migrations/bootstrapWorktree.mjs` (`:323, 329`) without specifying the `neomjs/neo-agent-brain` checkout path and illustrates a `neomjs/neo` canonical root at `:330` instead of the Brain runtime root holding `.neo-ai-data/sqlite/memory-core-graph.sqlite`.
   - Line `:374` contains a server-name typo (`neo.mjs-memory-core` with a dot instead of `neo-mjs-memory-core`).
2. **`buildScripts/README.md` (`Neo.mjs Application Engine Build Scripts & CLI Tools`) still documents eight removed `ai:*` script surfaces (`ai/scripts/**` / `ai/mcp/**`):**
   - `:138-150`: `npm run ai:defrag-kb` / `npm run ai:defrag-memory` (`ai/scripts/maintenance/defragChromaDB.mjs`)
   - `:151-156`: `npm run ai:download-kb` (`ai/scripts/maintenance/downloadKnowledgeBase.mjs`)
   - `:157-162`: `npm run ai:sync-kb` (`ai/scripts/maintenance/syncKnowledgeBase.mjs`)
   - `:163-170`: `npm run ai:structure-map` (`ai/scripts/diagnostics/structureMap.mjs`, including a deprecated `npm run --silent` invocation)
   - `:380-390`: `# Advanced Tools` → `npm run ai:mcp-client` (`ai/mcp/client/mcp-cli.mjs`)
   - `:392-397`: `npm run ai:server` (`chroma run --path ./chroma-neo-knowledge-base`)
   - `:400-404`: `npm run ai:server-neural-link` (`ai/mcp/server/neural-link/run-bridge.mjs`)
   - `:407-416`: `# Internal Infrastructure` table (`ai:mcp-server-github-workflow`, `ai:mcp-server-knowledge-base`, `ai:mcp-server-memory-core`, `ai:mcp-server-neural-link`).

## The Architectural Reality

- `package.json:16-60` in `neomjs/neo` defines **zero** `ai:*` scripts.
- `buildScripts/util/prepare.mjs:43-46` runs exactly two stages during `npm install` (`npm run prepare`): `husky` and `neo-agent-skills-materialize` (linking `.agents/skills/` and `.claude/skills/`).
- All `ai/**` MCP servers, `ai:*` npm scripts, Chroma/SQLite stores, and `bootstrapWorktree.mjs` live in the public `neomjs/neo-agent-brain` repository, as already noted in `CONTRIBUTING.md:159-168` and `.github/AI_QUICK_START.md:3`.
- `buildScripts/util/check-relative-links.mjs` (`npm run check-relative-links`) validates relative markdown links against `git ls-files`, so paths materialized at install time (`.agents/skills/...`) or living in `neomjs/neo-agent-brain` (`ai/...`) must be formatted as inline code spans or full `https://github.com/neomjs/neo-agent-brain/...` URLs rather than broken repo-relative links.

Design authority: "`npm install` runs two prepare steps (`husky` and `neo-agent-skills-materialize`, see `buildScripts/util/prepare.mjs`). Engine contributors do not need ChromaDB, SQLite, Docker, or any API keys — the full Agent OS lives in `neomjs/neo-agent-brain`." (`CONTRIBUTING.md:79-86, 159-168`; `buildScripts/util/prepare.mjs:43-46`).

## The Fix

1. **Update `.github/AI_QUICK_START.md`:**
   - Replace the stale Step 3.1 `prepare` / `.neo-ai-data` / `npm run ai:download-kb` Engine claim (`:48-65`) with the actual split setup: `npm install` in `neomjs/neo` materializes `husky` and `.agents/skills/` + `.claude/skills/` via `buildScripts/util/prepare.mjs`, while Knowledge Base / Memory Core initialization (`npm --prefix <YOUR_BRAIN_REPO_PATH> install` and `ai:*` commands) runs in `neomjs/neo-agent-brain`.
   - Scope remaining `ai:sync-kb` (`:107, 124`), `ai/mcp/server/knowledge-base/config.template.mjs` (`:115`), and `bootstrapWorktree.mjs` (`:315-336`) commands explicitly to `<YOUR_BRAIN_REPO_PATH>` (`neomjs/neo-agent-brain`).
   - Fix `neo.mjs-memory-core` → `neo-mjs-memory-core` at `:374`.
2. **Update `buildScripts/README.md`:**
   - Remove the eight retired `ai:*` entries (`:138-170` and `:380-416`) that no longer exist in `neomjs/neo`'s `package.json`, replacing them with a concise pointer to `neomjs/neo-agent-brain` for Agent OS / MCP / KB CLI scripts while keeping every active `buildScripts/` command documented.
