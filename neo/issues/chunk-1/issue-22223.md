# Open focused Portal example cards and tiles with Enter

Ownership: `@neo-gemini-julia` — `@tobiu` requested immediate delivery for the Engine 14 cut (*"this is definitely an item for now :) please create a ticket and grab it"*), so `good first issue` and `help wanted` are omitted.

## Context

With `#21676`, `#22061`, and `#22121` landed, keyboard visitors can walk the desktop examples side nav (`ArrowUp`/`ArrowDown`/`Home`/`End`), step into the stage's example cards (`ArrowRight`), and traverse multi-column cards and component tiles (`ArrowUp`/`ArrowDown`/`ArrowLeft`/`ArrowRight`). However, pressing `Enter` while a card or tile `<li class="neo-list-item">` holds focus does not open the example — instead, it synthesizes a wrapper click that **deselects** the active card and closes its progressive details.

## The Problem

1. **Arrow focus lands on `<li class="neo-list-item">`, not `<a class="neo-title">`:** `Portal.view.examples.ListModel#selectAndFocus` calls `view.focus(itemId)` (`apps/portal/view/examples/ListModel.mjs:282-291`), and `Neo.main.addon.Navigator#navigateTo` queries `DomUtils.query(target, DomUtils.isFocusable)` (`src/main/addon/Navigator.mjs:366-370`, `src/main/DomUtils.mjs:158-160`), which matches the `<li class="neo-list-item" tabindex="-1">` wrapper first. Today, opening an example via keyboard requires pressing `Tab` after arrow navigation to move focus from `<li>` onto `<a class="neo-title">`.
2. **`Enter` on a focused card toggles selection off instead of launching:** In `Neo.main.addon.Navigator#navigateKeyDownHandler` (`src/main/addon/Navigator.mjs:255-258`), `case 'Enter':` checks `!enterActivatedTags[target.tagName]` (`A` and `BUTTON` only) and calls `this.clickItem(data.activeItem)` (`li.click()`). Because that synthetic click on `<li>` has no `<a>` in `data.path`, `Portal.view.examples.ListModel#onListClick` (`apps/portal/view/examples/ListModel.mjs:253-275`) treats it as a card-body click and calls `deselect(record)` — closing the selection ring and `.portal-example-more` details (also noted during `#21676` cold review in `IC_kwDODSospM8AAAABpVtLnA`).

## The Architectural Reality

- `Design authority: "we can now navigate through the sidenav, and into example cards, but afaik we can not yet open an example via keyboard. e.g. \"Enter\" could do this... this is definitely an item for now"` (`@tobiu`, 2026-11-26 operator session).
- **Main-thread trusted user activation & target parity:** `Portal.view.examples.List#createLink` (`apps/portal/view/examples/List.mjs:334-350`) encodes both `?theme=`, `catalogMode` (`dist_prod`, `dist_esm`, `dist_dev`, `devmode`), and `target: '_blank'` vs same-window launch (`record.sharedWorkers && this.environment === Neo.config.environment && !externalLink`) directly on `<a class="neo-title">` across both full cards and compact component tiles (`tiles: true`, `List.mjs:276-284`). Activating `<a class="neo-title">` synchronously inside `Navigator#navigateKeyDownHandler` on the Main thread preserves browser transient user activation against popup blockers and reuses `createLink()`'s exact `href`/`target` contract.
- **Selection preservation via `hasAnchorInPath`:** Clicking `<a class="neo-title">` bubbles through `<li class="neo-list-item">` with `tagName: 'a'` in `data.path`, so `ExamplesListModel#hasAnchorInPath` (`ListModel.mjs:173-189`) ignores the click for selection toggling — keeping `.neo-selected` and focus on the launched card when opening a `target="_blank"` tab.
- **Nested `<a>` focus isolation:** Each full card renders two tabbable links (`.neo-title` and `.neo-github-image` `"View source on GitHub"`, `List.mjs:304-310`). Because `Navigator.mjs:256` guards `!enterActivatedTags[target.tagName]`, pressing `Tab` onto `.neo-github-image` (or `.neo-title`) and pressing `Enter` delegates cleanly to native browser link activation without double-launching.

## The Fix

1. **`src/main/addon/Navigator.mjs`:**
   - Support an optional `clickSelector` string on `Navigator#subscribe(data)`.
   - In `navigateKeyDownHandler` (`case 'Enter':`), when `data.activeItem && !enterActivatedTags[target.tagName]`, resolve `const clickTarget = data.clickSelector ? data.activeItem.querySelector(data.clickSelector) : data.activeItem`. When `clickTarget` exists, call `keyEvent.preventDefault()` and `this.clickItem(clickTarget)`.
2. **`apps/portal/view/examples/List.mjs` & `apps/portal/view/examples/ListModel.mjs`:**
   - Add `clickSelector: '.neo-title'` alongside `workerKeys: ['ArrowDown', 'ArrowLeft', 'ArrowRight', 'ArrowUp']` on `Portal.view.examples.List#navigator` (and `afterSetMounted` merge) and update JSDoc on `List` and `ListModel`.
3. **Tests:**
   - `test/playwright/unit/apps/portal/view/examples/ListModel.spec.mjs` & `test/playwright/component/list/NavigatorEventSource.spec.mjs` (or sibling `Navigator` spec): verify `list.navigator.clickSelector === '.neo-title'` and `Navigator` `clickSelector` `Enter` dispatch vs nested `<a>` target isolation.
   - `test/playwright/e2e/portal/ExamplesCatalogKeysNL.spec.mjs`: verify end-to-end `Sidenav -> ArrowRight -> Enter` opens a `target="_blank"` example popup while preserving `.neo-selected` and card focus on both full cards and compact tiles, opens a `sharedWorkers` example (`Workstation` in `devmode`) in the same window, and `Tab` onto `.neo-github-image` + `Enter` opens only the GitHub source URL without launching the example.

## Acceptance Criteria

- [ ] `Neo.main.addon.Navigator#subscribe` documents and honors `data.clickSelector`, clicking the matching descendant inside `data.activeItem` synchronously on `Enter` when `keyEvent.target` is not an `A` or `BUTTON` element, while preserving default `data.activeItem` click behavior when `clickSelector` is omitted.
- [ ] `Portal.view.examples.List` configures `navigator.clickSelector = '.neo-title'` so pressing `Enter` on a focused card or compact component tile (`Overview`, `GroupPage` cards, `GroupPage` tiles, and `SearchResults`) launches its `.neo-title` link without deselecting the card.
- [ ] Launching a `target="_blank"` card or tile via `Enter` opens the example tab with the active build mode and `?theme=` parameter while keeping `.neo-selected` and DOM focus on the card; launching a same-environment `sharedWorkers` card (`Workstation` in `devmode`) navigates in the same window.
- [ ] Pressing `Tab` from a focused card onto `.neo-github-image` (`"View source on GitHub"`) and pressing `Enter` activates only the GitHub source link (never launching `.neo-title` alongside it).
- [ ] Unit (`ListModel.spec.mjs`) and E2E (`ExamplesCatalogKeysNL.spec.mjs`) coverage pass.

## Out of Scope

- Changing `Space` behavior on example cards (kept as native page scroll on gallery pages).
- Changing `Tab` stop order inside cards or side-nav arrow-walk behavior (`#22061`, `#22120`, `#22121`).

## Avoided Traps

- **App-Worker `onKeyDownEnter` + `window.open` / async `DomAccess` RPC:** Crossing worker `MessageChannel` hops before opening `target="_blank"` risks browser popup-blocker rejection and duplicates `List#createLink`'s `catalogMode` / `?theme=` / `sharedWorkers` target rules.
- **Unguarded list-level `Enter` listener:** Firing on bubbled `Enter` when focus has `Tab`bed onto `.neo-github-image` would open both GitHub source and the live example (`2` tabs).
