# ROADMAP: Engine 13.5 replaces the shipped 13.4 section

## Context

Engine 13.4.0 shipped on 2026-11-09 and left five open issues at the cut. `ROADMAP.md` still opens with `## Next: Engine 13.4 — Householding` and points session intake at milestone #13.

The `update-roadmap` beat opened the same day: the release was celebrated, and the option space was broadcast. The operator then set the direction:

- Traction comes first, so the front door leads: example overviews, a home section that says what Neo is, a support path on Connect.
- The cut is Monday 2026-11-23, seven years after [the public release announcement](https://codeburst.io/neo-mjs-the-public-release-announcement-1519255bc8f9) of 2019-11-23.
- Scope is sized against the team's measured throughput, not against head-count.
- At least one `good first issue` is opened every day, and more when one is picked up.

Milestone v13.4 (#13) is closed. Milestone [v13.5](https://github.com/neomjs/neo/milestone/14) is open, due 2026-11-23, and holds #20498 and #20667.

## The Problem

The file every session starts from describes a release that has shipped, and no 13.5 scope exists in it. A reader cannot tell what 13.5 is for, which epics carry it, or what is deliberately left out.

## The Architectural Reality

`ROADMAP.md` keeps the release lines' table and riders at file level. Its next-release section holds:

- the gate sentence and a milestone pointer;
- the epic table (anchor, steward, done signal);
- what is carried in the milestone, and what runs beside the gate;
- **How it runs**;
- the deferred list;
- **Session intake**.

The `update-roadmap` skill governs the beat: replace the section, never append; name cornerstones with their rationale and let the milestone hold the full set; keep a visible deferred set; stewards self-select. #20401 is the precedent rewrite (13.3 → 13.4).

Measured basis for the sizing: 344 Engine pull requests merged between the 13.3.1 and 13.4.0 releases, seventeen days apart (`gh api search/issues`, `repo:neomjs/neo is:pr is:merged merged:2026-10-23T19:00:00Z..2026-11-09T14:00:00Z`, read at 2026-11-09T21:43Z).

Design authority: n/a — calls no existing behavior wrong.

## The Fix

Replace the section with `## Next: Engine 13.5 — The Front Door`:

- **Thesis:** 13.4 emptied the backlog; 13.5 spends that room on being found, understood and built on.
- **Gate:** observable on neomjs.com, plus the daily `good first issue`.
- **Cornerstones:** #20498 (Clio) and #20667 (Vega), each with its epic's terminal predicate as the done signal.
- **Open for a steward:** the home section, and search discoverability (#20089 is the prior work). Each enters the table once it has an epic and a self-selected steward.
- **How it runs:** the cut date, the two-week train after it, the sizing basis, the daily `good first issue` with its reviewer rule.
- **Deferred:** a second version of the docs app, the rest of Grid Multi-Body ([D#20579](https://github.com/neomjs/neo/discussions/20579)), the full worker boundary ([D#18730](https://github.com/neomjs/neo/discussions/18730)), the middleware's SSR rebuild on release, and the other lines' scope.
- **Session intake:** milestone #14.

The shipped-history line moves to 13.4.0.

- The Brain and Institution lines' roadmaps.
- The `update-roadmap` skill's cadence figure, which lives in `neomjs/neo-agent-skills`.
