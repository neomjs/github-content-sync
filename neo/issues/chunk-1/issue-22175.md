# Enable local/deployed pathname parity and windowId links in Portal

Curated contributor labels (`good first issue`, `help wanted`) omitted while `blocked_by` #22170 and #22173; ready to open once both prerequisites merge.

`unowned-rationale: Blocked on #22170 and #22173; ready for a contributor or maintainer once both prerequisites merge.`

## Context

Part of #22169 (graduated from [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) `OQ-1`, `OQ-2`, `OQ-4`, `OQ-5`, `DC_kwDODSospM4BLyrL`, and `DC_kwDODSospM4BLysh`). Switches `apps/portal` to `routerMode: 'pathname'` mounted at `/` (`package.json` `"neo": {"spaRoot": "apps/portal"}`), threads explicit `windowId` across `apps/portal/Util.mjs` and all `10` Portal view link-formatting modules, un-mocks `PathnameRoutingNL.spec.mjs` with `useSharedWorkers: true`, and aligns Portal E2E specs with canonical clean URLs.

## The Problem

1. **Local-vs-deployed Portal split (`#22138` root cause):** `apps/portal/neo-config.json` runs `'hash'` locally (`routerIgnorePaths` has `"^/examples/[^/]+/.+"`, missing trailing-slash two-segment demos like `examples/dialog/`), while `neomjs.com` patches `routerMode: 'pathname'` externally. `PathnameRoutingNL.spec.mjs:12-53` mocks `neo-config.json`, `<base href>`, and HTML responses via `page.route()` and disables `useSharedWorkers`.
2. **Portal `SharedWorker` link producers omit `windowId`:** `apps/portal` runs with `useSharedWorkers: true`, yet `apps/portal/Util.mjs` (`lines 80, 114`) and `10` `apps/portal/view/**` components call `StringUtil.toRouteHref(...)` or `rewriteRepoLinks(...)` without `me.windowId`.
3. **Portal E2E specs assert `#/...` URLs after load:** Once `routerMode: 'pathname'` is active at `/`, `DomEvents#upgradeHashRoute()` upgrades `#/examples` → `/examples`, so specs asserting `toHaveURL(/#\/examples/)` need canonical pathname expectations.

## The Architectural Reality

- `Design authority:` `apps/portal/neo-config.json`, `apps/portal/Util.mjs:70-120`, and [Discussion #22145](https://github.com/orgs/neomjs/discussions/22145) (`1C`, `2A + 2D`, `3D`, `4A`).
- Blocked by #22170 (`src/util/Route.mjs`, `?search` parity, per-`windowId` `String.toRouteHref`) and #22173 (`fileServer.mjs` `spaRoot` + dist/webpack `<base href>` transforms).

## The Fix

1. Declare `"neo": {"spaRoot": "apps/portal"}` in `package.json`, add `<base href="/apps/portal/">` to `apps/portal/index.html`, and update `apps/portal/neo-config.json` (`"routerMode": "pathname"`, `routerIgnorePaths`: `["^/(?:dist|raw|resources|resources_pub|badges|node_modules|apps|test)(?:/|$)", "^/examples/[^/]+/", "^/docs/"]`).
2. Thread `windowId` through `apps/portal/Util.mjs` (`rewriteRepoLinks(html, filePath, windowId)` and `resolveRepoLink(href, filePath, windowId)`) and pass `me.windowId` across all `10` `apps/portal/view/**` callers in the Binding Inventory below.
3. Add a unit/static call-site audit verifying zero un-scoped `toRouteHref` / `rewriteRepoLinks` / `resolveRepoLink` calls remain across `src/` and `apps/portal/`.
4. Remove `page.route()` mocks and enable `useSharedWorkers: true` in `test/playwright/e2e/portal/PathnameRoutingNL.spec.mjs` (adding direct `/apps/portal/` → `/` and `/apps/portal/index.html#/examples/grid` → `/examples/grid` bookmark canonicalization checks + depth-4 reload checks), and update affected `test/playwright/e2e/portal/*.spec.mjs` URL assertions.

## Avoided Traps

- **Keeping `"^/examples/[^/]+/.+"` in `routerIgnorePaths`:** Fails to ignore trailing-slash two-segment standalone demos (`examples/dialog/`, `examples/tableFiltering/`); `"^/examples/[^/]+/"` cleanly separates slashless `/examples/<group>` Portal routes from `/examples/<demo>/...` standalone apps.
- **Evaluating `toRouteHref` in `static config` at class-definition time:** Breaks per-window config resolution; evaluate at render/instance time with `this.windowId`.
