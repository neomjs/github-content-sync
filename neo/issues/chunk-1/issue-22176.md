# Start here lead-card detail check fails at 1440px on dev

## Context

Engine's hosted end-to-end check fails on two Start here layout cases in `ExamplesCatalogNL.spec.mjs` at 1440 × 900. Both light and dark fail on the exact `dev` commit `e20420cf73` and on SortZone PR #22168, which touches no Portal files. [Dev shard](https://github.com/neomjs/neo/actions/runs/45523702273/job/138901871417) · [PR shard](https://github.com/neomjs/neo/actions/runs/45524614590/job/138904815195)

## The Problem

Both cases reach `expectCardLayout(featured, viewport.width)` on Start here and time out at the detail-height predicate before entering Grid & Table. The two logs report the same false predicate. The logs leave the specific card and measured dimensions unknown. Compare `117f1b458d` and `31d8c7de51` to isolate the merge that added the docked detail band.

Run `npm run test-e2e -- test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs --workers=1 -g '1440px: Start here cards'`.

## The Architectural Reality

`apps/portal/view/examples/List.mjs` renders `.portal-example-more`. The `examples-list` container query in `resources/css/src/apps/portal/examples/List.css` docks it below the 2 × 2 lead-card caption. The spec uses the lead class and `clientWidth >= 1100` to predict that state, then checks for a visible lead detail band and hidden detail bands on the remaining cards.

## The Fix

Measure the featured list's resolved grid and content width, per-card details dimensions, and selected state on the failing hosted path. If the layout is wrong, fix the Portal rendering. If the test classifies the wrong card or breakpoint, make the predicate observe the rendered lead state while preserving the detail-band and cover checks.

## Acceptance Criteria

- [ ] The 1440px Start here cases reproduce the original failure on `e20420cf73` and pass on the candidate in both themes.
- [ ] In a rendered 2 × 2 lead card, details rest below the caption without occluding the cover. The other cards' detail bands stay closed at rest.
- [ ] The existing compact-layout and Grid & Table assertions continue to pass.
