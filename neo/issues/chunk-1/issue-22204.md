# Split ExamplesCatalogNL.spec.mjs below the 6m E2E shard ceiling

unowned-rationale: Active hosted CI step-timeout flake (~10 s margin on Portal PRs and full `dev` pushes); curated contributor labels (`good first issue`, `help wanted`) omitted so any maintainer can pick this up immediately while @neo-gemini-maryam resolves Engine 14 popup styling regression #22202.

## Context

On PR #22203 ([run 45636036072](https://github.com/neomjs/neo/actions/runs/45636036072), [job 139281712498](https://github.com/neomjs/neo/actions/runs/45636036072/job/139281712498), `e2e-engine (2/4)`), all 46 serial tests in `test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs` passed (`Slow test file: ... ExamplesCatalogNL.spec.mjs (5.4m)`, `46 passed (6.0m)`, `Benchmark completed in 360s` at `14:43:45.368Z`), and 50 ms later (`14:43:45.418Z`) GitHub Actions terminated the step with:

```text
##[error]The action 'Run e2e (engine tier)' has timed out after 6 minutes.
```

Rerunning `e2e-engine (2/4)` passed in `6m27s` total job time (`~5m50s` inside `Run e2e (engine tier)`), leaving only ~10 s of margin below `.github/workflows/test.yml:634`'s `timeout-minutes: 6` (`360 s`) ceiling.

## The Problem

When `#22115` raised `FULL_SHARDS.engine` from 15 to 18, `ExamplesCatalogNL.spec.mjs` was noted out of scope at `237 s`. Nine subsequent Portal PRs (`#22130`, `#22129`, `#22135`, `#22140`, `#22164`, `#22160`, `#22166`, `#22177`, `#22190`) appended tests to the same file (`test/` is outside `check-file-sizes.mjs:16`'s `DEFAULT_SCAN_ROOTS`). `ExamplesCatalogNL.spec.mjs` now stands at `1,934` lines (`112.6 KB`, `46` serial tests) — recorded at `305 s` in `buildScripts/util/e2eEngineDurations.json:191` (`1.85x` the second-heaviest spec in the repository, `WorkstationFilmTourNL.spec.mjs` at `164.4 s`).

On fast hosted runners ([run 45612541261](https://github.com/neomjs/neo/actions/runs/45612541261)), its 46 tests execute in `~270 s` (`4.5m`); on slower hosted VMs (`~1.2x`–`1.3x` CPU variance), the same 46 tests take `324 s` (`5.4m`) plus `~36 s` of Playwright/server/trace overhead = `360.0 s`. Worse, in full 18-shard runs (`dev` pushes), `balancedShard()` currently pairs `ExamplesCatalogNL.spec.mjs` (`305 s` stale weight) with `grid/GridViewFocus.spec.mjs` and `rendering/ShallowUpdateFlags.spec.mjs` in shard `5/18` (`309 s` planned).

## The Architectural Reality

- `buildScripts/util/e2eCiSelection.mjs:443-457` (`balancedShard()`) allocates whole `.spec.mjs` files across shards and never splits inside a single spec file (`--workers=1`, no Playwright `--shard`). Even when `ExamplesCatalogNL.spec.mjs` is the sole file in a shard (`e2e-engine (2/4)` on #22203), no shard count can reduce that shard's runtime below the file's own cost.
- `buildScripts/util/e2eCiSelection.mjs:59` lists `'test/playwright/e2e/portal'` as a directory in `RUN_PATHS`, so split `.spec.mjs` files under `test/playwright/e2e/portal/` are automatically selected, while shared non-spec helpers under `test/playwright/e2e/utils/` are followed automatically by `buildScripts/util/e2eSpecReach.mjs:478-482` (`MODULE_PATH` closure).
- Every split file importing `neuralLink` from `test/playwright/fixtures.mjs` must be registered in `ADAPTER_ELIGIBLE_SPECS` (`test/playwright/externalBrainSelection.mjs:28-180`) so `assertSelectionFloor()` (`test/playwright/unit/buildScripts/util/E2eCiSelection.spec.mjs:186-231`) passes.
- Design authority: `"Each shard's test step stops at six minutes"` ([`learn/guides/testing/WhiteboxE2E.md:67`](https://github.com/neomjs/neo/blob/dev/learn/guides/testing/WhiteboxE2E.md#L67)) and `"A shard planned at the run step's six-minute ceiling times out on ordinary runner variance, so the count keeps the plan near five minutes: recount once {@link ENGINE_DURATIONS} totals more than 300 s per shard"` (`buildScripts/util/e2eCiSelection.mjs:217-220`).
- Pre-Flight (structural fast-path): authoring `test/playwright/e2e/utils/portalExamplesCatalog.mjs` matches sibling pattern of `test/playwright/e2e/utils/workstationPopOut.mjs` in `test/playwright/e2e/utils/`, and authoring split `ExamplesCatalog*NL.spec.mjs` files matches `test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs` in `test/playwright/e2e/portal/`; sibling-file-lift applies; no novel directory choice.

Decision Record impact: `none`.

## The Fix

1. Extract shared Portal examples catalog constants and helpers (`CATALOG`, `groupSize`, `mobilePublished`, `PORTAL`, `SIDEBAR`, `MOBILE_IX`, `CRUMB`, `SHEET`, `PAGE`, `CARDS`, `TILES`, `FEATURED`, `THEME`, `GROUPS`, `readList`, `readOverviewList`, `expectOpenPage`, `openOverview`, `openGroup`, `selectBuild`, `expectCardLayout`, etc.) into `test/playwright/e2e/utils/portalExamplesCatalog.mjs`.
2. Split `test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs` (`46` tests) along its natural domain boundaries into three balanced files so no single file exceeds `~130 s` on hosted runners:
   - `test/playwright/e2e/portal/ExamplesCatalogNL.spec.mjs` — overview, responsive desktop rail vs phone crumb/sheet, `2x2` lead (`#22049`), `3n + 4` trailing cards (`#22127`), `Forms & Fields` tiles + pointer reflection/glint (`#22122`), and mixed Demonstrations/Components (~20 tests).
   - `test/playwright/e2e/portal/ExamplesCatalogLaunchNL.spec.mjs` — build control & 4 build routes, dark/light sidebar & `Start here`/Grid card fit matrix (`1440`/`375`/`390`/`844`), live Workstation & Grid launch, `Open live` cue across pointer/touch/keyboard/build modes, live `/` search filter, and card pointer/selection hitboxes (`#21676`) (~15 tests).
   - `test/playwright/e2e/portal/ExamplesCatalogKeysNL.spec.mjs` — existing top-level `test.describe` blocks at lines `1613–1934`: `Portal examples side nav keys (#22061)` (including `#22120` history Back focus), `Portal examples gallery rows across cards and tiles (#22121)`, and `Portal examples phone index keys (#22061)` (11 tests).
3. Register the new `*NL.spec.mjs` files in `ADAPTER_ELIGIBLE_SPECS` (`test/playwright/externalBrainSelection.mjs`) and update `buildScripts/util/e2eEngineDurations.json` for the split files from hosted E2E logs (removing the stale `305` single-file weight).

## Out of Scope

- Refining `UNBOUNDED_EXAMPLE_REFERENCE` (`/\bexamples\/\$\{/` in `buildScripts/util/e2eSpecReach.mjs:61`), which currently matches Portal `#/examples/${mode}` hash fragments and places `ExamplesCatalogNL.spec.mjs` into `map.unnamed` on non-Portal selective PRs.
