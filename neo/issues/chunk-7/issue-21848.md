# Support spoke learn manifests in local Portal and SEO generators

> **v14.0.0 Sprint Pickup (`2026-11-22`):** Operator lifted the temporary Engine hold for the 24h `v14.0.0` convergence sprint (`SEO` + `Portal Learning` explicitly in scope), and all non-Engine leaves of #21847 (`neomjs/devindex#162`, `neomjs/neo-agent-institution#1037`, `neomjs/neo-agent-brain#1892`, `neomjs/middleware-v2#105`, and `neomjs/pages#160`) are now **MERGED**. Landing `#21848` before the `v14.0.0` cut ships spoke `<lastmod>` preservation, hub+spoke tree composition, orphan guard, and on-site `/learn/*` links directly inside `neo.mjs@14.0.0`.

## Context

Graduated Engine/Portal leaf of `neomjs/neo` Discussion #20920 (`A0 + A1` Multi-Repo Guide Restore Slice, #21847). With `neomjs/pages#160` merged to compose the `95` federated spoke guides (`62` `neo-agent-brain` + `26` `devindex` + `7` `neo-agent-institution`) into the single `229`-leaf Portal Learn tree (`134 -> 229` leaves), `neomjs/neo`'s Portal Learn experience, Engine-side prose links, cross-repo cockpit guide boundaries, and `buildScripts/docs/seo/generate.mjs` `<lastmod>` resolution must cohere as one front door (#20498, #20527, `neomjs/neo#adr:neo-identity-source-of-truth-model` OD-4).

## The Problem

1. **Hub Navigation Composition & Reader-Path Coherence (#20498, [#discussioncomment-19803727](https://github.com/neomjs/neo/discussions/20920#discussioncomment-19803727)):**
   - All `95` restored spoke guides enter the single Portal Learn tree (`apps/portal/view/learn/MainContainerController.mjs:22`, `Component.mjs:32-35`, `seoJson.mjs:795`), growing `learn/tree.json` from `134` leaves to **`229` leaves**.
   - `learn/UsingTheseTopics.md` still describes `"ten sections"`, `"14 focused pages"`, and the third reader's path by the pre-restore `134`-leaf shape.
   - `neomjs/neo/learn/` currently leaves `neomjs.com` **`89` times** for `github.com/neomjs/neo-agent-brain/.../learn/*` (`35` targets, **`19` of which are in the `62`-guide Brain restore set** — including `36` links in `learn/benefits/ArchitectureOverview.md` and `8` in `learn/benefits/Introduction.md`). Unless rewritten to canonical `https://neomjs.com/learn/...` URLs (and routed in-SPA by `Portal.view.learn.Component#rewriteLinks` when the leaf is loaded in the Learn tree store), the front door keeps sending readers off-site to GitHub for guides `neomjs.com` now hosts.
2. **Cross-Repo Question Collisions on Cockpit Guides (#20527 precedent, [#discussioncomment-19803727](https://github.com/neomjs/neo/discussions/20920#discussioncomment-19803727)):**
   - Zero URL path collisions is not zero reader-question collisions: sharing one `AgentInterfaces` shelf puts `neomjs/neo`'s `agentos/RunningTheFleetCockpit` (`15 KB`) beside `Institution`'s `RunningTheInstitution` (*"how do I run the cockpit"*), and `neomjs/neo`'s `agentos/FleetManagerArchitecture` (`28 KB`) beside `Institution`'s `Introduction` and `CockpitTour` (*"what is the cockpit"*).
3. **Two Unlisted Orphan `.md` Files & Materialized Spoke `<lastmod>` (`STEP_BACK` point 4):**
   - `learn/agentos/tooling/GenesisNeuralLinkProbe.md` (`301 -> /learn/agentos/NeuralLink` in `neomjs/middleware-v2#105`) and `learn/agentos/tooling/ChromeDevToolsMcpServer.md` (`410` in `neomjs/middleware-v2#105`) still sit unlisted on disk in `neomjs/neo/learn/agentos/tooling/`.
   - Inside `neomjs/pages` Step 7 (`pages/node_modules/neo.mjs/`), `buildScripts/docs/seo/generate.mjs` has no spoke `.git` history and needs `.spoke-lastmod.json` / preserved file `mtime` fallback (winning over stale `existingSitemapPath` dates when authoritative spoke commit dates are supplied) so spoke commit dates flow into `seo.json` and `sitemap-core.xml`.

## The Architectural Reality

- Hub parent, order, and label rules (`#20498` & `neomjs/neo#adr:neo-identity-source-of-truth-model` OD-4, [#discussioncomment-19803727](https://github.com/neomjs/neo/discussions/20920#discussioncomment-19803727), [#discussioncomment-19804194](https://github.com/neomjs/neo/discussions/20920#discussioncomment-19804194)):
  - Brain `benefits/brain/*` (`6`): under `Benefits`, group `"The Brain - Agent OS"`, before the Body group (`#14312` order);
  - Brain `agentos/*` (`56`): under `AgentInterfaces`, three groups (`Agent OS` `23`, `Tooling & Configuration` `18`, `Deploying the Agent OS` `15`);
  - Institution (`7`): under `AgentInterfaces`, one group (`"Agent Institution"` per ADR 0018 OD-4);
  - DevIndex (`26`): under `Guides` > `"DevIndex App"`;
  - Root label of `AgentInterfaces` is verified/refined directly against the desktop + phone frames.
- Link-resolver invariant (`buildScripts/util/check-relative-links.mjs` & `apps/portal/view/learn/Component.mjs`): bare root-absolute `/learn/...` links break on GitHub (`github.com/learn/...` -> `404`) and are rejected by `check-relative-links.mjs`. Canonical `https://neomjs.com/learn/<id>` links resolve cleanly on GitHub, in Googlebot SSR, and under `check-relative-links.mjs`, while `Portal.view.learn.Component#rewriteLinks` routes them in-SPA (`#/learn/<id>`) whenever `store.get(id)` is present in the loaded Learn tree store (keeping external fallback in standalone Engine-only checkouts).

## The Fix

1. **Hub Tree Composition, Build-Time Collision Guard, & `<lastmod>` (`buildScripts/docs/seo/learnSpokes.mjs`, `seoJson.mjs`, `generate.mjs`, `verify.mjs`):**
   - Support hub+spoke `learn/` composition (for local multi-repo checkouts and `pages` Step 7) with a fail-closed hub+spoke route/id collision guard, spoke `<lastmod>` resolution from `.spoke-lastmod.json` / preserved `mtime` when `git log` is unavailable inside `pages/node_modules/neo.mjs/` (preserving authoritative spoke commit dates over stale `existingSitemapPath` dates), and clean titles/canonicals for `/learn/institution/*` and `/learn/guides/devindex/*`.
   - Remove the two unlisted orphan files `learn/agentos/tooling/GenesisNeuralLinkProbe.md` and `learn/agentos/tooling/ChromeDevToolsMcpServer.md` (`check-relative-links.mjs` proves nothing points at them) and add a check in `verify.mjs` rejecting unlisted `.md` orphans in `learn/`.
2. **`learn/UsingTheseTopics.md`, `Portal.view.learn.Component#rewriteLinks`, & `19`-Target On-Site Link Rewrite:**
   - Update `learn/UsingTheseTopics.md` section/page counts and third-reader path to reflect the `229`-leaf tree.
   - Rewrite all outbound `github.com/neomjs/neo-agent-brain/.../learn/*` links in non-blog `neomjs/neo/learn/` guides targeting any of the `19` restored Brain guides (including `learn/benefits/ArchitectureOverview.md` and `learn/benefits/Introduction.md`) to canonical `https://neomjs.com/learn/...` URLs, with `Portal.view.learn.Component#rewriteLinks` upgrading them to in-SPA `#/learn/...` navigation whenever the target leaf is loaded in the Portal Learn tree store.
3. **`#20527` Cross-Repo Cockpit Question-Owner Table & Cross-Linking:**
   - Produce and enforce a `#20527`-style one-owner-per-question table (`question | owning page | companion pages that link to it`) resolving the overlap between `agentos/RunningTheFleetCockpit` vs `institution/RunningTheInstitution` and `agentos/FleetManagerArchitecture` vs `institution/Introduction` + `institution/CockpitTour`, adding explicit cross-links in `RunningTheFleetCockpit.md` and `FleetManagerArchitecture.md`.
4. **Visual Look Verification (`#20498`):**
   - Capture frames of the Portal Learn nav collapsed and with the `AgentInterfaces` root expanded across **desktop + phone** and **dark + light** themes on the composed `229`-leaf tree, verifying the root label fits cleanly and each of the three `#20498` reader paths reaches its first page in **`<= 2` clicks**.
